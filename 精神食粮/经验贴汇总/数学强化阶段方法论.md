# 数学强化阶段方法论（10 篇经验贴萃取）

> "强化阶段是搭建金字塔中间 4 层的关键——基础决定速度，强化决定高度。" — Deya
>
> "二轮是关键。" — M佬

---

## 一、强化阶段定位

| 维度   | 基础阶段     | **强化阶段**               | 冲刺阶段      |
| :--- | :------- | :--------------------- | :-------- |
| 目标   | 知道有什么知识点 | **构建知识体系 + 形成解题反射**    | 查缺补漏 + 手感 |
| 核心动作 | 听课 + 例题  | **大量做题 + 整理错题 + 归纳总结** | 做卷子 + 复盘  |
| 题量   | 以老师例题为主  | **1~2 本习题集吃透**         | 至少 30 套卷子 |
| 截止时间 | 最晚 6 月   | **最晚 10 月中旬**          | 考前        |

> 邂逅遗憾："基础阶段不要做太多停留，把课听完题做完即可进入强化。"
>
> Deya："千万不可把基础和强化分裂开来——基础拓展宽度，强化才是高度。"

## 四、核心方法论：三件套循环

> 杨尼尔："**大量做题 + 整理好题错题 + 频繁回看**。数学不需要临场发明新解法，而是把新题转化为已知题型。"

```
大量做题 → 遇到好题/错题 → 整理到活页本 → 每两周通翻一遍
    ↑                                              ↓
    └────────────────────────────────────────────────┘
```

### 4.1 大量做题

- 每天上午做数学（全员共识）
- 数学一天不能停——"停一天不顺手，停一周要重学"（懒懒）
- 早上做错了 4 题并已订正 → 下午学习前花 20 分钟重复思考（Deya 的即时二刷法）

### 4.2 整理好题错题

**杨尼尔的活页本体系**：
- 从强化阶段起脱离书本笔记，单独用活页本
- 记录：精彩例题 + 归纳题型+解法 + 记忆公式定理
- "整理 = 反思 + 输出。提炼、归纳题型及其解法，内化为条件反射。"

**M佬的五级标记系统**（在题号上标）：
| 标记 | 含义 |
| :--- | :--- |
| ⭕️ | 很简单但有点代表性 |
| ♦️ | 做对了但答案有更好的方法 |
| ▪️ | 有难度，勉强做对但不太懂 |
| ⭐️ | 不会做（知识点没掌握），看答案会的 |
| ⭕️套⭐️ | 一点思路没有，看答案都费劲 |

**邂逅遗憾的复盘四步法**：
1. **识别**：看完答案觉得"这不是我的问题"→不值得复盘；觉得"是我自己的问题"→值得复盘
2. **费曼法**：脑补一个不会的小人，给他讲明白每一步
3. **扩展**：通过一道题吃透一类题 → 回归讲义对应章节复习同类题
4. **循环**：用套卷查缺 → 用讲义错题补漏

### 4.3 频繁回看

- 杨尼尔：每两周通翻一遍活页本
- M佬：二刷只刷标记题，不整体二刷
- 邂逅遗憾："渴了就去喝水，饿了就去吃饭，忘了就去翻讲义"

## 八、何时进入冲刺

**信号**：
- 880 综合篇做完
- 活页本/错题本有体系化的归纳
- 遇到大部分题能条件反射出"考什么 + 用什么方法"

**最早**：任何时候准备好都可以开始（邂逅遗憾："越早开卷子越好"）

**最晚**：10 月中旬（邂逅遗憾 / Deya 一致）

**衔接方式**：不需要"等所有题刷完"。邂逅遗憾："强化阶段做 1 本练习册就够了，**尽量早点开始做卷子**——做卷子和做练习册的感受完全不一样。"
