## 一、微分（中值定理 · 辅助函数构造）

### 题 1

> 设 $f(x)$ 在 $[0,1]$ 上连续，在 $(0,1)$ 内可导，且 $f(0)=f(1)=0$。
>
> 证明：存在 $\xi \in (0,1)$，使得 $f'(\xi) = f(\xi)$。

**思路溯源**

结论 $f'(\xi)=f(\xi)$ 可改写为 $f'(\xi)-f(\xi)=0$。这是 $f'(x)+p(x)f(x)=0$ 型（$p(x)=-1$），辅助函数取 $F(x)=e^{\int p(x)dx}f(x)=e^{-x}f(x)$。验证 $F(0)=0$，$F(1)=e^{-1}f(1)=0$，满足 Rolle 条件。

**解法**：

令 $F(x)=e^{-x}f(x)$。$F(x)$ 在 $[0,1]$ 上连续，在 $(0,1)$ 内可导。

$$F(0)=e^{0}\cdot f(0)=0,\qquad F(1)=e^{-1}\cdot f(1)=0$$

由 Rolle 定理，存在 $\xi \in (0,1)$ 使 $F'(\xi)=0$。

$$F'(x)=e^{-x}f'(x)-e^{-x}f(x)=e^{-x}[f'(x)-f(x)]$$

$$F'(\xi)=e^{-\xi}[f'(\xi)-f(\xi)]=0$$

由 $e^{-\xi}\neq 0$ 得 $f'(\xi)=f(\xi)$。证毕。

### 题 2

> 设 $f(x)$ 在 $[0,3]$ 上连续，在 $(0,3)$ 内可导，且
>
> $$f(0)=0,\quad f(1)=2,\quad f(2)=-1,\quad f(3)=0$$
>
> 证明：存在 $\xi_1\in(0,1)$，$\xi_2\in(1,2)$，$\xi_3\in(2,3)$，使得 $f'(\xi_1)+f'(\xi_2)+f'(\xi_3)=0$。

**思路溯源**

结论涉及三个不同区间上的导数之和，典型的分区间 Lagrange 中值定理。四个已知函数值恰好将 $[0,3]$ 分为三个子区间，每个区间上应用一次 Lagrange。

**解法**：

$f(x)$ 在 $[0,1]$ 上满足 Lagrange 定理条件，存在 $\xi_1\in(0,1)$ 使
$$f'(\xi_1)=\frac{f(1)-f(0)}{1-0}=\frac{2-0}{1}=2$$

$f(x)$ 在 $[1,2]$ 上满足 Lagrange 定理条件，存在 $\xi_2\in(1,2)$ 使
$$f'(\xi_2)=\frac{f(2)-f(1)}{2-1}=\frac{-1-2}{1}=-3$$

$f(x)$ 在 $[2,3]$ 上满足 Lagrange 定理条件，存在 $\xi_3\in(2,3)$ 使
$$f'(\xi_3)=\frac{f(3)-f(2)}{3-2}=\frac{0-(-1)}{1}=1$$

因此 $f'(\xi_1)+f'(\xi_2)+f'(\xi_3)=2+(-3)+1=0$。证毕。

### 题 3

> 设 $f(x)$ 在 $[1,2]$ 上连续，在 $(1,2)$ 内可导。
>
> 证明：存在 $\xi \in (1,2)$，使得 $\displaystyle \xi f'(\xi) = \frac{f(2)-f(1)}{\ln 2}$。

**思路溯源**

结论中出现 $f'(\xi)$ 除以某个函数的导数，这是 Cauchy 中值定理的标准信号。结论可改写为 $\frac{f'(\xi)}{1/\xi} = \frac{f(2)-f(1)}{\ln 2}$。注意到 $( \ln x)' = \frac{1}{x}$，取 $g(x)=\ln x$。

**解法**：

取 $g(x)=\ln x$。$g(x)$ 在 $[1,2]$ 上连续，在 $(1,2)$ 内可导，且 $g'(x)=\frac{1}{x}\neq 0$。

由 Cauchy 中值定理，存在 $\xi\in(1,2)$ 使
$$\frac{f(2)-f(1)}{g(2)-g(1)} = \frac{f'(\xi)}{g'(\xi)}$$

代入 $g(2)=\ln 2$，$g(1)=0$，$g'(\xi)=\frac{1}{\xi}$：
$$\frac{f(2)-f(1)}{\ln 2} = \frac{f'(\xi)}{1/\xi} = \xi f'(\xi)$$

证毕。

## 二、积分

### 题 4 — IBP 循环

> 计算不定积分：$\displaystyle \int e^{2x}\sin x\,dx$

**思路溯源**

指数函数 $\times$ 三角函数，分部积分两次后原积分重现，移项解方程。按"反对幂指三"口诀，指数和三角同级，可任选其一为 $u$。

**解法**：

记 $I = \int e^{2x}\sin x\,dx$。

第一次分部：取 $u=\sin x$，$dv=e^{2x}dx$，则 $du=\cos x\,dx$，$v=\frac{1}{2}e^{2x}$。

$$I = \frac{1}{2}e^{2x}\sin x - \frac{1}{2}\int e^{2x}\cos x\,dx$$

第二次分部：取 $u=\cos x$，$dv=e^{2x}dx$，则 $du=-\sin x\,dx$，$v=\frac{1}{2}e^{2x}$。

$$\int e^{2x}\cos x\,dx = \frac{1}{2}e^{2x}\cos x + \frac{1}{2}\int e^{2x}\sin x\,dx = \frac{1}{2}e^{2x}\cos x + \frac{1}{2}I$$

代回：
$$I = \frac{1}{2}e^{2x}\sin x - \frac{1}{2}\!\left(\frac{1}{2}e^{2x}\cos x + \frac{1}{2}I\right) = \frac{1}{2}e^{2x}\sin x - \frac{1}{4}e^{2x}\cos x - \frac{1}{4}I$$

移项：$I + \frac{1}{4}I = \frac{1}{4}e^{2x}(2\sin x - \cos x)$，即 $\frac{5}{4}I = \frac{1}{4}e^{2x}(2\sin x - \cos x)$。

$$\boxed{\int e^{2x}\sin x\,dx = \frac{e^{2x}}{5}(2\sin x - \cos x) + C}$$

### 题 5 — 三角换元

> 计算不定积分：$\displaystyle \int\sqrt{9-x^2}\,dx$

**思路溯源**

被积函数含 $\sqrt{a^2-x^2}$ 形式，令 $x = a\sin t$（$a=3$），利用 $1-\sin^2 t = \cos^2 t$ 消去根号。

**解法**：

令 $x = 3\sin t$ $\left(-\frac{\pi}{2} \le t \le \frac{\pi}{2}\right)$，则 $dx = 3\cos t\,dt$，$\sqrt{9-x^2} = 3\cos t$。

$$\begin{aligned}
\int\sqrt{9-x^2}\,dx
&= \int 3\cos t \cdot 3\cos t\,dt \\
&= 9\int\cos^2 t\,dt \\
&= 9\int\frac{1+\cos 2t}{2}\,dt \\
&= \frac{9}{2}\!\left(t + \frac{\sin 2t}{2}\right) + C \\
&= \frac{9}{2}t + \frac{9}{4}\sin 2t + C
\end{aligned}$$

回代：由 $x = 3\sin t$ 得 $\sin t = \frac{x}{3}$，$t = \arcsin\frac{x}{3}$。$\cos t = \frac{\sqrt{9-x^2}}{3}$。

$\sin 2t = 2\sin t\cos t = 2\cdot\frac{x}{3}\cdot\frac{\sqrt{9-x^2}}{3} = \frac{2x\sqrt{9-x^2}}{9}$。

$$\boxed{\int\sqrt{9-x^2}\,dx = \frac{9}{2}\arcsin\frac{x}{3} + \frac{x\sqrt{9-x^2}}{2} + C}$$

### 题 6 — 分子拆分（$\ln$ + $\arctan$）

> 计算不定积分：$\displaystyle \int\frac{2x+3}{x^2+2x+5}\,dx$

**思路溯源**

分母是二次三项式（判别式 $\Delta<0$，不可因式分解），分子含一次项。将分子拆为"分母导数的常数倍 + 常数"形式，分别积出 $\ln$ 和 $\arctan$。分母求导为 $2x+2$，分子 $2x+3 = (2x+2)+1$。

**解法**：

分母配方：$x^2+2x+5 = (x+1)^2+4$。分母导数：$(x^2+2x+5)' = 2x+2$。

分子拆分：$2x+3 = (2x+2) + 1$。

$$\begin{aligned}
\int\frac{2x+3}{x^2+2x+5}\,dx
&= \int\frac{2x+2}{x^2+2x+5}\,dx + \int\frac{1}{x^2+2x+5}\,dx
\end{aligned}$$

第一项——凑微分：
$$\int\frac{2x+2}{x^2+2x+5}\,dx = \int\frac{d(x^2+2x+5)}{x^2+2x+5} = \ln(x^2+2x+5) + C_1$$

第二项——配方换元：
$$\int\frac{dx}{x^2+2x+5} = \int\frac{dx}{(x+1)^2+4} = \frac{1}{4}\int\frac{dx}{\left(\frac{x+1}{2}\right)^2+1}$$

令 $u = \frac{x+1}{2}$，$dx = 2du$：
$$= \frac{1}{4}\int\frac{2du}{u^2+1} = \frac{1}{2}\arctan u + C_2 = \frac{1}{2}\arctan\frac{x+1}{2} + C_2$$

合并：
$$\boxed{\int\frac{2x+3}{x^2+2x+5}\,dx = \ln(x^2+2x+5) + \frac{1}{2}\arctan\frac{x+1}{2} + C}$$

### 题 7 — 三角恒等变换

> 计算不定积分：$\displaystyle \int\tan^3 x\,dx$

**思路溯源**

$\tan x$ 的高次幂，分离 $\tan^2 x = \sec^2 x - 1$，将 $\tan x\sec^2 x$ 凑成 $d(\tan x)$ 或 $d(\sec x)$。

**解法**：

$$\begin{aligned}
\int\tan^3 x\,dx
&= \int\tan x \cdot \tan^2 x\,dx \\
&= \int\tan x(\sec^2 x - 1)\,dx \\
&= \int\tan x\sec^2 x\,dx - \int\tan x\,dx
\end{aligned}$$

第一项：$\tan x\sec^2 x\,dx = \tan x \cdot d(\tan x)$。
$$\int\tan x\sec^2 x\,dx = \int\tan x\,d(\tan x) = \frac{1}{2}\tan^2 x + C_1$$

第二项（基本公式）：$\int\tan x\,dx = -\ln|\cos x| + C_2 = \ln|\sec x| + C_2$。

$$\boxed{\int\tan^3 x\,dx = \frac{1}{2}\tan^2 x + \ln|\cos x| + C}$$

### 题 8 — 辅助角公式 + 三角换元

> 计算不定积分：$\displaystyle \int\frac{dx}{\sin x + \cos x}$

**思路溯源**

分母为 $\sin x$ 与 $\cos x$ 的线性组合，用辅助角公式合为单一三角函数：$\sin x + \cos x = \sqrt{2}\sin\!\left(x + \frac{\pi}{4}\right)$。然后化为 $\csc$ 的积分，再用万能公式或半角代换处理。

**解法**：

$$\sin x + \cos x = \sqrt{2}\sin\!\left(x + \frac{\pi}{4}\right)$$

$$\int\frac{dx}{\sin x + \cos x} = \frac{1}{\sqrt{2}}\int\frac{dx}{\sin\!\left(x + \frac{\pi}{4}\right)} = \frac{1}{\sqrt{2}}\int\csc\!\left(x + \frac{\pi}{4}\right)dx$$

令 $u = x + \frac{\pi}{4}$，$du = dx$：

$$I = \frac{1}{\sqrt{2}}\int\csc u\,du$$

$\int\csc u\,du$ 的常用解法——分子分母同乘 $(\csc u - \cot u)$ 后凑微分：
$$\begin{aligned}
\int\csc u\,du
&= \int\frac{\csc u(\csc u - \cot u)}{\csc u - \cot u}\,du \\
&= \int\frac{\csc^2 u - \csc u\cot u}{\csc u - \cot u}\,du
\end{aligned}$$

分子恰为分母的导数：$(\csc u - \cot u)' = -\csc u\cot u + \csc^2 u$。
$$= \int\frac{d(\csc u - \cot u)}{\csc u - \cot u} = \ln|\csc u - \cot u| + C_0$$

回代：
$$\begin{aligned}
I &= \frac{1}{\sqrt{2}}\ln\!\left|\csc\!\left(x + \frac{\pi}{4}\right) - \cot\!\left(x + \frac{\pi}{4}\right)\right| + C
\end{aligned}$$

或等价地写成：

$$\boxed{\int\frac{dx}{\sin x + \cos x} = \frac{1}{\sqrt{2}}\ln\!\left|\tan\!\left(\frac{x}{2} + \frac{\pi}{8}\right)\right| + C}$$

## 三、避坑警示

| 1 | 题 1 辅助函数 $F=e^{-x}f(x)$ 求导时忘记负号 | $F'=e^{-x}f' - e^{-x}f = e^{-x}(f'-f)$ |
