## 一、极限题 (5题)

### 题1 — 困难 | $\infty-\infty$ 型通分

求极限：

$$L = \lim_{x\to 0} \left( \frac{1}{x^2} - \frac{1}{\sin^2 x} \right)$$

#### 思路溯源

$\infty-\infty$ 型，通分化为 $\frac{0}{0}$。$\sin^2 x$ 的 Taylor 展开至 $x^4$ 阶即可确定极限。

#### 解法

通分：

$$L = \lim_{x\to 0} \frac{\sin^2 x - x^2}{x^2\sin^2 x}$$

由 $\sin x = x - \frac{x^3}{6} + \frac{x^5}{120} + o(x^5)$，得

$$\sin^2 x = \left(x - \frac{x^3}{6}\right)^2 + o(x^4) = x^2 - \frac{x^4}{3} + o(x^4)$$

分子：$\sin^2 x - x^2 = -\frac{x^4}{3} + o(x^4)$

分母：$x^2\sin^2 x = x^2\left(x^2 + o(x^2)\right) = x^4 + o(x^4)$

故

$$L = \lim_{x\to 0} \frac{-\frac{x^4}{3} + o(x^4)}{x^4 + o(x^4)} = -\frac{1}{3}$$

$$\boxed{L = -\dfrac{1}{3}}$$

### 题2 — 困难 | $0^0$ 型幂指函数

求极限：

$$L = \lim_{x\to 0^+} x^x$$

#### 思路溯源

$0^0$ 型，取对数化为 $e^{\lim x\ln x}$。$\lim_{x\to 0^+} x\ln x = 0$（$\ln x$ 增长慢于 $1/x$ 趋于无穷）。这是两个重要极限之外的另一经典极限值。

#### 解法

$$x^x = e^{x\ln x}$$

计算指数部分的极限：

$$\lim_{x\to 0^+} x\ln x \xlongequal{t=1/x} \lim_{t\to+\infty} \frac{1}{t}\ln\frac{1}{t} = -\lim_{t\to+\infty}\frac{\ln t}{t} = 0$$

故

$$L = e^0 = 1$$

$$\boxed{L = 1}$$

### 题3 — 困难 | 已知极限反求参数

已知极限存在且有限：

$$\lim_{x\to 0} \frac{\sin 3x + a\sin x}{x^3} = b$$

求 $a, b$ 的值。

#### 思路溯源

分母 $x^3$，若分子不至少为 $x^3$ 阶无穷小，则极限为 $\infty$ 或不存在。将 $\sin 3x$ 和 $\sin x$ 分别 Taylor 展开至 $x^3$ 项，令 $x^1$ 项系数为零以确定 $a$，再求 $x^3$ 项系数得 $b$。

#### 解法

$$\sin 3x = 3x - \frac{(3x)^3}{6} + o(x^3) = 3x - \frac{9}{2}x^3 + o(x^3)$$

$$\sin x = x - \frac{x^3}{6} + o(x^3)$$

代入分子：

$$\sin 3x + a\sin x = (3+a)x - \left(\frac{9}{2} + \frac{a}{6}\right)x^3 + o(x^3)$$

极限存在且有限 $\Rightarrow$ $x^1$ 项系数为零：

$$3 + a = 0 \quad\Longrightarrow\quad a = -3$$

此时：

$$\lim_{x\to 0} \frac{\sin 3x - 3\sin x}{x^3} = \lim_{x\to 0} \frac{-\left(\frac{9}{2} - \frac{3}{6}\right)x^3 + o(x^3)}{x^3} = -\left(\frac{9}{2} - \frac{1}{2}\right) = -4$$

$$\boxed{a = -3,\quad b = -4}$$

### 题4 — 地狱难度 | Stolz 定理

设 $p > -1$ 为常数。求极限：

$$L = \lim_{n\to\infty} \frac{1^p + 2^p + \cdots + n^p}{n^{p+1}}$$

#### 思路溯源

分子分母均 $\to \infty$（$p>-1$ 时），满足 Stolz 定理条件（$\frac{*}{\infty}$ 型）。分子差分 $a_n - a_{n-1} = n^p$，分母差分 $n^{p+1} - (n-1)^{p+1}$ 用二项式展开。

#### 解法

令 $A_n = \sum_{k=1}^n k^p$，$B_n = n^{p+1}$。由 Stolz 定理：

$$L = \lim_{n\to\infty} \frac{A_n - A_{n-1}}{B_n - B_{n-1}} = \lim_{n\to\infty} \frac{n^p}{n^{p+1} - (n-1)^{p+1}}$$

由二项式展开：

$$(n-1)^{p+1} = n^{p+1}\left(1 - \frac{1}{n}\right)^{p+1} = n^{p+1}\left[1 - \frac{p+1}{n} + \frac{(p+1)p}{2n^2} + o\!\left(\frac{1}{n^2}\right)\right]$$

故分母：

$$n^{p+1} - (n-1)^{p+1} = (p+1)n^p - \frac{(p+1)p}{2}n^{p-1} + o(n^{p-1})$$

代入：

$$L = \lim_{n\to\infty} \frac{n^p}{(p+1)n^p - \frac{(p+1)p}{2}n^{p-1} + o(n^{p-1})} = \frac{1}{p+1}$$

$$\boxed{L = \dfrac{1}{p+1}}$$

> 特别地，$p=1$ 时 $L = 1/2$；$p=2$ 时 $L = 1/3$。此结论与定积分定义 $\int_0^1 x^p dx = 1/(p+1)$ 一致。

### 题5 — 困难 | 定积分定义

求极限：

$$L = \lim_{n\to\infty} \frac{1}{n}\sum_{k=1}^{n} \frac{k}{n} \cdot e^{k/n}$$

#### 思路溯源

抽取 $1/n$，和式形如 $\frac{1}{n}\sum f(k/n)$，被积函数 $f(x) = x e^x$。积分区间 $[0,1]$。

#### 解法

$$L = \lim_{n\to\infty} \frac{1}{n}\sum_{k=1}^{n} \frac{k}{n} e^{k/n} = \int_0^1 x e^x \,dx$$

分部积分：$\int x e^x dx = e^x(x-1) + C$

$$L = \bigl[e^x(x-1)\bigr]_0^1 = e^1(1-1) - e^0(0-1) = 0 - (-1) = 1$$

$$\boxed{L = 1}$$

## 二、中值定理题 (5题)

### 题6 — 困难 | 三零点 $\to$ Rolle 两次

设 $f$ 在 $[0,1]$ 上二阶可导，且 $f(0)=f\!\left(\frac{1}{2}\right)=f(1)=0$。证明：存在 $\xi\in(0,1)$ 使 $f''(\xi)=0$。

#### 思路溯源

三个等值点 → 在 $[0,1/2]$ 和 $[1/2,1]$ 上分别用 Rolle → 两个导数为零的点 → 再在它们之间用 Rolle → 二阶导数为零。

#### 解法

$f$ 在 $[0,\frac{1}{2}]$ 上满足 Rolle 条件，存在 $\xi_1\in(0,\frac{1}{2})$ 使 $f'(\xi_1)=0$。

$f$ 在 $[\frac{1}{2},1]$ 上满足 Rolle 条件，存在 $\xi_2\in(\frac{1}{2},1)$ 使 $f'(\xi_2)=0$。

$f'$ 在 $[\xi_1,\xi_2]$ 上满足 Rolle 条件，存在 $\xi\in(\xi_1,\xi_2)\subset(0,1)$ 使 $f''(\xi)=0$。证毕。

> 推广：若 $f$ 在 $[a,b]$ 上有 $n+1$ 个零点且 $n$ 阶可导，则 $f^{(n)}$ 至少有一个零点。

### 题7 — 困难 | 辅助函数 $e^{-x}f(x)$ 型

设 $f$ 在 $[0,1]$ 上可导，$f(0)=1$，$f(1)=e$。证明：存在 $\xi\in(0,1)$ 使 $f'(\xi)=f(\xi)$。

#### 思路溯源

结论 $f'(\xi)=f(\xi)$ 可改写为 $f'(\xi)-f(\xi)=0$。观察 $\left(e^{-x}f(x)\right)' = e^{-x}(f'(x)-f(x))$，故构造 $F(x)=e^{-x}f(x)$。条件 $F(0)=1$，$F(1)=e^{-1}\cdot e=1$，由 Rolle 得 $F'=0$。

#### 解法

令 $F(x)=e^{-x}f(x)$。$F$ 在 $[0,1]$ 上可导，且

$$F(0)=e^0 f(0)=1,\qquad F(1)=e^{-1}f(1)=e^{-1}\cdot e=1$$

$F(0)=F(1)$，由 Rolle 定理存在 $\xi\in(0,1)$ 使 $F'(\xi)=0$。

$$F'(x)=e^{-x}f'(x)-e^{-x}f(x)=e^{-x}\bigl(f'(x)-f(x)\bigr)$$

$e^{-\xi}\neq 0$，故 $f'(\xi)-f(\xi)=0$，即 $f'(\xi)=f(\xi)$。证毕。

### 题8 — 困难 | Lagrange 中值定理证不等式

证明：对任意 $x>0$，有

$$\frac{x}{1+x} < \ln(1+x) < x$$

#### 思路溯源

对 $f(t)=\ln(1+t)$ 在 $[0,x]$ 上用 Lagrange 中值定理，$f'(\xi)=\frac{1}{1+\xi}$（$0<\xi<x$）。再利用 $0<\xi<x$ 对 $\frac{1}{1+\xi}$ 放缩。

#### 解法

令 $f(t)=\ln(1+t)$，在 $[0,x]$ 上满足 Lagrange 定理条件。存在 $\xi\in(0,x)$ 使

$$\frac{\ln(1+x)-\ln 1}{x-0}=f'(\xi)=\frac{1}{1+\xi}$$

即

$$\ln(1+x)=\frac{x}{1+\xi}$$

由 $0<\xi<x$，取倒数：$\frac{1}{1+x}<\frac{1}{1+\xi}<1$。两边乘以 $x>0$：

$$\frac{x}{1+x}<\ln(1+x)<x$$

证毕。

### 题9 — 地狱难度 | 积分中值定理 + 极限联用

设 $f$ 在 $[0,1]$ 上连续，求极限：

$$L = \lim_{n\to\infty} n\int_0^{1/n} f(x)\,dx$$

#### 思路溯源

区间长度为 $1/n$，积分中值定理给出 $\int_0^{1/n} f(x)dx = f(\xi_n)\cdot(1/n)$，其中 $\xi_n\in[0,1/n]$。乘以 $n$ 后得 $f(\xi_n)$，$\xi_n\to 0$ 由 $f$ 连续得 $f(0)$。

#### 解法

由积分中值定理，对每个 $n$，存在 $\xi_n\in[0,1/n]$ 使

$$\int_0^{1/n} f(x)\,dx = f(\xi_n)\cdot\frac{1}{n}$$

故

$$n\int_0^{1/n} f(x)\,dx = f(\xi_n)$$

当 $n\to\infty$ 时 $1/n\to 0$，故 $\xi_n\to 0$。由 $f$ 在 $x=0$ 处连续：

$$L = \lim_{n\to\infty} f(\xi_n) = f(0)$$

$$\boxed{L = f(0)}$$

### 题10 — 地狱难度 | 连续函数不动点 + 中值定理

设 $f$ 在 $[0,1]$ 上可导，$f(0)=0$，$f(1)=1$。证明：

(1) 存在 $c\in(0,1)$ 使 $f(c)=1-c$；

(2) 存在 $\xi\in(0,1)$ 使 $f'(\xi)=2\xi$。

#### 思路溯源

(1) 构造 $g(x)=f(x)-(1-x)=f(x)+x-1$，$g(0)=-1<0$，$g(1)=1>0$，由介值定理得证。

(2) 结论 $f'(\xi)=2\xi$ ⇔ $f'(\xi)-2\xi=0$ ⇔ $\left(f(x)-x^2\right)'_{x=\xi}=0$。构造 $h(x)=f(x)-x^2$。由 (1) 知 $f(c)=1-c$，$c$ 处可验证 $h$ 在何处等值。需找两点使 $h$ 等值用 Rolle。

计算：$h(0)=0-0=0$，$h(1)=1-1=0$。由 Rolle 即得 $h'(\xi)=0$，不需要 (1) 的结论。但题目意思可能是两步独立。

实际上 (1) 的结果 $f(c)=1-c$ 可用来在 $[c,1]$ 上构造其他结论。此处 (2) 直接用 $h(x)=f(x)-x^2$ + Rolle：$h(0)=0$，$h(1)=0$，存在 $\xi\in(0,1)$ 使 $h'(\xi)=f'(\xi)-2\xi=0$。

#### 解法

(1) 令 $g(x)=f(x)+x-1$。$g(0)=f(0)+0-1=-1<0$，$g(1)=f(1)+1-1=1>0$。由连续函数介值定理，存在 $c\in(0,1)$ 使 $g(c)=0$，即 $f(c)=1-c$。

(2) 令 $h(x)=f(x)-x^2$。$h(0)=0$，$h(1)=f(1)-1=0$。由 Rolle 定理，存在 $\xi\in(0,1)$ 使 $h'(\xi)=0$，即 $f'(\xi)=2\xi$。证毕。

## 三、积分题 (5题)

### 题11 — 困难 | 三角函数定积分特殊换元

计算：

$$I = \int_0^{\pi/2} \frac{\sin x}{\sin x + \cos x}\,dx$$

#### 思路溯源

区间 $[0,\pi/2]$ 上被积函数在 $x\to \pi/2-x$ 下有特殊对称性。令 $t=\pi/2-x$，原式变为 $\int_0^{\pi/2} \frac{\cos t}{\sin t+\cos t}dt$。两式相加消去分子。

#### 解法

令 $x=\frac{\pi}{2}-t$，则 $dx=-dt$：

$$I = \int_{\pi/2}^0 \frac{\sin(\frac{\pi}{2}-t)}{\sin(\frac{\pi}{2}-t)+\cos(\frac{\pi}{2}-t)}(-dt) = \int_0^{\pi/2} \frac{\cos t}{\cos t + \sin t}\,dt$$

即

$$I = \int_0^{\pi/2} \frac{\cos x}{\sin x + \cos x}\,dx$$

将原式与上式相加：

$$2I = \int_0^{\pi/2} \frac{\sin x + \cos x}{\sin x + \cos x}\,dx = \int_0^{\pi/2} 1\,dx = \frac{\pi}{2}$$

故

$$\boxed{I = \dfrac{\pi}{4}}$$

### 题12 — 困难 | 无理函数不定积分（根式换元）

计算不定积分：

$$I = \int \frac{dx}{1+\sqrt{x}}$$

#### 思路溯源

令 $t=\sqrt{x}$，则 $x=t^2$，$dx=2t\,dt$。化为有理函数积分。

#### 解法

令 $t=\sqrt{x}$（$x\geq 0$），$dx=2t\,dt$：

$$I = \int \frac{2t}{1+t}\,dt = 2\int \frac{t}{1+t}\,dt = 2\int \left(1 - \frac{1}{1+t}\right)dt$$

$$= 2\bigl(t - \ln|1+t|\bigr) + C$$

回代 $t=\sqrt{x}$：

$$\boxed{I = 2\sqrt{x} - 2\ln(1+\sqrt{x}) + C}$$

### 题13 — 困难 | 定积分的几何意义

利用定积分的几何意义计算：

$$I = \int_0^2 \sqrt{4x - x^2}\,dx$$

#### 思路溯源

$y=\sqrt{4x-x^2}$ ⇒ $y^2 = 4x-x^2$ ⇒ $(x-2)^2 + y^2 = 4$。这是圆心在 $(2,0)$、半径 $2$ 的圆。积分区间 $[0,2]$ 对应右半圆的右四分之一。

#### 解法

配方：$y = \sqrt{4x - x^2} = \sqrt{4 - (x-2)^2}$。

此为上半圆 $(x-2)^2+y^2=4$（$y\geq 0$），$x\in[0,2]$ 对应 $x$ 从 $0$ 到圆心的左半段。该段对应的圆心角从 $\pi/2$ 到 $0$（极坐标），面积为四分之一圆。

面积 = $\frac{1}{4}\pi\cdot 2^2 = \pi$。

更精确地，在 $x\in[0,2]$ 范围内该区域为半圆被 $x=2$ 分割后的左半部分——即四分之一圆。故

$$\boxed{I = \pi}$$

### 题14 — 地狱难度 | Cauchy-Schwarz 证积分不等式

设 $f,g$ 在 $[a,b]$ 上连续。证明：

$$\left(\int_a^b f(x)g(x)\,dx\right)^2 \leq \int_a^b f^2(x)\,dx \cdot \int_a^b g^2(x)\,dx$$

并给出等号成立的条件。

#### 思路溯源

这是积分形式的 Cauchy-Schwarz 不等式。构造二次型 $\int_a^b (f(x)+\lambda g(x))^2 dx \geq 0$，展开为 $\lambda$ 的二次三项式，判别式 $\Delta \leq 0$。

#### 解法

对任意实数 $\lambda$，

$$\int_a^b \bigl(f(x)+\lambda g(x)\bigr)^2 dx \geq 0$$

展开：

$$\int_a^b f^2\,dx + 2\lambda\int_a^b fg\,dx + \lambda^2\int_a^b g^2\,dx \geq 0$$

这是关于 $\lambda$ 的二次三项式 $A\lambda^2 + 2B\lambda + C \geq 0$（对所有 $\lambda$），其中

$$A = \int_a^b g^2\,dx,\quad B = \int_a^b fg\,dx,\quad C = \int_a^b f^2\,dx$$

$A \geq 0$。若 $A>0$，二次函数非负 ⇔ 判别式 $\leq 0$：

$$4B^2 - 4AC \leq 0 \;\Longrightarrow\; B^2 \leq AC$$

即所证。

若 $A=0$，则 $g\equiv 0$，不等式两边均为 $0$，等号成立。

**等号成立条件**：$g\equiv 0$ 时显然成立；$g\not\equiv 0$ 时，判别式 $=0$ ⇔ 存在 $\lambda_0$ 使 $\int (f+\lambda_0 g)^2 dx = 0$ ⇔ $f(x)+\lambda_0 g(x)\equiv 0$，即 $f$ 与 $g$ 线性相关。证毕。

### 题15 — 地狱难度 | 含参变量定积分求导

设 $f$ 在 $\mathbb{R}$ 上连续，定义

$$F(x) = \int_0^x (x-t)f(t)\,dt$$

求 $F''(x)$。

#### 思路溯源

含参变量 $x$ 同时出现在上限和被积函数中。先将 $(x-t)f(t)=x f(t)-t f(t)$ 拆分：$F(x)=x\int_0^x f(t)dt - \int_0^x t f(t)dt$。再对 $x$ 求导。

#### 解法

$$F(x) = x\int_0^x f(t)\,dt - \int_0^x t f(t)\,dt$$

求一阶导数（乘积法则 + 变限积分求导）：

$$F'(x) = \int_0^x f(t)\,dt + x f(x) - x f(x) = \int_0^x f(t)\,dt$$

再求导：

$$F''(x) = f(x)$$

$$\boxed{F''(x) = f(x)}$$

## 四、级数题 (5题)

### 题16 — 困难 | 比值+根值判别法

讨论级数的敛散性：

$$\sum_{n=1}^{\infty} \frac{n^n}{3^n \cdot n!}$$

#### 思路溯源

通项含 $n^n$ 和 $n!$，比值判别法最自然。$\frac{a_{n+1}}{a_n} = \frac{(n+1)^{n+1}}{3^{n+1}(n+1)!} \cdot \frac{3^n n!}{n^n} = \frac{1}{3}\left(1+\frac{1}{n}\right)^n$。

#### 解法

$$a_n = \frac{n^n}{3^n\,n!} > 0$$

$$\frac{a_{n+1}}{a_n} = \frac{(n+1)^{n+1}}{3^{n+1}(n+1)!} \cdot \frac{3^n n!}{n^n} = \frac{1}{3} \cdot \frac{(n+1)^n}{n^n} = \frac{1}{3}\left(1+\frac{1}{n}\right)^n$$

$$\lim_{n\to\infty}\frac{a_{n+1}}{a_n} = \frac{e}{3}$$

$e/3 < 1$（$e \approx 2.718 < 3$），由比值判别法知级数**收敛**。

$$\boxed{\text{级数收敛}}$$

### 题17 — 困难 | Leibniz 交错级数判别法

讨论级数 $\displaystyle\sum_{n=1}^{\infty} (-1)^{n-1}\frac{\ln n}{n}$ 的敛散性，并判断是条件收敛还是绝对收敛。

#### 思路溯源

交错级数，用 Leibniz 判别法：需验证 $a_n=\frac{\ln n}{n}$ 单调递减（$n$ 充分大时）且趋于零。绝对收敛则需 $\sum \frac{\ln n}{n}$ 与调和级数比较。

#### 解法

令 $a_n = \frac{\ln n}{n}$。

**Leibniz 条件检验**：

(1) $\lim_{n\to\infty} a_n = \lim_{n\to\infty}\frac{\ln n}{n} = 0$ ✓

(2) 单调性：令 $f(x)=\frac{\ln x}{x}$，$f'(x)=\frac{1-\ln x}{x^2} < 0$（$x>e$）。故 $n\geq 3$ 时 $\{a_n\}$ 单调递减 ✓

由 Leibniz 判别法，$\sum (-1)^{n-1}\frac{\ln n}{n}$ **收敛**。

**绝对收敛性**：$\frac{\ln n}{n} \geq \frac{1}{n}$（$n\geq 3$）。$\sum\frac{1}{n}$ 发散，由比较判别法知 $\sum\left|(-1)^{n-1}\frac{\ln n}{n}\right|$ 发散。

**结论**：该级数**条件收敛**。

$$\boxed{\text{条件收敛}}$$

### 题18 — 地狱难度 | 幂级数逐项求导求和函数

求幂级数的和函数并确定收敛域：

$$S(x) = \sum_{n=1}^{\infty} n x^{n-1},\qquad |x|<1$$

#### 思路溯源

这不是等比级数求和——$\sum n x^{n-1}$ 可以看作是 $\sum x^n = \frac{x}{1-x}$ 的逐项求导结果。或者直接观察：$\sum n x^{n-1} = \frac{d}{dx}\sum x^n = \frac{d}{dx}\frac{x}{1-x}$。

#### 解法

已知几何级数 $\sum_{n=0}^{\infty} x^n = \frac{1}{1-x}$（$|x|<1$）。两边逐项求导（幂级数在收敛区间内可逐项求导）：

$$\sum_{n=1}^{\infty} n x^{n-1} = \frac{d}{dx}\frac{1}{1-x} = \frac{1}{(1-x)^2}$$

收敛半径与原级数相同，$R=1$。在端点 $x=\pm 1$ 处，$a_n=n\to\infty\neq 0$，发散。

故和函数 $S(x)=\frac{1}{(1-x)^2}$，收敛域 $(-1,1)$。

$$\boxed{S(x)=\dfrac{1}{(1-x)^2},\quad |x|<1}$$

### 题19 — 困难 | 收敛半径 + Abel 定理综合

求幂级数 $\displaystyle\sum_{n=1}^{\infty} \frac{(x-1)^n}{n\cdot 2^n}$ 的收敛域。

#### 思路溯源

令 $t=x-1$ 化为 $\sum \frac{t^n}{n\cdot 2^n}$。收敛半径 $R = 1/\limsup \sqrt[n]{|a_n|} = 2$。检查端点 $t=\pm 2$。

#### 解法

令 $t=x-1$，考虑 $\sum_{n=1}^{\infty} \frac{t^n}{n\cdot 2^n}$。

收敛半径：

$$R = \lim_{n\to\infty} \left|\frac{a_n}{a_{n+1}}\right| = \lim_{n\to\infty} \frac{1/(n\cdot 2^n)}{1/((n+1)\cdot 2^{n+1})} = \lim_{n\to\infty} \frac{2(n+1)}{n} = 2$$

端点检验：

- $t=2$：$\sum_{n=1}^{\infty} \frac{2^n}{n\cdot 2^n} = \sum_{n=1}^{\infty}\frac{1}{n}$，调和级数，**发散**。
- $t=-2$：$\sum_{n=1}^{\infty} \frac{(-2)^n}{n\cdot 2^n} = \sum_{n=1}^{\infty} \frac{(-1)^n}{n}$，交错调和级数，由 Leibniz 判别法**收敛**（Abel 定理保证和函数在 $t=-2$ 处连续）。

故 $t\in[-2,2)$，回代 $t=x-1$：

$$-2 \leq x-1 < 2 \;\Longrightarrow\; -1 \leq x < 3$$

$$\boxed{\text{收敛域：}[-1,3)}$$

### 题20 — 地狱难度 | 条件收敛的精细判定

讨论 $\displaystyle\sum_{n=2}^{\infty} \frac{(-1)^n}{\sqrt{n}+(-1)^n}$ 的敛散性。

#### 思路溯源

分母含 $(-1)^n$，直接 Leibniz 判别法失效（通项非严格单调）。需通分化简：$\frac{(-1)^n}{\sqrt{n}+(-1)^n} = \frac{(-1)^n(\sqrt{n}-(-1)^n)}{n-1} = \frac{(-1)^n\sqrt{n}}{n-1} - \frac{1}{n-1}$。前项由 Leibniz 型可判收敛，后项 $\sum\frac{1}{n-1}$ 发散，故原级数发散。

#### 解法

$$\frac{(-1)^n}{\sqrt{n}+(-1)^n} = \frac{(-1)^n(\sqrt{n}-(-1)^n)}{(\sqrt{n}+(-1)^n)(\sqrt{n}-(-1)^n)} = \frac{(-1)^n\sqrt{n}-1}{n-1}$$

$$= \frac{(-1)^n\sqrt{n}}{n-1} - \frac{1}{n-1}$$

$\sum_{n=2}^{\infty}\frac{1}{n-1} = \sum_{n=1}^{\infty}\frac{1}{n}$ 发散（调和级数）。

$\sum_{n=2}^{\infty}\frac{(-1)^n\sqrt{n}}{n-1}$：$b_n = \frac{\sqrt{n}}{n-1} \searrow 0$（$n$ 充分大时 $b_n\sim n^{-1/2}\to 0$），满足 Leibniz 条件，收敛。

收敛 + 发散 = 发散。故原级数**发散**。

$$\boxed{\text{级数发散}}$$

### 题21 — 困难 | Lagrange 乘数法条件极值

求函数 $u=x^2+y^2+z^2$ 在约束条件 $x+2y+3z=14$ 下的极值。

#### 思路溯源

Lagrange 乘数法：构造 $L(x,y,z,\lambda)=x^2+y^2+z^2+\lambda(x+2y+3z-14)$，对各变量求偏导设为零。

#### 解法

令 $L=x^2+y^2+z^2+\lambda(x+2y+3z-14)$。

$$\begin{cases}
L_x = 2x + \lambda = 0 &\Rightarrow x = -\lambda/2\\[2pt]
L_y = 2y + 2\lambda = 0 &\Rightarrow y = -\lambda\\[2pt]
L_z = 2z + 3\lambda = 0 &\Rightarrow z = -3\lambda/2
\end{cases}$$

代入约束：$x+2y+3z = -\frac{\lambda}{2} - 2\lambda - \frac{9\lambda}{2} = -7\lambda = 14$，故 $\lambda = -2$。

得唯一驻点：$x=1,\;y=2,\;z=3$。

$u=x^2+y^2+z^2$ 在原点到平面的距离问题中取最小值。此处仅有唯一条件驻点且几何意义明确（原点到平面上最近点），故

$$u_{\min}=1^2+2^2+3^2=14$$

$$\boxed{u_{\min}=14}$$

### 题22 — 困难 | 二重积分极坐标变换

计算二重积分：

$$I = \iint_D \sqrt{x^2+y^2}\,dxdy$$

其中 $D: x^2+y^2 \leq 1,\; x\geq 0,\; y\geq 0$。

#### 思路溯源

被积函数 $\sqrt{x^2+y^2}=r$，区域为第一象限单位圆。极坐标变换 $x=r\cos\theta$，$y=r\sin\theta$，$dxdy=r\,dr d\theta$。

#### 解法

极坐标：$D$ 对应 $0\leq r\leq 1$，$0\leq\theta\leq\frac{\pi}{2}$。

$$I = \int_0^{\pi/2} d\theta \int_0^1 r \cdot r\,dr = \int_0^{\pi/2} d\theta \cdot \int_0^1 r^2\,dr = \frac{\pi}{2} \cdot \frac{1}{3} = \frac{\pi}{6}$$

$$\boxed{I = \dfrac{\pi}{6}}$$

### 题23 — 地狱难度 | 抽象复合函数二阶偏导

设 $z=f(xy,\; x^2+y^2)$，其中 $f$ 具有二阶连续偏导数。求 $\displaystyle\frac{\partial^2 z}{\partial x^2}$。

#### 思路溯源

链式法则两次。令 $u=xy$，$v=x^2+y^2$，则 $z=f(u,v)$。一阶偏导含 $f_u$ 和 $f_v$ 对 $x$ 再求导时，注意 $f_u$、$f_v$ 本身仍是 $(u,v)$ 的函数。

#### 解法

令 $u=xy$，$v=x^2+y^2$。$z=f(u,v)$。

$$\frac{\partial z}{\partial x} = f_u \cdot \frac{\partial u}{\partial x} + f_v \cdot \frac{\partial v}{\partial x} = y f_u + 2x f_v$$

二阶偏导：

$$\frac{\partial^2 z}{\partial x^2} = \frac{\partial}{\partial x}\bigl(y f_u + 2x f_v\bigr) = y\frac{\partial}{\partial x}f_u + 2f_v + 2x\frac{\partial}{\partial x}f_v$$

$f_u$ 和 $f_v$ 对 $x$ 的偏导同样经 $u,v$：

$$\frac{\partial}{\partial x}f_u = f_{uu}\frac{\partial u}{\partial x} + f_{uv}\frac{\partial v}{\partial x} = y f_{uu} + 2x f_{uv}$$

$$\frac{\partial}{\partial x}f_v = f_{vu}\frac{\partial u}{\partial x} + f_{vv}\frac{\partial v}{\partial x} = y f_{vu} + 2x f_{vv}$$

由 $f$ 二阶连续偏导，$f_{uv}=f_{vu}$。代入：

$$\frac{\partial^2 z}{\partial x^2} = y(y f_{uu} + 2x f_{uv}) + 2f_v + 2x(y f_{vu} + 2x f_{vv})$$

$$= y^2 f_{uu} + 4xy f_{uv} + 4x^2 f_{vv} + 2f_v$$

$$\boxed{\frac{\partial^2 z}{\partial x^2} = y^2 f_{uu} + 4xy f_{uv} + 4x^2 f_{vv} + 2f_v}$$

## 六、概念题 (2题)

### 题24 — 困难 | 一致连续 vs. 不一致连续

判断函数 $f(x)=\sqrt{x}$ 在 $[0,+\infty)$ 上是否一致连续，并证明。

#### 思路溯源

一致连续定义为 $\forall\varepsilon>0,\exists\delta>0,\forall x,y:|x-y|<\delta\Rightarrow|f(x)-f(y)|<\varepsilon$。$\sqrt{x}$ 在 $[0,\infty)$ 上（含 $0$ 附近陡峭段）是否一致连续？证法：对 $\sqrt{x}$ 用不等式 $|\sqrt{x}-\sqrt{y}|\leq\sqrt{|x-y|}$。

#### 解法

$f(x)=\sqrt{x}$ 在 $[0,+\infty)$ 上**一致连续**。

证明：对任意 $x,y\geq 0$，

$$|\sqrt{x}-\sqrt{y}| = \frac{|x-y|}{\sqrt{x}+\sqrt{y}} \leq \sqrt{|x-y|}$$

（最后一个不等号由 $\sqrt{x}+\sqrt{y}\geq\sqrt{|x-y|}$ 可得——验证：两边平方得 $x+y+2\sqrt{xy}\geq |x-y|$，即 $2x+2y\geq 0$ 或 $2x+2y\geq 2y$，均成立。）

对任意 $\varepsilon>0$，取 $\delta=\varepsilon^2$。当 $|x-y|<\delta$ 时，

$$|\sqrt{x}-\sqrt{y}| \leq \sqrt{|x-y|} < \sqrt{\varepsilon^2} = \varepsilon$$

故 $\sqrt{x}$ 在 $[0,\infty)$ 上一致连续。证毕。

> 对比：$f(x)=x^2$ 在 $[0,\infty)$ 上**不一致连续**（导函数无界）。

### 题25 — 地狱难度 | 多元函数极限不存在的路径法

判断下列二元函数在 $(0,0)$ 处的极限是否存在：

$$f(x,y)=\frac{xy^2}{x^2+y^4},\quad (x,y)\neq(0,0);\qquad f(0,0)=0$$

#### 思路溯源

沿不同路径趋近 $(0,0)$ 看极限是否一致。路径 $y=kx$ 只覆盖 $y^2$ 可表示为 $x$ 的二次方的场景；$y^2$ 与 $x$ 同阶的特殊路径 $x=my^2$ 是揭示不一致的关键。

#### 解法

**路径 1**：$y=kx$（$k$ 常数），

$$f(x,kx)=\frac{x\cdot k^2 x^2}{x^2 + k^4 x^4} = \frac{k^2 x}{1 + k^4 x^2} \to 0 \quad(x\to 0)$$

**路径 2**：$x = m y^2$（$m$ 常数），

$$f(my^2, y) = \frac{m y^2 \cdot y^2}{m^2 y^4 + y^4} = \frac{m}{m^2+1}$$

极限值依赖 $m$。取 $m=1$ 得 $\frac{1}{2}$，取 $m=0$ 得 $0$。

路径 1 和路径 2 给出不同的极限值，故 $\displaystyle\lim_{(x,y)\to(0,0)} f(x,y)$ **不存在**。

> ⚠️ 路径 $y=kx$（直线路径）得出极限为 $0$ 不足以说明极限存在——必须沿**所有可能路径**（包括曲线 $x=my^2$）极限一致才存在。

$$\boxed{\text{极限不存在}}$$
