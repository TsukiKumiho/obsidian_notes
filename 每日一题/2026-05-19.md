## 一、极限题 (5题)

### 题1 — 困难

求极限：

$$L = \lim_{x\to 0} \frac{\cos(\tan x) - \cos x}{x^4}$$

#### 思路溯源

分子是 $\cos A - \cos B$ 形式，直观思路是分别 Taylor 展开。$\cos(\tan x)$ 需先展开 $\tan x$ 再代入 $\cos$ 的展开式。因为 $\tan x \sim x$，$\cos$ 展开到 $u^2$ 项即可得到 $x^2$ 阶，但此处分子两 $\cos$ 的 $x^2$ 项会抵消，必须展开到 $x^4$ 阶。

#### 解法

由 Taylor 展开：

$$\tan x = x + \frac{x^3}{3} + o(x^4)$$

$$\cos u = 1 - \frac{u^2}{2} + \frac{u^4}{24} + o(u^4)$$

令 $u = \tan x$。计算 $u^2$ 与 $u^4$：

$$u^2 = \left(x + \frac{x^3}{3}\right)^2 + o(x^4) = x^2 + \frac{2}{3}x^4 + o(x^4)$$

$$u^4 = x^4 + o(x^4)$$

代入 $\cos(\tan x)$：

$$\cos(\tan x) = 1 - \frac{1}{2}\left(x^2 + \frac{2}{3}x^4\right) + \frac{1}{24}x^4 + o(x^4) = 1 - \frac{x^2}{2} - \frac{7}{24}x^4 + o(x^4)$$

又 $\cos x = 1 - \dfrac{x^2}{2} + \dfrac{x^4}{24} + o(x^4)$，相减：

$$\cos(\tan x) - \cos x = \left(-\frac{7}{24} - \frac{1}{24}\right)x^4 + o(x^4) = -\frac{1}{3}x^4 + o(x^4)$$

故

$$\boxed{L = -\dfrac{1}{3}}$$

### 题2 — 困难

求极限：

$$L = \lim_{n\to\infty} \prod_{k=2}^{n} \left(1 - \frac{1}{k^2}\right)$$

#### 思路溯源

无穷乘积的通法：先考察通项能否因式分解为相邻项的比值，形成裂项相消的"望远镜"结构。观察 $1-1/k^2 = (k-1)(k+1)/k^2$，分子中的 $k-1$ 与上一项分母的因子相消，$k+1$ 与下一项分母的因子相消。

#### 解法

$$1 - \frac{1}{k^2} = \frac{k^2-1}{k^2} = \frac{(k-1)(k+1)}{k^2}$$

$$\prod_{k=2}^{n} \frac{(k-1)(k+1)}{k^2} = \frac{(2-1)(2+1)}{2^2} \cdot \frac{(3-1)(3+1)}{3^2} \cdots \frac{(n-1)(n+1)}{n^2}$$

分子中因子 $1,2,3,\ldots,n-1$ 各出现一次（来自 $k-1$），因子 $3,4,5,\ldots,n+1$ 各出现一次（来自 $k+1$）。分母为 $(2\cdot 3\cdots n)^2$。

整理得：

$$L_n = \frac{1}{2}\cdot\frac{n+1}{n} \to \frac{1}{2} \quad (n\to\infty)$$

$$\boxed{L = \dfrac{1}{2}}$$

### 题3 — 困难

求极限：

$$L = \lim_{x\to 0} \frac{a^x - b^x}{x} \quad (a>0,\;b>0)$$

#### 思路溯源

分子是 $a^x-b^x$，当 $x\to 0$ 时分子分母均趋于 $0$（$\frac{0}{0}$ 型）。两种思路：一是直接识别导数定义 $\lim_{x\to0}(a^x-1)/x = \ln a$；二是用 $e^{x\ln a}$ 的 Taylor 展开。

#### 解法

将 $a^x$ 写成 $e^{x\ln a}$，由等价无穷小 $e^u-1 \sim u$（$u\to 0$）：

$$a^x - b^x = (a^x-1) - (b^x-1) = e^{x\ln a}-1 - (e^{x\ln b}-1)$$

当 $x\to 0$ 时，$e^{x\ln a}-1 \sim x\ln a$，$e^{x\ln b}-1 \sim x\ln b$。故

$$L = \lim_{x\to 0} \frac{x\ln a - x\ln b}{x} = \ln a - \ln b = \ln\frac{a}{b}$$

$$\boxed{L = \ln\dfrac{a}{b}}$$

> 也可用导数定义：$L = \left.\dfrac{d}{dx}(a^x-b^x)\right|_{x=0} = \ln a - \ln b$。

### 题4 — 地狱

求极限：

$$L = \lim_{n\to\infty} n^2\left(\sqrt[n]{a} - \sqrt[n+1]{a}\right) \quad (a>0,\;a\neq 1)$$

#### 思路溯源

$\sqrt[n]{a} = a^{1/n}$，$\sqrt[n+1]{a} = a^{1/(n+1)}$。两者都是 $a$ 的分数次幂。用指数形式 $a^{1/n}=e^{\ln a/n}$，然后用 Taylor 展开到 $1/n^2$ 阶，因为外面有 $n^2$ 因子。

#### 解法

令 $t = 1/n$，则 $\sqrt[n]{a} = a^t = e^{t\ln a}$，$\sqrt[n+1]{a} = a^{\frac{t}{1+t}} = e^{\frac{t}{1+t}\ln a}$。

由 Taylor 展开 $e^u = 1+u+\frac{u^2}{2}+o(u^2)$：

$$a^t = 1 + t\ln a + \frac{t^2\ln^2 a}{2} + o(t^2)$$

对于第二项，先展开指数：

$$\frac{t}{1+t} = t(1-t+t^2+o(t^2)) = t - t^2 + o(t^2)$$

$$a^{\frac{t}{1+t}} = 1 + (t-t^2)\ln a + \frac{t^2\ln^2 a}{2} + o(t^2)$$

两式相减：

$$a^t - a^{\frac{t}{1+t}} = \left[t\ln a - (t-t^2)\ln a\right] + o(t^2) = t^2\ln a + o(t^2)$$

代回 $t = 1/n$：

$$\sqrt[n]{a} - \sqrt[n+1]{a} = \frac{\ln a}{n^2} + o\left(\frac{1}{n^2}\right)$$

故

$$L = \lim_{n\to\infty} n^2 \cdot \frac{\ln a}{n^2} = \ln a$$

$$\boxed{L = \ln a}$$

### 题5 — 地狱

求极限：

$$L = \lim_{n\to\infty} \sum_{k=1}^{n} \frac{1}{\sqrt{n^2 + kn}}$$

#### 思路溯源

和式中每一项均含 $n$，这是典型的"夹逼准则"适用场景——对每一项进行放缩使其不依赖于 $k$。上下界取 $k=1$ 和 $k=n$ 时 $\sqrt{n^2+kn}$ 的最值。

#### 解法

对 $k=1,2,\ldots,n$，有

$$n^2 + n \leq n^2 + kn \leq n^2 + n^2 = 2n^2$$

故

$$\frac{1}{\sqrt{2n^2}} \leq \frac{1}{\sqrt{n^2+kn}} \leq \frac{1}{\sqrt{n^2+n}}$$

即

$$\frac{1}{n\sqrt{2}} \leq \frac{1}{\sqrt{n^2+kn}} \leq \frac{1}{\sqrt{n^2+n}}$$

对 $k$ 求和（共 $n$ 项）：

$$\frac{n}{n\sqrt{2}} \leq S_n \leq \frac{n}{\sqrt{n^2+n}}$$

即

$$\frac{1}{\sqrt{2}} \leq S_n \leq \frac{n}{\sqrt{n^2+n}}$$

右端 $\frac{n}{\sqrt{n^2+n}} = \frac{1}{\sqrt{1+1/n}} \to 1$（$n\to\infty$）。

此放缩不够紧——上下界不相等。需更精细的放缩。

**精细放缩**：用定积分定义。

$$S_n = \frac{1}{n}\sum_{k=1}^{n} \frac{1}{\sqrt{1 + \frac{k}{n}}}$$

令 $f(x) = \frac{1}{\sqrt{1+x}}$，$x\in[0,1]$。这是 $f$ 在 $[0,1]$ 上的 Riemann 和，分点为 $x_k = k/n$。

$$\lim_{n\to\infty} S_n = \int_0^1 \frac{dx}{\sqrt{1+x}} = \left[2\sqrt{1+x}\right]_0^1 = 2(\sqrt{2}-1)$$

$$\boxed{L = 2(\sqrt{2}-1)}$$

## 二、中值定理题 (5题)

### 题6 — 困难

设 $f(x)$ 在 $[0,1]$ 上二阶可导，$f(0)=f(1)=0$，且 $\displaystyle\max_{x\in[0,1]} f(x) = 1$。证明：存在 $\xi \in (0,1)$ 使得 $f''(\xi) \leq -8$。

#### 思路溯源

最大值在内部取到（端点值为 $0$，最大值为 $1$）。由 Fermat 定理，最大值点处一阶导数为零。将 $f(0)$ 和 $f(1)$ 在最大值点处用 Taylor 公式展开至一阶（带 Lagrange 余项），利用 $f(0)=f(1)=0$ 导出 $f''$ 与最大值位置的定量关系。

#### 解法

设 $f$ 在 $x_0 \in (0,1)$ 处取得最大值，即 $f(x_0) = 1$。由 Fermat 定理，$f'(x_0) = 0$。

将 $f(0)$ 在 $x_0$ 处 Taylor 展开（带 Lagrange 余项）：

$$0 = f(0) = f(x_0) + f'(x_0)(0-x_0) + \frac{f''(\xi_1)}{2}(0-x_0)^2 = 1 + \frac{f''(\xi_1)}{2}x_0^2$$

其中 $\xi_1 \in (0, x_0)$。解得 $f''(\xi_1) = -\dfrac{2}{x_0^2}$。

同理，将 $f(1)$ 在 $x_0$ 处展开：

$$0 = f(1) = f(x_0) + f'(x_0)(1-x_0) + \frac{f''(\xi_2)}{2}(1-x_0)^2 = 1 + \frac{f''(\xi_2)}{2}(1-x_0)^2$$

其中 $\xi_2 \in (x_0, 1)$。解得 $f''(\xi_2) = -\dfrac{2}{(1-x_0)^2}$。

若 $x_0 \leq \dfrac{1}{2}$，则 $x_0^2 \leq \dfrac{1}{4}$，故 $f''(\xi_1) = -\dfrac{2}{x_0^2} \leq -8$，取 $\xi = \xi_1$。

若 $x_0 \geq \dfrac{1}{2}$，则 $(1-x_0)^2 \leq \dfrac{1}{4}$，故 $f''(\xi_2) = -\dfrac{2}{(1-x_0)^2} \leq -8$，取 $\xi = \xi_2$。

综上，存在 $\xi \in (0,1)$ 使得 $f''(\xi) \leq -8$。证毕。

### 题7 — 困难

设 $f(x)$ 在 $[0,\pi]$ 上可导，且 $f(0) = f(\pi) = 0$。证明：存在 $\xi \in (0,\pi)$ 使得

$$f'(\xi)\cos\xi = f(\xi)\sin\xi$$

#### 思路溯源

结论可改写为 $f'(\xi)\cos\xi - f(\xi)\sin\xi = 0$。左端形如 $(f\cdot g)'$：注意到 $(f(x)\cos x)' = f'(x)\cos x - f(x)\sin x$。因此构造 $F(x) = f(x)\cos x$。

#### 解法

构造辅助函数 $F(x) = f(x)\cos x$，$x \in [0,\pi]$。

$F(0) = f(0)\cos 0 = 0 \cdot 1 = 0$，
$F(\pi) = f(\pi)\cos\pi = 0 \cdot (-1) = 0$，

即 $F(0) = F(\pi)$。$F(x)$ 在 $[0,\pi]$ 上连续，$(0,\pi)$ 内可导。由 Rolle 定理，存在 $\xi \in (0,\pi)$ 使得

$$F'(\xi) = f'(\xi)\cos\xi - f(\xi)\sin\xi = 0$$

即 $f'(\xi)\cos\xi = f(\xi)\sin\xi$。证毕。

### 题8 — 困难

设 $f(x)$ 在 $[0,1]$ 上连续可导，$f(0)=0$，且 $\int_0^1 f(x)\,dx = \frac{1}{2}$。证明：存在 $\xi \in (0,1)$ 使得 $f(\xi) = \xi$。

#### 思路溯源

结论 $f(\xi)=\xi$ 即 $f(\xi)-\xi=0$。构造 $F(x)=\int_0^x f(t)\,dt - \frac{x^2}{2}$，则 $F'(\xi)=f(\xi)-\xi$。验证 $F(0)=F(1)$？$F(0)=0$，$F(1)=\int_0^1 f - 1/2 = 0$。恰好可用 Rolle 定理。

#### 解法

构造辅助函数 $F(x) = \int_0^x f(t)\,dt - \frac{x^2}{2}$，$x \in [0,1]$。

$F(0) = 0 - 0 = 0$，
$F(1) = \int_0^1 f(t)\,dt - \frac{1}{2} = \frac{1}{2} - \frac{1}{2} = 0$。

$F(x)$ 在 $[0,1]$ 上可导，且 $F(0)=F(1)$。由 Rolle 定理，存在 $\xi \in (0,1)$ 使得

$$F'(\xi) = f(\xi) - \xi = 0$$

即 $f(\xi) = \xi$。证毕。

### 题9 — 地狱

设 $f(x)$ 在 $[a,b]$ 上二阶可导，且 $f''(x) \geq 0$（$f$ 为凸函数）。证明：

$$f\!\left(\frac{a+b}{2}\right) \leq \frac{1}{b-a}\int_a^b f(x)\,dx \leq \frac{f(a)+f(b)}{2}$$

#### 思路溯源

这是 Hadamard 不等式的核心部分。对于凸函数，中点值 $\leq$ 平均值 $\leq$ 端点平均值。证明需用到凸函数的几何意义（切线在曲线下方）以及积分中值定理 / Taylor 展开。

#### 解法

**证左半部分** $f(\frac{a+b}{2}) \leq \frac{1}{b-a}\int_a^b f$：

由 Taylor 公式在 $x_0 = \frac{a+b}{2}$ 处展开至一阶（带 Lagrange 余项）：

$$f(x) = f(x_0) + f'(x_0)(x-x_0) + \frac{f''(\xi)}{2}(x-x_0)^2$$

由 $f''(\xi) \geq 0$，得 $f(x) \geq f(x_0) + f'(x_0)(x-x_0)$。

两边在 $[a,b]$ 上积分：

$$\int_a^b f(x)\,dx \geq \int_a^b [f(x_0) + f'(x_0)(x-x_0)]\,dx$$

$$= f(x_0)(b-a) + f'(x_0)\int_a^b (x-x_0)\,dx$$

令 $h = \frac{b-a}{2}$，则 $x_0 = a+h = b-h$，$\int_a^b (x-x_0)\,dx = 0$（对称区间上奇函数的积分为零）。

故 $\int_a^b f \geq f(x_0)(b-a)$，即

$$f\!\left(\frac{a+b}{2}\right) \leq \frac{1}{b-a}\int_a^b f(x)\,dx$$

**证右半部分** $\frac{1}{b-a}\int_a^b f \leq \frac{f(a)+f(b)}{2}$：

由凸性，对任意 $\lambda \in [0,1]$：

$$f((1-\lambda)a + \lambda b) \leq (1-\lambda)f(a) + \lambda f(b)$$

令 $x = (1-\lambda)a + \lambda b$，则 $\lambda = \frac{x-a}{b-a}$。两边在 $[a,b]$ 上积分：

$$\int_a^b f(x)\,dx \leq f(a)\int_a^b \frac{b-x}{b-a}\,dx + f(b)\int_a^b \frac{x-a}{b-a}\,dx$$

两个积分均为 $\frac{b-a}{2}$，故

$$\int_a^b f \leq (b-a)\frac{f(a)+f(b)}{2}$$

即 $\frac{1}{b-a}\int_a^b f \leq \frac{f(a)+f(b)}{2}$。

综上，

$$\boxed{f\!\left(\frac{a+b}{2}\right) \leq \frac{1}{b-a}\int_a^b f(x)\,dx \leq \frac{f(a)+f(b)}{2}}$$

证毕。

### 题10 — 地狱

设 $f(x)$ 在 $[0,1]$ 上可导，$f(0)=0$，$f(1)=1$。证明：存在两个不同的点 $\xi, \eta \in (0,1)$ 使得

$$\frac{1}{f'(\xi)} + \frac{1}{f'(\eta)} = 2$$

#### 思路溯源

结论涉及两个独立中值点的倒数关系。由 Lagrange 中值定理，可以在两个子区间上分别找到中值点。关键是如何分割 $[0,1]$ 使得两个中值的关系恰好满足等式。

由 $f(0)=0, f(1)=1$，存在某点 $c \in (0,1)$ 使得 $f(c) = 1/2$（连续函数的介值性）。在 $[0,c]$ 和 $[c,1]$ 上分别用 Lagrange 中值定理。

#### 解法

由 $f$ 的连续性及 $f(0)=0$，$f(1)=1$，由介值定理，存在 $c \in (0,1)$ 使得 $f(c) = \frac{1}{2}$。

在 $[0,c]$ 上应用 Lagrange 中值定理：$\exists \xi \in (0,c)$ 使得

$$f'(\xi) = \frac{f(c)-f(0)}{c-0} = \frac{1/2}{c} = \frac{1}{2c}$$

在 $[c,1]$ 上应用 Lagrange 中值定理：$\exists \eta \in (c,1)$ 使得

$$f'(\eta) = \frac{f(1)-f(c)}{1-c} = \frac{1-1/2}{1-c} = \frac{1}{2(1-c)}$$

于是

$$\frac{1}{f'(\xi)} = 2c,\quad \frac{1}{f'(\eta)} = 2(1-c)$$

$$\frac{1}{f'(\xi)} + \frac{1}{f'(\eta)} = 2c + 2(1-c) = 2$$

且 $\xi \in (0,c)$，$\eta \in (c,1)$，故 $\xi \neq \eta$。证毕。

## 三、积分题 (5题)

### 题11 — 困难

计算不定积分：

$$I = \int \frac{dx}{x^4+1}$$

#### 思路溯源

$x^4+1 = (x^2+1)^2 - 2x^2 = (x^2+\sqrt{2}x+1)(x^2-\sqrt{2}x+1)$。用部分分式拆分为两个二次不可约因式的有理函数之和，每个对应 $\arctan$ 型 + $\ln$ 型积分。

#### 解法

将分母分解：

$$x^4+1 = (x^2+1)^2 - 2x^2 = (x^2+\sqrt{2}x+1)(x^2-\sqrt{2}x+1)$$

设

$$\frac{1}{x^4+1} = \frac{Ax+B}{x^2+\sqrt{2}x+1} + \frac{Cx+D}{x^2-\sqrt{2}x+1}$$

由对称性可解得 $A = \frac{1}{2\sqrt{2}},\; B = \frac{1}{2},\; C = -\frac{1}{2\sqrt{2}},\; D = \frac{1}{2}$。

于是

$$I = \frac{1}{2\sqrt{2}}\int\frac{x+\sqrt{2}}{x^2+\sqrt{2}x+1}\,dx - \frac{1}{2\sqrt{2}}\int\frac{x-\sqrt{2}}{x^2-\sqrt{2}x+1}\,dx$$

对第一项，配方分母 $x^2+\sqrt{2}x+1 = \left(x+\frac{\sqrt{2}}{2}\right)^2 + \frac{1}{2}$。拆分子：

$$\int\frac{x+\sqrt{2}}{x^2+\sqrt{2}x+1}\,dx = \frac{1}{2}\int\frac{2x+\sqrt{2}}{x^2+\sqrt{2}x+1}\,dx + \frac{\sqrt{2}}{2}\int\frac{dx}{x^2+\sqrt{2}x+1}$$

第一子项 $= \frac{1}{2}\ln(x^2+\sqrt{2}x+1)$。第二子项用 $\arctan$：

$$\int\frac{dx}{\left(x+\frac{\sqrt{2}}{2}\right)^2+\frac{1}{2}} = \sqrt{2}\arctan(\sqrt{2}x+1)$$

同理处理第二项的积分。最终合并得：

### 题12 — 困难

计算定积分：

$$I = \int_0^{\pi/2} \sin^5 x \cos^2 x\,dx$$

#### 思路溯源

被积函数为 $\sin^m x \cos^n x$（$m=5,n=2$ 均为正整数）在 $[0,\pi/2]$ 上的积分，适用 Wallis 公式（点火公式）。将 $\sin^5 x$ 拆为 $(1-\cos^2 x)^2 \sin x$，用代换 $t=\cos x$；或直接用 Wallis 闭式。

#### 解法

法一：代换 $t = \cos x$，$dt = -\sin x\,dx$。

$$\sin^5 x \cos^2 x = \sin^4 x \cos^2 x \cdot \sin x = (1-\cos^2 x)^2 \cos^2 x \cdot \sin x$$

$$I = \int_1^0 -(1-t^2)^2 t^2\,dt = \int_0^1 (1-2t^2+t^4)t^2\,dt$$

$$= \int_0^1 (t^2 - 2t^4 + t^6)\,dt = \left[\frac{t^3}{3} - \frac{2t^5}{5} + \frac{t^7}{7}\right]_0^1$$

$$= \frac{1}{3} - \frac{2}{5} + \frac{1}{7} = \frac{35 - 42 + 15}{105} = \frac{8}{105}$$

法二：Wallis 公式 $\int_0^{\pi/2} \sin^m x \cos^n x\,dx = \dfrac{\Gamma(\frac{m+1}{2})\Gamma(\frac{n+1}{2})}{2\Gamma(\frac{m+n}{2}+1)}$

$m=5, n=2$：

$$I = \frac{\Gamma(3)\Gamma(1.5)}{2\Gamma(4.5)} = \frac{2! \cdot \frac{\sqrt{\pi}}{2}}{2\cdot\frac{7}{2}\cdot\frac{5}{2}\cdot\frac{3}{2}\cdot\frac{\sqrt{\pi}}{2}} = \frac{8}{105}$$

$$\boxed{I = \dfrac{8}{105}}$$

### 题13 — 地狱

讨论反常积分的敛散性（含参数 $p,q>0$）：

$$I(p,q) = \int_0^{\infty} \frac{x^{p-1}}{1+x^q}\,dx$$

并在收敛时求其值。

#### 思路溯源

$\int_0^{\infty} x^{p-1}/(1+x^q)dx$ 是经典的 Beta 函数形式。令 $t = x^q$ 可化为 $\frac{1}{q}\int_0^{\infty} t^{p/q-1}/(1+t)dt = \frac{1}{q}B(p/q, 1-p/q) = \frac{\pi}{q\sin(p\pi/q)}$。需讨论 $x=0$ 和 $x\to\infty$ 两端的敛散条件。

#### 解法

将积分拆为 $\int_0^1 + \int_1^\infty$。

在 $x \to 0^+$ 处：$x^{p-1}/(1+x^q) \sim x^{p-1}$。$\int_0^1 x^{p-1}dx$ 收敛当且仅当 $p > 0$。

在 $x \to \infty$ 处：$x^{p-1}/(1+x^q) \sim x^{p-1-q}$。$\int_1^\infty x^{p-1-q}dx$ 收敛当且仅当 $p-1-q < -1$，即 $p < q$。

故收敛条件为 $0 < p < q$。

在此条件下求值。令 $t = x^q$，$x = t^{1/q}$，$dx = \frac{1}{q}t^{1/q-1}dt$：

$$I = \int_0^\infty \frac{t^{(p-1)/q}}{1+t} \cdot \frac{1}{q}t^{1/q-1}dt = \frac{1}{q}\int_0^\infty \frac{t^{p/q-1}}{1+t}\,dt$$

已知 $\int_0^\infty \frac{t^{\alpha-1}}{1+t}\,dt = \frac{\pi}{\sin(\alpha\pi)}$（$0<\alpha<1$）。令 $\alpha = p/q$：

$$I = \frac{1}{q} \cdot \frac{\pi}{\sin(p\pi/q)}$$

$$\boxed{I = \dfrac{\pi}{q\sin(p\pi/q)},\quad 0 < p < q}$$

### 题14 — 困难

求摆线 $x = a(t-\sin t)$，$y = a(1-\cos t)$（$t \in [0, 2\pi]$）的一拱绕 $x$ 轴旋转所得旋转体的体积。

#### 思路溯源

旋转体体积公式 $V = \pi\int y^2\,dx$。参数方程下，$dx = a(1-\cos t)dt$，$y = a(1-\cos t)$。代入后化为三角函数的定积分。

#### 解法

由旋转体体积公式：

$$V = \pi\int_0^{2\pi a} y^2\,dx = \pi\int_0^{2\pi} [a(1-\cos t)]^2 \cdot a(1-\cos t)\,dt$$

$$= \pi a^3\int_0^{2\pi} (1-\cos t)^3\,dt$$

展开 $(1-\cos t)^3 = 1 - 3\cos t + 3\cos^2 t - \cos^3 t$。

在 $[0,2\pi]$ 上，$\cos t$ 和 $\cos^3 t$ 的积分为 $0$（奇函数性质）。利用 $\int_0^{2\pi} \cos^2 t\,dt = \pi$：

$$V = \pi a^3\left[\int_0^{2\pi} 1\,dt + 3\int_0^{2\pi} \cos^2 t\,dt\right] = \pi a^3[2\pi + 3\pi] = 5\pi^2 a^3$$

$$\boxed{V = 5\pi^2 a^3}$$

### 题15 — 地狱

设 $m$ 为正整数，$n$ 为非负整数。计算：

$$I_{m,n} = \int_0^1 x^m (\ln x)^n\,dx$$

并用结果求 $\displaystyle\int_0^1 x^3 (\ln x)^4\,dx$ 的值。

#### 思路溯源

$\ln x$ 的幂次提示用分部积分或代换 $x = e^{-t}$ 化为 Gamma 函数。代换后积分变为 $\int_0^\infty e^{-(m+1)t}(-t)^n dt = (-1)^n \int_0^\infty t^n e^{-(m+1)t} dt$，后者是标准的 Gamma 积分。

#### 解法

令 $x = e^{-t}$，则 $dx = -e^{-t}dt$，$\ln x = -t$。当 $x:0\to 1$ 时 $t:\infty\to 0$。

$$I_{m,n} = \int_\infty^0 e^{-mt}(-t)^n \cdot (-e^{-t})\,dt = (-1)^n\int_0^\infty t^n e^{-(m+1)t}\,dt$$

再令 $u = (m+1)t$，$t = \frac{u}{m+1}$，$dt = \frac{du}{m+1}$：

$$I_{m,n} = (-1)^n\int_0^\infty \left(\frac{u}{m+1}\right)^n e^{-u}\frac{du}{m+1}$$

$$= \frac{(-1)^n}{(m+1)^{n+1}}\int_0^\infty u^n e^{-u}\,du = \frac{(-1)^n n!}{(m+1)^{n+1}}$$

当 $m=3, n=4$ 时：

$$I_{3,4} = \frac{(-1)^4 \cdot 4!}{(3+1)^5} = \frac{24}{4^5} = \frac{24}{1024} = \frac{3}{128}$$

$$\boxed{I_{m,n} = \dfrac{(-1)^n n!}{(m+1)^{n+1}},\quad I_{3,4} = \dfrac{3}{128}}$$

## 四、级数题 (5题)

### 题16 — 困难

判别级数 $\displaystyle\sum_{n=1}^\infty \frac{(-1)^{n-1}}{n+(-1)^{n-1}}$ 的敛散性（若收敛，指明是条件收敛还是绝对收敛）。

#### 思路溯源

分母含 $(-1)^{n-1}$ 的交错项，不能直接用 Leibniz 判别法——该判别法要求 $a_n$ 单调递减。本题中交错项在分母中，不满足单调性条件。应拆分为奇数项与偶数项分别分析，或展开为渐近形式。

#### 解法

记 $a_n = \dfrac{(-1)^{n-1}}{n+(-1)^{n-1}}$。分别考察 $n$ 为奇数和偶数：

$n=2k-1$ 时：$(-1)^{n-1}=1$，$a_{2k-1} = \dfrac{1}{2k-1+1} = \dfrac{1}{2k}$。

$n=2k$ 时：$(-1)^{n-1} = -1$，$a_{2k} = \dfrac{-1}{2k-1} = -\dfrac{1}{2k-1}$。

两相邻项合并：

$$S_{2m} = \sum_{k=1}^m \left(\frac{1}{2k} - \frac{1}{2k-1}\right) = -\sum_{k=1}^m \frac{1}{2k(2k-1)}$$

由于 $\dfrac{1}{2k(2k-1)} \sim \dfrac{1}{4k^2}$，$\sum \dfrac{1}{k^2}$ 收敛，故 $S_{2m}$ 收敛。又 $a_{2m+1} = \dfrac{1}{2m+2} \to 0$，故 $S_{2m+1} = S_{2m} + a_{2m+1}$ 也收敛于同一极限。

原级数收敛。

再考察绝对收敛性：$|a_n| = \dfrac{1}{|n+(-1)^{n-1}|} \sim \dfrac{1}{n}$，$\sum \dfrac{1}{n}$ 发散，故原级数不绝对收敛。

$$\boxed{\text{条件收敛}}$$

### 题17 — 困难

求幂级数 $\displaystyle\sum_{n=1}^\infty \frac{x^n}{n\cdot 3^n}$ 的收敛域与和函数。

#### 思路溯源

标准幂级数形式，先求收敛半径 $R = \lim |a_n/a_{n+1}| = 3$。端点 $x=\pm 3$ 代回原级数单独检验。和函数通过逐项求导去掉分母中的 $n$，化为几何级数再积分回来。

#### 解法

收敛半径：

$$\rho = \lim_{n\to\infty} \left|\frac{a_{n+1}}{a_n}\right| = \lim_{n\to\infty} \frac{n\cdot 3^n}{(n+1)\cdot 3^{n+1}} = \frac{1}{3}$$

$R = 1/\rho = 3$。

检验端点：
- $x=3$：$\displaystyle\sum \frac{1}{n}$ 发散（调和级数）。
- $x=-3$：$\displaystyle\sum \frac{(-1)^n}{n}$ 条件收敛（交错调和级数）。

收敛域为 $[-3, 3)$。

求和函数。令 $S(x) = \displaystyle\sum_{n=1}^\infty \frac{x^n}{n\cdot 3^n}$，$|x| < 3$。

逐项求导：

$$S'(x) = \sum_{n=1}^\infty \frac{x^{n-1}}{3^n} = \frac{1}{3}\sum_{n=0}^\infty \left(\frac{x}{3}\right)^n = \frac{1}{3}\cdot\frac{1}{1-x/3} = \frac{1}{3-x}$$

积分（注意 $S(0)=0$）：

$$S(x) = \int_0^x \frac{dt}{3-t} = -\ln(3-t)\Big|_0^x = \ln\frac{3}{3-x}$$

$x=-3$ 时用 Abel 定理，$\lim_{x\to-3^+} S(x) = \ln\frac{3}{6} = -\ln 2$，级数和为 $-\ln 2$。

$$\boxed{\text{收敛域：}[-3,\,3),\quad S(x)=\ln\dfrac{3}{3-x}\;(|x|<3)}$$

### 题18 — 困难

求级数和：

$$S = \sum_{n=1}^\infty \frac{1}{n(n+1)(n+2)}$$

#### 思路溯源

分母为三个相邻整数的乘积，标准手法是部分分式裂项，使各项形成望远镜（telescoping）结构。

#### 解法

设

$$\frac{1}{n(n+1)(n+2)} = \frac{A}{n} + \frac{B}{n+1} + \frac{C}{n+2}$$

乘 $n(n+1)(n+2)$ 并比较系数得 $A = \frac{1}{2}$，$B = -1$，$C = \frac{1}{2}$。

故

$$\frac{1}{n(n+1)(n+2)} = \frac{1}{2}\left(\frac{1}{n} - \frac{2}{n+1} + \frac{1}{n+2}\right)$$

进一步拆为望远镜形式：

$$= \frac{1}{2}\left[\left(\frac{1}{n} - \frac{1}{n+1}\right) - \left(\frac{1}{n+1} - \frac{1}{n+2}\right)\right]$$

$$S_N = \frac{1}{2}\sum_{n=1}^N \left[\left(\frac{1}{n} - \frac{1}{n+1}\right) - \left(\frac{1}{n+1} - \frac{1}{n+2}\right)\right]$$

前一半裂项和 $= 1 - \dfrac{1}{N+1}$，后一半裂项和 $= \dfrac{1}{2} - \dfrac{1}{N+2}$。

$$S_N = \frac{1}{2}\left[\left(1 - \frac{1}{N+1}\right) - \left(\frac{1}{2} - \frac{1}{N+2}\right)\right]$$

令 $N\to\infty$：

$$S = \frac{1}{2}\left(1 - \frac{1}{2}\right) = \frac{1}{4}$$

$$\boxed{S = \dfrac{1}{4}}$$

### 题19 — 地狱

判别级数 $\displaystyle\sum_{n=1}^\infty \frac{(2n-1)!!}{(2n)!!}$ 的敛散性（若收敛，指明是条件收敛还是绝对收敛）。

#### 思路溯源

双阶乘比值 $\frac{(2n-1)!!}{(2n)!!} = \frac{1\cdot3\cdot5\cdots(2n-1)}{2\cdot4\cdot6\cdots(2n)}$，可用 Wallis 渐近式或 Raabe 判别法。比值法极限为 $1$（失效），需用更高阶的审敛法（Raabe 判别法）。

#### 解法

记 $a_n = \dfrac{(2n-1)!!}{(2n)!!} > 0$。

比值法：

$$\frac{a_{n+1}}{a_n} = \frac{2n+1}{2n+2} \to 1 \quad (n\to\infty)$$

比值法失效。用 Raabe 判别法，计算

$$n\left(\frac{a_n}{a_{n+1}} - 1\right) = n\left(\frac{2n+2}{2n+1} - 1\right) = n\cdot\frac{1}{2n+1} \to \frac{1}{2} < 1$$

Raabe 判别法：当 $\lim n(a_n/a_{n+1}-1) < 1$ 时，正项级数发散。

故原级数发散。

$$\boxed{\text{发散}}$$

### 题20 — 地狱

判别级数 $\displaystyle\sum_{n=2}^\infty (-1)^n \frac{\ln n}{\sqrt{n}}$ 的敛散性（若收敛，指明是条件收敛还是绝对收敛）。

#### 思路溯源

$|a_n| = \ln n/\sqrt{n}$。$\sum \ln n/\sqrt{n}$ 发散（与 $1/n^{1/2}$ 比较）。需判断是否条件收敛：验证 Leibniz 判别法的两个条件——$a_n \to 0$ 且 $a_n$ 最终单调递减。

#### 解法

绝对收敛性：$|a_n| = \dfrac{\ln n}{\sqrt{n}}$。当 $n \geq 3$ 时，$\ln n > 1$，故 $\dfrac{\ln n}{\sqrt{n}} > \dfrac{1}{\sqrt{n}}$，而 $\sum \dfrac{1}{\sqrt{n}}$ 发散（$p=1/2$）。由比较判别法，$\sum |a_n|$ 发散。

条件收敛性：验证 Leibniz 判别法。

(1) $\lim_{n\to\infty} \dfrac{\ln n}{\sqrt{n}} = 0$。

(2) 令 $f(x) = \dfrac{\ln x}{\sqrt{x}}$（$x>0$）。求导：

$$f'(x) = \frac{\frac{1}{x}\cdot\sqrt{x} - \ln x \cdot \frac{1}{2\sqrt{x}}}{x} = \frac{2 - \ln x}{2x^{3/2}}$$

当 $x > e^2 \approx 7.39$ 时 $f'(x) < 0$，即 $n \geq 8$ 时 $a_n$ 单调递减。

Leibniz 条件满足，故交错级数收敛。结合 $\sum |a_n|$ 发散，原级数条件收敛。

$$\boxed{\text{条件收敛}}$$

## 五、多元函数题 (3题)

### 题21 — 困难

设 $z = f(x,y)$ 由方程组

$$\begin{cases}
x = u + v \\
y = u^2 + v^2
\end{cases}$$

隐式定义，其中 $u, v$ 为中间变量。求 Jacobi 行列式 $\dfrac{\partial(u,v)}{\partial(x,y)}$。

#### 思路溯源

已知 $(x,y)$ 关于 $(u,v)$ 的函数，需求其逆变换的 Jacobi 行列式。由逆映射定理，$\dfrac{\partial(u,v)}{\partial(x,y)} = \left[\dfrac{\partial(x,y)}{\partial(u,v)}\right]^{-1}$。

#### 解法

计算 $\dfrac{\partial(x,y)}{\partial(u,v)}$：

$$\frac{\partial(x,y)}{\partial(u,v)} = \begin{vmatrix}
\frac{\partial x}{\partial u} & \frac{\partial x}{\partial v} \\[4pt]
\frac{\partial y}{\partial u} & \frac{\partial y}{\partial v}
\end{vmatrix} = \begin{vmatrix}
1 & 1 \\
2u & 2v
\end{vmatrix} = 2v - 2u = 2(v-u)$$

由逆映射定理：

$$\frac{\partial(u,v)}{\partial(x,y)} = \left[\frac{\partial(x,y)}{\partial(u,v)}\right]^{-1} = \frac{1}{2(v-u)}$$

用 $x,y$ 表示 $v-u$：由 $x^2 - y = (u+v)^2 - (u^2+v^2) = 2uv$，$(v-u)^2 = v^2+u^2-2uv = y - 2uv = y - (x^2-y) = 2y - x^2$。

故 $|v-u| = \sqrt{2y-x^2}$（假定 $v>u$，则 $v-u = \sqrt{2y-x^2}$）。

$$\boxed{\dfrac{\partial(u,v)}{\partial(x,y)} = \dfrac{1}{2\sqrt{2y-x^2}}}$$

### 题22 — 困难

计算二重积分：

$$I = \iint_D \sqrt{x^2+y^2}\,dx\,dy$$

其中 $D$ 为 $x^2 + y^2 \leq 2x$。

#### 思路溯源

积分区域 $x^2+y^2 \leq 2x$ 即 $(x-1)^2 + y^2 \leq 1$，是以 $(1,0)$ 为圆心、$1$ 为半径的圆域。被积函数 $\sqrt{x^2+y^2} = r$，适合极坐标变换。

#### 解法

令 $x = r\cos\theta$，$y = r\sin\theta$，$dx\,dy = r\,dr\,d\theta$。

区域边界 $x^2+y^2 = 2x$ 化为 $r^2 = 2r\cos\theta$，即 $r = 2\cos\theta$（$r>0$ 部分）。$\theta$ 范围：$\cos\theta \geq 0$，即 $-\pi/2 \leq \theta \leq \pi/2$。

$$I = \int_{-\pi/2}^{\pi/2} d\theta \int_0^{2\cos\theta} r \cdot r\,dr = \int_{-\pi/2}^{\pi/2} d\theta \int_0^{2\cos\theta} r^2\,dr$$

$$= \int_{-\pi/2}^{\pi/2} \frac{(2\cos\theta)^3}{3}\,d\theta = \frac{8}{3}\int_{-\pi/2}^{\pi/2} \cos^3\theta\,d\theta$$

$\cos^3\theta$ 为偶函数，积分化为 $2\int_0^{\pi/2}$。由 Wallis 公式：

$$\int_0^{\pi/2} \cos^3\theta\,d\theta = \frac{2}{3}$$

故

$$I = \frac{8}{3} \times 2 \times \frac{2}{3} = \frac{32}{9}$$

$$\boxed{I = \dfrac{32}{9}}$$

### 题23 — 地狱

求二元函数 $f(x,y) = x^2 + 2y^2 - 2x - 4y + xy$ 在闭三角形区域 $D$（顶点为 $(0,0), (3,0), (0,3)$）上的最大值与最小值。

#### 思路溯源

闭区域上的最值需分两步：(1) 内部驻点（令偏导为零）；(2) 三条边界上的最值（化为单变量函数）。

#### 解法

**第一步**：求内部驻点。

$$\frac{\partial f}{\partial x} = 2x - 2 + y = 0$$
$$\frac{\partial f}{\partial y} = 4y - 4 + x = 0$$

由 (1) 得 $y = 2 - 2x$，代入 (2)：$4(2-2x) - 4 + x = 8 - 8x - 4 + x = 4 - 7x = 0$，$x = 4/7$。

$y = 2 - 8/7 = 6/7$。

$(4/7, 6/7)$ 在三角形内部。$f(4/7, 6/7) = \dfrac{16}{49} + \dfrac{72}{49} - \dfrac{8}{7} - \dfrac{24}{7} + \dfrac{24}{49} = \dfrac{112}{49} - \dfrac{32}{7} = \dfrac{16}{7} - \dfrac{32}{7} = -\dfrac{16}{7}$。

**第二步**：三条边界。

边界 $L_1$：$y=0$，$x\in[0,3]$。$f(x,0) = x^2 - 2x = (x-1)^2 - 1$。最小值 $-1$（$x=1$），最大值 $3$（$x=3$）。

边界 $L_2$：$x=0$，$y\in[0,3]$。$f(0,y) = 2y^2 - 4y = 2(y-1)^2 - 2$。最小值 $-2$（$y=1$），最大值 $6$（$y=3$）。

边界 $L_3$：$x+y=3$，$x\in[0,3]$。代入 $y=3-x$：

$$f(x,3-x) = x^2 + 2(3-x)^2 - 2x - 4(3-x) + x(3-x)$$
$$= x^2 + 2(9-6x+x^2) - 2x - 12 + 4x + 3x - x^2$$
$$= x^2 + 18 - 12x + 2x^2 - 2x - 12 + 4x + 3x - x^2$$
$$= 2x^2 - 7x + 6$$

令 $g(x) = 2x^2 - 7x + 6$，$x\in[0,3]$。$g'(x) = 4x - 7 = 0$，$x = 7/4 \in [0,3]$。

$g(0) = 6$，
$g(7/4) = 2\cdot\frac{49}{16} - \frac{49}{4} + 6 = \frac{49}{8} - \frac{98}{8} + 6 = -\frac{49}{8} + 6 = -\frac{1}{8}$，
$g(3) = 18 - 21 + 6 = 3$。

**第三步**：汇总比较。

所有候选值：$-\frac{16}{7} \approx -2.29$，$-1$，$-2$，$-\frac{1}{8}$，$3$，$6$。

$$\boxed{\min_D f = -\dfrac{16}{7},\quad \max_D f = 6}$$

## 六、概念题 (2题)

### 题24 — 困难

判断函数 $f(x) = \sin(x^2)$ 在 $\mathbb{R}$ 上是否一致连续，并证明你的结论。

#### 思路溯源

一致连续的定义：$\forall\varepsilon>0, \exists\delta>0$ 使 $|x_1-x_2|<\delta \Rightarrow |f(x_1)-f(x_2)|<\varepsilon$。对于振荡频率随 $|x|$ 增大而增大的函数，直观上不一致连续（如 $\sin(x^2)$ 在无穷远处任意小的区间内可完成多次全振幅振荡）。

#### 解法

$f(x) = \sin(x^2)$ 在 $\mathbb{R}$ 上**不一致连续**。

证：取 $x_n = \sqrt{2n\pi}$，$y_n = \sqrt{2n\pi + \pi/2}$。

则 $f(x_n) = \sin(2n\pi) = 0$，$f(y_n) = \sin(2n\pi + \pi/2) = 1$，$|f(x_n)-f(y_n)| = 1$。

但

$$|x_n - y_n| = \sqrt{2n\pi + \frac{\pi}{2}} - \sqrt{2n\pi}$$

$$= \frac{\pi/2}{\sqrt{2n\pi+\pi/2} + \sqrt{2n\pi}} \to 0 \quad (n\to\infty)$$

即存在 $\varepsilon_0 = 1/2$（或 $1$），对任意 $\delta > 0$，当 $n$ 充分大时 $|x_n-y_n|<\delta$ 但 $|f(x_n)-f(y_n)| = 1 > \varepsilon_0$。这与一致连续的定义矛盾。

故 $f(x) = \sin(x^2)$ 在 $\mathbb{R}$ 上不一致连续。

$$\boxed{\text{不一致连续}}$$

### 题25 — 地狱

讨论含参变量反常积分

$$I(\alpha) = \int_0^\infty \frac{\sin(\alpha x)}{x}\,dx$$

关于 $\alpha \in \mathbb{R}$ 的一致收敛性。

#### 思路溯源

这是经典的 Dirichlet 积分。$\int_0^\infty \sin(\alpha x)/x\,dx = \frac{\pi}{2}\operatorname{sgn}(\alpha)$，但被积函数在 $x=0$ 和 $x\to\infty$ 两端都需要考虑。一致收敛性需看积分是否对 $\alpha$ 一致收敛——即能否在积分号下取极限或求导。

#### 解法

记 $I(\alpha) = \int_0^\infty \frac{\sin(\alpha x)}{x}\,dx$。作变量代换 $t = |\alpha|x$。

当 $\alpha > 0$ 时：$I(\alpha) = \int_0^\infty \frac{\sin t}{t}\,dt = \frac{\pi}{2}$。

当 $\alpha < 0$ 时：$I(\alpha) = \int_0^\infty \frac{\sin(-|\alpha|x)}{x}dx = -\int_0^\infty \frac{\sin t}{t}dt = -\frac{\pi}{2}$。

当 $\alpha = 0$ 时：$I(0) = 0$。

$I(\alpha)$ 在 $\alpha=0$ 处有跳跃间断：$\lim_{\alpha\to 0^+} I(\alpha) = \pi/2 \neq I(0) = 0$。

若该积分关于 $\alpha$ 在某区间（含 $0$）上一致收敛，则 $I(\alpha)$ 在该区间上应连续（一致收敛积分的连续性定理）。但 $I(\alpha)$ 在 $\alpha=0$ 处不连续，故积分在含 $\alpha=0$ 的任何区间上**不一致收敛**。

对于不含原点的闭区间 $[\alpha_1,\alpha_2]$（$\alpha_1>0$ 或 $\alpha_2<0$），由 Dirichlet 判别法可证一致收敛。

$$\boxed{\text{在含}\;\alpha=0\;\text{的区间上不一致收敛，在}\;\alpha\;\text{有正下界(或负上界)时一致收敛}}$$
