## 一、微分（中值定理 · 综合应用）

### 题 1

> 设 $f(x)$ 在 $[0,1]$ 上连续，在 $(0,1)$ 内可导，且 $f(0)=0$，$f(1)=1$。
>
> (1) 证明：存在 $c \in (0,1)$，使得 $f(c) = 1-c$。
>
> (2) 证明：存在 $\xi,\eta \in (0,1)$ 且 $\xi\neq\eta$，使得 $f'(\xi)\,f'(\eta) = 1$。

**思路溯源**

(1) 将结论 $f(c)=1-c$ 改写为 $f(c)+c-1=0$，构造辅助函数 $g(x)=f(x)+x-1$，利用介值定理。

(2) 由 (1) 知 $f(c)$ 与 $c$ 的关系。在 $[0,c]$ 和 $[c,1]$ 上分别用 Lagrange 中值定理，两个导数与 $c$ 的关系恰好互为倒数。

**解法**：

**(1)** 令 $g(x) = f(x) + x - 1$。$g(x)$ 在 $[0,1]$ 上连续。

$$g(0) = f(0) + 0 - 1 = -1 < 0, \qquad g(1) = f(1) + 1 - 1 = 1 > 0$$

由**介值定理**，存在 $c \in (0,1)$ 使得 $g(c) = 0$，即 $f(c) + c - 1 = 0$，亦即 $f(c) = 1-c$。

**(2)** $f(x)$ 在 $[0,c]$ 上满足 Lagrange 中值定理条件，存在 $\xi \in (0,c)$ 使

$$f'(\xi) = \frac{f(c)-f(0)}{c-0} = \frac{(1-c)-0}{c} = \frac{1-c}{c}$$

$f(x)$ 在 $[c,1]$ 上满足 Lagrange 中值定理条件，存在 $\eta \in (c,1)$ 使

$$f'(\eta) = \frac{f(1)-f(c)}{1-c} = \frac{1-(1-c)}{1-c} = \frac{c}{1-c}$$

两式相乘：

$$f'(\xi)\,f'(\eta) = \frac{1-c}{c} \cdot \frac{c}{1-c} = 1$$

由 $\xi \in (0,c)$ 且 $\eta \in (c,1)$ 知 $\xi < c < \eta$，故 $\xi \neq \eta$。证毕。

### 题 2

> 设 $f(x)$ 在 $[0,\pi]$ 上连续，在 $(0,\pi)$ 内可导。
>
> 证明：存在 $\xi \in (0,\pi)$，使得 $f'(\xi)\sin\xi + f(\xi)\cos\xi = 0$。

**思路溯源**

结论 $f'(x)\sin x + f(x)\cos x$ 恰为 $[f(x)\sin x]'$（乘积求导结果）。构造 $F(x) = f(x)\sin x$，注意到 $\sin 0 = \sin \pi = 0$，因此 **无需 $f$ 在端点的任何额外条件**，$F(0)=F(\pi)=0$ 自然成立，直接 Rolle。

**解法**：

令 $F(x) = f(x)\sin x$。$F(x)$ 在 $[0,\pi]$ 上连续，在 $(0,\pi)$ 内可导。

$$F(0) = f(0)\sin 0 = 0, \qquad F(\pi) = f(\pi)\sin\pi = 0$$

由 **Rolle 定理**，存在 $\xi \in (0,\pi)$ 使得 $F'(\xi) = 0$。

$$F'(x) = f'(x)\sin x + f(x)\cos x$$

$$F'(\xi) = f'(\xi)\sin\xi + f(\xi)\cos\xi = 0$$

证毕。

> 💡 **亮点**：本题是极少见的"无需给 $f$ 加端点条件"的中值定理题——$\sin x$ 在两端点自然取零，承担了所有端点验证的负担。这种"构造函数自带端点归零"的思路值得牢记。

### 题 3

> 设 $f(x)$ 在 $[0,1]$ 上二阶可导，$f(0) = f(1) = 0$，且 $\displaystyle\min_{x\in[0,1]} f(x) = -1$。
>
> 证明：存在 $\xi \in (0,1)$，使得 $f''(\xi) \geq 8$。

**思路溯源**

最小值在某个内点 $x_0$ 处取得，由 Fermat 引理得 $f'(x_0)=0$。在 $x_0$ 处将 $f(0)$ 和 $f(1)$ 作 Taylor 展开（带 Lagrange 余项的一阶展开），解出两处二阶导数与 $x_0$ 的关系。利用 $x_0(1-x_0) \leq \frac{1}{4}$ 得到二阶导数的下界。

**解法**：

因为 $f(x)$ 在 $[0,1]$ 上连续，必有最小值。设 $x_0 \in (0,1)$ 使得 $f(x_0) = -1$（最小值在区间内部取到，因为端点值为 $0$）。

由 **Fermat 引理**（极值点处导数为零），$f'(x_0) = 0$。

在 $x_0$ 处将 $f(0)$ 和 $f(1)$ 作 **Taylor 展开**（一阶展开 + Lagrange 余项）：

$$f(0) = f(x_0) + f'(x_0)(0 - x_0) + \frac{f''(\xi_1)}{2}(0 - x_0)^2 = -1 + \frac{f''(\xi_1)}{2}x_0^2 = 0 \quad (\xi_1 \in (0, x_0))$$

$$\Rightarrow \;\; f''(\xi_1) = \frac{2}{x_0^2}$$

$$f(1) = f(x_0) + f'(x_0)(1 - x_0) + \frac{f''(\xi_2)}{2}(1 - x_0)^2 = -1 + \frac{f''(\xi_2)}{2}(1-x_0)^2 = 0 \quad (\xi_2 \in (x_0, 1))$$

$$\Rightarrow \;\; f''(\xi_2) = \frac{2}{(1-x_0)^2}$$

现在分类讨论：
- 若 $x_0 \leq \frac{1}{2}$，则 $x_0^2 \leq \frac{1}{4}$，故 $f''(\xi_1) = \frac{2}{x_0^2} \geq 8$，取 $\xi = \xi_1$。
- 若 $x_0 \geq \frac{1}{2}$，则 $(1-x_0)^2 \leq \frac{1}{4}$，故 $f''(\xi_2) = \frac{2}{(1-x_0)^2} \geq 8$，取 $\xi = \xi_2$。

综上，无论哪种情况，均存在 $\xi \in (0,1)$ 使得 $f''(\xi) \geq 8$。证毕。

> 💡 **亮点**：本题是 Taylor 展开在证明题中的经典应用——"已知函数值和最值信息，推出导数/二阶导数的界"。核心技巧：在最值点处展开到端点。

## 二、积分

### 题 4 — 表格法（分部积分的快捷形式）

> 计算不定积分：$\displaystyle \int x^3 e^x\,dx$

**思路溯源**

多项式 $x^3$ 乘以 $e^x$。分部积分一次降幂一次，需反复 3 次。用 **表格法**（Tabular Integration）避免逐次书写：对 $x^3$ 逐次求导直到归零，对 $e^x$ 逐次积分，正负号交替，各项相乘即得结果。

**解法**：

构造表格（D = 求导列，I = 积分列）：

| 符号 | D（对 $x^3$ 求导） | I（对 $e^x$ 积分） |
| :---: | :--- | :--- |
| + | $x^3$ | $e^x$ |
| − | $3x^2$ | $e^x$ |
| + | $6x$ | $e^x$ |
| − | $6$ | $e^x$ |
| + | $0$ | $e^x$ |

将同行 D 与 I 相乘，乘以符号列后求和：

$$\begin{aligned}
\int x^3 e^x\,dx
&= +\,x^3 e^x - 3x^2 e^x + 6x e^x - 6 e^x + C \\[4pt]
&= e^x(x^3 - 3x^2 + 6x - 6) + C
\end{aligned}$$

> 验证：求导 $[e^x(x^3-3x^2+6x-6)]' = e^x(x^3-3x^2+6x-6 + 3x^2-6x+6) = e^x \cdot x^3 = x^3 e^x$。✓

$$\boxed{\int x^3 e^x\,dx = e^x(x^3 - 3x^2 + 6x - 6) + C}$$

### 题 5 — 区间再现

> 计算定积分：$\displaystyle \int_0^\pi \frac{x\sin x}{1+\cos^2 x}\,dx$

**思路溯源**

被积函数含 $x \cdot f(\sin x, \cos x)$ 型，且积分区间为 $[0,\pi]$。这是"区间再现换元"的标准信号。令 $t = \pi - x$，原积分与新积分相加后 $x$ 项抵消。后续利用 $\sin x\,dx = -d(\cos x)$ 凑微分。

**解法**：

记 $\displaystyle I = \int_0^\pi \frac{x\sin x}{1+\cos^2 x}\,dx$。

令 $t = \pi - x$，则 $dx = -dt$。当 $x = 0$ 时 $t = \pi$，$x = \pi$ 时 $t = 0$。

$$\begin{aligned}
I &= \int_\pi^0 \frac{(\pi-t)\,\sin(\pi-t)}{1+\cos^2(\pi-t)}(-dt) \\[4pt]
  &= \int_0^\pi \frac{(\pi-t)\sin t}{1+\cos^2 t}\,dt \\[4pt]
  &= \pi\int_0^\pi \frac{\sin t}{1+\cos^2 t}\,dt - \int_0^\pi \frac{t\sin t}{1+\cos^2 t}\,dt \\[4pt]
  &= \pi\int_0^\pi \frac{\sin x}{1+\cos^2 x}\,dx - I
\end{aligned}$$

移项得：

$$2I = \pi\int_0^\pi \frac{\sin x}{1+\cos^2 x}\,dx$$

令 $u = \cos x$，则 $du = -\sin x\,dx$。当 $x = 0$ 时 $u = 1$，$x = \pi$ 时 $u = -1$。

$$\int_0^\pi \frac{\sin x}{1+\cos^2 x}\,dx = \int_1^{-1}\frac{-du}{1+u^2} = \int_{-1}^1\frac{du}{1+u^2} = \Bigl[\arctan u\Bigr]_{-1}^1 = \frac{\pi}{4} - \left(-\frac{\pi}{4}\right) = \frac{\pi}{2}$$

代回：

$$2I = \pi \cdot \frac{\pi}{2} = \frac{\pi^2}{2}$$

$$\boxed{\int_0^\pi \frac{x\sin x}{1+\cos^2 x}\,dx = \frac{\pi^2}{4}}$$

### 题 6 — 分子加减法

> 计算不定积分：$\displaystyle \int\frac{dx}{1+e^x}$

**思路溯源**

分母含 $e^x$，常用两种思路：① 分子分母同乘 $e^{-x}$，化为 $\int \frac{e^{-x}}{e^{-x}+1}dx$ 后凑微分；② 分子加减 $e^x$：$\frac{1}{1+e^x} = \frac{1+e^x-e^x}{1+e^x} = 1 - \frac{e^x}{1+e^x}$。

**解法**（采用思路②，更直观）：

$$\begin{aligned}
\int\frac{dx}{1+e^x}
&= \int\frac{1+e^x-e^x}{1+e^x}\,dx \\[4pt]
&= \int\!\left(1 - \frac{e^x}{1+e^x}\right)dx \\[4pt]
&= \int 1\,dx - \int\frac{d(1+e^x)}{1+e^x} \\[4pt]
&= x - \ln(1+e^x) + C
\end{aligned}$$

$$\boxed{\int\frac{dx}{1+e^x} = x - \ln(1+e^x) + C}$$

> 💡 思路①的等价结果：分子分母同乘 $e^{-x}$ 得 $-\ln(e^{-x}+1)+C$，展开后与上式一致。

### 题 7 — 根式换元

> 计算不定积分：$\displaystyle \int\sqrt{e^x-1}\,dx$

**思路溯源**

被积函数含 $\sqrt{e^x-1}$，令 $t = \sqrt{e^x-1}$，则 $e^x = t^2+1$，$x = \ln(t^2+1)$，$dx = \frac{2t}{t^2+1}dt$。根号消失，化为有理函数积分。最后用 $t^2/(t^2+1) = 1 - 1/(t^2+1)$ 拆分。

**解法**：

令 $t = \sqrt{e^x-1}$，则 $t \geq 0$，$e^x = t^2+1$，$x = \ln(t^2+1)$。

$$dx = \frac{2t}{t^2+1}\,dt$$

$$\begin{aligned}
\int\sqrt{e^x-1}\,dx
&= \int t \cdot \frac{2t}{t^2+1}\,dt \\[4pt]
&= 2\int\frac{t^2}{t^2+1}\,dt \\[4pt]
&= 2\int\!\left(1 - \frac{1}{t^2+1}\right)dt \\[4pt]
&= 2\!\left(t - \arctan t\right) + C
\end{aligned}$$

回代 $t = \sqrt{e^x-1}$：

$$\boxed{\int\sqrt{e^x-1}\,dx = 2\sqrt{e^x-1} - 2\arctan\sqrt{e^x-1} + C}$$

### 题 8 — 反常积分 + 部分分式

> 计算反常积分：$\displaystyle \int_0^\infty\frac{dx}{(x^2+1)(x^2+4)}$

**思路溯源**

被积函数分母为两个二次不可约因式的乘积。将 $\frac{1}{(x^2+1)(x^2+4)}$ 拆分为 $\frac{A}{x^2+1} + \frac{B}{x^2+4}$ 的形式（以 $x^2$ 为变量的部分分式法）。拆得两项分别积出 $\arctan$，代入无穷限即得结果。

**解法**：

**第一步：部分分式分解。** 设

$$\frac{1}{(x^2+1)(x^2+4)} = \frac{A}{x^2+1} + \frac{B}{x^2+4}$$

通分比较分子：

$$1 = A(x^2+4) + B(x^2+1) = (A+B)x^2 + (4A+B)$$

比较系数得：

$$\begin{cases}
A + B = 0 \\
4A + B = 1
\end{cases}
\quad\Rightarrow\quad 3A = 1,\; A = \frac{1}{3},\; B = -\frac{1}{3}$$

$$\frac{1}{(x^2+1)(x^2+4)} = \frac{1}{3}\cdot\frac{1}{x^2+1} - \frac{1}{3}\cdot\frac{1}{x^2+4}$$

**第二步：逐项积分。**

$$\begin{aligned}
\int_0^\infty\frac{dx}{(x^2+1)(x^2+4)}
&= \frac{1}{3}\int_0^\infty\frac{dx}{x^2+1} - \frac{1}{3}\int_0^\infty\frac{dx}{x^2+4} \\[4pt]
&= \frac{1}{3}\Bigl[\arctan x\Bigr]_0^\infty - \frac{1}{3}\cdot\frac{1}{2}\Bigl[\arctan\frac{x}{2}\Bigr]_0^\infty \\[4pt]
&= \frac{1}{3}\cdot\frac{\pi}{2} - \frac{1}{6}\cdot\frac{\pi}{2} \\[4pt]
&= \frac{\pi}{6} - \frac{\pi}{12} = \frac{\pi}{12}
\end{aligned}$$

$$\boxed{\int_0^\infty\frac{dx}{(x^2+1)(x^2+4)} = \frac{\pi}{12}}$$
