## 一、微分（中值定理 · 辅助函数构造）

### 题 1

> 设 $f(x)$ 在 $[0,1]$ 上连续，在 $(0,1)$ 内可导，且 $f(0)=f(1)=0$。
>
> 证明：存在 $\xi \in (0,1)$，使得 $f'(\xi) + f(\xi) = 0$。

**思路溯源**

结论中含有 $f'(\xi) + f(\xi) = 0$，即 $f'(\xi) = -f(\xi)$。与 05-28 题 1（$f'(\xi)=f(\xi)$，构造 $F(x)=e^{-x}f(x)$）对比，两者仅差一个符号。若构造 $F(x) = e^x f(x)$，求导得 $F'(x) = e^x f(x) + e^x f'(x) = e^x[f'(x) + f(x)]$，Rolle 定理即可迫使括号为零。该构造的通则是：结论形如 $f' + kf = 0$ 时，辅助函数取 $F(x)=e^{kx}f(x)$。

**解法**：

令 $F(x) = e^x f(x)$。$F(x)$ 在 $[0,1]$ 上连续，在 $(0,1)$ 内可导。

$$F(0) = e^0 f(0) = 0,\qquad F(1) = e^1 f(1) = 0$$

由 Rolle 定理，存在 $\xi \in (0,1)$ 使 $F'(\xi) = 0$。

$$F'(x) = e^x f(x) + e^x f'(x) = e^x\bigl[f'(x) + f(x)\bigr]$$

$$F'(\xi) = e^\xi\bigl[f'(\xi) + f(\xi)\bigr] = 0$$

由 $e^\xi \neq 0$ 得 $f'(\xi) + f(\xi) = 0$。证毕。

### 题 2

> 设 $f(x)$ 在 $[0,1]$ 上二阶可导，且 $f(0) = 0$，$f'(0) = 0$，$f(1) = 1$。
>
> 证明：存在 $\xi \in (0,1)$，使得 $f''(\xi) = 2$。

**思路溯源**

条件中 $f(0)=f'(0)=0$ 暗示在 $x=0$ 处的一阶近似为零，因此 $f(1)=1$ 的"全部贡献"来自二阶及以上项。这恰好是 Taylor 公式带 Lagrange 余项的标准信号——在 $x=0$ 处展开到二阶，余项中的 $f''(\xi)$ 将被迫承担 $f(1)$ 的全部值。

**解法**：

将 $f(x)$ 在 $x=0$ 处展开为一阶 Taylor 公式，带 Lagrange 余项：

$$f(x) = f(0) + f'(0)x + \frac{f''(\xi_x)}{2}x^2$$

其中 $\xi_x$ 介于 $0$ 与 $x$ 之间。代入 $f(0)=0$，$f'(0)=0$：

$$f(x) = \frac{f''(\xi_x)}{2}x^2$$

取 $x = 1$：

$$f(1) = \frac{f''(\xi)}{2} \cdot 1^2 = \frac{f''(\xi)}{2}$$

其中 $\xi = \xi_1 \in (0,1)$。代入 $f(1) = 1$：

$$\frac{f''(\xi)}{2} = 1 \quad\Longrightarrow\quad f''(\xi) = 2$$

证毕。

### 题 3

> 设 $f(x)$ 在 $[0,1]$ 上连续，在 $(0,1)$ 内可导，且 $f(0) = 0$，$f(1) = 1$。
>
> 证明：存在两个不同的点 $\xi, \eta \in (0,1)$，使得 $f'(\xi) \cdot f'(\eta) = 1$。

**思路溯源**

结论涉及两个中值的乘积为 $1$。观察：若能在 $(0,1)$ 内找到一点 $c$ 使 $f(c) = 1-c$，则在 $[0,c]$ 和 $[c,1]$ 上分别使用 Lagrange 中值定理，所得两个导数值会互为倒数（因为分母 $c$ 和 $1-c$ 分别与分子 $1-c$ 和 $c$ 交叉抵消）。而 $f(c) = 1-c$ 即 $f(c)+c=1$，令 $g(x)=f(x)+x$，由 $g(0)=0$，$g(1)=2$，介值定理保证这样的 $c$ 存在。

**解法**：

令 $g(x) = f(x) + x$。$g(x)$ 在 $[0,1]$ 上连续。

$$g(0) = f(0) + 0 = 0,\qquad g(1) = f(1) + 1 = 2$$

由介值定理，存在 $c \in (0,1)$ 使 $g(c) = 1$，即

$$f(c) = 1 - c$$

对 $f(x)$ 在 $[0,c]$ 上应用 Lagrange 中值定理，存在 $\xi \in (0,c)$ 使

$$f'(\xi) = \frac{f(c) - f(0)}{c - 0} = \frac{1-c}{c}$$

对 $f(x)$ 在 $[c,1]$ 上应用 Lagrange 中值定理，存在 $\eta \in (c,1)$ 使

$$f'(\eta) = \frac{f(1) - f(c)}{1 - c} = \frac{1 - (1-c)}{1-c} = \frac{c}{1-c}$$

两式相乘：

$$f'(\xi) \cdot f'(\eta) = \frac{1-c}{c} \cdot \frac{c}{1-c} = 1$$

且 $\xi \in (0,c)$，$\eta \in (c,1)$，故 $\xi \neq \eta$。证毕。

## 二、积分

### 题 4 — 分部积分（对数 $\times$ 幂）

> 计算不定积分：$\displaystyle \int \frac{\ln x}{x^2}\,dx \quad (x>0)$

**思路溯源**

被积函数是 $\ln x$ 乘以 $x^{-2}$。按"反对幂指三"口诀，对数函数优先选作 $u$。$u = \ln x$ 求导得 $1/x$，$dv = x^{-2}dx$ 积分得 $-1/x$。分部后新的积分 $\int x^{-3}dx$ 为简单幂函数。

**解法**：

取 $u = \ln x$，$dv = x^{-2}\,dx$，则 $du = \frac{1}{x}dx$，$v = -\frac{1}{x}$。

$$\begin{aligned}
\int \frac{\ln x}{x^2}\,dx
&= -\frac{\ln x}{x} - \int \left(-\frac{1}{x}\right) \cdot \frac{1}{x}\,dx \\[4pt]
&= -\frac{\ln x}{x} + \int \frac{1}{x^2}\,dx \\[4pt]
&= -\frac{\ln x}{x} - \frac{1}{x} + C
\end{aligned}$$

$$\boxed{\int \frac{\ln x}{x^2}\,dx = -\frac{\ln x + 1}{x} + C}$$

### 题 5 — 三角恒等换元

> 计算不定积分：$\displaystyle \int \sin^3 x \cos^2 x\,dx$

**思路溯源**

$\sin$ 为奇次幂，可提取一个 $\sin x$ 与 $dx$ 结合为 $-d(\cos x)$，剩余的 $\sin^2 x = 1 - \cos^2 x$ 化为多项式。这比用倍角公式降幂更直接。

**解法**：

$$\begin{aligned}
\int \sin^3 x \cos^2 x\,dx
&= \int \sin^2 x \cos^2 x \cdot \sin x\,dx \\[4pt]
&= \int (1 - \cos^2 x) \cos^2 x \cdot \sin x\,dx
\end{aligned}$$

令 $u = \cos x$，则 $du = -\sin x\,dx$，$\sin x\,dx = -du$。

$$\begin{aligned}
&= \int (1 - u^2) u^2 \cdot (-du) \\[4pt]
&= -\int (u^2 - u^4)\,du \\[4pt]
&= -\left(\frac{u^3}{3} - \frac{u^5}{5}\right) + C \\[4pt]
&= \frac{u^5}{5} - \frac{u^3}{3} + C
\end{aligned}$$

回代 $u = \cos x$：

$$\boxed{\int \sin^3 x \cos^2 x\,dx = \frac{\cos^5 x}{5} - \frac{\cos^3 x}{3} + C}$$

### 题 6 — 分子拆分 + 配方

> 计算不定积分：$\displaystyle \int \frac{x}{x^2+2x+2}\,dx$

**思路溯源**

分母判别式 $\Delta = 4 - 8 = -4 < 0$，不可因式分解。配方得 $(x+1)^2+1$。分子 $x = (x+1) - 1$，拆分后第一项凑微分得 $\ln$，第二项为 $\arctan$ 标准型。

**解法**：

分母配方：

$$x^2+2x+2 = (x+1)^2 + 1$$

分子拆分：

$$\frac{x}{x^2+2x+2} = \frac{(x+1) - 1}{(x+1)^2 + 1} = \frac{x+1}{(x+1)^2+1} - \frac{1}{(x+1)^2+1}$$

分别积分：

$$\begin{aligned}
\int \frac{x+1}{(x+1)^2+1}\,dx
&= \frac{1}{2}\int \frac{2(x+1)}{(x+1)^2+1}\,dx \\[4pt]
&= \frac{1}{2}\ln\!\left[(x+1)^2+1\right] + C_1
\end{aligned}$$

$$\int \frac{1}{(x+1)^2+1}\,dx = \arctan(x+1) + C_2$$

合并：

$$\boxed{\int \frac{x}{x^2+2x+2}\,dx = \frac{1}{2}\ln(x^2+2x+2) - \arctan(x+1) + C}$$

### 题 7 — 有理函数三分式分解

> 计算不定积分：$\displaystyle \int \frac{dx}{(x+1)(x+2)(x+3)}$

**思路溯源**

分母为三个不同的一次因式的乘积。用待定系数法（部分分式分解）将被积函数拆为三项 $\frac{A}{x+1} + \frac{B}{x+2} + \frac{C}{x+3}$ 的和，每项各自积出 $\ln$。系数 $A,B,C$ 可用"遮盖法"（留数法）快速求得。

**解法**：

设

$$\frac{1}{(x+1)(x+2)(x+3)} = \frac{A}{x+1} + \frac{B}{x+2} + \frac{C}{x+3}$$

用遮盖法求系数：

$$A = \left.\frac{1}{(x+2)(x+3)}\right|_{x=-1} = \frac{1}{(1)(2)} = \frac{1}{2}$$

$$B = \left.\frac{1}{(x+1)(x+3)}\right|_{x=-2} = \frac{1}{(-1)(1)} = -1$$

$$C = \left.\frac{1}{(x+1)(x+2)}\right|_{x=-3} = \frac{1}{(-2)(-1)} = \frac{1}{2}$$

故

$$\frac{1}{(x+1)(x+2)(x+3)} = \frac{1/2}{x+1} - \frac{1}{x+2} + \frac{1/2}{x+3}$$

积分：

$$\begin{aligned}
\int \frac{dx}{(x+1)(x+2)(x+3)}
&= \frac{1}{2}\int \frac{dx}{x+1} - \int \frac{dx}{x+2} + \frac{1}{2}\int \frac{dx}{x+3} \\[4pt]
&= \frac{1}{2}\ln|x+1| - \ln|x+2| + \frac{1}{2}\ln|x+3| + C
\end{aligned}$$

利用对数性质合并：

$$\boxed{\int \frac{dx}{(x+1)(x+2)(x+3)} = \frac{1}{2}\ln\left|\frac{(x+1)(x+3)}{(x+2)^2}\right| + C}$$

### 题 8 — 区间再现

> 计算定积分：$\displaystyle I = \int_0^{\frac{\pi}{2}} \frac{\sin x}{\sin x + \cos x}\,dx$

**思路溯源**

被积函数的分母为 $\sin x + \cos x$，分子仅为 $\sin x$。利用对称性：令 $x \to \frac{\pi}{2} - x$，则 $\sin x \leftrightarrow \cos x$ 互换，原积分变为 $\int \frac{\cos x}{\sin x + \cos x}dx$。将两个积分相加，分子恰为 $\sin x + \cos x$，与分母约分，积分化为常数。这是区间再现（"K 字法"）处理对称分母的经典套路。

**解法**：

令 $x = \dfrac{\pi}{2} - t$，则 $dx = -dt$。当 $x=0$ 时 $t=\frac{\pi}{2}$；当 $x=\frac{\pi}{2}$ 时 $t=0$。

$$\begin{aligned}
I &= \int_0^{\frac{\pi}{2}} \frac{\sin x}{\sin x + \cos x}\,dx \\[4pt]
&= \int_{\frac{\pi}{2}}^0 \frac{\sin(\frac{\pi}{2}-t)}{\sin(\frac{\pi}{2}-t) + \cos(\frac{\pi}{2}-t)}(-dt) \\[4pt]
&= \int_0^{\frac{\pi}{2}} \frac{\cos t}{\cos t + \sin t}\,dt
\end{aligned}$$

即

$$I = \int_0^{\frac{\pi}{2}} \frac{\cos x}{\sin x + \cos x}\,dx$$

将原式与上式相加：

$$\begin{aligned}
2I &= \int_0^{\frac{\pi}{2}} \frac{\sin x}{\sin x + \cos x}\,dx + \int_0^{\frac{\pi}{2}} \frac{\cos x}{\sin x + \cos x}\,dx \\[4pt]
&= \int_0^{\frac{\pi}{2}} \frac{\sin x + \cos x}{\sin x + \cos x}\,dx \\[4pt]
&= \int_0^{\frac{\pi}{2}} 1 \cdot dx = \frac{\pi}{2}
\end{aligned}$$

故 $I = \dfrac{\pi}{4}$。

$$\boxed{\int_0^{\frac{\pi}{2}} \frac{\sin x}{\sin x + \cos x}\,dx = \frac{\pi}{4}}$$

| 3 | 题 3 用 $f(c)=1-c$ 而非 $f(c)=c$ | 若取 $f(c)=c$，则 $f'(\xi)=c/c=1$，$f'(\eta)=(1-c)/(1-c)=1$，两导数均为 1 而非乘积为 1；取 $f(c)=1-c$ 才是正确构造 |
| 4 | 题 4 分部积分时 $dv=x^{-2}dx$ 积分得 $v=-x^{-1}$ | 幂次为 $-2$，积分后幂次为 $-1$，符号为负，勿与 $\int x^n dx = x^{n+1}/(n+1)$ 混淆 |
| 5 | 题 5 换元后多出一个负号 | $\sin x\,dx = -du$，两个负号相乘为正：$(1-u^2)u^2\cdot (-du)$ 提出负号后为 $-\int (u^2-u^4)du$ |
| 6 | 题 6 分子拆分：$x=(x+1)-1$ | 分子拆分依赖于分母配方后的平移量，不可直接写 $x = x - (-1)$ 套用 $\frac{x}{x^2+a^2}$ 套路 |
| 7 | 题 7 遮盖法代入时的符号 | $x=-2$ 时 $x+2=0$，遮盖该项后代入其余因式：$1/[(x+1)(x+3)] = 1/[(-1)(1)] = -1$ |
