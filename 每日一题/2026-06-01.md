## 一、微分（中值定理 · 辅助函数构造）

### 题 1

> 设 $f(x)$ 在 $[0,3]$ 上三阶可导，且 $f(0)=f(1)=f(2)=f(3)=0$。
>
> 证明：存在 $\xi \in (0,3)$，使得 $f'''(\xi) = 0$。

**思路溯源**

四个等值点（均为 $0$）分布在区间 $[0,3]$ 上。每次使用 Rolle 定理，导数的零点个数减一，且零点位置被"夹逼"在上一层的零点之间。从 $f$ 的四个零点出发，经三次 Rolle 迭代，$f'''$ 至少有一个零点。这是多重 Rolle 定理的标准链式推理：$f$ 的零点 → $f'$ 的零点 → $f''$ 的零点 → $f'''$ 的零点。

**解法**：

$f(x)$ 在 $[0,3]$ 上三阶可导，故 $f$、$f'$、$f''$ 均在对应区间上连续且可导。

对 $f$ 在 $[0,1]$ 上使用 Rolle 定理，存在 $c_1 \in (0,1)$ 使 $f'(c_1) = 0$。

对 $f$ 在 $[1,2]$ 上使用 Rolle 定理，存在 $c_2 \in (1,2)$ 使 $f'(c_2) = 0$。

对 $f$ 在 $[2,3]$ 上使用 Rolle 定理，存在 $c_3 \in (2,3)$ 使 $f'(c_3) = 0$。

此时 $f'(c_1) = f'(c_2) = f'(c_3) = 0$，且 $0 < c_1 < c_2 < c_3 < 3$。

对 $f'$ 在 $[c_1, c_2]$ 上使用 Rolle 定理，存在 $d_1 \in (c_1, c_2)$ 使 $f''(d_1) = 0$。

对 $f'$ 在 $[c_2, c_3]$ 上使用 Rolle 定理，存在 $d_2 \in (c_2, c_3)$ 使 $f''(d_2) = 0$。

对 $f''$ 在 $[d_1, d_2]$ 上使用 Rolle 定理，存在 $\xi \in (d_1, d_2) \subset (0,3)$ 使 $f'''(\xi) = 0$。

证毕。

### 题 2

> 设 $f(x)$ 在 $[0,1]$ 上二阶可导，且 $f(0) = f(1) = 0$，$\min\limits_{x \in [0,1]} f(x) = -1$。
>
> 证明：存在 $\xi \in (0,1)$，使得 $f''(\xi) \geq 8$。

**思路溯源**

条件给出 $f$ 在两个端点处为零，内部某点 $x_0$ 处取到最小值 $-1$。最小值点处一阶导数为零，因此 $f$ 在 $x_0$ 的 Taylor 展开中一阶项消失——$f(0)$ 和 $f(1)$ 的值只能由二阶项承担。分别对 $0$ 和 $1$ 方向上展开，得到 $f''$ 在两个不同位置的值，它们由 $x_0$ 的位置决定，其中一个必然 $\geq 8$（因为 $x_0$ 与区间某一端点的距离不超过 $1/2$）。

**解法**：

设 $x_0 \in (0,1)$ 为 $f(x)$ 在 $[0,1]$ 上的最小值点，则 $f(x_0) = -1$。由 $x_0$ 是内点且 $f$ 可导，得 $f'(x_0) = 0$。

将 $f(x)$ 在 $x = x_0$ 处展开为一阶 Taylor 公式，带 Lagrange 余项：

$$f(x) = f(x_0) + f'(x_0)(x - x_0) + \frac{f''(\zeta)}{2}(x - x_0)^2 = -1 + \frac{f''(\zeta)}{2}(x - x_0)^2$$

其中 $\zeta$ 介于 $x_0$ 与 $x$ 之间。

代入 $x = 0$：存在 $\xi_1 \in (0, x_0)$ 使 $f(0) = -1 + \dfrac{f''(\xi_1)}{2}(-x_0)^2$，由 $f(0) = 0$ 得

$$f''(\xi_1) = \frac{2}{x_0^2}$$

代入 $x = 1$：存在 $\xi_2 \in (x_0, 1)$ 使 $f(1) = -1 + \dfrac{f''(\xi_2)}{2}(1 - x_0)^2$，由 $f(1) = 0$ 得

$$f''(\xi_2) = \frac{2}{(1 - x_0)^2}$$

若 $x_0 \leq \dfrac{1}{2}$，则 $f''(\xi_1) = \dfrac{2}{x_0^2} \geq \dfrac{2}{(1/2)^2} = 8$。

若 $x_0 > \dfrac{1}{2}$，则 $1 - x_0 < \dfrac{1}{2}$，$f''(\xi_2) = \dfrac{2}{(1-x_0)^2} > 8$。

综上所述，存在 $\xi \in (0,1)$（取 $\xi_1$ 或 $\xi_2$ 中使 $f''$ 值较大者）使 $f''(\xi) \geq 8$。证毕。

### 题 3

> 设 $f(x)$ 在 $[0,1]$ 上连续，在 $(0,1)$ 内可导，且 $f(0) = 0$，$f(1) = 1$。
>
> 证明：存在两个不同的点 $a, b \in (0,1)$，使得 $\displaystyle \frac{1}{f'(a)} + \frac{1}{f'(b)} = 2$。

**思路溯源**

结论涉及两个导数值的倒数之和。若能找到一个点 $c$ 使 $f(c) = 1/2$，在 $[0,c]$ 和 $[c,1]$ 上分别使用 Lagrange，导出的两个导数值恰好是 $1/(2c)$ 和 $1/[2(1-c)]$——它们的倒数之和恰为 $2c + 2(1-c) = 2$，与 $c$ 无关。$f(c)=1/2$ 的点由介值定理保证。

**解法**：

$f(x)$ 在 $[0,1]$ 上连续，$f(0)=0$，$f(1)=1$。由介值定理，存在 $c \in (0,1)$ 使

$$f(c) = \frac{1}{2}$$

对 $f$ 在 $[0, c]$ 上应用 Lagrange 中值定理，存在 $a \in (0, c)$ 使

$$f'(a) = \frac{f(c) - f(0)}{c - 0} = \frac{1/2}{c} = \frac{1}{2c}$$

对 $f$ 在 $[c, 1]$ 上应用 Lagrange 中值定理，存在 $b \in (c, 1)$ 使

$$f'(b) = \frac{f(1) - f(c)}{1 - c} = \frac{1 - 1/2}{1 - c} = \frac{1}{2(1 - c)}$$

计算倒数之和：

$$\frac{1}{f'(a)} + \frac{1}{f'(b)} = 2c + 2(1 - c) = 2$$

且 $a \in (0, c)$，$b \in (c, 1)$，故 $a \neq b$。证毕。

## 二、积分

### 题 4 — 换元 + 分部积分

> 计算不定积分：$\displaystyle \int e^{\sqrt{x}}\,dx \quad (x \geq 0)$

**思路溯源**

指数复合根式。标准策略：令 $t = \sqrt{x}$，则 $x = t^2$，$dx = 2t\,dt$。被积函数化为 $e^t \cdot 2t = 2t e^t$，这是多项式乘指数函数的经典分部积分模式。

**解法**：

令 $t = \sqrt{x}$，则 $x = t^2$，$dx = 2t\,dt$。

$$\begin{aligned}
\int e^{\sqrt{x}}\,dx
&= \int e^t \cdot 2t\,dt \\[4pt]
&= 2\int t e^t\,dt
\end{aligned}$$

对 $\int t e^t\,dt$ 使用分部积分：取 $u = t$，$dv = e^t\,dt$，则 $du = dt$，$v = e^t$。

$$\begin{aligned}
2\int t e^t\,dt
&= 2\!\left(t e^t - \int e^t\,dt\right) \\[4pt]
&= 2(t e^t - e^t) + C \\[4pt]
&= 2e^t(t - 1) + C
\end{aligned}$$

回代 $t = \sqrt{x}$：

$$\boxed{\int e^{\sqrt{x}}\,dx = 2e^{\sqrt{x}}\left(\sqrt{x} - 1\right) + C}$$

### 题 5 — 配方 $\to \arcsin$

> 计算不定积分：$\displaystyle \int \frac{dx}{\sqrt{x(1-x)}} \quad (0 < x < 1)$

**思路溯源**

根号内为 $x - x^2$，是典型的二次式配方。$x - x^2 = \frac{1}{4} - \left(x - \frac{1}{2}\right)^2$，配方后 $\int \frac{du}{\sqrt{a^2 - u^2}} = \arcsin\frac{u}{a}$ 即得。这种「配方 $\to \arcsin$」模式与「配方 $\to \arctan$」对偶，区别在于配方后常数项的符号。

**解法**：

$$\begin{aligned}
x(1-x) = x - x^2 &= -\left(x^2 - x\right) \\[4pt]
&= -\left[\left(x - \frac{1}{2}\right)^2 - \frac{1}{4}\right] \\[4pt]
&= \frac{1}{4} - \left(x - \frac{1}{2}\right)^2
\end{aligned}$$

$$\int \frac{dx}{\sqrt{x(1-x)}} = \int \frac{dx}{\sqrt{\frac{1}{4} - \left(x - \frac{1}{2}\right)^2}}$$

令 $u = x - \dfrac{1}{2}$，$du = dx$：

$$\begin{aligned}
\int \frac{du}{\sqrt{\frac{1}{4} - u^2}}
&= \int \frac{du}{\sqrt{\left(\frac{1}{2}\right)^2 - u^2}} \\[4pt]
&= \arcsin\frac{u}{1/2} + C \\[4pt]
&= \arcsin(2u) + C
\end{aligned}$$

回代 $u = x - \frac{1}{2}$：

$$\boxed{\int \frac{dx}{\sqrt{x(1-x)}} = \arcsin(2x - 1) + C}$$

### 题 6 — 倒代换

> 计算不定积分：$\displaystyle \int \frac{dx}{x\sqrt{x^2 - 1}} \quad (x > 1)$

**思路溯源**

分母中 $x$ 在根号外有一次幂，根号内为 $x^2 - 1$。使用倒代换 $t = \frac{1}{x}$ 可将 $x$ 的负幂次翻转为正幂次，化简后根号恰好化为 $\sqrt{1-t^2}$，积出 $\arcsin$。此题也可用三角换元 $x = \sec\theta$，但倒代换在"分母 $x$ 的幂次高于根号内"时更具通用性。

**解法**：

令 $t = \dfrac{1}{x}$，则 $x = \dfrac{1}{t}$，$dx = -\dfrac{1}{t^2}\,dt$。当 $x > 1$ 时 $0 < t < 1$。

$$\sqrt{x^2 - 1} = \sqrt{\frac{1}{t^2} - 1} = \frac{\sqrt{1 - t^2}}{|t|} = \frac{\sqrt{1 - t^2}}{t} \quad (t > 0)$$

代入原积分：

$$\begin{aligned}
\int \frac{dx}{x\sqrt{x^2 - 1}}
&= \int \frac{-\frac{1}{t^2}\,dt}{\frac{1}{t} \cdot \frac{\sqrt{1 - t^2}}{t}} \\[4pt]
&= \int \frac{-\frac{1}{t^2}}{\frac{\sqrt{1 - t^2}}{t^2}}\,dt \\[4pt]
&= -\int \frac{dt}{\sqrt{1 - t^2}} \\[4pt]
&= -\arcsin t + C
\end{aligned}$$

回代 $t = \dfrac{1}{x}$：

$$\boxed{\int \frac{dx}{x\sqrt{x^2 - 1}} = -\arcsin\frac{1}{x} + C}$$

> 备注入：此结果也可写为 $\operatorname{arcsec}|x| + C$，两种形式等价（相差常数 $\frac{\pi}{2}$），考研中均视为正确答案。

### 题 7 — 分子拆分 + 配方

> 计算不定积分：$\displaystyle \int \frac{x}{x^2 + x + 1}\,dx$

**思路溯源**

分母判别式 $\Delta = 1 - 4 = -3 < 0$，不可因式分解，配方为 $(x+1/2)^2 + 3/4$。分子 $x = (x+1/2) - 1/2$，拆分后第一项凑微分积出 $\ln$，第二项为 $\arctan$ 标准型。这是「分子拆分 + 配方 → $\ln$ + $\arctan$」的固定套路，与 05-31 题 6（分母 $x^2+2x+2$）属同一题型、不同参数。

**解法**：

分母配方：

$$x^2 + x + 1 = \left(x + \frac{1}{2}\right)^2 + \frac{3}{4}$$

分子拆分：

$$\frac{x}{x^2 + x + 1}
= \frac{(x + \frac{1}{2}) - \frac{1}{2}}{(x + \frac{1}{2})^2 + \frac{3}{4}}
= \frac{x + \frac{1}{2}}{(x + \frac{1}{2})^2 + \frac{3}{4}} - \frac{\frac{1}{2}}{(x + \frac{1}{2})^2 + \frac{3}{4}}$$

分别积分。第一项——凑微分：

$$\begin{aligned}
\int \frac{x + \frac{1}{2}}{(x + \frac{1}{2})^2 + \frac{3}{4}}\,dx
&= \frac{1}{2}\int \frac{2(x + \frac{1}{2})}{(x + \frac{1}{2})^2 + \frac{3}{4}}\,dx \\[4pt]
&= \frac{1}{2}\ln\!\left[\left(x + \frac{1}{2}\right)^2 + \frac{3}{4}\right] + C_1 \\[4pt]
&= \frac{1}{2}\ln(x^2 + x + 1) + C_1
\end{aligned}$$

第二项——$\arctan$ 标准型（$\int \frac{du}{u^2 + a^2} = \frac{1}{a}\arctan\frac{u}{a}$）：

$$\begin{aligned}
\frac{1}{2}\int \frac{dx}{(x + \frac{1}{2})^2 + \frac{3}{4}}
&= \frac{1}{2} \cdot \frac{1}{\sqrt{3}/2} \arctan\frac{x + \frac{1}{2}}{\sqrt{3}/2} + C_2 \\[4pt]
&= \frac{1}{\sqrt{3}}\arctan\frac{2x + 1}{\sqrt{3}} + C_2
\end{aligned}$$

合并：

$$\boxed{\int \frac{x}{x^2 + x + 1}\,dx = \frac{1}{2}\ln(x^2 + x + 1) - \frac{1}{\sqrt{3}}\arctan\frac{2x + 1}{\sqrt{3}} + C}$$

### 题 8 — 区间再现

> 计算定积分：$\displaystyle I = \int_0^{\frac{\pi}{4}} \ln(1 + \tan x)\,dx$

**思路溯源**

积分上限为 $\pi/4$，被积函数含 $\tan x$。利用 $\tan(\pi/4 - x) = \frac{1 - \tan x}{1 + \tan x}$ 的恒等式，做换元 $x \to \pi/4 - x$ 后原积分变为 $\int \ln\frac{2}{1+\tan x}\,dx$，即 $\int (\ln 2 - \ln(1+\tan x))dx$。此时出现原积分 $I$ 的相反数，联立方程解出 $I$。这是区间再现处理「和角公式诱导型」对称的经典题，常与 $\int \ln(1+\cot x)dx$ 成对出现。

**解法**：

令 $x = \dfrac{\pi}{4} - t$，则 $dx = -dt$。当 $x = 0$ 时 $t = \dfrac{\pi}{4}$；当 $x = \dfrac{\pi}{4}$ 时 $t = 0$。

$$\begin{aligned}
I &= \int_0^{\frac{\pi}{4}} \ln(1 + \tan x)\,dx \\[4pt]
&= \int_{\frac{\pi}{4}}^0 \ln\!\left[1 + \tan\!\left(\frac{\pi}{4} - t\right)\right](-dt) \\[4pt]
&= \int_0^{\frac{\pi}{4}} \ln\!\left[1 + \frac{1 - \tan t}{1 + \tan t}\right]dt \qquad \left(\text{由 }\tan\!\left(\frac{\pi}{4}-t\right) = \frac{1-\tan t}{1+\tan t}\right) \\[4pt]
&= \int_0^{\frac{\pi}{4}} \ln\!\left(\frac{1 + \tan t + 1 - \tan t}{1 + \tan t}\right)dt \\[4pt]
&= \int_0^{\frac{\pi}{4}} \ln\!\left(\frac{2}{1 + \tan t}\right)dt \\[4pt]
&= \int_0^{\frac{\pi}{4}} \bigl[\ln 2 - \ln(1 + \tan t)\bigr]\,dt \\[4pt]
&= \frac{\pi}{4}\ln 2 - I
\end{aligned}$$

故 $2I = \dfrac{\pi}{4}\ln 2$，即

$$\boxed{\int_0^{\frac{\pi}{4}} \ln(1 + \tan x)\,dx = \frac{\pi}{8}\ln 2}$$
