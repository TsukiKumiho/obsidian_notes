### 题 1 | 困难 | 无穷大阶的比较

求极限：

$$L = \lim_{n\to\infty} \frac{\ln(n!)}{n\ln n}$$

---

#### 思路溯源

$\ln(n!) = \sum_{k=1}^n \ln k$，当 $n$ 很大时，主要贡献来自 $k$ 接近 $n$ 的项。用夹逼准则：将 $\ln(n!)$ 夹在 $n\ln n$ 的下界和上界之间，发现与 $\int_1^n \ln x\,dx = n\ln n - n + 1$ 有关，提取主导项 $n\ln n$。

#### 解

由 Stolz 定理（$\frac{\infty}{\infty}$ 型），

$$L = \lim_{n\to\infty} \frac{\ln((n+1)!) - \ln(n!)}{(n+1)\ln(n+1) - n\ln n}
= \lim_{n\to\infty} \frac{\ln(n+1)}{(n+1)\ln(n+1) - n\ln n}$$

分母 $(n+1)\ln(n+1) - n\ln n = \ln(n+1) + n\ln\frac{n+1}{n} = \ln(n+1) + n\left(\frac{1}{n} + o(\frac{1}{n})\right) = \ln(n+1) + 1 + o(1)$。

故 $L = \lim_{n\to\infty} \frac{\ln(n+1)}{\ln(n+1) + 1} = 1$。

$$\boxed{L = 1}$$

### 题 2 | 困难 | $\epsilon-\delta$ 定义证明极限

用 $\epsilon-\delta$ 语言证明：

$$\lim_{x\to 1} \frac{x^3 - 1}{x - 1} = 3$$

---

#### 思路溯源

$\frac{x^3-1}{x-1} = x^2+x+1$（$x\neq 1$），问题化归为证明 $\lim_{x\to 1} (x^2+x+1) = 3$。只需找到 $\delta(\epsilon)$ 使 $|x-1|<\delta \Rightarrow |(x^2+x+1)-3|<\epsilon$。

#### 解

当 $x \neq 1$ 时，$\frac{x^3-1}{x-1} = x^2+x+1$。需证：$\forall \epsilon > 0$，$\exists \delta > 0$，当 $0 < |x-1| < \delta$ 时，$|(x^2+x+1)-3| < \epsilon$。

限制 $|x-1| < 1$，则 $0 < x < 2$，于是 $|x+2| < 4$。

$$|(x^2+x+1)-3| = |x^2+x-2| = |(x-1)(x+2)| = |x-1|\cdot|x+2| < 4|x-1|$$

取 $\delta = \min\{1, \frac{\epsilon}{4}\}$，则当 $0 < |x-1| < \delta$ 时，

$$|(x^2+x+1)-3| < 4|x-1| < 4\cdot\frac{\epsilon}{4} = \epsilon$$

由 $\epsilon-\delta$ 定义，$\lim_{x\to 1}\frac{x^3-1}{x-1} = 3$。证毕。

### 题 3 | 地狱 | 含参极限分类讨论

求极限并讨论参数 $a, b > 0$：

$$L = \lim_{x\to 0} \frac{(1+ax)^{\frac{1}{x}} - (1+bx)^{\frac{1}{x}}}{x}$$

---

#### 思路溯源

$(1+kx)^{1/x} \to e^k$（$x\to 0$），分子趋于 $e^a - e^b$。但 $x\to 0$ 时分母也为 0，是 $\frac{0}{0}$ 型。Taylor 展开 $(1+kx)^{1/x} = e^{k - \frac{k^2}{2}x + O(x^2)}$，再减去相减。

#### 解

利用展开：$(1+kx)^{1/x} = \exp\left(\frac{\ln(1+kx)}{x}\right) = \exp\left(\frac{kx - \frac{k^2 x^2}{2} + O(x^3)}{x}\right) = e^{k}\cdot e^{-\frac{k^2}{2}x + O(x^2)}$。

由 $e^u = 1 + u + O(u^2)$，

$$(1+kx)^{1/x} = e^k\left(1 - \frac{k^2}{2}x + O(x^2)\right) = e^k - \frac{k^2 e^k}{2}x + O(x^2)$$

代入分子：

$$(1+ax)^{1/x} - (1+bx)^{1/x} = (e^a - e^b) - \frac{a^2 e^a - b^2 e^b}{2}x + O(x^2)$$

- 若 $a \neq b$，$e^a \neq e^b$，极限为 $\infty$（分母 $x\to 0$，分子非零）
- 若 $a = b$，$e^a = e^b$，则

$$L = \lim_{x\to 0} \frac{-\frac{a^2 e^a - a^2 e^a}{2}x + O(x^2)}{x} = 0$$

$$\boxed{L = \begin{cases} \infty, & a \neq b \\ 0, & a = b \end{cases}}$$

### 题 4 | 困难 | 变限积分极限

求极限：

$$L = \lim_{x\to 0} \frac{\displaystyle\int_0^x e^{t^2}\,dt}{\displaystyle\int_0^x t e^{t^2}\,dt}$$

---

#### 思路溯源

$x\to 0$，两个积分都趋于 0，$\frac{0}{0}$ 型。洛必达法则：分子求导 $e^{x^2}$，分母求导 $x e^{x^2}$。

#### 解

由洛必达法则（$\frac{0}{0}$ 型），

$$L = \lim_{x\to 0} \frac{e^{x^2}}{x e^{x^2}} = \lim_{x\to 0} \frac{1}{x} = \infty$$

但需注意：洛必达要求 $x \neq 0$，原式 $x\to 0^+$ 时 $\int_0^x te^{t^2}dt > 0$，$x\to 0^-$ 时积分也可能有意义。考虑 $x\to 0^+$：

$$\boxed{L = +\infty \quad (x\to 0^+)}$$

> 当 $x\to 0^-$ 时分母 $\int_0^x te^{t^2}dt = -\int_x^0 te^{t^2}dt < 0$，故 $L = -\infty$（$x\to 0^-$）。因此双侧极限不存在。

### 题 5 | 地狱 | 夹逼准则 + 最大项放缩

求极限：

$$L = \lim_{n\to\infty} \frac{1}{n} \left(1^n + 2^n + \cdots + n^n\right)^{\frac{1}{n}}$$

---

#### 思路溯源

和式中最大项是 $n^n$，最小项是 $1^n = 1$。将和式夹在最大项和 $n$ 倍最大项之间，提取 $n^n$。

#### 解

令 $S_n = 1^n + 2^n + \cdots + n^n$。显然 $n^n \leq S_n \leq n \cdot n^n = n^{n+1}$。

$$\frac{1}{n} (n^n)^{\frac{1}{n}} \leq L_n \leq \frac{1}{n} (n^{n+1})^{\frac{1}{n}}$$

即 $\frac{1}{n} \cdot n \leq L_n \leq \frac{1}{n} \cdot n^{1+\frac{1}{n}} = n^{\frac{1}{n}}$。

下界 $= 1$，上界 $= n^{1/n} \to 1$（$n\to\infty$）。由夹逼准则，$L = 1$。

但此放缩不够精细。重新放缩：

$$n^n \leq S_n \leq n^n\left(1 + \frac{(n-1)^n}{n^n} + \cdots\right) = n^n\left(1 + (1-\frac{1}{n})^n + (1-\frac{2}{n})^n + \cdots\right)$$

当 $n\to\infty$，$(1-\frac{k}{n})^n \to e^{-k}$，其余项指数衰减。更精确的下界利用 $S_n \geq n^n$：

$$L_n = \frac{1}{n}(S_n)^{1/n} \geq \frac{1}{n} \cdot n = 1$$

上界：$S_n = \sum_{k=1}^n k^n = n^n \sum_{k=1}^n (\frac{k}{n})^n$。令 $t = \frac{k}{n}$，则 $\sum_{k=1}^n (\frac{k}{n})^n \leq \sum_{k=1}^{\infty} e^{-n(1-k/n)} = O(1)$（由 $(1-x)^n \leq e^{-nx}$）。更严谨地：

$$S_n \leq n^n\left(1 + e^{-1} + e^{-2} + \cdots\right) < n^n \cdot \frac{1}{1-e^{-1}}$$

故 $L_n \leq \frac{1}{n} \cdot n \cdot (\frac{1}{1-e^{-1}})^{1/n} \to 1$。由夹逼准则，

$$\boxed{L = 1}$$

### 题 6 | 困难 | 三零点 → 两次 Rolle 证 $f''=0$

设 $f(x)$ 在 $[0, 1]$ 上二阶可导，$f(0) = f(\frac{1}{2}) = f(1) = 0$。证明：存在 $\xi \in (0, 1)$ 使得 $f''(\xi) = 0$。

---

#### 思路溯源

二阶导零点 $\leftarrow$ $f'$ 有两个零点 $\leftarrow$ $f$ 在 $[0,\frac{1}{2}]$ 和 $[\frac{1}{2},1]$ 上各满足 Rolle 条件。三个等值点提供两段区间，每段 Rolle 给出一个 $f'$ 的零点。

#### 解

在 $[0, \frac{1}{2}]$ 上对 $f$ 应用 Rolle 定理：$f(0)=f(\frac{1}{2})=0$，故 $\exists \eta_1 \in (0,\frac{1}{2})$ 使 $f'(\eta_1)=0$。

在 $[\frac{1}{2}, 1]$ 上对 $f$ 应用 Rolle 定理：$f(\frac{1}{2})=f(1)=0$，故 $\exists \eta_2 \in (\frac{1}{2}, 1)$ 使 $f'(\eta_2)=0$。

$f$ 二阶可导 $\Rightarrow$ $f'$ 可导，在 $[\eta_1,\eta_2]$ 上对 $f'$ 应用 Rolle 定理：$f'(\eta_1)=f'(\eta_2)=0$，故 $\exists \xi \in (\eta_1,\eta_2) \subset (0,1)$ 使 $f''(\xi)=0$。$\square$

### 题 7 | 地狱 | 双函数中值等式

设 $f,g$ 在 $[a,b]$ 上连续，在 $(a,b)$ 内可导，$g'(x) \neq 0$。证明存在 $\xi \in (a,b)$ 使

$$\frac{f'(\xi)}{g'(\xi)} = \frac{f(b)-f(a)}{g(b)-g(a)}$$

---

#### 思路溯源

这是 Cauchy 中值定理的**标准证明**。构造 $F(x) = f(x) - \lambda g(x)$，选 $\lambda$ 使 $F(a)=F(b)$，用 Rolle。

#### 解

令 $\lambda = \dfrac{f(b)-f(a)}{g(b)-g(a)}$（分母非零，因为 $g' \neq 0$ 且 Lagrange 保证 $g(b)\neq g(a)$）。

构造 $F(x) = f(x) - \lambda g(x)$。则 $F$ 在 $[a,b]$ 上连续，在 $(a,b)$ 内可导，且

$$F(b) - F(a) = [f(b)-\lambda g(b)] - [f(a)-\lambda g(a)] = [f(b)-f(a)] - \lambda[g(b)-g(a)] = 0$$

故 $F(a) = F(b)$。由 Rolle 定理，$\exists \xi \in (a,b)$ 使 $F'(\xi) = 0$。

而 $F'(x) = f'(x) - \lambda g'(x)$，故 $f'(\xi) - \lambda g'(\xi) = 0$，即 $\dfrac{f'(\xi)}{g'(\xi)} = \lambda = \dfrac{f(b)-f(a)}{g(b)-g(a)}$。证毕。

### 题 8 | 困难 | $f''(\xi)=0$ 型 — 三零点两次 Rolle

设 $f$ 在 $[0,3]$ 上二阶可导，$f(0)=f(1)$，$f(2)=f(3)$。证明存在 $\xi \in (0,3)$ 使 $f''(\xi)=0$。

---

#### 思路溯源

二阶导零点 $\leftarrow$ $f'$ 有两个零点 $\leftarrow$ $f$ 有三个零点或两个函数的差值在两段上相同。由 $f(0)=f(1)$ 在 $[0,1]$ 上 Rolle 得 $\eta_1$；由 $f(2)=f(3)$ 在 $[2,3]$ 上 Rolle 得 $\eta_2$。$\eta_1 < \eta_2$，$f'(\eta_1)=f'(\eta_2)=0$，再对 $f'$ 在 $[\eta_1,\eta_2]$ 上 Rolle。

#### 解

在 $[0,1]$ 上对 $f$ 用 Rolle：$\exists \eta_1 \in (0,1)$ 使 $f'(\eta_1) = 0$。
在 $[2,3]$ 上对 $f$ 用 Rolle：$\exists \eta_2 \in (2,3)$ 使 $f'(\eta_2) = 0$。

$f$ 二阶可导故 $f'$ 可导（亦连续），$f'(\eta_1) = f'(\eta_2) = 0$，在 $[\eta_1,\eta_2]$ 上对 $f'$ 用 Rolle：$\exists \xi \in (\eta_1,\eta_2) \subset (0,3)$ 使 $f''(\xi) = 0$。证毕。

### 题 9 | 地狱 | 含定积分的中值等式

设 $f$ 在 $[0,1]$ 上连续可导，$f(0)=0$，且 $\int_0^1 f(x)dx = 0$。证明：存在 $\xi \in (0,1)$ 使 $\int_0^\xi f(x)dx = \xi f(\xi)$。

---

#### 思路溯源

结论 $\int_0^\xi f = \xi f(\xi)$ 等价于 $\frac{\int_0^\xi f}{\xi} = f(\xi)$（$\xi \neq 0$），即 $f$ 在 $[0,\xi]$ 上的平均值等于在 $\xi$ 处的值。这与 Lagrange 中值定理的形式相似。构造 $F(x) = \frac{1}{x}\int_0^x f(t)dt$（$x>0$）或 $G(x) = x\int_0^x f - (\int_0^x f)^2$... 不。

重写：$\int_0^\xi f = \xi f(\xi) \iff \xi f(\xi) - \int_0^\xi f(t)dt = 0$。令 $H(x) = xf(x) - \int_0^x f(t)dt$。$H'(x) = f(x) + xf'(x) - f(x) = xf'(x)$。这对寻找零点不直接有用。

更佳：令 $\Phi(x) = \frac{1}{x}\int_0^x f(t)dt - f(x)$。需 $\Phi(\xi)=0$。

或者：结论 $\iff \frac{d}{dx}\left(\frac{1}{x}\int_0^x f\right) = 0$ 在某点成立。令 $A(x) = \frac{1}{x}\int_0^x f(t)dt$（$x>0$），$A(1) = 0$（已知 $\int_0^1 f = 0$）。$\lim_{x\to 0^+} A(x) = \lim_{x\to 0^+} \frac{\int_0^x f}{x} = f(0) = 0$（洛必达）。但 $A$ 在 $x=0$ 无定义，需延拓。

定义 $A(0) = f(0) = 0$。$A(1) = 0$。由 Rolle，$\exists \xi \in (0,1)$ 使 $A'(\xi) = 0$。

$A'(x) = \frac{xf(x) - \int_0^x f(t)dt}{x^2}$。$A'(\xi) = 0 \Rightarrow \xi f(\xi) = \int_0^\xi f(t)dt$。得证。

#### 解

令 $F(x) = \begin{cases} \dfrac{1}{x}\displaystyle\int_0^x f(t)\,dt, & x\in(0,1] \\ f(0), & x = 0 \end{cases}$

由洛必达法则，$\lim_{x\to 0^+} F(x) = f(0)$，故 $F$ 在 $[0,1]$ 上连续。

$F(0)=f(0)=0$，$F(1)=\int_0^1 f(t)dt = 0$。由 Rolle 定理，$\exists \xi \in (0,1)$ 使 $F'(\xi)=0$。

$F'(x) = \dfrac{xf(x) - \int_0^x f(t)dt}{x^2}$，故 $F'(\xi)=0 \Longrightarrow \xi f(\xi) = \int_0^\xi f(t)dt$。证毕。

$$\boxed{\text{证毕}}$$

### 题 10 | 困难 | 含指数因子的中值问题

设 $f$ 在 $[0,1]$ 上连续可导，$f(0)=f(1)=0$。证明存在 $\xi \in (0,1)$ 使得 $f'(\xi) = f(\xi)$。

---

#### 思路溯源

结论 $f'(\xi) = f(\xi)$ 等价于 $f'(\xi) - f(\xi) = 0$，即 $(e^{-x}f(x))'\big|_{x=\xi} = 0$。故构造 $F(x) = e^{-x}f(x)$，利用 $f(0)=f(1)=0$ 得 $F(0)=F(1)=0$，Rolle 定理即得证。

#### 解

**证明**：令 $F(x) = e^{-x}f(x)$。$F(0) = e^0 f(0) = 0$，$F(1) = e^{-1}f(1) = 0$。

由 Rolle 定理，$\exists \xi \in (0,1)$ 使 $F'(\xi) = 0$。

$$F'(x) = e^{-x}f'(x) - e^{-x}f(x) = e^{-x}(f'(x) - f(x))$$

$$F'(\xi) = e^{-\xi}(f'(\xi) - f(\xi)) = 0$$

由于 $e^{-\xi} \neq 0$，故 $f'(\xi) = f(\xi)$。$\square$

---

> **推广**：若结论为 $f'(\xi) + f(\xi) = 0$，则构造 $F(x) = e^x f(x)$，Rolle 同理可证。此构造背后的原理是：$f' \pm f = 0$ 等价于 $(e^{\pm x}f)' = 0$，积分因子 $e^{\pm x}$ 是解一阶线性微分方程 $y' \pm y = 0$ 的积分因子。

### 题 11 | 困难 | 无理函数不定积分

求不定积分：

$$I = \int \frac{dx}{1+\sqrt{x}+\sqrt{1+x}}$$

---

#### 思路溯源

含 $\sqrt{x}$ 和 $\sqrt{1+x}$ 同时出现，先有理化分母：分子分母同乘 $(1+\sqrt{x})-\sqrt{1+x}$，展开后化简。或者用三角代换 $x = \tan^2\theta$。

#### 解

法一（有理化分母）：

$$\frac{1}{1+\sqrt{x}+\sqrt{1+x}} = \frac{(1+\sqrt{x})-\sqrt{1+x}}{(1+\sqrt{x})^2 - (1+x)} = \frac{1+\sqrt{x}-\sqrt{1+x}}{1+2\sqrt{x}+x-1-x} = \frac{1+\sqrt{x}-\sqrt{1+x}}{2\sqrt{x}}$$

$$= \frac{1}{2\sqrt{x}} + \frac{1}{2} - \frac{\sqrt{1+x}}{2\sqrt{x}}$$

前三项容易积分，最后一项令 $t=\sqrt{1+x}$ 处理。

$$\int \frac{dx}{2\sqrt{x}} = \sqrt{x} + C,\quad \int \frac{1}{2}dx = \frac{x}{2} + C$$

$$\int \frac{\sqrt{1+x}}{2\sqrt{x}}dx = \frac{1}{2}\int \sqrt{\frac{1+x}{x}}dx = \frac{1}{2}\int \frac{\sqrt{1+x}}{\sqrt{x}}dx$$

令 $u = \sqrt{x}$，$x = u^2$，$dx = 2u du$：

$$\frac{1}{2}\int \frac{\sqrt{1+u^2}}{u} \cdot 2u\,du = \int \sqrt{1+u^2}\,du$$

### 题 12 | 地狱 | 含参变量定积分的最值

设 $F(a) = \displaystyle\int_0^1 |x^2 - a^2|\,dx$，$a \in [0, 1]$。求 $F(a)$ 的解析表达式，并求其最小值。

---

#### 思路溯源

$|x^2 - a^2|$ 的零点在 $x = a$。需分段积分：$[0, a]$ 上 $x^2 \leq a^2$ 故 $|x^2-a^2| = a^2 - x^2$；$[a, 1]$ 上 $x^2 \geq a^2$ 故 $|x^2-a^2| = x^2 - a^2$。

#### 解

当 $a \in [0,1]$：

$$F(a) = \int_0^a (a^2 - x^2)dx + \int_a^1 (x^2 - a^2)dx$$

第一段：$\int_0^a (a^2 - x^2)dx = \left[a^2 x - \frac{x^3}{3}\right]_0^a = a^3 - \frac{a^3}{3} = \frac{2}{3}a^3$

第二段：$\int_a^1 (x^2 - a^2)dx = \left[\frac{x^3}{3} - a^2 x\right]_a^1 = \left(\frac{1}{3} - a^2\right) - \left(\frac{a^3}{3} - a^3\right) = \frac{1}{3} - a^2 + \frac{2}{3}a^3$

相加：$F(a) = \frac{4}{3}a^3 - a^2 + \frac{1}{3}$。

求导：$F'(a) = 4a^2 - 2a = 2a(2a-1)$。$a \in [0,1]$ 内驻点 $a=0, \frac{1}{2}$。

$F(0) = \frac{1}{3}$，$F(1) = \frac{4}{3} - 1 + \frac{1}{3} = \frac{2}{3}$，$F(\frac{1}{2}) = \frac{4}{3}\cdot\frac{1}{8} - \frac{1}{4} + \frac{1}{3} = \frac{1}{6} - \frac{1}{4} + \frac{1}{3} = \frac{2}{12} - \frac{3}{12} + \frac{4}{12} = \frac{3}{12} = \frac{1}{4}$。

$$\boxed{F_{\min} = F\left(\frac{1}{2}\right) = \frac{1}{4}}$$

### 题 13 | 困难 | 周期函数的定积分

设 $f(x)$ 是以 $T$ 为周期的连续函数。证明：

$$\int_a^{a+T} f(x)\,dx = \int_0^T f(x)\,dx \quad (\forall a \in \mathbb{R})$$

---

#### 思路溯源

将积分区间 $[a, a+T]$ 拆分为 $[a, T] + [T, a+T]$（当 $a \in [0,T]$ 时）。第二段用 $u = x - T$ 变换，利用周期性归化为 $[0, a]$ 上的积分。

#### 解

$$\int_a^{a+T} f(x)dx = \int_a^T f(x)dx + \int_T^{a+T} f(x)dx$$

第二段令 $u = x - T$，则 $x = u + T$，$dx = du$，当 $x = T$ 时 $u = 0$，当 $x = a+T$ 时 $u = a$。

$$\int_T^{a+T} f(x)dx = \int_0^a f(u+T)du = \int_0^a f(u)du \quad (\text{周期性 } f(u+T)=f(u))$$

故原式 $= \int_a^T f(x)dx + \int_0^a f(x)dx = \int_0^T f(x)dx$。证毕。

### 题 14 | 地狱 | 积分不等式证明

设 $f$ 在 $[0,1]$ 上有连续的导数，$f(0)=0$。证明：

$$\int_0^1 |f(x)|\,dx \leq \int_0^1 |f'(x)|\,dx$$

---

#### 思路溯源

$f(0)=0$ 意味着 $f(x) = \int_0^x f'(t)dt$。取绝对值后：$|f(x)| \leq \int_0^x |f'(t)|dt$，再对 $x$ 积分。

#### 解

由 Newton-Leibniz 公式：$f(x) = f(x) - f(0) = \int_0^x f'(t)dt$。

取绝对值：$|f(x)| = \left|\int_0^x f'(t)dt\right| \leq \int_0^x |f'(t)|dt$。

两边对 $x$ 在 $[0,1]$ 上积分：

$$\int_0^1 |f(x)|dx \leq \int_0^1 \left(\int_0^x |f'(t)|dt\right)dx$$

交换积分次序（$0 \leq t \leq x \leq 1$ → $0 \leq t \leq 1, t \leq x \leq 1$）：

$$\int_0^1 \int_0^x |f'(t)|dt\,dx = \int_0^1 |f'(t)| \left(\int_t^1 dx\right) dt = \int_0^1 |f'(t)|(1-t)dt \leq \int_0^1 |f'(t)|dt$$

因此 $\int_0^1 |f(x)|dx \leq \int_0^1 |f'(x)|dx$。证毕。

### 题 17 | 地狱 | 幂级数直接展开

将函数 $f(x) = \ln(x + \sqrt{1+x^2})$ 展开为 $x$ 的幂级数，并求收敛域。

---

#### 思路溯源

注意到 $f'(x) = \frac{1}{\sqrt{1+x^2}}$。先展开 $f'(x)$ 为二项式级数，再逐项积分回 $f(x)$。

#### 解

$f'(x) = \frac{1}{\sqrt{1+x^2}} = (1+x^2)^{-1/2}$。由二项式展开：

$$(1+x^2)^{-1/2} = \sum_{n=0}^\infty \binom{-1/2}{n} x^{2n}$$

其中 $\binom{-1/2}{n} = \frac{(-\frac{1}{2})(-\frac{3}{2})\cdots(-\frac{2n-1}{2})}{n!} = (-1)^n \frac{(2n-1)!!}{2^n n!} = (-1)^n \frac{(2n)!}{4^n (n!)^2}$。

故 $f'(x) = \sum_{n=0}^\infty (-1)^n \frac{(2n)!}{4^n (n!)^2} x^{2n}$，收敛半径 $R=1$。

逐项积分（$f(0) = \ln(1) = 0$）：

$$f(x) = \sum_{n=0}^\infty (-1)^n \frac{(2n)!}{4^n (n!)^2} \cdot \frac{x^{2n+1}}{2n+1}$$

收敛域：$x = \pm 1$ 时，级数 $\sim \sum \frac{1}{n^{3/2}}$ 收敛（由 Stirling 公式）。故收敛域为 $[-1, 1]$。

$$\boxed{f(x) = \sum_{n=0}^\infty \frac{(-1)^n (2n)!}{4^n (n!)^2 (2n+1)} x^{2n+1},\quad x\in[-1,1]}$$

### 题 18 | 困难 | 级数收敛性证明

#### 思路溯源

$\sum \frac{\sin n}{n}$ 非交错级数（$\sin n$ 不恒正也不恒负），需用 Dirichlet 判别法：$\frac{1}{n}$ 单调递减趋于 0，$\sum_{k=1}^N \sin k$ 有界。

$$\boxed{\text{条件收敛}}$$

### 题 19 | 地狱 | 傅里叶正弦展开

将 $f(x) = x$ 在 $[0, \pi]$ 上展开为正弦级数，并利用 Parseval 等式求 $\displaystyle\sum_{n=1}^\infty \frac{1}{n^2}$。

---

#### 思路溯源

正弦级数 $\leftarrow$ 奇延拓。$b_n = \frac{2}{\pi}\int_0^\pi x \sin(nx)dx$。Parseval：$\frac{1}{\pi}\int_{-\pi}^\pi f^2 = \frac{a_0^2}{2} + \sum (a_n^2 + b_n^2)$。注意奇延拓后 $a_n = 0$。

#### 解

正弦展开系数：

$$b_n = \frac{2}{\pi} \int_0^\pi x \sin(nx)\,dx = \frac{2}{\pi}\left(\left[-\frac{x\cos(nx)}{n}\right]_0^\pi + \int_0^\pi \frac{\cos(nx)}{n}dx\right)$$

$$= \frac{2}{\pi}\left(-\frac{\pi\cos(n\pi)}{n} + 0\right) = -\frac{2\cos(n\pi)}{n} = (-1)^{n+1}\frac{2}{n}$$

故 $x \sim \sum_{n=1}^\infty \frac{2(-1)^{n+1}}{n}\sin(nx)$，$x \in (0,\pi)$。

Parseval 等式（奇延拓后 $f$ 在 $[-\pi,\pi]$ 上的 $L^2$ 范数）：

$$\frac{1}{\pi}\int_{-\pi}^\pi |f_{\text{odd}}(x)|^2 dx = \sum_{n=1}^\infty b_n^2$$

$$\frac{2}{\pi}\int_0^\pi x^2 dx = \sum_{n=1}^\infty \frac{4}{n^2}$$

$$\frac{2}{\pi}\cdot\frac{\pi^3}{3} = 4\sum_{n=1}^\infty \frac{1}{n^2}$$

$$\frac{2\pi^2}{3} = 4\sum_{n=1}^\infty \frac{1}{n^2} \Longrightarrow \sum_{n=1}^\infty \frac{1}{n^2} = \frac{\pi^2}{6}$$

$$\boxed{\sum_{n=1}^\infty \frac{1}{n^2} = \frac{\pi^2}{6}}$$

### 题 22 | 地狱 | 条件极值（Lagrange 乘数法）

#### 解

$$L_x = 2x + 3\lambda x^2 = x(2 + 3\lambda x) = 0$$
$$L_y = 2y + 3\lambda y^2 = y(2 + 3\lambda y) = 0$$
$$L_\lambda = x^3 + y^3 - 1 = 0$$

情况 1：$x=0$。由约束 $y^3=1 \Rightarrow y=1$。此时 $f=1$。

情况 2：$y=0$。类似得 $x=1$，$f=1$。

情况 3：$x \neq 0, y \neq 0$。$x = -\frac{2}{3\lambda} = y$。由约束 $2x^3 = 1$，$x = \frac{1}{\sqrt[3]{2}}$，$f = 2x^2 = 2\left(\frac{1}{\sqrt[3]{2}}\right)^2 = 2^{1-2/3} = 2^{1/3} = \sqrt[3]{2}$。

检查 $x \to -\infty$ 方向？约束是 $x^3 + y^3 = 1$，当 $x \to +\infty$ 时 $y^3 = 1 - x^3 \to -\infty$，$y \to -\infty$，$f = x^2 + y^2 \to +\infty$。故无最大值！

无界。实际上题目问的是最小值。修正为最小值和最大值的有界条件，或确认无最大值。

**检验有界性**：$x^3 + y^3 = 1$。$x, y$ 可以同时趋向 $+\infty$ 和 $-\infty$（$y = \sqrt[3]{1-x^3} \sim -x$），$f = x^2 + y^2 \sim 2x^2 \to +\infty$。故**无最大值**。

$$\boxed{\text{无最大值（无上界）}}$$

### 题 24 | 困难 | 中值定理条件必要性

Rolle 定理要求 $f$ 在 $[a,b]$ 上连续、在 $(a,b)$ 内可导、$f(a)=f(b)$。举例说明三个条件每个都是必要的（去掉任一条结论均不成立）。

### 题 25 | 地狱 | 函数项级数非一致收敛证明

证明函数项级数 $\displaystyle\sum_{n=1}^\infty \frac{x}{(1+x^2)^n}$ 在 $\mathbb{R}$ 上逐点收敛但不一致收敛。

---

#### 思路溯源

判定非一致收敛最简洁的方法：利用「一致收敛 + 每项连续 → 和函数连续」的逆否命题。若每项连续而和函数不连续，则一定不一致收敛。计算和函数（几何级数），检查间断点。

#### 解

**逐点收敛性**：

当 $x=0$ 时，通项 $u_n(0)=0$，级数收敛于 $0$。

当 $x \neq 0$ 时，这是几何级数，公比 $r = \frac{1}{1+x^2} \in (0,1)$，故收敛。和函数：

$$S(x) = \sum_{n=1}^\infty \frac{x}{(1+x^2)^n} = \frac{\frac{x}{1+x^2}}{1 - \frac{1}{1+x^2}} = \frac{\frac{x}{1+x^2}}{\frac{x^2}{1+x^2}} = \frac{1}{x}$$

综上，逐点和函数为

$$S(x) = \begin{cases} \dfrac{1}{x}, & x \neq 0 \\ 0, & x = 0 \end{cases}$$

**非一致收敛性**：

每一项 $u_n(x) = \frac{x}{(1+x^2)^n}$ 在 $\mathbb{R}$ 上连续。若级数在 $\mathbb{R}$ 上一致收敛，由一致收敛的连续性定理，和函数 $S(x)$ 应在 $\mathbb{R}$ 上连续。

但 $\lim_{x\to 0} S(x) = \lim_{x\to 0} \frac{1}{x}$ 不存在（$\lim_{x\to 0^+}=+\infty, \lim_{x\to 0^-}=-\infty$），$S(x)$ 在 $x=0$ 处不连续。故级数在 $\mathbb{R}$ 上不一致收敛。

> 实际上在任何含 $x=0$ 的区间上均不一致收敛；在任意不包含 $0$ 的闭区间上一致收敛。

### 题 27 | 地狱 | 伯努利方程

求微分方程的通解：

$$\frac{dy}{dx} + \frac{1}{x}y = x^2 y^2 \quad (x > 0)$$

---

#### 思路溯源

伯努利方程 $y' + P(x)y = Q(x)y^n$（$n \neq 0,1$）。令 $z = y^{1-n}$ 化为一阶线性。

#### 解

$n=2$。令 $z = y^{1-2} = y^{-1}$，则 $y = z^{-1}$，$y' = -z^{-2}z'$。代入：

$$-z^{-2}z' + \frac{1}{x}z^{-1} = x^2 z^{-2}$$

两边乘 $-z^2$：

$$z' - \frac{1}{x}z = -x^2$$

这是一阶线性方程。$P(x) = -\frac{1}{x}$，$Q(x) = -x^2$。

$\mu(x) = e^{\int -\frac{1}{x}dx} = e^{-\ln x} = \frac{1}{x}$。

$$z = x\left(\int (-x^2)\cdot\frac{1}{x}\,dx + C\right) = x\left(\int -x\,dx + C\right) = x\left(-\frac{x^2}{2} + C\right) = Cx - \frac{x^3}{2}$$

代回 $y = \frac{1}{z}$：

$$\boxed{y = \frac{1}{Cx - \frac{x^3}{2}}}$$

### 题 28 | 困难 | 二阶常系数齐次

求微分方程的通解：

$$y'' - 5y' + 6y = 0$$

---

#### 思路溯源

二阶常系数齐次线性方程。特征方程 $r^2 - 5r + 6 = 0$，根据根的类型（相异实根/重根/共轭复根）写出通解。

#### 解

特征方程：$r^2 - 5r + 6 = 0$。判别式 $\Delta = 25 - 24 = 1 > 0$。

$r = \frac{5 \pm 1}{2}$，$r_1 = 3$，$r_2 = 2$。两相异实根。

通解：

$$\boxed{y = C_1 e^{3x} + C_2 e^{2x}}$$

### 题 29 | 地狱 | 二阶常系数非齐次 + 初始条件

求微分方程的特解：

$$y'' - 3y' + 2y = e^x, \quad y(0) = 1,\; y'(0) = 0$$

---

#### 思路溯源

先求齐次通解，再待定系数法求特解。注意 $e^x$ 是齐次解的一部分（$r=1$ 是特征根），特解形式需乘 $x$。

#### 解

**齐次**：$r^2 - 3r + 2 = 0$，$r_1=1, r_2=2$。齐次通解 $y_h = C_1 e^x + C_2 e^{2x}$。

**特解**：右端 $e^x$，$r=1$ 是单重特征根，设特解 $y_p = Axe^x$。

$y_p' = A(e^x + xe^x) = A(1+x)e^x$
$y_p'' = A(e^x + (1+x)e^x) = A(2+x)e^x$

代入原方程：$A(2+x)e^x - 3A(1+x)e^x + 2Axe^x = e^x$

提取 $Ae^x$：$A[(2+x) - 3(1+x) + 2x] = A[2+x-3-3x+2x] = A[-1] = 1$。故 $A = -1$。

$y_p = -xe^x$。

**通解**：$y = C_1 e^x + C_2 e^{2x} - xe^x$。

**初始条件**：

$y(0) = C_1 + C_2 = 1$
$y' = C_1 e^x + 2C_2 e^{2x} - (e^x + xe^x)$
$y'(0) = C_1 + 2C_2 - 1 = 0 \Rightarrow C_1 + 2C_2 = 1$

联立：$\begin{cases} C_1 + C_2 = 1 \\ C_1 + 2C_2 = 1 \end{cases}$，解得 $C_2 = 0, C_1 = 1$。

$$\boxed{y = e^x - xe^x = e^x(1-x)}$$

### 题 30 | 地狱 | 欧拉方程

求微分方程的通解（$x > 0$）：

$$x^2 y'' + xy' - y = x^2$$

---

#### 思路溯源

欧拉方程：$x^2 y'' + axy' + by = f(x)$。令 $x = e^t$，$t = \ln x$，化为常系数方程。

#### 解

令 $x = e^t$，$t = \ln x$。记 $D = \frac{d}{dt}$。

$xy' = Dy$，$x^2 y'' = D(D-1)y$。

方程化为：$D(D-1)y + Dy - y = e^{2t}$，即 $(D^2 - D + D - 1)y = e^{2t}$，$(D^2 - 1)y = e^{2t}$。

即 $\frac{d^2 y}{dt^2} - y = e^{2t}$。

**齐次**：$r^2 - 1 = 0$，$r = \pm 1$。$y_h = C_1 e^t + C_2 e^{-t}$。

**特解**：右端 $e^{2t}$，$r=2$ 不是特征根，设 $y_p = Ae^{2t}$。

$y_p'' = 4A e^{2t}$。代入：$4A e^{2t} - A e^{2t} = e^{2t} \Rightarrow 3A = 1 \Rightarrow A = \frac{1}{3}$。

$y_p = \frac{1}{3}e^{2t}$。

通解：$y(t) = C_1 e^t + C_2 e^{-t} + \frac{1}{3}e^{2t}$。

代回 $x = e^t$：

$$\boxed{y = C_1 x + \frac{C_2}{x} + \frac{x^2}{3}}$$
