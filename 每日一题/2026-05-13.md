# 每日一题 | 积分 #1

> **日期**: 2026-05-13 | **难度**: 普通 | **类型**: 积分

---

## 题目

计算定积分：

$$\int_0^{\frac{\pi}{2}} \frac{\sin x}{\sin x + \cos x}\,dx$$

---

## 解析与答案

### 解法一：对称区间换元（经典技巧）

令 $x = \dfrac{\pi}{2} - t$，则 $dx = -dt$，$\sin x = \cos t$，$\cos x = \sin t$。

当 $x: 0 \to \frac{\pi}{2}$ 时，$t: \frac{\pi}{2} \to 0$：

$$
\begin{aligned}
I &= \int_0^{\frac{\pi}{2}} \frac{\sin x}{\sin x + \cos x}\,dx \\
&= \int_{\frac{\pi}{2}}^{0} \frac{\cos t}{\cos t + \sin t}\,(-dt) \\
&= \int_0^{\frac{\pi}{2}} \frac{\cos t}{\sin t + \cos t}\,dt = \int_0^{\frac{\pi}{2}} \frac{\cos x}{\sin x + \cos x}\,dx
\end{aligned}
$$

将原积分记为 $I$，新积分记为 $J$，注意到 $I + J$：

$$I + J = \int_0^{\frac{\pi}{2}} \frac{\sin x + \cos x}{\sin x + \cos x}\,dx = \int_0^{\frac{\pi}{2}} 1\,dx = \frac{\pi}{2}$$

而由对称性 $I = J$，故 $2I = \dfrac{\pi}{2}$，即 $I = \dfrac{\pi}{4}$。

---

### 解法二：万能公式换元

令 $t = \tan\dfrac{x}{2}$，则 $\sin x = \dfrac{2t}{1+t^2}$，$\cos x = \dfrac{1-t^2}{1+t^2}$，$dx = \dfrac{2}{1+t^2}dt$。转化为有理函数积分后也可得 $\frac{\pi}{4}$（过程略繁琐，不推荐）。

---

### 答案

$$\boxed{\frac{\pi}{4}}$$

---

### 妙处所在

> 利用**区间再现换元**（$x \to \frac{\pi}{2}-x$）后，原积分与新积分恰好**互为补充**，相加消去分母的复杂性，一招制敌。

---

## 避坑警示

> ⚠️ 换元 $x = \frac{\pi}{2}-t$ 后，积分上下限必须同步变换：$x: 0 \to \frac{\pi}{2}$ 对应 $t: \frac{\pi}{2} \to 0$，别忘了 $dx = -dt$ 带来的符号翻转。

## 知识点关联

- 区间再现法：令 $t = a+b-x$
- 定积分的对称性
- $\sin$ 与 $\cos$ 在 $[0,\frac{\pi}{2}]$ 上的「交换对称」
