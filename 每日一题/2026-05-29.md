## 一、微分（中值定理 · 辅助函数构造）

### 题 1

> 设 $f(x)$ 在 $[0,1]$ 上连续，在 $(0,1)$ 内可导，且 $f(0)=f(1)=0$。
>
> 证明：存在 $\xi \in (0,1)$，使得 $\xi f'(\xi) + 2f(\xi) = 0$。

**思路溯源**

结论中 $\xi f'(\xi) + 2f(\xi) = 0$ 可识别为乘积求导：$(x^2 f(x))' = 2x f(x) + x^2 f'(x) = x[x f'(x) + 2f(x)]$。构造 $F(x) = x^2 f(x)$ 即可消去 $x$ 因子后在 $\xi$ 处得零。

**解法**：

令 $F(x) = x^2 f(x)$。$F(x)$ 在 $[0,1]$ 上连续，在 $(0,1)$ 内可导。

$$F(0) = 0^2\cdot f(0) = 0,\qquad F(1) = 1^2\cdot f(1) = 0$$

由 Rolle 定理，存在 $\xi \in (0,1)$ 使 $F'(\xi) = 0$。

$$F'(x) = 2x f(x) + x^2 f'(x)$$

$$F'(\xi) = 2\xi f(\xi) + \xi^2 f'(\xi) = \xi[\xi f'(\xi) + 2f(\xi)] = 0$$

由 $\xi \in (0,1)$ 得 $\xi \neq 0$，故 $\xi f'(\xi) + 2f(\xi) = 0$。证毕。

### 题 2

> 设 $f(x)$ 在 $[0,3]$ 上连续，在 $(0,3)$ 内可导，且
>
> $$f(0)=0,\quad f(1)=1,\quad f(2)=2,\quad f(3)=0$$
>
> 证明：存在 $\xi \in (0,3)$，使得 $f'(\xi) = 0$。

**思路溯源**

四个点不全是端点，不能用直接的 Rolle 或 Lagrange 一步到位。但观察 $f(2)=2 > 0$ 而 $f(3)=0$，由连续函数的介值性可在 $(2,3)$ 内找到函数值等于 $f(1)=1$ 的点，从而构造出两个函数值相等的点，再用 Rolle。

**解法**：

$f(x)$ 在 $[2,3]$ 上连续，$f(2)=2$，$f(3)=0$。由介值定理，存在 $c \in (2,3)$ 使 $f(c) = 1$。

又 $f(1) = 1$，故 $f(1) = f(c) = 1$。

$f(x)$ 在 $[1, c]$ 上满足 Rolle 定理条件（连续、可导、端点函数值相等），存在 $\xi \in (1, c) \subset (0,3)$ 使 $f'(\xi) = 0$。证毕。

### 题 3

> 设 $f(x)$ 在 $[0,1]$ 上连续，在 $(0,1)$ 内可导。
>
> 证明：存在 $\xi \in (0,1)$，使得 $f'(\xi) = 2\xi\,[f(1)-f(0)]$。

**思路溯源**

结论中含 $\xi$ 与 $f'(\xi)$ 的乘积关系，右侧 $f(1)-f(0)$ 是函数值之差。这是 Cauchy 中值定理的标准信号。取 $g(x) = x^2$，则 $g'(x) = 2x$，$g(1)-g(0) = 1$，代入 Cauchy 公式约分即得。

**解法**：

取 $g(x) = x^2$。$g(x)$ 在 $[0,1]$ 上连续，在 $(0,1)$ 内可导，且 $g'(x) = 2x \neq 0$（$x \in (0,1)$）。

由 Cauchy 中值定理，存在 $\xi \in (0,1)$ 使
$$\frac{f(1)-f(0)}{g(1)-g(0)} = \frac{f'(\xi)}{g'(\xi)}$$

代入 $g(1) = 1$，$g(0) = 0$，$g'(\xi) = 2\xi$：
$$\frac{f(1)-f(0)}{1-0} = \frac{f'(\xi)}{2\xi}$$

即 $f'(\xi) = 2\xi\,[f(1)-f(0)]$。证毕。

## 二、积分

### 题 4 — 分部积分（反三角）

> 计算不定积分：$\displaystyle \int x\arctan x\,dx$

**思路溯源**

反三角函数 $\times$ 多项式。按"反对幂指三"，反三角函数优先级最高，选作 $u$。$u = \arctan x$ 求导得 $\frac{1}{1+x^2}$，$dv = x\,dx$ 积分得 $\frac{1}{2}x^2$。分部后剩下的积分是 $\int\frac{x^2}{1+x^2}dx$，通过加一减一凑成 $1 - \frac{1}{1+x^2}$。

**解法**：

取 $u = \arctan x$，$dv = x\,dx$，则 $du = \frac{1}{1+x^2}dx$，$v = \frac{1}{2}x^2$。

$$\begin{aligned}
\int x\arctan x\,dx
&= \frac{1}{2}x^2\arctan x - \frac{1}{2}\int\frac{x^2}{1+x^2}\,dx \\[4pt]
&= \frac{1}{2}x^2\arctan x - \frac{1}{2}\int\!\left(1 - \frac{1}{1+x^2}\right)dx \\[4pt]
&= \frac{1}{2}x^2\arctan x - \frac{1}{2}\!\left(x - \arctan x\right) + C
\end{aligned}$$

$$\boxed{\int x\arctan x\,dx = \frac{1}{2}(x^2+1)\arctan x - \frac{x}{2} + C}$$

### 题 5 — 配方 $\to \arctan$

> 计算不定积分：$\displaystyle \int\frac{dx}{x^2+6x+13}$

**思路溯源**

分母判别式 $\Delta = 36-52 = -16 < 0$，不可因式分解。配方化为 $(x+a)^2 + b^2$ 形式后，凑成 $\arctan$ 标准积分 $\int\frac{du}{u^2+a^2} = \frac{1}{a}\arctan\frac{u}{a}$。

**解法**：

分母配方：
$$x^2+6x+13 = (x+3)^2 - 9 + 13 = (x+3)^2 + 4$$

$$\int\frac{dx}{x^2+6x+13} = \int\frac{dx}{(x+3)^2 + 4} = \frac{1}{4}\int\frac{dx}{\left(\frac{x+3}{2}\right)^2 + 1}$$

令 $u = \frac{x+3}{2}$，$dx = 2\,du$：
$$= \frac{1}{4}\int\frac{2\,du}{u^2+1} = \frac{1}{2}\arctan u + C$$

回代：
$$\boxed{\int\frac{dx}{x^2+6x+13} = \frac{1}{2}\arctan\frac{x+3}{2} + C}$$

### 题 6 — 凑微分

> 计算不定积分：$\displaystyle \int\frac{x}{x^4+1}\,dx$

**思路溯源**

分子 $x\,dx$ 恰好是 $\frac{1}{2}d(x^2)$，分母 $x^4+1 = (x^2)^2+1$。令 $u = x^2$ 即化为 $\frac{1}{2}\int\frac{du}{u^2+1}$，直接积出 $\arctan$。

**解法**：

令 $u = x^2$，则 $du = 2x\,dx$，$x\,dx = \frac{1}{2}du$。

$$\begin{aligned}
\int\frac{x}{x^4+1}\,dx
&= \int\frac{x}{(x^2)^2+1}\,dx \\[4pt]
&= \frac{1}{2}\int\frac{du}{u^2+1} \\[4pt]
&= \frac{1}{2}\arctan u + C
\end{aligned}$$

$$\boxed{\int\frac{x}{x^4+1}\,dx = \frac{1}{2}\arctan(x^2) + C}$$

### 题 7 — 降幂公式

> 计算不定积分：$\displaystyle \int\cos^4 x\,dx$

**思路溯源**

$\cos x$ 的偶次幂，无 $\sin x$ 可配微分。用倍角公式逐次降幂：$\cos^2\theta = \frac{1+\cos 2\theta}{2}$。需要降两次。

**解法**：

$$\cos^4 x = (\cos^2 x)^2 = \left(\frac{1+\cos 2x}{2}\right)^2 = \frac{1}{4}\!\left(1 + 2\cos 2x + \cos^2 2x\right)$$

对 $\cos^2 2x$ 再次降幂：$\cos^2 2x = \frac{1+\cos 4x}{2}$。

$$\cos^4 x = \frac{1}{4}\!\left(1 + 2\cos 2x + \frac{1+\cos 4x}{2}\right) = \frac{1}{4}\!\left(\frac{3}{2} + 2\cos 2x + \frac{\cos 4x}{2}\right) = \frac{3}{8} + \frac{1}{2}\cos 2x + \frac{1}{8}\cos 4x$$

$$\begin{aligned}
\int\cos^4 x\,dx
&= \int\!\left(\frac{3}{8} + \frac{1}{2}\cos 2x + \frac{1}{8}\cos 4x\right)dx \\[4pt]
&= \frac{3}{8}x + \frac{1}{4}\sin 2x + \frac{1}{32}\sin 4x + C
\end{aligned}$$

$$\boxed{\int\cos^4 x\,dx = \frac{3}{8}x + \frac{1}{4}\sin 2x + \frac{1}{32}\sin 4x + C}$$

### 题 8 — 倒代换

> 计算不定积分：$\displaystyle \int\frac{dx}{x^2\sqrt{x^2-1}} \quad (x>1)$

**思路溯源**

分母中 $x$ 的幂次远高于根号内的幂次（$x^2$ vs $\sqrt{x^2}$），适合用倒代换 $t = \frac{1}{x}$，将分子分母的幂次关系反转。

**解法**：

令 $t = \frac{1}{x}$，则 $x = \frac{1}{t}$，$dx = -\frac{1}{t^2}dt$。

当 $x>1$ 时，$0<t<1$。$\sqrt{x^2-1} = \sqrt{\frac{1}{t^2}-1} = \frac{\sqrt{1-t^2}}{|t|} = \frac{\sqrt{1-t^2}}{t}$（$t>0$）。

$$\begin{aligned}
\int\frac{dx}{x^2\sqrt{x^2-1}}
&= \int\frac{-\frac{1}{t^2}dt}{\frac{1}{t^2}\cdot\frac{\sqrt{1-t^2}}{t}} \\[4pt]
&= -\int\frac{t}{\sqrt{1-t^2}}\,dt
\end{aligned}$$

凑微分：$t\,dt = -\frac{1}{2}d(1-t^2)$。

$$-\int\frac{t}{\sqrt{1-t^2}}\,dt = -\int\frac{-\frac{1}{2}d(1-t^2)}{\sqrt{1-t^2}} = \frac{1}{2}\int\frac{d(1-t^2)}{\sqrt{1-t^2}} = \sqrt{1-t^2} + C$$

回代 $t = \frac{1}{x}$：
$$\sqrt{1-t^2} = \sqrt{1-\frac{1}{x^2}} = \frac{\sqrt{x^2-1}}{|x|} = \frac{\sqrt{x^2-1}}{x} \quad (x>0)$$

$$\boxed{\int\frac{dx}{x^2\sqrt{x^2-1}} = \frac{\sqrt{x^2-1}}{x} + C}$$
