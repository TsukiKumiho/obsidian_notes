## 一、极限题（5 题）

### 题 1 | 困难 | $0^0$ 型 · 取对数 + 洛必达

**题目**：求极限

$$\lim_{x\to 0^+} (\sin x)^{\frac{1}{\ln x}}$$

**思路溯源**：底数和指数均含 $x$，且 $\sin x\to 0$、$1/\ln x\to 0$（因 $\ln x\to -\infty$），为 $0^0$ 型。标准套路：取对数将指数"拉下来"，化为 $\frac{-\infty}{-\infty}$ 型用洛必达。关键在于 $\frac{d}{dx}\ln\sin x = \cot x$ 与 $\frac{d}{dx}\ln x = \frac{1}{x}$ 的比值化简。

**解法**：

令 $L$ 为原极限。取对数：

$$\ln L = \lim_{x\to 0^+} \frac{\ln(\sin x)}{\ln x}$$

当 $x\to 0^+$ 时，分子 $\ln(\sin x)\to -\infty$，分母 $\ln x\to -\infty$，为 $\frac{-\infty}{-\infty}$ 型。洛必达：

$$\ln L = \lim_{x\to 0^+} \frac{\frac{\cos x}{\sin x}}{\frac{1}{x}} = \lim_{x\to 0^+} x\cot x = \lim_{x\to 0^+} \frac{x}{\tan x} \cdot \cos x$$

$\frac{x}{\tan x}\to 1$，$\cos x\to 1$，故 $\ln L = 1$。从而 $L = e$。

$$\boxed{e}$$

### 题 2 | 地狱 | 数列精细渐近 · $(1+1/n)^n$ 展开

**题目**：求极限

$$\lim_{n\to\infty} n\left[\left(1+\frac{1}{n}\right)^n - e\right]$$

**思路溯源**：$(1+1/n)^n\to e$，但仅知此不足以确定 $n[(1+1/n)^n-e]$ 的极限（$n\cdot 0$ 不定式）。需将 $(1+1/n)^n$ 展开到 $1/n$ 阶：利用 $n\ln(1+1/n)$ 的 Taylor 展开，代入指数函数后再展开。目标：找出 $e$ 与 $(1+1/n)^n$ 之差的渐近主项。

**解法**：

$$n\ln\left(1+\frac{1}{n}\right) = n\left(\frac{1}{n} - \frac{1}{2n^2} + \frac{1}{3n^3} + O\!\left(\frac{1}{n^4}\right)\right) = 1 - \frac{1}{2n} + \frac{1}{3n^2} + O\!\left(\frac{1}{n^3}\right)$$

代入指数函数：

$$\begin{aligned}
\left(1+\frac{1}{n}\right)^n &= \exp\!\left(1 - \frac{1}{2n} + \frac{1}{3n^2} + O\!\left(\frac{1}{n^3}\right)\right) \\
&= e \cdot \exp\!\left(-\frac{1}{2n} + \frac{1}{3n^2} + O\!\left(\frac{1}{n^3}\right)\right) \\
&= e\left[1 + \left(-\frac{1}{2n} + \frac{1}{3n^2}\right) + \frac{1}{2}\!\left(-\frac{1}{2n}\right)^2 + O\!\left(\frac{1}{n^3}\right)\right] \\
&= e\left[1 - \frac{1}{2n} + \left(\frac{1}{3}+\frac{1}{8}\right)\frac{1}{n^2} + O\!\left(\frac{1}{n^3}\right)\right] \\
&= e - \frac{e}{2n} + O\!\left(\frac{1}{n^2}\right)
\end{aligned}$$

故

$$n\left[\left(1+\frac{1}{n}\right)^n - e\right] = n\left[-\frac{e}{2n} + O\!\left(\frac{1}{n^2}\right)\right] = -\frac{e}{2} + O\!\left(\frac{1}{n}\right) \xrightarrow{n\to\infty} -\frac{e}{2}$$

$$\boxed{-\dfrac{e}{2}}$$

### 题 3 | 地狱 | 嵌套 Taylor 展开 · $\cos(\sin x)$

**题目**：求极限

$$\lim_{x\to 0}\frac{\cos(\sin x) - \cos x}{x^4}$$

**思路溯源**：分子为 $\cos$ 作用于两个不同的小量。分别对 $\cos(\sin x)$ 和 $\cos x$ 做 Taylor 展开至 $x^4$ 项。$\cos(\sin x)$ 的展开需两步：先用 $\sin x$ 的展开，再代入 $\cos$ 的展开式（复合函数的 Taylor 展开）。关键在于 $\sin x$ 展开至 $x^3$ 后再代入 $\cos$，确保最终截断到 $x^4$。

**解法**：

先展开 $\sin x$：

$$\sin x = x - \frac{x^3}{6} + O(x^5)$$

将 $\cos t$ 在 $t=0$ 展开至 $t^4$：$\cos t = 1 - \frac{t^2}{2} + \frac{t^4}{24} + O(t^6)$。

代入 $t = \sin x$：

$$\begin{aligned}
\cos(\sin x) &= 1 - \frac{1}{2}\!\left(x - \frac{x^3}{6}\right)^2 + \frac{1}{24}x^4 + O(x^6) \\
&= 1 - \frac{1}{2}\!\left(x^2 - \frac{x^4}{3} + O(x^6)\right) + \frac{x^4}{24} + O(x^6) \\
&= 1 - \frac{x^2}{2} + \frac{x^4}{6} + \frac{x^4}{24} + O(x^6) \\
&= 1 - \frac{x^2}{2} + \frac{5}{24}x^4 + O(x^6)
\end{aligned}$$

而 $\cos x = 1 - \frac{x^2}{2} + \frac{x^4}{24} + O(x^6)$。

两式相减：

$$\cos(\sin x) - \cos x = \left(\frac{5}{24} - \frac{1}{24}\right)x^4 + O(x^6) = \frac{1}{6}x^4 + O(x^6)$$

故

$$\lim_{x\to 0}\frac{\cos(\sin x) - \cos x}{x^4} = \boxed{\frac{1}{6}}$$

### 题 4 | 困难 | 嵌套根式有理化

**题目**：求极限

$$\lim_{x\to +\infty}\left(\sqrt{x + \sqrt{x + \sqrt{x}}} - \sqrt{x}\right)$$

**思路溯源**：$\infty-\infty$ 型，用平方差有理化 $(a-b)(a+b)=a^2-b^2$。分子变为 $\sqrt{x+\sqrt{x}}$，分母变为两平方根之和 $\approx 2\sqrt{x}$，整体趋于 $1/2$。关键在于有理化后分子/分母的阶数比较——嵌套根号在最外层"剥掉"后，剩余结构的渐近阶数正好给出有限极限。

**解法**：

记原极限为 $L$。用平方差有理化：

$$\begin{aligned}
L &= \lim_{x\to +\infty}\frac{\left(x + \sqrt{x + \sqrt{x}}\right) - x}{\sqrt{x + \sqrt{x + \sqrt{x}}} + \sqrt{x}} \\
&= \lim_{x\to +\infty}\frac{\sqrt{x + \sqrt{x}}}{\sqrt{x + \sqrt{x + \sqrt{x}}} + \sqrt{x}}
\end{aligned}$$

分子分母同除以 $\sqrt{x}$：

$$L = \lim_{x\to +\infty}\frac{\sqrt{1 + \frac{1}{\sqrt{x}}}}{\sqrt{1 + \frac{1}{\sqrt{x}}\sqrt{1 + \frac{1}{\sqrt{x}}}} + 1}$$

当 $x\to +\infty$ 时，$\frac{1}{\sqrt{x}}\to 0$。故

$$L = \frac{\sqrt{1 + 0}}{\sqrt{1 + 0} + 1} = \frac{1}{2}$$

$$\boxed{\dfrac{1}{2}}$$

### 题 5 | 困难 | 导数定义求极限

**题目**：求极限

$$\lim_{x\to 0}\frac{\ln(\cos x + \sin x)}{x}$$

**思路溯源**：$\frac{0}{0}$ 型。注意分子 $\ln(\cos 0 + \sin 0) = \ln 1 = 0$。令 $f(x) = \ln(\cos x + \sin x)$，原极限恰为 $f'(0)$ 的定义 $\lim_{x\to 0}\frac{f(x)-f(0)}{x}$。用导数定义计算比洛必达更直接——这是"看出极限即导数"的经典思维。

**解法**：

令 $f(x) = \ln(\cos x + \sin x)$。则 $f(0) = \ln(1+0) = 0$。由导数定义：

$$\lim_{x\to 0}\frac{\ln(\cos x + \sin x)}{x} = \lim_{x\to 0}\frac{f(x)-f(0)}{x-0} = f'(0)$$

计算 $f'(x)$：

$$f'(x) = \frac{-\sin x + \cos x}{\cos x + \sin x}$$

$$f'(0) = \frac{0 + 1}{1 + 0} = 1$$

$$\boxed{1}$$

## 二、中值定理题（5 题）

### 题 6 | 困难 | 辅助函数 $F(x)=f(x)\cos x$

**题目**：设 $f(x)$ 在 $[0,\frac{\pi}{2}]$ 上可导，且 $f(0)=0$。证明：存在 $\xi\in(0,\frac{\pi}{2})$ 使得

$$f'(\xi)\cos\xi = f(\xi)\sin\xi$$

**思路溯源**：结论可改写为 $f'(\xi)\cos\xi - f(\xi)\sin\xi = 0$，左边正是 $(f(x)\cos x)'$ 在 $x=\xi$ 处的值。构造 $F(x)=f(x)\cos x$，则 $F(0)=f(0)\cdot 1 = 0$，$F(\frac{\pi}{2})=f(\frac{\pi}{2})\cdot 0 = 0$（无论 $f(\frac{\pi}{2})$ 取何值！这是巧妙之处）。Rolle 定理即得结论。

**解法**：

令 $F(x) = f(x)\cos x$。$F$ 在 $[0,\frac{\pi}{2}]$ 上可导，且

$$F(0) = f(0)\cos 0 = 0\cdot 1 = 0$$
$$F\!\left(\frac{\pi}{2}\right) = f\!\left(\frac{\pi}{2}\right)\cos\frac{\pi}{2} = f\!\left(\frac{\pi}{2}\right)\cdot 0 = 0$$

$F(0)=F(\frac{\pi}{2})$，由 Rolle 定理，存在 $\xi\in(0,\frac{\pi}{2})$ 使 $F'(\xi)=0$。而

$$F'(x) = f'(x)\cos x - f(x)\sin x$$

故 $f'(\xi)\cos\xi - f(\xi)\sin\xi = 0$，即 $f'(\xi)\cos\xi = f(\xi)\sin\xi$。证毕。

> 关键技巧：**选择乘积因子使辅助函数在右端点自动为零**——$\cos\frac{\pi}{2}=0$ 使 $F(\frac{\pi}{2})=0$ 无需 $f(\frac{\pi}{2})$ 的任何条件。

### 题 7 | 困难 | Taylor 公式直接应用

**题目**：设 $f(x)$ 在 $[0,1]$ 上二阶可导，$f(0)=0$，$f'(0)=0$，$f(1)=1$。证明：存在 $\xi\in(0,1)$ 使得 $f''(\xi)=2$。

**思路溯源**：条件给出 $x=0$ 处的函数值与一阶导数值，以及 $x=1$ 处的函数值——这正是 Taylor 公式的标准使用场景。将 $f(1)$ 在 $x=0$ 展开至一阶，Lagrange 余项自然引出 $f''(\xi)$。由于 $f(0)=f'(0)=0$，展开式中仅余项非零。

**解法**：

将 $f$ 在 $x_0=0$ 处展开为一阶 Taylor 公式（带 Lagrange 余项）：

$$f(x) = f(0) + f'(0)x + \frac{f''(\eta)}{2}x^2$$

其中 $\eta$ 在 $0$ 与 $x$ 之间。

取 $x=1$：存在 $\xi\in(0,1)$ 使得

$$f(1) = f(0) + f'(0)\cdot 1 + \frac{f''(\xi)}{2}\cdot 1^2$$

代入已知条件 $f(0)=0$，$f'(0)=0$，$f(1)=1$：

$$1 = 0 + 0 + \frac{f''(\xi)}{2}$$

故 $f''(\xi) = 2$。证毕。

### 题 8 | 困难 | Lagrange 中值定理证双边不等式

**题目**：证明：当 $x>0$ 时，

$$\frac{x}{1+x^2} < \arctan x < x$$

**思路溯源**：$\arctan x$ 在 $[0,x]$ 上用 Lagrange 中值定理：$\frac{\arctan x - \arctan 0}{x-0} = \frac{1}{1+\xi^2}$，其中 $0<\xi<x$。右不等式 $\arctan x < x$ 由 $\frac{1}{1+\xi^2}<1$ 直接得到；左不等式需利用 $\xi<x$ 推出 $\frac{1}{1+\xi^2} > \frac{1}{1+x^2}$。左右两边约束来自中值点 $\xi$ 在不同位置时导数值的上下界。

**解法**：

对 $f(t)=\arctan t$ 在 $[0,x]$ 上用 Lagrange 中值定理：存在 $\xi\in(0,x)$ 使得

$$\frac{\arctan x - \arctan 0}{x-0} = f'(\xi) = \frac{1}{1+\xi^2}$$

即 $\arctan x = \frac{x}{1+\xi^2}$。

由 $0<\xi<x$，得 $1 < 1+\xi^2 < 1+x^2$。取倒数（所有量均为正）：

$$\frac{1}{1+x^2} < \frac{1}{1+\xi^2} < 1$$

乘以 $x>0$：

$$\frac{x}{1+x^2} < \frac{x}{1+\xi^2} < x$$

中间项即为 $\arctan x$。故 $\frac{x}{1+x^2} < \arctan x < x$。证毕。

### 题 9 | 地狱 | 推广积分中值定理的证明

**题目**：设 $f(x)$ 在 $[a,b]$ 上连续，$g(x)$ 在 $[a,b]$ 上可积且不变号（即恒有 $g(x)\ge 0$ 或恒有 $g(x)\le 0$）。证明：存在 $\xi\in[a,b]$ 使得

$$\int_a^b f(x)g(x)\,dx = f(\xi)\int_a^b g(x)\,dx$$

**思路溯源**：这是积分第一中值定理的推广形式（标准形式对应 $g(x)\equiv 1$）。证明思路：由 $f$ 连续知其有最大值 $M$ 和最小值 $m$，利用 $g$ 不变号建立不等式链，再对连续函数用介值定理即得。若 $\int_a^b g = 0$，则 $\int_a^b fg = 0$，结论平凡成立（任意 $\xi$ 均可）。

**解法**：

不妨设 $g(x)\ge 0$（$g\le 0$ 时用 $-g$ 替换，结论等价）。

$f$ 在 $[a,b]$ 上连续，故有最大值 $M$ 和最小值 $m$，使 $m\le f(x)\le M$ 对所有 $x\in[a,b]$ 成立。

因 $g(x)\ge 0$，乘以 $g(x)$ 不等式方向不变：

$$m\,g(x) \le f(x)g(x) \le M\,g(x)$$

在 $[a,b]$ 上积分：

$$m\int_a^b g(x)\,dx \le \int_a^b f(x)g(x)\,dx \le M\int_a^b g(x)\,dx$$

记 $I = \int_a^b g(x)\,dx$。

若 $I = 0$，则上式推出 $\int_a^b fg = 0$，结论对任意 $\xi$ 均成立（等式两边均为 $0$）。

若 $I > 0$，两边除以 $I$：

$$m \le \frac{\int_a^b f(x)g(x)\,dx}{I} \le M$$

令 $\mu = \frac{1}{I}\int_a^b f(x)g(x)\,dx$（介于 $f$ 的最小值与最大值之间）。由连续函数的介值定理，存在 $\xi\in[a,b]$ 使得 $f(\xi)=\mu$。代入即得所证。证毕。

### 题 10 | 地狱 | 辅助函数 $x\int_0^x f$ + Rolle

**题目**：设 $f(x)$ 在 $[0,1]$ 上连续，且 $\int_0^1 f(x)\,dx = 0$。证明：存在 $\xi\in(0,1)$ 使得

$$\int_0^\xi f(x)\,dx + \xi f(\xi) = 0$$

**思路溯源**：结论左边正是 $\left[x\int_0^x f(t)\,dt\right]'$ 在 $x=\xi$ 处的值。构造 $F(x)=x\int_0^x f(t)\,dt$。由条件知 $F(0)=0$，$F(1)=1\cdot\int_0^1 f = 0$。Rolle 定理给出 $F'(\xi)=0$，即结论。这是利用乘积求导法则构造辅助函数的典型范例。

**解法**：

令 $F(x) = x\int_0^x f(t)\,dt$。$F$ 在 $[0,1]$ 上连续，在 $(0,1)$ 内可导。且

$$F(0) = 0\cdot 0 = 0,\qquad F(1) = 1\cdot\int_0^1 f(t)\,dt = 1\cdot 0 = 0$$

$F(0)=F(1)$，由 Rolle 定理，存在 $\xi\in(0,1)$ 使 $F'(\xi)=0$。

由乘积求导法则：

$$F'(x) = 1\cdot\int_0^x f(t)\,dt + x\cdot f(x) = \int_0^x f(t)\,dt + xf(x)$$

故 $F'(\xi) = \int_0^\xi f(x)\,dx + \xi f(\xi) = 0$。证毕。

### 题 11 | 困难 | Wallis 递推公式

**题目**：设 $I_n = \displaystyle\int_0^{\pi/2}\sin^n x\,dx$（$n=0,1,2,\dots$）。

(1) 证明递推公式 $I_n = \frac{n-1}{n}I_{n-2}$（$n\ge 2$）；

(2) 计算 $I_7$。

**思路溯源**：将 $\sin^n x$ 写为 $\sin^{n-1}x\cdot\sin x$，以 $\sin^{n-1}x$ 为 $u$、$\sin x\,dx = -d(\cos x)$ 为 $dv$ 作分部积分。化简中利用 $\cos^2 x = 1-\sin^2 x$ 将 $I_n$ 用 $I_{n-2}$ 表示，即得递推。最后利用 $I_0=\frac{\pi}{2}$ 和 $I_1=1$ 为基础，按递推降次计算。

**解法**：

**(1) 建立递推**

$$I_n = \int_0^{\pi/2}\sin^{n-1}x\cdot\sin x\,dx$$

分部积分：令 $u=\sin^{n-1}x$，$dv=\sin x\,dx$，则 $du=(n-1)\sin^{n-2}x\cos x\,dx$，$v=-\cos x$。

$$\begin{aligned}
I_n &= \left[-\sin^{n-1}x\cos x\right]_0^{\pi/2} + (n-1)\int_0^{\pi/2}\sin^{n-2}x\cos^2 x\,dx \\
&= 0 + (n-1)\int_0^{\pi/2}\sin^{n-2}x(1-\sin^2 x)\,dx \\
&= (n-1)I_{n-2} - (n-1)I_n
\end{aligned}$$

移项：$I_n + (n-1)I_n = (n-1)I_{n-2}$，即 $nI_n = (n-1)I_{n-2}$。

故 $I_n = \dfrac{n-1}{n}I_{n-2}$（$n\ge 2$）。

**(2) 计算 $I_7$**

基础值：$I_0 = \int_0^{\pi/2}1\,dx = \frac{\pi}{2}$，$I_1 = \int_0^{\pi/2}\sin x\,dx = 1$。

反复使用递推式（仅含奇数下标）：

$$I_7 = \frac{6}{7}I_5 = \frac{6}{7}\cdot\frac{4}{5}I_3 = \frac{6}{7}\cdot\frac{4}{5}\cdot\frac{2}{3}I_1 = \frac{6\cdot 4\cdot 2}{7\cdot 5\cdot 3}\cdot 1 = \frac{48}{105} = \frac{16}{35}$$

$$\boxed{I_7 = \dfrac{16}{35}}$$

### 题 12 | 地狱 | $\int_0^{\pi/2}\ln(\sin x)\,dx$ 对称性巧算

**题目**：计算定积分

$$I = \int_0^{\pi/2}\ln(\sin x)\,dx$$

**思路溯源**：积分区间为 $[0,\frac{\pi}{2}]$，被积函数中 $\sin x$ 与 $\cos x$ 对称。作换元 $x=\frac{\pi}{2}-t$ 得 $I = \int_0^{\pi/2}\ln(\cos t)\,dt$。两式相加后用 $\ln(\sin x\cos x) = \ln(\frac{\sin 2x}{2})$ 化简，再利用换元 $u=2x$ 将积分回到 $I$ 的形式，解方程即得 $I$。这是一个经典的"自指方程"积分。

**解法**：

令 $x = \frac{\pi}{2} - t$，则 $dx = -dt$：

$$I = \int_{\pi/2}^0 \ln\!\left(\sin\!\left(\frac{\pi}{2}-t\right)\right)(-dt) = \int_0^{\pi/2}\ln(\cos t)\,dt$$

故 $I = \int_0^{\pi/2}\ln(\cos x)\,dx$。与原式相加：

$$2I = \int_0^{\pi/2}\left[\ln(\sin x) + \ln(\cos x)\right]dx = \int_0^{\pi/2}\ln(\sin x\cos x)\,dx$$

利用 $\sin x\cos x = \frac{\sin 2x}{2}$：

$$2I = \int_0^{\pi/2}\ln\!\left(\frac{\sin 2x}{2}\right)dx = \int_0^{\pi/2}\ln(\sin 2x)\,dx - \int_0^{\pi/2}\ln 2\,dx$$

第一项换元 $u=2x$，$dx = \frac{du}{2}$，积分限变为 $0\to\pi$：

$$\int_0^{\pi/2}\ln(\sin 2x)\,dx = \frac{1}{2}\int_0^\pi\ln(\sin u)\,du = \frac{1}{2}\cdot 2\int_0^{\pi/2}\ln(\sin u)\,du = I$$

（因 $\sin u$ 在 $[0,\pi]$ 上关于 $u=\frac{\pi}{2}$ 对称。）

第二项：$\int_0^{\pi/2}\ln 2\,dx = \frac{\pi}{2}\ln 2$。

故 $2I = I - \frac{\pi}{2}\ln 2$，解得

$$\boxed{I = -\dfrac{\pi}{2}\ln 2}$$

### 题 13 | 地狱 | 反常积分双参数敛散性

**题目**：讨论反常积分 $\displaystyle\int_2^{+\infty}\frac{dx}{x^p\ln^q x}$ 的敛散性（$p,q\in\mathbb{R}$，$q>0$）。

**思路溯源**：$\ln x$ 增长极慢，对敛散性的影响体现在：(1) 当 $p>1$ 时，$\frac{1}{x^p}$ 的衰减足以使积分收敛（可乘任意 $\ln$ 的幂）；(2) 当 $p=1$ 时，$\frac{1}{x}$ 本身使积分发散，此时 $\ln^q x$ 决定是否收敛——类比 $\int\frac{du}{u^q}$ 的敛散性；(3) 当 $p<1$ 时必发散。这是罕见的**双参数**含参反常积分。

**解法**：

**情况 1：$p > 1$。**
取 $\varepsilon$ 满足 $0<\varepsilon<p-1$。当 $x$ 充分大时 $\ln^q x < x^\varepsilon$（$\ln$ 增长慢于任何正幂），故

$$\frac{1}{x^p\ln^q x} < \frac{1}{x^{p-\varepsilon}}$$

而 $p-\varepsilon>1$，$\int_2^\infty\frac{dx}{x^{p-\varepsilon}}$ 收敛。由比较判别法，原积分**收敛**。

**情况 2：$p = 1$。**
作换元 $u=\ln x$，$du=\frac{dx}{x}$：

$$\int_2^{+\infty}\frac{dx}{x\ln^q x} = \int_{\ln 2}^{+\infty}\frac{du}{u^q}$$

由 $u^{-q}$ 积分敛散性：**收敛**当且仅当 $q>1$。

**情况 3：$p < 1$。**
取 $\varepsilon$ 满足 $0<\varepsilon<1-p$。当 $x$ 充分大时，

$$\frac{1}{x^p\ln^q x} > \frac{1}{x^{p+\varepsilon}}$$

而 $p+\varepsilon<1$，$\int_2^\infty\frac{dx}{x^{p+\varepsilon}}$ 发散。由比较判别法（反向），原积分**发散**。

综上：

$$\boxed{\text{收敛}\iff p>1\text{ 或 }(p=1\text{ 且 }q>1)}$$

> ⚠️ 当 $p=1$ 时，**$q$ 的取值决定了敛散性**——这是考试中常见的陷阱。$p>1$ 时 $q$ 的取值不影响收敛。

### 题 14 | 困难 | 积分不等式 · 单调函数的加权积分

**题目**：设 $f(x)$ 在 $[0,1]$ 上连续且单调递增。证明：

$$\int_0^1 x f(x)\,dx \ge \frac{1}{2}\int_0^1 f(x)\,dx$$

**思路溯源**：将右侧移到左侧，不等号变为 $\int_0^1(x-\frac{1}{2})f(x)\,dx\ge 0$。在 $x=\frac{1}{2}$ 处因子 $x-\frac{1}{2}$ 变号——前负后正。利用 $f$ 递增在左右两段上放缩：左段 $f(x)\le f(\frac{1}{2})$，右段 $f(x)\ge f(\frac{1}{2})$。关键的"神来之笔"是：$\int_0^1 (x-\frac{1}{2})\,dx = 0$，故可以减去 $f(\frac{1}{2})$ 将积分转化为恒非负的乘积。

**解法**：

考虑

$$\int_0^1 \left(x-\frac{1}{2}\right)f(x)\,dx = \int_0^1 \left(x-\frac{1}{2}\right)\bigl[f(x)-f\!\left(\tfrac{1}{2}\right)\bigr]\,dx + f\!\left(\tfrac{1}{2}\right)\int_0^1\left(x-\frac{1}{2}\right)dx$$

因 $\int_0^1(x-\frac{1}{2})\,dx = 0$，第二项为零。故

$$\int_0^1 \left(x-\frac{1}{2}\right)f(x)\,dx = \int_0^1 \left(x-\frac{1}{2}\right)\bigl[f(x)-f\!\left(\tfrac{1}{2}\right)\bigr]\,dx$$

在 $[0,\frac{1}{2}]$ 上：$x-\frac{1}{2}\le 0$，且由 $f$ 递增知 $f(x)-f(\frac{1}{2})\le 0$，故乘积 $\ge 0$。

在 $[\frac{1}{2},1]$ 上：$x-\frac{1}{2}\ge 0$，且 $f(x)-f(\frac{1}{2})\ge 0$，故乘积 $\ge 0$。

因此被积函数在 $[0,1]$ 上非负，积分 $\ge 0$。即

$$\int_0^1 \left(x-\frac{1}{2}\right)f(x)\,dx \ge 0$$

展开即得 $\int_0^1 x f(x)\,dx \ge \frac{1}{2}\int_0^1 f(x)\,dx$。证毕。

### 题 15 | 困难 | 定积分定义 + 几何意义

**题目**：求极限

$$\boxed{\dfrac{\pi}{4}}$$

### 题 16 | 困难 | 根值判别法（Cauchy 判别法）

**题目**：判别级数 $\displaystyle\sum_{n=1}^{\infty}\left(\frac{n}{n+1}\right)^{n^2}$ 的敛散性。

**思路溯源**：通项为 $n$ 次幂的形式——这是根值判别法（Cauchy 判别法）的典型适用场景。取 $n$ 次根后，$\sqrt[n]{a_n} = (\frac{n}{n+1})^n = 1/(1+1/n)^n \to 1/e < 1$，直接得收敛。相比于比值判别法，根值判别法在此处避免了复杂的阶乘处理。

$$\sqrt[n]{a_n} = \left(\frac{n}{n+1}\right)^n = \frac{1}{\left(1+\frac{1}{n}\right)^n}$$

$$\lim_{n\to\infty}\sqrt[n]{a_n} = \frac{1}{e} < 1$$

故级数**收敛**。

$$\boxed{\text{收敛}}$$

### 题 17 | 困难 | 比较判别法 + 等价无穷小

**题目**：讨论级数 $\displaystyle\sum_{n=1}^{\infty}\ln\!\left(1+\frac{1}{n^p}\right)$ 的敛散性（$p>0$）。

**思路溯源**：当 $n\to\infty$ 时，$\frac{1}{n^p}\to 0$，$\ln(1+\frac{1}{n^p})\sim\frac{1}{n^p}$。由比较判别法的极限形式，原级数与 $\sum\frac{1}{n^p}$ 同敛散。这是将等价无穷小从函数极限迁移到级数敛散判别的范例。

**解法**：

当 $n\to\infty$ 时，$\frac{1}{n^p}\to 0$，由等价无穷小：

$$\ln\!\left(1+\frac{1}{n^p}\right) \sim \frac{1}{n^p}\quad(n\to\infty)$$

由正项级数比较判别法的极限形式，$\sum\ln(1+\frac{1}{n^p})$ 与 $\sum\frac{1}{n^p}$ 同敛散。

而 $\sum\frac{1}{n^p}$（$p$-级数）收敛当且仅当 $p>1$。故

$$\boxed{\text{收敛}\iff p>1}$$

> 对于 $p\le 0$ 的情形：$\frac{1}{n^p}\not\to 0$，通项不趋于 $0$，级数发散（不满足收敛必要条件）。

### 题 18 | 地狱 | 幂级数逐项积分求和

**题目**：求幂级数 $\displaystyle\sum_{n=0}^{\infty}\frac{x^{2n}}{2n+1}$ 的和函数（$|x|<1$），并利用该结果求 $\displaystyle\sum_{n=0}^{\infty}\frac{1}{(2n+1)\,4^n}$ 的值。

**思路溯源**：$\sum\frac{x^{2n}}{2n+1}$ 的分母含 $2n+1$——这是逐项积分（而非逐项求导）的信号。对幂级数先逐项求导消去分母：$S'(x)=\sum x^{2n}=\frac{1}{1-x^2}$，再积分回代即得和函数。代入 $x=\frac{1}{2}$ 求常数项级数。

**解法**：

令 $S(x)=\sum_{n=0}^{\infty}\frac{x^{2n}}{2n+1}$（$|x|<1$）。收敛半径 $R=1$（由比值判别法）。

逐项求导（幂级数在收敛区间内可逐项求导）：

$$S'(x) = \sum_{n=0}^{\infty}x^{2n} = \frac{1}{1-x^2},\quad |x|<1$$

积分回代（注意 $S(0)=1$）：

$$\begin{aligned}
S(x) - S(0) &= \int_0^x\frac{dt}{1-t^2} = \frac{1}{2}\int_0^x\left(\frac{1}{1-t}+\frac{1}{1+t}\right)dt \\
&= \frac{1}{2}\ln\frac{1+x}{1-x}
\end{aligned}$$

$S(0) = \frac{0^0}{1} = 1$（$n=0$ 项：$\frac{x^0}{1}=1$）。故

$$S(x) = 1 + \frac{1}{2}\ln\frac{1+x}{1-x} = \frac{1}{2}\ln\frac{1+x}{1-x} + 1$$

取 $x = \frac{1}{2}$（满足 $|x|<1$）：

$$S\!\left(\frac{1}{2}\right) = \sum_{n=0}^{\infty}\frac{1}{(2n+1)\,4^n} = 1 + \frac{1}{2}\ln\frac{1+\frac{1}{2}}{1-\frac{1}{2}} = 1 + \frac{1}{2}\ln 3$$

$$\boxed{S(x)=1+\frac{1}{2}\ln\frac{1+x}{1-x},\qquad \sum_{n=0}^{\infty}\frac{1}{(2n+1)4^n}=1+\frac{1}{2}\ln 3}$$

### 题 19 | 困难 | 等价量判敛 · $\sqrt[n]{a}-1$

**题目**：讨论级数 $\displaystyle\sum_{n=1}^{\infty}\left(\sqrt[n]{a}-1\right)$ 的敛散性（$a>0$）。

**思路溯源**：$\sqrt[n]{a} = a^{1/n} = e^{\ln a/n}$。当 $n\to\infty$ 时，$e^{\ln a/n}-1\sim\frac{\ln a}{n}$。由比较判别法，原级数与调和级数 $\sum\frac{1}{n}$ 同敛散——发散（除非 $\ln a=0$ 即 $a=1$）。关键在于识别 $a^{1/n}-1$ 的等价无穷小量级。

**解法**：

$$\sqrt[n]{a} - 1 = e^{\frac{\ln a}{n}} - 1$$

当 $n\to\infty$ 时，$\frac{\ln a}{n}\to 0$（$a>0$ 固定）。由 $e^t-1\sim t$（$t\to 0$）：

$$\sqrt[n]{a} - 1 \sim \frac{\ln a}{n}\quad(n\to\infty)$$

**若 $a=1$**：$\sqrt[n]{1}-1 = 0$，所有项均为 $0$，级数**收敛**（和为 $0$）。

**若 $a\neq 1$**：由比较判别法的极限形式，$\sum(\sqrt[n]{a}-1)$ 与 $\sum\frac{\ln a}{n}$ 同敛散。因 $\ln a\neq 0$，$\sum\frac{\ln a}{n}$ 发散（调和级数乘以非零常数）。故原级数**发散**。

$$\boxed{\text{收敛}\iff a=1}$$

### 题 20 | 地狱 | 级数与积分互化 · $\sum 1/n^2 = \pi^2/6$ 的应用

**题目**：已知 $\displaystyle\sum_{n=1}^{\infty}\frac{1}{n^2}=\frac{\pi^2}{6}$。利用此结果计算定积分：

$$I = \int_0^1\frac{\ln\frac{1}{x}}{1+x}\,dx$$

**思路溯源**：将 $\frac{1}{1+x}$ 展开为几何级数 $\sum_{n=0}^{\infty}(-1)^n x^n$（$|x|<1$），与被积函数中的 $\ln\frac{1}{x}=-\ln x$ 相乘后逐项积分。每项积分 $\int_0^1 x^n(-\ln x)\,dx$ 可用换元 $t=-\ln x$ 化为 $\Gamma$ 型积分，结果为 $1/(n+1)^2$。最终级数与已知和 $\pi^2/6$ 挂钩。

**解法**：

当 $0<x<1$ 时，$\frac{1}{1+x} = \sum_{n=0}^{\infty}(-1)^n x^n$。代入：

$$I = \int_0^1 (-\ln x)\sum_{n=0}^{\infty}(-1)^n x^n\,dx = \sum_{n=0}^{\infty}(-1)^n\int_0^1 x^n(-\ln x)\,dx$$

（幂级数在 $[0,1]$ 内闭一致收敛，可逐项积分；$x=1$ 处为瑕点，但 Abel 定理保证连续性。）

计算 $\int_0^1 x^n(-\ln x)\,dx$。令 $t=-\ln x$，$x=e^{-t}$，$dx=-e^{-t}dt$。$x=0\to t=+\infty$，$x=1\to t=0$。

$$\int_0^1 x^n(-\ln x)\,dx = \int_{\infty}^0 e^{-nt}\cdot t\cdot(-e^{-t})\,dt = \int_0^{\infty}t\,e^{-(n+1)t}\,dt$$

再换元 $s=(n+1)t$，$dt=\frac{ds}{n+1}$：

$$= \frac{1}{(n+1)^2}\int_0^{\infty}s\,e^{-s}\,ds = \frac{1}{(n+1)^2}\cdot\Gamma(2) = \frac{1}{(n+1)^2}$$

代入：

$$I = \sum_{n=0}^{\infty}(-1)^n\frac{1}{(n+1)^2} = \sum_{k=1}^{\infty}\frac{(-1)^{k-1}}{k^2}$$

将交错级数用已知和表示：

$$\sum_{k=1}^{\infty}\frac{(-1)^{k-1}}{k^2} = \sum_{k=1}^{\infty}\frac{1}{k^2} - 2\sum_{m=1}^{\infty}\frac{1}{(2m)^2} = \frac{\pi^2}{6} - 2\cdot\frac{1}{4}\cdot\frac{\pi^2}{6} = \frac{\pi^2}{6} - \frac{\pi^2}{12} = \frac{\pi^2}{12}$$

$$\boxed{I = \dfrac{\pi^2}{12}}$$

### 题 21 | 困难 | 隐函数极值

**题目**：设 $y=y(x)$ 由方程 $x^2+xy+y^2=3$ 确定。求 $y(x)$ 的极值。

**思路溯源**：方程两边对 $x$ 求导（视 $y$ 为 $x$ 的函数），解出 $y'$。令 $y'=0$ 得驻点条件，与方程本身联立求出可疑极值点。再通过 $y''$ 的符号（或一阶导的符号变化）判定极值类型。也可用配方法：将原方程视为 $(x+y/2)^2+\frac{3}{4}y^2=3$，直接看出 $y$ 的范围。

**解法**：

方程两边对 $x$ 求导（隐函数求导）：

$$2x + y + x y' + 2y y' = 0$$

解出 $y'$：

$$y' = -\frac{2x+y}{x+2y}$$

令 $y'=0$，得 $2x+y=0$，即 $y=-2x$。

代入原方程 $x^2+xy+y^2=3$：

$$x^2 + x(-2x) + (-2x)^2 = 3 \;\Longrightarrow\; x^2 - 2x^2 + 4x^2 = 3 \;\Longrightarrow\; 3x^2 = 3 \;\Longrightarrow\; x = \pm 1$$

对应 $y = \mp 2$。得到两个可疑极值点：$(1,-2)$ 和 $(-1,2)$。

求 $y''$ 判定类型（在 $y'=0$ 即 $2x+y=0$ 处）：

对 $y' = -\frac{2x+y}{x+2y}$ 再次求导，利用 $y'=0$ 简化：

$$y'' = -\frac{(2+y')(x+2y)-(2x+y)(1+2y')}{(x+2y)^2}$$

在 $y'=0$ 且 $2x+y=0$ 处，分子 $= 2(x+2y)-0 = 2(x+2y)$。而 $x+2y = x+2(-2x)=-3x$。

故 $y'' = -\frac{2(-3x)}{(x+2y)^2} = \frac{6x}{(x+2y)^2}$。

- 在 $(1,-2)$ 处：$x=1>0$，$y''>0$，$y$ 取**极小值** $y=-2$。
- 在 $(-1,2)$ 处：$x=-1<0$，$y''<0$，$y$ 取**极大值** $y=2$。

$$\boxed{y_{\min}=-2\;(x=1),\quad y_{\max}=2\;(x=-1)}$$

### 题 22 | 困难 | 二重积分交换次序

**题目**：交换下列二次积分的积分次序：

$$I = \int_0^1 dx\int_{x^2}^{x} f(x,y)\,dy$$

并画出积分区域 $D$ 的草图。

**思路溯源**：先确定积分区域 $D$：$0\le x\le 1$，$x^2\le y\le x$。将 $D$ 重新表述为 $y$ 型区域：求 $y$ 的上下界，对每个固定的 $y$，$x$ 的范围由曲线 $y=x^2$（即 $x=\sqrt{y}$）和 $y=x$（即 $x=y$）确定。注意区域中 $x^2\le y\le x$ 隐含 $x^2\le x$，即 $x\in[0,1]$。

积分区域 $D = \{(x,y)\mid 0\le x\le 1,\; x^2\le y\le x\}$。

两条边界曲线：$y=x^2$（抛物线）和 $y=x$（直线），在 $(0,0)$ 与 $(1,1)$ 处相交。

故交换次序后：

$$I = \int_0^1 dy\int_{y}^{\sqrt{y}} f(x,y)\,dx$$

$$\boxed{I = \int_0^1 dy\int_{y}^{\sqrt{y}} f(x,y)\,dx}$$

### 题 23 | 困难 | Lagrange 乘数法 · 球面上线性函数最值

**题目**：求函数 $u = x + 2y + 3z$ 在约束条件 $x^2+y^2+z^2=1$ 下的最大值和最小值。

**思路溯源**：Lagrange 乘数法标准应用。构造 $L = x+2y+3z + \lambda(x^2+y^2+z^2-1)$，对各变量求偏导设为零，解出驻点坐标与 $\lambda$ 的关系式，代入约束方程定出 $\lambda$，回代得驻点。由于目标函数是线性的而约束为球面（紧集），最大值与最小值均存在且互为相反数（目标函数为奇函数，约束集关于原点对称）。

**解法**：

令 $L(x,y,z,\lambda) = x + 2y + 3z + \lambda(x^2+y^2+z^2-1)$。

$$\begin{cases}
L_x = 1 + 2\lambda x = 0 &\Rightarrow\; x = -\dfrac{1}{2\lambda} \\[6pt]
L_y = 2 + 2\lambda y = 0 &\Rightarrow\; y = -\dfrac{1}{\lambda} \\[6pt]
L_z = 3 + 2\lambda z = 0 &\Rightarrow\; z = -\dfrac{3}{2\lambda}
\end{cases}$$

代入约束 $x^2+y^2+z^2=1$：

$$\frac{1}{4\lambda^2} + \frac{1}{\lambda^2} + \frac{9}{4\lambda^2} = 1 \;\Longrightarrow\; \frac{1+4+9}{4\lambda^2} = 1 \;\Longrightarrow\; \frac{14}{4\lambda^2} = 1 \;\Longrightarrow\; \lambda^2 = \frac{7}{2}$$

$\lambda = \pm\sqrt{\frac{7}{2}}$。

对应两个驻点：$(x,y,z) = \pm\frac{1}{\sqrt{14}}(1,2,3)$（标准化向量）。

在 $P_1 = \frac{1}{\sqrt{14}}(1,2,3)$ 处：$u = \frac{1}{\sqrt{14}}(1+4+9) = \sqrt{14}$。

在 $P_2 = -\frac{1}{\sqrt{14}}(1,2,3)$ 处：$u = -\sqrt{14}$。

由几何意义：$u$ 是线性函数在单位球面上的值，其最大值即梯度方向 $(1,2,3)$ 的长度 $\sqrt{1+4+9}$。

$$\boxed{u_{\max} = \sqrt{14},\quad u_{\min} = -\sqrt{14}}$$

## 六、概念题（2 题）

### 题 24 | 困难 | 间断点分类 + 连续性与可导性判定

**题目**：考虑函数

$$f(x) = \begin{cases}
\sin\frac{1}{x}, & x\neq 0\\[4pt]
0, & x=0
\end{cases}\qquad
g(x) = \begin{cases}
x\sin\frac{1}{x}, & x\neq 0\\[4pt]
0, & x=0
\end{cases}$$

(1) 判断 $f(x)$ 在 $x=0$ 处的间断点类型；
(2) 判断 $g(x)$ 在 $x=0$ 处的连续性与可导性。

**思路溯源**：(1) $x\to 0$ 时 $\sin\frac{1}{x}$ 在 $-1$ 与 $1$ 之间无限震荡，极限不存在——此为第二类间断点（振荡间断点）。(2) $g(x)=x\sin\frac{1}{x}$ 中，$\sin\frac{1}{x}$ 有界，乘以 $x$（无穷小）得无穷小→ $g$ 在 $0$ 处连续。但 $\frac{g(h)-g(0)}{h}=\sin\frac{1}{h}$ 无极限，故不可导。这是"连续但不可导"的经典示例。

**解法**：

**(1) $f(x)$ 在 $x=0$ 处**

当 $x\to 0$ 时，$\frac{1}{x}\to\infty$，$\sin\frac{1}{x}$ 在 $[-1,1]$ 之间剧烈振荡，无极限。由间断点分类：

$$f(0^+)\text{ 和 }f(0^-)\text{ 均不存在（振荡不趋于任何确定值）}$$

此为**第二类间断点**（振荡间断点）。

**(2) $g(x)$ 在 $x=0$ 处**

**连续性**：$|g(x)-g(0)| = |x\sin\frac{1}{x}| \le |x|$（$x\neq 0$）。当 $x\to 0$ 时，$|x|\to 0$，由夹逼准则 $\lim_{x\to 0}|g(x)-g(0)|=0$，故 $\lim_{x\to 0}g(x)=0=g(0)$。$g$ 在 $x=0$ 处**连续**。

**可导性**：由导数定义，

$$g'(0) = \lim_{h\to 0}\frac{g(h)-g(0)}{h} = \lim_{h\to 0}\frac{h\sin\frac{1}{h}}{h} = \lim_{h\to 0}\sin\frac{1}{h}$$

此极限不存在（振荡）。故 $g$ 在 $x=0$ 处**不可导**。

$$\boxed{f\text{ 在 }0\text{ 处为第二类间断点；}g\text{ 在 }0\text{ 处连续但不可导}}$$

### 题 25 | 地狱 | 凸函数性质证明 · Jensen 不等式

**题目**：设 $f(x)$ 在 $(a,b)$ 内二阶可导，且 $f''(x)>0$ 恒成立。证明：对任意 $x_1,x_2\in(a,b)$（$x_1\neq x_2$），有

$$f\!\left(\frac{x_1+x_2}{2}\right) < \frac{f(x_1)+f(x_2)}{2}$$

**思路溯源**：$f''>0$ 意味着 $f$ 是严格凸函数，中点处的函数值应小于两端点函数值的平均值（Jensen 不等式）。证明思路：令 $c=\frac{x_1+x_2}{2}$，将 $f(x_1)$ 和 $f(x_2)$ 分别在 $x=c$ 处作一阶 Taylor 展开（带 Lagrange 余项）。由于 $x_1-c=-(x_2-c)$，一阶项在相加时抵消（$f'(c)(x_1-c)+f'(c)(x_2-c)=0$），二阶余项因 $f''>0$ 为正，导致 $f(x_1)+f(x_2)>2f(c)$。

**解法**：

令 $c = \frac{x_1+x_2}{2}$，则 $x_1 = c - d$，$x_2 = c + d$，其中 $d = \frac{x_2-x_1}{2}>0$（不妨设 $x_1<x_2$）。

将 $f(x_1)$ 和 $f(x_2)$ 在 $x=c$ 处展开为一阶 Taylor 公式（Lagrange 余项）：

$$f(x_1) = f(c) + f'(c)(x_1-c) + \frac{f''(\xi_1)}{2}(x_1-c)^2,\quad \xi_1\in(x_1,c)$$

$$f(x_2) = f(c) + f'(c)(x_2-c) + \frac{f''(\xi_2)}{2}(x_2-c)^2,\quad \xi_2\in(c,x_2)$$

注意到 $x_1-c = -d$，$x_2-c = d$。两式相加：

$$f(x_1) + f(x_2) = 2f(c) + f'(c)\underbrace{(x_1-c+x_2-c)}_{=0} + \frac{f''(\xi_1)}{2}d^2 + \frac{f''(\xi_2)}{2}d^2$$

$$= 2f(c) + \frac{d^2}{2}\bigl[f''(\xi_1) + f''(\xi_2)\bigr]$$

由条件 $f''(x)>0$，故 $f''(\xi_1)>0$，$f''(\xi_2)>0$。因此

$$\frac{d^2}{2}\bigl[f''(\xi_1) + f''(\xi_2)\bigr] > 0$$

从而

$$f(x_1) + f(x_2) > 2f(c) = 2f\!\left(\frac{x_1+x_2}{2}\right)$$

即 $f\!\left(\frac{x_1+x_2}{2}\right) < \frac{f(x_1)+f(x_2)}{2}$。证毕。

> 此即**严格凸函数的 Jensen 不等式（$n=2$ 情形）**。若 $f''<0$（严格凹函数），不等号反向。
