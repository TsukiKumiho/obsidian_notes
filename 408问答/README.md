## 二、计算机组成原理

### 第 1 章 · 概述（Q1–Q3, Q5, Q6, Q9–Q11）

| Q# | 类型 | 关键词 | 问题 | 核心结论 |
| :---: | :---: | :--- | :--- | :--- |
| Q1 | 概念 | 系统调用/系统命令 | 系统调用是否等同于系统命令？ | 不是。系统调用是内核原子功能（核心态），系统命令是用户态可执行程序，一条命令通常调用多个系统调用 |
| Q2 | 概念 | 系统调用位置 | 系统调用到底在哪里发生？ | 发起在用户态（执行陷入指令），处理在内核态。408 真题定调 |
| Q3 | 概念 | 特权指令 | 哪些指令/事件不能在用户态执行？ | I/O、关中断、改页表、改控制寄存器、停机等—必须核心态 |
| Q5 | 总结 | 硬件/OS 分工 | 系统调用/中断/异常中硬件和 OS 分别做什么？ | 硬件：保存 PC/PSW、切换栈、查向量表。OS：保存通用寄存器、执行处理、恢复上下文 |
| Q6 | 概念 | 中断/子程序/库函数 | 中断 vs 子程序、系统调用 vs 库函数 | 中断：硬件触发、异步、内核态。子程序：软件调用、同步、同态。系统调用：跨边界。库函数：全程用户态 |
| Q9 | 概念 | 外核 Exokernel | 什么是外核？与微内核区别？ | 外核只隔离不复抽象，硬件暴露给应用层库 OS。微内核最小化抽象+IPC。外核性能最高 |
| Q10 | 概念 | 用户态/内核态 | 用户态与内核态的本质区别是什么？ | CPU 特权级别决定可执行指令集合。用户→内核通过 trap/中断，内核→用户通过中断返回 |
| Q11 | 概念 | VMM/虚拟化 | Type 1 vs Type 2 VMM 中 Guest OS 如何运行？ | Type 1：Guest OS 内核在非根模式（降权）。Type 2：Guest OS 是宿主机用户进程。两者内核态都被降权 |

### 第 2 章 · 进程管理（Q7, Q8, Q12–Q16, Q18–Q21）

| Q# | 类型 | 关键词 | 问题 | 核心结论 |
| :---: | :---: | :--- | :--- | :--- |
| Q7 | 概念 | 时钟中断 ISR | 时钟中断服务程序需更新哪些内容？ | 时间片计数器、系统全局时间、定时器链表检查、CPU 使用统计、就绪队列调整 |
| Q8 | 概念 | 信号 Signal | 信号的核心概念？ | OS 的软件中断机制—异步通知进程。生命周期：生成→递送→处理 |
| Q12 | 概念 | KLT/一对一模型 | 纯 KLT 与一对一模型区别？ | 仅区别在用户空间是否有线程库层。内核 TCB 和调度行为完全一致 |
| Q13 | 总结 | 进程阻塞事件 | 哪些事件导致 Running→Blocked？ | 9 类：I/O、资源申请失败、等待子进程、同步、消息通信、定时/睡眠、缺页、用户输入、网络 I/O。Run→Blocked 必为主动 |
| Q14 | 概念 | 读磁盘本质 | 进程读磁盘是激活另一个进程还是自带能力？ | 都不是。进程委托 OS 内核完成—进程发起（用户态）→ 内核驱动（内核态）→ DMA（硬件） |
| Q15 | 概念 | ULT 双层管理 | 用户级线程管理在用户空间但进程仍由内核创建—正确吗？ | 完全正确。进程是内核容器（PCB），线程是用户空间内容（TCB）。纯 ULT 致命缺陷：一阻塞全陪葬 |
| Q16 | 概念 | 就绪队列/周转时间 | 进程进入就绪队列时开始计算周转时间？ | New→Ready 即为到达。Running→Ready 和 Blocked→Ready 不是新到达，周转时间不重置 |
| Q18 | 概念 | TestAndSet/锁机制 | lock 变量为什么叫共享？管所有资源吗？ | "共享"指存储属性（共享内存可见），非管辖范围。N 个资源需 N 把锁 |
| Q19 | 总结 | 同步机制全景 | OS 同步机制如何分类？事件驱动 vs 时间线 | 两大类：事件驱动（锁/信号量/管程）等条件就绪；时间线（屏障/锁步）等所有人到齐 |
| Q20 | 概念 | PV 命名 | PV 操作就是 wait/signal 吗？ | 是。同一操作的不同命名体系。陷阱：信号量 wait/signal ≠ 管程条件变量 wait/signal |
| Q21 | 概念 | 锁粒度/生产者-消费者 | mutex 锁整缓冲区还是逐槽？ | 粗粒度锁—锁整缓冲区数据结构。empty 管资源数、mutex 管并发安全，两维度独立 |

### 第 5 章 · I/O 管理（Q4, Q17）

| Q# | 类型 | 关键词 | 问题 | 核心结论 |
| :---: | :---: | :--- | :--- | :--- |
| Q4 | 总结 | I/O 软件层次 | 一次完整 I/O 操作分哪几阶段？ | 四层软件：用户层→设备无关层→驱动程序→中断处理。三阶段：请求→进行→完成 |

## 四、计算机网络

### 第 1 章 · 体系结构（Q1–Q2）

| Q# | 类型 | 关键词 | 问题 | 核心结论 |
| :---: | :---: | :--- | :--- | :--- |
| Q1 | 概念 | 数据报/分组交换/虚电路 | 三者区别？ | 分组交换是宏观交换方式，数据报和虚电路是两种服务。数据报=无连接独立选路（IP），虚电路=先建逻辑连接同路有序（ATM/X.25） |
| Q2 | 计算 | 奈奎斯特/香农 | 两定理区别？同现时怎么算？ | 奈奎斯特管码元上限（$2W\log_2 V$），香农管噪声上限（$W\log_2(1+S/N)$）。同现取 min。dB 必须先转功率比。采样频率 $f_s\ge2f_{\max}$ 属 PCM 体系 |

### 第 3 章 · 数据链路层（Q3–Q14）

| Q# | 类型 | 关键词 | 问题 | 核心结论 |
| :---: | :---: | :--- | :--- | :--- |
| Q3 | 概念 | 帧出错/确认帧 | 数据帧出错会产生错误确认帧吗？ | 不会。CRC 失败→帧丢弃→不发 ACK→超时重传。不可检测错误（$G(x)\mid E(x)$）概率极低 |
| Q4 | 概念 | 滑动窗口/GBN/SR | 发送方和接收方谁滑几格？ | GBN 发送方可能一次滑多格（累积 ACK），接收方每次只滑一格（只收按序帧） |
| Q5 | 计算 | 连续 ARQ 利用率 | GBN vs SR 利用率公式区别？ | 无错时完全相同。有错时 GBN 多出 $(W-1)P_f$ 额外代价，SR 只乘 $(1-P_f)$ |
| Q6 | 概念 | 发送窗口/序号位数 | W_T 和 n 的约束关系？ | GBN: $W_T\le2^n-1$，SR: $W_T+W_R\le2^n$。本质防止序号循环后新旧帧混淆 |
| Q7 | 概念 | GBN/ACK 乱序 | ACK1→ACK2→ACK5 到达时窗口怎么滑？ | 依次滑 1 格→1 格→3 格（ACK5 累积确认覆盖 3,4,5）。帧 6 悬在窗口下沿 |
| Q8 | 计算 | 卫星链路延时 | 卫星链路 T_P 怎么算？ | 累加所有传播段（上行+下行≈540ms GEO）。弯管卫星无处理延时，再生式/星上交换需加 |
| Q9 | 概念 | CDM 码分复用 | 多站同时发送信号怎么叠加？ | 同比特周期内各站码片向量线性叠加，多周期拼接 |
| Q10 | 概念 | 802.3 帧/协议识别 | 帧如何识别上层协议？ | 类型字段（Type/Length）标识。MAC 地址只在同一广播域有效 |
| Q11 | 汇总 | 计网英文缩写 | | 详见 `计网英文缩写速查表.md` |
| Q12 | 概念 | CSMA/CA 退避 | CSMA/CA 退避算法详解 | NAV+RTS/CTS+DIFS/SIFS，随机退避避免碰撞 |

### 第 4 章 · 网络层（Q15–Q32）

| Q# | 类型 | 关键词 | 问题 | 核心结论 |
| :---: | :---: | :--- | :--- | :--- |
| Q15 | 概念 | 路由概念 | 路由器转发时变什么不变什么？ | 普通转发只改 MAC 不改 IP。经 NAT 时才改 IP |
| Q16 | 概念 | NAT/转发联动 | 先查路由表还是先 NAT？ | 先路由后 NAT。回包先 NAT 后路由。家用路由器两者叠加 |
| Q17 | 概念 | IP 地址逻辑/物理 | IP 地址 vs MAC 地址本质区别？ | MAC 是出厂烧录的固有属性（身份证号），IP 是分配的临时逻辑编号（收件地址） |
| Q18 | 概念 | 私网不可路由 | 私网地址为什么不能走公网？ | 公网路由器不认识私网地址，直接丢弃。必须 NAT 转公网 IP |
| Q19 | 概念 | IP 源/目的控制 | 谁分配源 IP？谁确定目的 IP？ | 源 IP 由主机自身配置（或 DHCP 分配），目的 IP 由应用层指定 |
| Q20 | 概念 | 路由转发全流程 | 路由器查表→下一跳→IP 不变 MAC 变 | 逐跳改 MAC，IP 端到端不变（除非 NAT） |
| Q21 | 概念 | 边界路由器 | 边界路由器收到私网地址包？ | 直接丢弃。私网地址在公网无意义 |
| Q22 | 概念 | IP vs MAC 转发 | 路由器用 IP 还是 MAC 转发？255 为什么不行？ | 用 IP 查表、用 MAC 封装帧。255.255.255.255 是受限广播，路由器不转发 |
| Q23 | 概念 | IP 分片/ARP | IP 分片机制+ARP 全流程 | 片偏移 8B 单位，MF/DF 标志。ARP 广播请求+单播应答，同广播域内 IP→MAC |
| Q24 | 概念 | 子网划分 | 聚合后还剩几位主机号 | CIDR 最长前缀匹配，路由聚合减小表项 |
| Q25 | 概念 | 同局域网通信 | 没有 MAC 地址能通信吗？ | 不能。ARP 广播拿 MAC，无 MAC 填不了帧头 |
| Q26 | 概念 | RIP 最大跳数 | 为什么正常跳数不能超 15？ | 16 代表不可达。距离向量协议用跳数作度量，15 是上限 |
| Q27 | 概念 | RIP 传递路由 | 为什么选 3 不选 16？ | RIP 直接传递路由，3 跳以内可靠，16=不可达 |
| Q28 | 概念 | TCP 停等 | TCP 为什么不用停等协议？ | 停等利用率太低。滑动窗口实现流水线传输 |
| Q29 | 概念 | TCP 按序到达 | TCP 数据包一定按序到达吗？ | IP 层可能乱序，TCP 用序号和缓存重排，上层看到的就是有序的 |
| Q30 | 概念 | TCP 快恢复 | 3 个 ACK 后 cwnd 变化时机 | 收到 3 个重复 ACK→ssthresh=cwnd/2，cwnd=ssthresh+3，进入快恢复 |
| Q31 | 概念 | 路由器-IP 对应 | 路由器有没有一一对应 IP？ | 每个接口一个 IP，一台路由器可有多个 IP |
| Q32 | 概念 | 多设备同 IP | 多台设备同一 IP vs 同设备多 IP | 同一 IP 多设备=冲突。同一设备多 IP=多网卡或多别名 |

### 第 5-6 章 · 传输层/应用层（Q33–Q39）

| Q# | 类型 | 关键词 | 问题 | 核心结论 |
| :---: | :---: | :--- | :--- | :--- |
