> 两个有序数组 `arr1`，`arr2`，长度分别为`n1`，`n2`，将其合并为一个新的有序数组`arr3`
>
> (数组操作，双指针) O(n1 + n2)
>
> 用 `i`、`j` 两个指针分别从两个数组开头扫描，每次把较小者放入 `arr3` 并后移对应指针；某个数组遍历完后，把另一个数组剩余部分整体拷入。
>
> 空间复杂度分析：除结果数组 `arr3` 外只用了常数个额外变量，额外的空间复杂度是 O(1)。
> 时间复杂度分析：每个元素最多被比较并放入一次，时间复杂度是 O(n1 + n2)。

```c++
void merge(int arr1[], int n1, int arr2[], int n2, int arr3[]){
    int i = 0, j = 0, k = 0;
    while (i < n1 && j < n2){                               // 两个数组都还没扫完
        if (arr1[i] < arr2[j]) arr3[k ++ ] = arr1[i ++ ];   // 取较小者
        else arr3[k ++ ] = arr2[j ++ ];
    }
    while (i < n1) arr3[k ++ ] = arr1[i ++ ];               // 左数组剩余
    while (j < n2) arr3[k ++ ] = arr2[j ++ ];               // 右数组剩余
}
```

> 合并两个有序链表
>
> (链表操作，迭代) O(n + m)
>
> 用哑节点 `preHead` 统一处理头节点，`prev` 负责串联：每次比较 `l1`、`l2` 的 `data`，把较小者接到 `prev` 后面，最后把剩余的那条链整体接上。
>
> 空间复杂度分析：只用常数个额外指针，空间复杂度是 O(1)。
> 时间复杂度分析：每条链的节点最多被比较一次，时间复杂度是 O(n + m)。

```c++
struct node{
    int data;
    node* next;
    node(int val = 0, node* nxt = nullptr) : data(val), next(nxt) {}
};

node* mergeTwoLists(node* l1, node* l2){
    node* preHead = new node(-1);         // 哑节点，统一头节点处理
    node* prev = preHead;
    while (l1 != nullptr && l2 != nullptr){
        if (l1->data < l2->data){         // 取较小者接上
            prev->next = l1;
            l1 = l1->next;
        }
        else{
            prev->next = l2;
            l2 = l2->next;
        }
        prev = prev->next;
    }
    if (l1 == nullptr) prev->next = l2;   // 接上剩余的一条链
    else prev->next = l1;
    return preHead->next;
}
```

> 一个整型数组`a[]`，数组大小为`size`，删除所有值为 `x`的数

快速排序（模板）

> (分治，递归) O(nlogn)
>
> 取 `q[l + r >> 1]` 作为分界值 `x`，双指针从两端向中间扫描，把小于 `x` 的换到左边、大于 `x` 的换到右边；划分完成后递归处理左右两段。
>
> 空间复杂度分析：递归调用栈的期望深度是 O(logn)，空间复杂度是 O(logn)。
> 时间复杂度分析：平均 O(nlogn)；若每次划分都极不平衡，最坏退化为 O(n^2)（分界值取中点可规避大多数有序数据的最坏情况）。

```c++
void quick_sort(int q[], int l, int r){
    if (l >= r) return;
    int i = l - 1, j = r + 1, x = q[l + r >> 1];
    while (i < j){
        do i ++ ; while (q[i] < x);   //while(q[++i] < x);
        do j -- ; while (q[j] > x);   //while(q[--j] > x);
        if (i < j) swap(q[i], q[j]);
    }
    quick_sort(q, l, j), quick_sort(q, j + 1, r);
}
```

快速选择（模板）

> 给定一个长度为 `n` 的整数数列，以及一个整数 `k`，求出数列从小到大排序后的第 `k` 个数。
>
> (分治，递归) O(n)
>
> 复用快速排序的划分过程，划分后若 `k <= j` 则答案在左半段，否则在右半段；每次只需递归处理一侧。
>
> 空间复杂度分析：期望递归深度 O(logn)，空间复杂度是 O(logn)。
> 时间复杂度分析：每次划分只处理一侧，平均 O(n)；若每次划分都极不平衡，最坏退化为 O(n^2)。

```c++
int quick_select(int q[], int l, int r, int k){
    if (l >= r) return q[l];
    int i = l - 1, j = r + 1, x = q[l + r >> 1];
    while (i < j){
        do i ++ ; while (q[i] < x);
        do j -- ; while (q[j] > x);
        if (i < j) swap(q[i], q[j]);
    }
    if (k <= j) return quick_select(q, l, j, k);   // 答案在左半段
    else return quick_select(q, j + 1, r, k);      // 答案在右半段
}
```

堆排序

> (堆，迭代) O(nlogn)
>
> `down` 让节点下沉恢复堆序：先自底向上从最后一个非叶节点开始建大根堆，再把堆顶与末尾交换、缩小堆范围并下沉，重复直到堆空，得到升序序列。
>
> 空间复杂度分析：原地排序，只用常数个额外变量，空间复杂度是 O(1)。
> 时间复杂度分析：建堆 O(n)，共 n 次交换与下沉、每次 O(logn)，总时间复杂度是 O(nlogn)。

```c++
void down(int nums[], int n, int i){                                     // 大根堆：让 i 下沉
    while (true){
        int largest = i, left = 2 * i + 1, right = 2 * i + 2;
        if (left < n && nums[left] > nums[largest]) largest = left;      // 左孩子更大
        if (right < n && nums[right] > nums[largest]) largest = right;   // 右孩子更大
        if (largest == i) break;                                         // 已到位，无需再沉
        swap(nums[i], nums[largest]);
        i = largest;
    }
}

void heapSort(int nums[], int n){
    for (int i = n / 2 - 1; i >= 0; i -- ) down(nums, n, i);             // 自底向上建堆
    for (int i = n - 1; i > 0; i -- ){                                   // 堆顶换到末尾，缩小堆
        swap(nums[0], nums[i]);
        down(nums, i, 0);
    }
}
```

归并排序（分治思想）

> (分治，递归) O(nlogn)
>
> 取中点 `mid` 把区间一分为二，递归排好左右两段后用双指针合并到辅助数组 `tmp`，再拷回原数组。
>
> 空间复杂度分析：辅助数组 `tmp` 需要 O(n)，递归栈 O(logn)，总空间复杂度是 O(n)。
> 时间复杂度分析：每层合并共 O(n)，共 logn 层，时间复杂度是 O(nlogn)。

```c++
const int N = 100010;
int tmp[N];                                                  // 辅助数组，或 tmp[r - l + 1] 动态分配

void merge_sort(int q[], int l, int r){
    if (l >= r) return;

    int mid = l + r >> 1;
    merge_sort(q, l, mid);
    merge_sort(q, mid + 1, r);

    int k = 0, i = l, j = mid + 1;
    while (i <= mid && j <= r)                               // 双指针合并
        if (q[i] <= q[j]) tmp[k ++ ] = q[i ++ ];
        else tmp[k ++ ] = q[j ++ ];

    while (i <= mid) tmp[k ++ ] = q[i ++ ];                  // 左半剩余
    while (j <= r) tmp[k ++ ] = q[j ++ ];                    // 右半剩余

    for (i = l, j = 0; i <= r; i ++, j ++ ) q[i] = tmp[j];   // 拷回原数组
}
```

数组反转

> (数组操作，双指针) O(n)
>
> `start`、`end` 两个指针从两端向中间靠拢，每次交换所指元素，直到相遇。
>
> 空间复杂度分析：只用 1 个临时变量，空间复杂度是 O(1)。
> 时间复杂度分析：每两个元素交换一次，共约 n/2 次，时间复杂度是 O(n)。

```c++
void reverse(int r[], int start, int end){
    while (start < end){
        int tmp = r[start];
        r[start] = r[end];
        r[end] = tmp;   // 或直接 swap(r[start], r[end])
        start ++ ;
        end -- ;
    }
}
```

链表反转

> (链表操作，迭代) O(n)
>
> 翻转即将所有节点的 next 指针指向前驱节点。由于是单链表，我们在迭代时不能直接找到前驱节点，所以我们需要一个额外的指针保存前驱节点。同时在改变当前节点的 next 指针前，不要忘记保存它的后继节点。
>
> 空间复杂度分析：遍历时只有 3 个额外指针变量，所以额外的空间复杂度是 O(1)。
> 时间复杂度分析：只遍历一次链表，时间复杂度是 O(n)。

```c++
node* reverseList(node* head){
    node *pre = nullptr, *cur = head;
    while (cur){
        node *next = cur->next;   // 先保存后继节点，防止断链
        cur->next = pre;          // 当前节点指向前驱
        pre = cur;
        cur = next;
    }
    return pre;                   // pre 就是反转后的头节点
}
```

> 树与图的遍历（DFS/BFS）—— 模板题 AcWing 846. 树的重心 / 847. 图中点的层次
>
> (图，递归/迭代) O(n + m)
>
> 存储：邻接表。h[u] 是 u 的第一条边的编号，e[i] 是第 i 条边指向的结点，ne[i] 是下一条边的编号，idx 是当前边编号；add(a, b) 用头插法把边 (a, b) 挂到 a 的名单上。
> DFS 一句话：一条路走到黑，撞墙（没有未访问邻居）就回头换一条路，用递归实现。

> 空间复杂度分析：邻接表存储需要 O(n + m)，`st` 标记数组 O(n)，BFS 队列最坏 O(n)，总空间复杂度是 O(n + m)。
> 时间复杂度分析：DFS 和 BFS 中每个点恰好被访问一次、每条边恰好被检查一次，时间复杂度是 O(n + m)。

```c++
标记 st[u];                             	// 共同骨架：先标记 u，再翻名单
for (i = h[u]; i != -1; i = ne[i]) {  	 // 翻 u 的名单
    j = e[i];                          	 // 取出一个邻居
    if (!st[j])  DFS递归 / BFS入队;       // 没去过就处理它
}
```

```c++
void add(int a, int b){   // 邻接表建边（头插法）
    e[idx] = b;
    ne[idx] = h[a];
    h[a] = idx ++ ;
}
```

> 拓扑排序（Kahn 算法）—— 模板题 AcWing 848. 有向图的拓扑序列
>
> (图，BFS/队列) O(n + m)
>
> 把边 a→b 看成"约束：a 必须先于 b"，拓扑排序就是排出满足所有约束的一个顺序。Kahn 算法（BFS 思想）：入度为 0 的点没有前置约束，可以随时输出。先把所有入度为 0 的点入队；每次出队一个点 t（相当于"删掉 t 和它的所有出边"），t 的后继 j 的入度减 1，减到 0 说明 j 的前置约束全部满足，入队。重复到队列空：若入队点数恰好为 n，说明无环、拓扑排序成功；否则剩下的点构成环（环上每个点入度永远不为 0，无法入队）。
>
> 空间复杂度分析：邻接表 O(n + m)，入度数组 d 和队列 q 各 O(n)，总空间复杂度是 O(n + m)。
> 时间复杂度分析：每个点入队、出队各一次 O(n)，每条边恰好被"删除"一次 O(m)，时间复杂度是 O(n + m)。

```c++
int q[N], hh = 0, tt = -1;                        // d[i] 入度，q 模拟队列，h/e/ne 邻接表

bool topsort(){
    for (int i = 1; i <= n; i ++ )                // 入度为 0 的点全部入队
        if (!d[i])
            q[ ++ tt] = i;

    while (hh <= tt){                             // 队列不空
        int t = q[hh ++ ];                        // 出队：t 加入拓扑序列

        for (int i = h[t]; i != -1; i = ne[i]){   // 删掉 t 的所有出边
            int j = e[i];
            if (-- d[j] == 0)                     // j 的入度减到 0
                q[ ++ tt] = j;                    // 前置全部完成，j 入队
        }
    }

    return tt == n - 1;                           // 所有点都入过队 => 无环，成功
}
```

> 判定有向图是否存在唯一的拓扑序列（邻接矩阵存储）—— 408 真题
>
> (图，Kahn 算法/拓扑排序) O(n^2)
>
> 基本思想：拓扑序列唯一的充要条件是——Kahn 算法每一轮都恰好只有 1 个"入度为 0 且尚未输出"的顶点。共选 n 轮，每轮扫描全部顶点并统计入度为 0 的候选个数 cnt：
> - cnt == 1：选中它，标记已输出，并把它的所有后继入度减 1（相当于删除它的出边）；
> - cnt > 1：多个候选之间没有先后约束、可互相交换顺序，拓扑序列不唯一，返回 0；
> - cnt == 0：剩余顶点构成环（入度全被环锁死），无拓扑序列，返回 0。
> 顺利选出全部 n 个顶点说明每轮都唯一，返回 1。
>
> 空间复杂度分析：`inDegree` 和 `vis` 两个数组 O(n)，空间复杂度是 O(n)。
> 时间复杂度分析：初始化入度遍历邻接矩阵 O(n^2)；n 轮每轮扫描全部顶点 O(n^2)，更新后继入度也共 O(n^2)。总时间复杂度是 O(n^2)（邻接矩阵存储，读边本身就要 O(n^2)）。

```c++
int uniquely(MGraph G){                 // 判断是否存在唯一拓扑序列，唯一返回 1，不唯一/有环返回 0
    int n = G.numVertices;
    int inDegree[MAXV] = {0};           // 记录每个顶点入度
    bool vis[MAXV] = {false};           // 标记顶点是否已加入拓扑序列

    for (int j = 0; j < n; j ++ )       // 步骤 1：遍历邻接矩阵，初始化所有顶点入度
        for (int i = 0; i < n; i ++ )
            if (G.Edge[i][j] == 1)
                inDegree[j] ++ ;

    for (int k = 0; k < n; k ++ ){      // 一共需要选出 n 个顶点
        int cnt = 0;                    // 本轮入度为 0 且未访问的顶点计数
        int select = -1;                // 本轮选中的唯一入度 0 顶点

        for (int i = 0; i < n; i ++ )   // 统计本轮入度为 0 的顶点数量
            if (!vis[i] && inDegree[i] == 0){
                cnt ++ ;
                select = i;
            }

        if (cnt > 1) return 0;          // 情况 1：本轮有多个入度 0 顶点，拓扑不唯一
        if (cnt == 0) return 0;         // 情况 2：没有入度 0 顶点，说明存在环，无合法拓扑序列

        vis[select] = true;             // 标记选中顶点为已访问
        for (int j = 0; j < n; j ++ )   // 更新该顶点所有后继的入度
            if (G.Edge[select][j] == 1) inDegree[j] -- ;
    }
    return 1;                           // 选出全部 n 个顶点，每轮都只有 1 个入度 0 点，拓扑唯一
}
```
> 二分查找（折半查找）—— 只适用于有序数组
>
> (查找，迭代) O(logn)
>
> 每次取中间元素 `mid` 与 `x` 比较：相等则命中返回；`nums[mid] > x` 说明 x 只可能在左半段，`high = mid - 1`；否则在右半段，`low = mid + 1`。每轮把待查区间缩小一半。循环条件 `low <= high` 表示区间内还有元素（`low == high` 时也要再比一次）；正常跳出循环说明没找到，返回 -1。
>
> 空间复杂度分析：只用 low/high/mid 三个变量，空间复杂度是 O(1)。
> 时间复杂度分析：每轮区间减半，最多比较 ⌈log2(n+1)⌉ 次（折半查找判定树的高度），时间复杂度是 O(logn)。
>
> 注意：C 风格数组形参会退化为指针，形参里写 `nums.size()` 拿不到长度，实际应把长度 n 作为参数传入。

```c++
int binary_search(int nums[], int n, int x){
    int low = 0, high = n - 1, mid;
    while (low <= high){
        mid = (low + high) / 2;
        if (nums[mid] == x) return mid;           // 命中，返回下标
        else if (nums[mid] > x) high = mid - 1;   // 中间值偏大，去左半段
        else low = mid + 1;                       // 中间值偏小，去右半段
    }
    return -1;                                    // 未找到
}
```

> 整数二分（yxc 模板）—— 模板题 AcWing 789. 数的范围
>
> (查找/二分答案，迭代) O(logn)
>
> yxc 的二分不要求"精确命中"，而是找"边界"：把区间按 `check` 性质切成"满足 / 不满足"两半，二分出分界点。两个模板对应两种划分：
> - 模板 1：区间划分成 [l, mid] 和 [mid+1, r]，`check(mid)` 为真时 `r = mid`（答案在左半边），用于求"满足性质的最小位置"，如 x 第一次出现的位置、`>= x` 的最小下标；
> - 模板 2：区间划分成 [l, mid-1] 和 [mid, r]，`check(mid)` 为真时 `l = mid`（答案在右半边），用于求"满足性质的最大位置"，如 x 最后一次出现的位置、`<= x` 的最大下标。
> 关键记忆：只要写 `l = mid`，`mid` 就必须取 `(l + r + 1) / 2`（上取整），否则 l、r 相邻时会死循环；写 `r = mid` 时 `mid = (l + r) / 2` 即可。
>
> 空间复杂度分析：只用常数个变量，空间复杂度是 O(1)。
> 时间复杂度分析：每轮区间减半，时间复杂度是 O(logn)。

```c++
bool check(int x){ /* ... */ }      // 检查 x 是否满足某种性质

int bsearch_1(int l, int r){        // 区间划分成 [l, mid] 和 [mid+1, r] 时使用
    while (l < r){
        int mid = l + r >> 1;       // 下取整
        if (check(mid)) r = mid;    // 满足性质，答案在左半边
        else l = mid + 1;
    }
    return l;
}

int bsearch_2(int l, int r){        // 区间划分成 [l, mid-1] 和 [mid, r] 时使用
    while (l < r){
        int mid = l + r + 1 >> 1;   // 上取整，防死循环
        if (check(mid)) l = mid;    // 满足性质，答案在右半边
        else r = mid - 1;
    }
    return l;
}
```

> 二叉排序树（BST）查找 —— 王道 4.2
>
> (树查找，迭代) O(logn) 平均 / O(n) 最坏
>
> 利用 BST 的性质（左子树所有结点 < 根 < 右子树所有结点）查找：从根开始，x 与当前结点比较——相等则查找成功；x 小则去左子树继续，x 大则去右子树继续；直到遇到空结点说明查找失败，返回 nullptr。整个过程等价于在 BST 上从根走到叶子的一条路径，比较次数不超过树的高度。
>
> 空间复杂度分析：迭代版只用常数个指针，空间复杂度是 O(1)。
> 时间复杂度分析：比较次数不超过树高。树较平衡时树高约 logn，平均 O(logn)；若插入序列有序，BST 会退化成单链表，最坏 O(n)。与折半查找相比，BST 的插入删除更灵活，但平均查找长度取决于树的形态，这就是后面引入平衡二叉树（AVL）的原因。

```c++
struct node{
    int data;
    node *left, *right;                          // 注意 right 前也要加 *
};

node* bst_search(node* head, int x){             // 返回找到的结点指针；找不到返回 nullptr
    while (head != nullptr && x != head->data){
        if (x < head->data) head = head->left;   // 小于当前结点，去左子树
        else head = head->right;                 // 大于当前结点，去右子树
    }
    return head;
}
```

> 相关模板：AcWing 3786. 二叉排序树（yxc 考研算法辅导课）—— 插入、前驱、后继
>
> 插入：查找失败的位置就是插入位置，新结点一定是叶子。递归：x < 根则往左插，x > 根则往右插，遇到空指针就 new。
> 前驱（小于 x 的最大数）/ 后继（大于 x 的最小数）：仍是 BST 查找，只是把"相等返回"换成"收集候选值"——根 >= x 时答案只可能在左子树；根 < x 时答案是"根 或 右子树中的最大值"。
> 删除（三种情况，408 重点）：叶子直接删；只有一个孩子则孩子顶上；左右都有则用左子树最大值（左孩子最右链末端）替换根的值，再递归删除那个结点。

```c++
struct TreeNode{
    int val;
    TreeNode *left, *right;
    TreeNode(int _val) : val(_val), left(NULL), right(NULL) {}
} *root;

void insert(TreeNode *&root, int x){   // 插入：查找失败的位置就是插入位置，新结点必是叶子
    if (!root) root = new TreeNode(x);
    else if (root->val > x) insert(root->left, x);
    else insert(root->right, x);
}

int get_pre(TreeNode *root, int x){    // 前驱：小于 x 的最大数（找不到返回 -INF）
    if (!root) return -INF;
    if (root->val >= x) return get_pre(root->left, x);
    return max(root->val, get_pre(root->right, x));
}

int get_suc(TreeNode *root, int x){    // 后继：大于 x 的最小数（找不到返回 INF）
    if (!root) return INF;
    if (root->val <= x) return get_suc(root->right, x);
    return min(root->val, get_suc(root->left, x));
}
```

> 并查集（Union-Find）—— 王道 第五章（树章节）/ 模板题 AcWing 836. 合并集合
>
> (集合操作，迭代/递归) O(α(n)) 摊还
>
> 用双亲表示法的一维数组 S[] 表示集合森林：S[i] 存 i 的父结点下标，根结点的 S[i] 是负数，其绝对值表示树中结点总数。find 沿双亲链一路向上走到根（S[x] < 0 就是根），根的下标即集合编号；merge 把一棵树的根挂到另一棵树的根下。
> 两个优化（408 高频考点）：① 小树并入大树——比较两个根存的负数（负得越多树越大），把结点数少的树并入大的，树高被控制在 O(logn)；② 路径压缩——find 时把路径上经过的所有结点直接挂到根上，之后 find 几乎就是 O(1)。
>
> 空间复杂度分析：只需要一个长度为 size 的数组 S[]，空间复杂度是 O(n)。
> 时间复杂度分析：不带优化的 find 最坏 O(n)（树退化成链）；只做「小树并入大树」时树高 O(logn)，find 为 O(logn)；再加路径压缩后，n 次操作的摊还时间约为 O(n·α(n))（α 为反阿克曼函数，增长极慢，实际可视为常数），这是常考结论。

```c++
#define SIZE 100                             // S[根] 为负，绝对值 = 树中结点数

void init(int S[]){                          // 初始化：每个元素各自是一棵只有根结点的树
    for (int i = 0; i < SIZE; i ++ ) S[i] = -1;
}

int find(int S[], int x){                    // find：沿双亲链向上走到根（S[x] < 0 说明 x 
    while (S[x] >= 0) x = S[x];				 //根），返回根的下标	
    return x;
}

void merge(int S[], int root1, int root2){   // merge（基本版）：把 root1 挂到 root2 下面
    if (root1 == root2) return;
    S[root1] = root2;                        // 让 root1 成为 root2 的子树
}

void merge(int S[], int root1, int root2){   // 优化一：小树并入大树（S[根] 的负数越小，树越大）
    if (root1 == root2) return;
    if (S[root1] > S[root2]){                // root2 是大树
        S[root2] += S[root1];
        S[root1] = root2;
    }
    else{                                    // root1 是大树
        S[root1] += S[root2];
        S[root2] = root1;
    }
}

int find(int S[], int x){                    // 路径压缩（先找根，再把路径上每个结点直接挂到根）
    int root = x;
    while (S[root] >= 0) root = S[root];
    while (x != root){
        int tmp = S[x];
        S[x] = root;
        x = tmp;
    }
    return root;
}
```

> 相关模板：AcWing 836. 合并集合（yxc 算法基础课）—— 完整三件套
>
> yxc 写法与王道不同：p[x] 存 x 的父结点，根结点的父结点是它自己（p[root] == root）；find 递归找祖宗并顺手压缩路径（p[x] = find(p[x])），返回 x 的祖宗。理解技巧：p[x] 类似「通项公式」，find 递归到根后逐层返回赋值，路径上每个结点都直接指向祖宗。
>
> (1) 朴素并查集：只维护「是否在同一集合」。合并一行 p[find(a)] = find(b)，即 a 的祖宗认 b 的祖宗当爹。
> 空间复杂度分析：一个 p 数组，O(n)。
> 时间复杂度分析：find 带路径压缩，n 次操作摊还 O(n·α(n))，α(n) 是反阿克曼函数，实际可视为常数。
>
> (2) 维护 size：size[] 只有根结点的值有意义，表示该集合的点数。合并顺序不能反：先 size[find(b)] += size[find(a)]，再 p[find(a)] = find(b)，否则先改父结点后 find(a) 就找不到原集合、size 会加错。考试里变量名写成 sz 更稳妥（避免与 std::size 冲突）。
> 空间复杂度分析：p 和 size 两个数组，O(n)。
> 时间复杂度分析：与 (1) 相同，摊还 O(α(n))。
> 应用：AcWing 837. 连通块中点的数量。
>
> (3) 维护到祖宗距离：d[x] 存 x 到 p[x] 的距离。find 时先递归，返回后 d[p[x]] 已被更新成「旧父结点到祖宗的距离」，所以 d[x] += d[p[x]] 就得到 x 到祖宗的距离，最后 p[x] = u 完成路径压缩；合并时 d[find(a)] 按题目要求设偏移量。
> 空间复杂度分析：p 和 d 两个数组，O(n)。
> 时间复杂度分析：与 (1) 相同，摊还 O(α(n))。
> 应用：AcWing 240. 食物链（带权并查集）。

> 5. 树的递归
>
> 原题1：二叉树的最大深度（LeetCode 104）
>
> (树，递归) O(n)
>
> 树的最大深度 = max(左子树深度, 右子树深度) + 1，根结点自身算一层。递归边界：空结点返回 0——空树深度为 0，叶子结点深度为 1。
>
> 空间复杂度分析：递归栈深度等于树高，树平衡时 O(logn)，退化成链时最坏 O(n)。
> 时间复杂度分析：每个结点恰好访问一次，时间复杂度是 O(n)。

``` C++
struct TreeNode {
    int val;
    TreeNode *left;
    TreeNode *right;
    TreeNode() : val(0), left(nullptr), right(nullptr) {}
    TreeNode(int x) : val(x), left(nullptr), right(nullptr) {}
    TreeNode(int x, TreeNode *left, TreeNode *right) : val(x), left(left), right(right) {}
}
 
int maxDepth(TreeNode* root) {
    if (root == nullptr) return 0;
    return max(maxDepth(root->left), maxDepth(root->right)) + 1;   //左右子树取大者+1
}
```

> 原题2：判断两棵二叉树是否互为镜像（LeetCode 101 对称二叉树）
>
> (树，递归) O(n)
>
> 互为镜像：两个根结点值相同，且 root1 的左子树与 root2 的右子树互为镜像、root1 的右子树与 root2 的左子树互为镜像——两个指针朝相反方向走。递归出口先判空：两个都空 → 对称；一个空一个不空 → 不对称。
>
> 空间复杂度分析：递归栈深度 O(树高)，最坏 O(n)。
> 时间复杂度分析：每个结点对恰好访问一次，O(n) 已是最优——必须看完所有结点才能下结论。

```c++
bool is_mirror(binode* root1, binode* root2){
    if (root1 == nullptr && root2 == nullptr) return true;         // 同时到空，对称
    else if (root1 == nullptr || root2 == nullptr) return false;   // 一个为空，不对称
    else if (root1->data != root2->data) return false;             // 数据不同，不对称
    else return is_mirror(root1->left, root2->right)               // 两指针朝相反方向走
                && is_mirror(root1->right, root2->left);
}
```
