## 四、数据链路层——MAC 子层

| 缩写 | 全称 | 含义 |
| :--- | :--- | :--- |
| **MAC** | Media Access Control | 介质访问控制子层（帧封装、CSMA/CD、编址） |
| **LLC** | Logical Link Control | 逻辑链路控制子层（DSAP/SSAP、复用上层协议） |
| **SNAP** | Sub-Network Access Protocol | 子网访问协议（LLC 中 DSAP=0xAA 时，5B 扩展含 Type） |
| **SAP** | Service Access Point | 服务访问点（LLC 中标记上层协议的 1B 标识） |
| **DSAP** | Destination SAP | 目的服务访问点 |
| **SSAP** | Source SAP | 源服务访问点 |
| **OUI** | Organizationally Unique Identifier | 组织唯一标识符（MAC 前 24 位，IEEE 分配给厂商） |
| **EUI-48** | Extended Unique Identifier-48 | 48 位扩展唯一标识符（即 MAC 地址） |
| **EUI-64** | EUI-64 | 64 位扩展唯一标识符（IPv6 接口 ID 用） |
| **MTU** | Maximum Transmission Unit | 最大传输单元（以太网 1500B） |
| **FCS** | Frame Check Sequence | 帧检验序列（CRC 结果，4B） |
| **CRC** | Cyclic Redundancy Check | 循环冗余检验 |
| **IFG / IPG** | Inter-Frame / Inter-Packet Gap | 帧间间隔（以太网 96bit 时间） |
| **DIX** | DEC-Intel-Xerox | Ethernet V2 的三个创始公司（称 DIX Ethernet） |
| **NIC** | Network Interface Card | 网卡（网络接口卡） |
| **MAU** | Medium Attachment Unit | 介质连接单元（收发器） |

## 五、CSMA/CD 与 CSMA/CA——冲突相关

| 缩写 | 全称 | 含义 |
| :--- | :--- | :--- |
| **CSMA/CD** | Carrier Sense Multiple Access with Collision Detection | 载波监听多路访问/冲突检测（以太网） |
| **CSMA/CA** | CSMA with Collision Avoidance | 载波监听多路访问/冲突避免（Wi-Fi） |
| **RTS** | Request To Send | 请求发送帧（CA 握手机制） |
| **CTS** | Clear To Send | 允许发送帧 |
| **NAV** | Network Allocation Vector | 网络分配向量（虚拟载波监听，记录信道占用时间） |
| **DIFS** | Distributed Inter-Frame Spacing | 分布式帧间间隔（DCF 模式下发送前等待） |
| **SIFS** | Short IFS | 短帧间间隔（ACK/RTS/CTS 等高优先级帧用） |
| **BEB** | Binary Exponential Backoff | 截断二进制指数退避（冲突后随机等待算法） |

## 七、差错控制与流量控制

| 缩写 | 全称 | 含义 |
| :--- | :--- | :--- |
| **ARQ** | Automatic Repeat reQuest | 自动重传请求（CRC 错/超时 → 重传） |
| **GBN** | Go-Back-N | 后退 N 帧协议（累积 ACK + 回退 N） |
| **SR** | Selective Repeat | 选择重传协议（独立 ACK + 只重传出错帧） |
| **ACK** | Acknowledgment | 确认帧（肯定确认） |
| **NAK / NACK** | Negative Acknowledgment | 否认帧（否定确认，请求重传指定帧） |
| **FEC** | Forward Error Correction | 前向纠错（接收方自行纠正） |
| **HEC** | Header Error Control | 首部差错控制（如 ATM 信元头 CRC） |

## 八、链路层协议

| 缩写 | 全称 | 含义 |
| :--- | :--- | :--- |
| **HDLC** | High-Level Data Link Control | 高级数据链路控制（bit 填充） |
| **PPP** | Point-to-Point Protocol | 点对点协议（字节填充 + LCP + NCP） |
| **LCP** | Link Control Protocol | 链路控制协议（PPP 的建链/认证/参数协商） |
| **NCP** | Network Control Protocol | 网络控制协议（PPP 的 IP 地址分配等） |
| **SLIP** | Serial Line Internet Protocol | 串行线路 IP 协议（PPP 前身，已淘汰） |

## 九、交换机 / 网桥

| 缩写 | 全称 | 含义 |
| :--- | :--- | :--- |
| **STP** | Spanning Tree Protocol | 生成树协议（消环，选根桥+根端口+指定端口） |
| **RSTP** | Rapid STP | 快速生成树协议（802.1w，收敛加速） |
| **BPDU** | Bridge Protocol Data Unit | 网桥协议数据单元（STP 的配置消息） |
| **CAM** | Content Addressable Memory | 内容可寻址存储器（交换机 MAC 地址表的硬件实现） |
| **VLAN** | Virtual LAN | 虚拟局域网（802.1Q，隔离广播域） |
| **LAG / LACP** | Link Aggregation Group / Control Protocol | 链路聚合 / 链路聚合控制协议 |

## 十、408 最常考缩写 TOP 10

| 排名 | 缩写 | 考频 | 一句话 |
| :---: | :--- | :---: | :--- |

| 2 | **MAC** | ★★★★★ | 48 位硬件地址 + 帧封装 + 介质访问控制 |

| 4 | **ARQ** | ★★★★ | 自动重传请求，含 GBN（累积 ACK）/ SR（独立 ACK） |
| 5 | **GBN / SR** | ★★★★ | 连续 ARQ 的两种协议，区别在重传范围 |
| 6 | **LLC** | ★★★★ | 逻辑链路控制，802.2，DSAP/SSAP 标识上层协议 |
| 7 | **SNAP** | ★★★ | LLC 中 DSAP=0xAA 时的 5B 扩展，含 2B Type |
| 8 | **MTU** | ★★★ | 最大传输单元 1500B，分片依据 |
| 9 | **CSMA/CA** | ★★★ | Wi-Fi 的避让机制：RTS/CTS + NAV + DIFS/SIFS |
| 10 | **VLAN** | ★★★ | 802.1Q 虚拟局域网，隔离广播域，4B Tag 含 VID |

---

> **核心记忆优先级：** CSMA/CD → MAC → CRC → ARQ(GBN/SR) → LLC/SNAP → MTU → CSMA/CA → VLAN
> 记住全称即理解含义——例如 CSMA/CD 全称本身就是它的工作流程：载波监听(Carrier Sense) → 多路访问(Multiple Access) → 冲突检测(Collision Detection)。
