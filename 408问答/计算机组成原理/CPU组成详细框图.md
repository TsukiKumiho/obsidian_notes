## 三、寄存器组详表

```text
+==============================================================================+
|                            寄 存 器 组 (Register File)                        |
+=====+============+==========+================================================+
| 缩写 |   中文名   |  位宽    |              功 能 描 述                        |
+-----+------------+----------+------------------------------------------------+
| PC  | 程序计数器  | 同MAR    | 存放下一条指令在主存中的地址；自动 +1 / +跳转偏移  |
| IR  | 指令寄存器  | 指令字长  | 存放当前正在执行的指令（操作码 + 地址码）           |
| MAR | 存储器地址  | 地址线宽  | 存放本次访存的地址，连接地址总线                    |
|     | 寄存器     |          |                                                   |
| MDR | 存储器数据  | 数据线宽  | 存放本次访存的数据（读出/写入），连接数据总线        |
|     | 寄存器     |          |                                                   |
| ACC | 累加器      | 机器字长  | ALU 运算的默认目的寄存器，存放运算结果               |
| PSW | 程序状态字  | 8~32 bit | 存放标志位 (ZF/CF/OF/SF) + 中断允许位 + 特权级等    |
| SP  | 堆栈指针    | 同MAR    | 指向栈顶地址，PUSH/POP 时自动 ±1                    |
| BP  | 基址指针    | 同MAR    | 指向当前栈帧基址，用于访问局部变量 / 参数            |
| IX  | 变址寄存器  | 机器字长  | 存放数组遍历的偏移量，EA = (IX) + A                  |
| BR  | 基址寄存器  | 机器字长  | 存放程序基地址，EA = (BR) + A，程序浮动用            |
| R0~ | 通用寄存器  | 机器字长  | 存放临时数据 / 中间结果 / 地址，程序员可见            |
| Rn  |            |          |                                                   |
+-----+------------+----------+------------------------------------------------+
```

## 五、控制器 (CU) 双实现方案对比

```text
+==============================================================================+
|                       控 制 器 (Control Unit)                                 |
+====================+=========================================================+
|  硬布线控制器       |  微程序控制器                                            |
| (Hardwired CU)     |  (Microprogrammed CU)                                   |
+--------------------+---------------------------------------------------------+
|                    |                                                         |
|  指令 → 译码器     |  指令 → CMAR(微地址寄存器)                                |
|    ↓              |       ↓                                                  |
|  组合逻辑网络      |  控制存储器(CM, 存微指令)                                 |
|    ↓              |       ↓                                                  |
|  控制信号序列      |  CMDR(微指令寄存器) → 下地址字段 + 控制信号字段            |
|                    |                                                         |
|  优点: 速度快       |  优点: 规整、易修改、适合复杂指令系统                     |
|  缺点: 不易修改     |  缺点: 慢（多一次控制存储器读）                          |
|  适用: RISC        |  适用: CISC                                              |
+--------------------+---------------------------------------------------------+
```

## 六、指令执行数据通路（以 ADD R1, [addr] 为例）

```text
时钟周期     数据通路动作
========     ==========================================
   T1        PC → MAR ──────────→ 地址总线 → 主存
   T2        M(MAR) → MDR → IR   (取指令)
   T3        PC + 1 → PC         (PC 更新)
   T4        IR[地址码] → MAR ──→ 地址总线 → 主存     (取操作数)
   T5        M(MAR) → MDR → 暂存器B
   T6        R1 → 暂存器A
   T7        (暂存器A) + (暂存器B) → ACC, 置标志         (执行)
   T8        [若是变长指令周期则继续取下一指令]
```

## 八、标志位 (PSW 核心位) 定义

|   标志   | 名称    | 含义             | 置 1 条件                   |
| :----: | :---- | :------------- | :----------------------- |
| **ZF** | 零标志   | 运算结果 = 0       | 结果全 0                    |
| **CF** | 进位/借位 | 最高位有进位/借位      | 无符号数溢出                   |
| **OF** | 溢出标志  | 有符号数结果超范围      | $C_n \oplus C_{n-1} = 1$ |
| **SF** | 符号标志  | 结果的符号          | 结果最高位 = 1（负）             |
| **PF** | 奇偶标志  | 结果低 8 位中 1 的个数 | 偶数个 1 (x86)              |
| **AF** | 辅助进位  | 低 4 位向高 4 位进位  | BCD 码调整用                 |
| **IF** | 中断允许  | 是否响应可屏蔽中断      | 开中断 (STI)                |
| **DF** | 方向标志  | 串操作方向          | 1 = 自减 (STD)             |

> ⚠️ **OF vs CF** 是高频考点：OF 针对**有符号数**（看最高两位进位异或）；CF 针对**无符号数**（看最高位进位）。

## 九、数据通路结构对比

| 结构 | 特点 | 优缺点 | 典型 CPU |
| :--- | :--- | :--- | :--- |
| **单总线** | 所有部件挂一条内部总线 | 结构最简单，但同一时刻只能传一个数据 → 速度最慢 | 早期 CPU / 简单教学模型 |
| **双总线** | 两条总线（如 A 总线 + B 总线）| ALU 可同时取两操作数 → 速度更快 | 中档 CPU |
| **三总线** | 三条独立总线 | 同时送两操作数 + 写回结果，一个时钟周期完成一条指令 | 现代高性能 CPU |
