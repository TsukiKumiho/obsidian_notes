## 一、英文原文

**Why Forgetting Is Not a Failure**

We tend to think of forgetting as a flaw — a malfunction of memory that we should strive to correct. From ancient mnemonic techniques to modern brain-training apps, the cultural message is consistent: remembering is good, forgetting is bad. Yet recent neuroscience suggests that this picture is not merely incomplete but fundamentally backwards. Forgetting, far from being a defect, is an essential cognitive function without which the brain could not operate effectively.

The brain is not a video recorder. It does not passively store every experience in exhaustive detail; rather, it actively filters, compresses, and discards information. This filtering process — known as synaptic pruning — occurs most aggressively during sleep, when the brain weakens or eliminates connections that were seldom used during waking hours. The goal is not to preserve the past but to extract useful patterns from it, and pattern extraction demands the suppression of irrelevant detail.

Consider the rare individuals who suffer from highly superior autobiographical memory — a condition in which people remember nearly every day of their lives in vivid detail. One might imagine this as a gift, but those who have it describe it as a burden. The inability to forget makes it difficult to generalize, to abstract, to see the forest for the trees. Every new situation triggers an avalanche of specific, often irrelevant memories, impeding the kind of flexible thinking that everyday life requires.

What this reveals is a deeper truth about cognition: remembering and forgetting are not opponents but partners in a single process of making sense of the world. The brain forgets not because it is weak, but because it is wise — it knows that clarity requires omission. In an age of infinite digital storage, where we are encouraged to preserve everything, this lesson is worth remembering: sometimes the best way to understand is to let go.

## 二、中文翻译

我们倾向于把遗忘视为一种缺陷——一种记忆的故障，我们应当努力去纠正它。从古代的助记术到现代的脑力训练应用，文化传递的信息是一致的：记住是好的，遗忘是坏的。然而，最近的神经科学研究表明，这幅图景不仅不完整，而且从根本上就是颠倒的。遗忘远非一种缺陷，而是一种至关重要的认知功能——没有它，大脑就无法有效运作。

大脑不是一台录像机。它不会被动地、详尽无遗地存储每一次经历；相反，它积极地过滤、压缩和丢弃信息。这一过滤过程——被称为突触修剪——在睡眠期间最为剧烈，此时大脑会削弱或消除那些在清醒时很少使用的连接。其目标不是保存过去，而是从中提取有用的模式，而模式提取恰恰要求抑制无关细节。

不妨考虑那些罕见的患有高度优异自传体记忆的人——在这种状况下，人们几乎能以生动的细节记住他们一生中的每一天。人们可能会把这想象为一种天赋，但拥有它的人却将其描述为一种负担。无法遗忘使人难以概括、难以抽象、难以见林不见树。每一个新的情境都会触发一场特定记忆——往往是无关记忆——的雪崩，从而阻碍日常生活所需的那种灵活思维。

这揭示了一个关于认知的更深层真理：记忆与遗忘不是一个单一认知过程中的对手，而是伙伴——这个过程就是理解世界。大脑遗忘不是因为它虚弱，而是因为它智慧——它知道清晰需要省略。在一个鼓励我们保存一切的无限数字存储时代，这一教训值得铭记：有时候，最好的理解方式就是放手。

## 五、考研阅读长难句精析

### 结构一：not merely A but fundamentally B 递进否定

> **原句**：Yet recent neuroscience suggests that this picture is not merely incomplete but fundamentally backwards.

| 维度 | 分析 |
| :--- | :--- |
| **识别关键** | `not merely... but fundamentally...` = "不仅…而且从根本上…"，`not merely` 否定程度较浅，`but fundamentally` 递进到更深层次的否定 |
| **结构骨架** | [主语] suggests that [事物] is not merely [adj1] but fundamentally [adj2] |
| **翻译** | 然而最近的神经科学研究表明，这幅图景不仅不完整，而且从根本上就是颠倒的。 |
| **提分要点** | `not merely A but B` 比 `not only A but also B` 书面化程度更高；`fundamentally` 作为程度副词修饰形容词，是学术写作高频用法 |

### 结构二：破折号分隔的插入式同位语

> **原句**：This filtering process — known as synaptic pruning — occurs most aggressively during sleep, when the brain weakens or eliminates connections that were seldom used during waking hours.

| 维度 | 分析 |
| :--- | :--- |
| **识别关键** | 双破折号 `— known as... —` 为术语同位语；`when` 引导非限定性定语从句修饰 `sleep`（而非时间状语从句）；`that were seldom used...` 为定语从句修饰 `connections` |
| **结构骨架** | [主语] — known as [术语] — [谓语] during [N], when [从句含 that 定语从句] |
| **翻译** | 这一过滤过程——被称为突触修剪——在睡眠期间最为剧烈，此时大脑会削弱或消除那些在清醒时很少使用的连接。 |
| **提分要点** | `when` 引导非限定性定语从句修饰时间名词是考研英语标志性结构——译作"此时"而非"当……时" |

### 结构三：not because... but because... 双重原因从句

> **原句**：The brain forgets not because it is weak, but because it is wise — it knows that clarity requires omission.

| 维度 | 分析 |
| :--- | :--- |
| **识别关键** | `not because A, but because B` = "不是因为A，而是因为B"；破折号后 `it knows that...` 是对 `because it is wise` 的展开解释 |
| **结构骨架** | [主语] [谓语] not because [从句A], but because [从句B] — [展开解释B] |
| **翻译** | 大脑遗忘不是因为它虚弱，而是因为它智慧——它知道清晰需要省略。 |
| **提分要点** | `not because... but because...` 是驳斥常见误解+提出正确解释的标准句式，大作文中可直接套用于结尾段的深化论证 |

## 六、考研翻译重点句

### 句 1

> It does not passively store every experience in exhaustive detail; rather, it actively filters, compresses, and discards information.

**标准翻译**：它不会被动地、详尽无遗地存储每一次经历；相反，它积极地过滤、压缩和丢弃信息。

| 踩分点 | 说明 |
| :--- | :--- |
| `not passively... rather, actively...` | "不是被动地……而是积极地……" |
| `in exhaustive detail` | "详尽无遗地"（方式状语后置翻译为前置） |
| `filters, compresses, and discards` | 三个并列动词，保持中文节奏——"过滤、压缩和丢弃" |

### 句 2

> The inability to forget makes it difficult to generalize, to abstract, to see the forest for the trees.

**标准翻译**：无法遗忘使人难以概括、难以抽象、难以见林不见树。

| 踩分点 | 说明 |
| :--- | :--- |
| `The inability to forget` | "无法遗忘"（名词短语译为主谓结构） |
| `makes it difficult to...` | "使人难以……"（形式宾语 it 不译出） |
| `see the forest for the trees` | "见林不见树"（英语习语，保留比喻直译即可） |

### 句 3

> Every new situation triggers an avalanche of specific, often irrelevant memories, impeding the kind of flexible thinking that everyday life requires.

**标准翻译**：每一个新的情境都会触发一场特定记忆——往往是无关记忆——的雪崩，从而阻碍日常生活所需的那种灵活思维。

| 踩分点 | 说明 |
| :--- | :--- |
| `triggers an avalanche of` | "触发一场……的雪崩"（比喻义） |
| `often irrelevant` | 插入语，译为"往往是无关的"（破折号处理） |
| `impeding...` | 现在分词作结果状语——"从而阻碍……" |
| `that everyday life requires` | that 定语从句——"日常生活所需的" |

## 九、提分关键提醒

1. **`far from` 是考研阅读中最容易被反向理解的短语之一**——它表示"远非、根本不"，而不是"远离"。如 `far from being a defect` = "根本不是缺陷"（而非"远离缺陷"）。

2. **`not because... but because...` 句式**在大作文结尾段是论证深度的标志——先否定一种肤浅解释，再给出更深层的原因。比单独使用 `because` 论证层次高出一档。

3. **`when` 引导非限定性定语从句修饰时间名词**（如本文的 `during sleep, when...`）几乎是每年考研翻译的必考结构——一定译作"此时/在这一过程中"而非"当……时"。

4. 注意 **`see the forest for the trees`** 这类英语习语——考研翻译中如果出现，**不要意译为"顾全大局"**，直译"见林不见树"保留原文比喻即可得分。
