### 三、常见补充导数公式

#### 3.1 反三角函数补充

| 函数 | 导数 | 备注 |
| :--- | :--- | :--- |
| $\arcsin x$ | $\frac{1}{\sqrt{1-x^2}}$ | 基础高频 |
| $\arccos x$ | $-\frac{1}{\sqrt{1-x^2}}$ | 只比上式多负号 |
| $\arctan x$ | $\frac{1}{1+x^2}$ | 常和积分互反 |
| $\mathrm{arccot}\,x$ | $-\frac{1}{1+x^2}$ | 注意负号 |
| $\mathrm{arcsec}\,x$ | $\frac{1}{|x|\sqrt{x^2-1}}$ | 了解型 |
| $\mathrm{arccsc}\,x$ | $-\frac{1}{|x|\sqrt{x^2-1}}$ | 了解型 |

---

#### 3.2 双曲函数与反双曲函数导数

| 函数 | 导数 | 备注 |
| :--- | :--- | :--- |
| $\sinh x$ | $\cosh x$ | 常见于构造题 |
| $\cosh x$ | $\sinh x$ | 与三角函数不同，无负号 |
| $\tanh x$ | $\mathrm{sech}^2 x$ | 了解即可 |
| $\operatorname{arsinh}x$ | $\frac{1}{\sqrt{1+x^2}}$ | 和 $\ln(x+\sqrt{1+x^2})$ 密切相关 |
| $\operatorname{arcosh}x$ | $\frac{1}{\sqrt{x^2-1}}$ | 通常要求 $x>1$ |
| $\operatorname{artanh}x$ | $\frac{1}{1-x^2}$ | 和部分分式常联动 |

---

#### 3.3 常见“做题型”导数公式

| 形式 | 导数 | 识别思路 |
| :--- | :--- | :--- |
| $\ln|u(x)|$ | $\frac{u'(x)}{u(x)}$ | 看到对数先想“里面求导比外面” |
| $e^{u(x)}$ | $e^{u(x)}u'(x)$ | 指数函数本身不变 |
| $a^{u(x)}$ | $a^{u(x)}\ln a\cdot u'(x)$ | 多出 $\ln a$ |
| $[u(x)]^\alpha$ | $\alpha [u(x)]^{\alpha-1}u'(x)$ | 幂函数复合 |
| $\sin(u(x))$ | $\cos(u(x))u'(x)$ | 三角复合 |
| $\tan(u(x))$ | $\sec^2(u(x))u'(x)$ | 常用于凑导数 |
| $\sqrt{u(x)}$ | $\frac{u'(x)}{2\sqrt{u(x)}}$ | 根式本质仍是幂函数 |
| $\frac{1}{u(x)}$ | $-\frac{u'(x)}{[u(x)]^2}$ | 倒数结构 |
| $\ln\big(x+\sqrt{x^2+1}\big)$ | $\frac{1}{\sqrt{x^2+1}}$ | 高频补充结果 |
| $\ln\big|x+\sqrt{x^2-a^2}\big|$ | $\frac{1}{\sqrt{x^2-a^2}}$ | 高频补充结果 |
| $\arcsin(u(x))$ | $\frac{u'(x)}{\sqrt{1-u(x)^2}}$ | 链式法则 |
| $\arctan(u(x))$ | $\frac{u'(x)}{1+u(x)^2}$ | 链式法则 |

---

#### 3.4 幂指函数求导

| 形式 | 求导公式 | 适用说明 |
| :--- | :--- | :--- |
| $u(x)^{v(x)}$ | $u(x)^{v(x)}\left[v'(x)\ln u(x)+v(x)\frac{u'(x)}{u(x)}\right]$ | 最常用补充公式之一 |
| $x^x$ | $x^x(\ln x+1)$ | 高频 |
| $x^{\sin x}$ | $x^{\sin x}\left(\cos x\ln x+\frac{\sin x}{x}\right)$ | 典型幂指函数 |
| $(\sin x)^x$ | $(\sin x)^x\left(\ln(\sin x)+x\cot x\right)$ | 常用于综合题 |

> ⚠️ 幂指函数一律优先取对数：设 $y=u(x)^{v(x)}$，先写 $\ln y=v(x)\ln u(x)$。

#### 3.5 反函数型与参数型常见导数结果

| 形式 | 结果 | 备注 |
| :--- | :--- | :--- |
| 反函数 $y=f^{-1}(x)$ | $(f^{-1})'(x)=\frac{1}{f'(f^{-1}(x))}$ | 理论题常用 |
| 参数方程 $x=x(t),y=y(t)$ | $\frac{dy}{dx}=\frac{y'(t)}{x'(t)}$ | 曲线切线斜率 |
| 参数二阶导 | $\frac{d^2y}{dx^2}=\frac{d}{dt}(\frac{dy}{dx})/\frac{dx}{dt}$ | 了解并会套 |
| 隐函数 $F(x,y)=0$ | $y'=-\frac{F_x}{F_y}$ | 高频 |
| 对数求导法 | 先取对数再求导 | 适合连乘、连幂、幂指混合 |

### 四、常见补充积分公式

#### 4.1 含根式与反三角型常见积分

| 积分公式 | 结果 | 备注 |
| :--- | :--- | :--- |
| $\int \frac{1}{a^2+x^2}\,dx$ | $\frac{1}{a}\arctan\frac{x}{a}+C$ | 高频 |
| $\int \frac{1}{\sqrt{a^2-x^2}}\,dx$ | $\arcsin\frac{x}{a}+C$ | 高频 |
| $\int \frac{1}{\sqrt{x^2+a^2}}\,dx$ | $\ln\big(x+\sqrt{x^2+a^2}\big)+C$ | 高频补充 |
| $\int \frac{1}{\sqrt{x^2-a^2}}\,dx$ | $\ln\big|x+\sqrt{x^2-a^2}\big|+C$ | 高频补充 |
| $\int \sqrt{a^2-x^2}\,dx$ | $\frac{x}{2}\sqrt{a^2-x^2}+\frac{a^2}{2}\arcsin\frac{x}{a}+C$ | 常考 |
| $\int \sqrt{x^2+a^2}\,dx$ | $\frac{x}{2}\sqrt{x^2+a^2}+\frac{a^2}{2}\ln\big(x+\sqrt{x^2+a^2}\big)+C$ | 常考 |
| $\int \sqrt{x^2-a^2}\,dx$ | $\frac{x}{2}\sqrt{x^2-a^2}-\frac{a^2}{2}\ln\big|x+\sqrt{x^2-a^2}\big|+C$ | 高频 |

#### 4.2 常见分式与对数型积分

| 积分公式 | 结果 | 备注 |
| :--- | :--- | :--- |
| $\int \frac{1}{x^2-a^2}\,dx$ | $\frac{1}{2a}\ln\left|\frac{x-a}{x+a}\right|+C$ | 需记型 |
| $\int \frac{1}{a^2-x^2}\,dx$ | $\frac{1}{2a}\ln\left|\frac{a+x}{a-x}\right|+C$ | 与上式对应 |
| $\int \frac{1}{x}\,dx$ | $\ln|x|+C$ | 最基础 |
| $\int \ln x\,dx$ | $x\ln x-x+C$ | 分部积分经典题 |
| $\int \frac{dx}{x\ln x}$ | $\ln|\ln x|+C$ | 高频 |
| $\int \frac{u'(x)}{u(x)}dx$ | $\ln|u(x)|+C$ | 最重要识别公式 |

| :--- | :--- | :--- |

### 五、技巧公式索引

#### 5.1 区间再现公式

| 原式 | 换元 | 结果 |
| :--- | :--- | :--- |
| $I=\int_a^b f(x)dx$ | 令 $x=a+b-t$ | $I=\int_a^b f(a+b-t)dt$ |
| $I=\int_0^a f(x)dx$ | 令 $x=a-t$ | $I=\int_0^a f(a-t)dt$ |
| 两式相加 | — | $2I=\int_a^b [f(x)+f(a+b-x)]dx$ |
| 两式相减 | — | $0=\int_a^b [f(x)-f(a+b-x)]dx$ |

**最常见特例：**

| 题型 | 结论 |
| :--- | :--- |
| $I=\int_0^\pi x f(\sin x)dx$ | $I=\pi\int_0^\pi f(\sin x)dx-I$，故 $I=\frac\pi2\int_0^\pi f(\sin x)dx$ |
| $I=\int_0^1 f(x)dx$ | 可写成 $I=\int_0^1 f(1-x)dx$ |
| $I=\int_0^{\frac\pi2} F(\sin x,\cos x)dx$ | 常可用 $x\mapsto \frac\pi2-x$ 交换 $\sin x$ 与 $\cos x$ |

---

#### 5.2 对称性公式

| 条件 | 公式 | 用途 |
| :--- | :--- | :--- |
| 奇函数，区间 $[-a,a]$ | $\int_{-a}^a f(x)dx=0$ | 秒杀型 |
| 偶函数，区间 $[-a,a]$ | $\int_{-a}^a f(x)dx=2\int_0^a f(x)dx$ | 秒杀型 |
| 周期函数 $f(x+T)=f(x)$ | $\int_a^{a+T}f(x)dx=\int_0^T f(x)dx$ | 平移区间 |
| $f(x)+f(a-x)$ 易化简 | 联立区间再现 | 常用于定积分 |

#### 5.3 华里士公式

设
$$
I_n=\int_0^{\frac\pi2}\sin^n x\,dx=\int_0^{\frac\pi2}\cos^n x\,dx
$$

则有递推：
$$
I_n=\frac{n-1}{n}I_{n-2}\quad (n\ge 2)
$$

并且：

| 情况 | 结果 |
| :--- | :--- |
| $n=2m$ 为偶数 | $I_{2m}=\frac{(2m-1)!!}{(2m)!!}\cdot\frac\pi2$ |
| $n=2m+1$ 为奇数 | $I_{2m+1}=\frac{(2m)!!}{(2m+1)!!}$ |

进一步可写成：

$$
\frac{\pi}{2}=\prod_{n=1}^{\infty}\frac{(2n)^2}{(2n-1)(2n+1)}
$$

**常用场景表：**

| 场景 | 怎么用 |
| :--- | :--- |
| $\int_0^{\frac\pi2}\sin^n x\,dx$ | 直接用递推或偶奇结论 |
| $\int_0^{\frac\pi2}\cos^n x\,dx$ | 与上完全相同 |
| 极限题里出现双阶乘 | 可能和华里士公式有关 |
| 证明不等式 | 可结合单调性或夹逼 |

#### 5.4 三角积分常用降幂与化积公式

| 公式 | 作用 |
| :--- | :--- |
| $\sin^2 x=\frac{1-\cos 2x}{2}$ | 降幂 |
| $\cos^2 x=\frac{1+\cos 2x}{2}$ | 降幂 |
| $\sin x\cos x=\frac12\sin 2x$ | 化积 |
| $\sin A\cos B=\frac12[\sin(A+B)+\sin(A-B)]$ | 化积为和 |
| $\cos A\cos B=\frac12[\cos(A+B)+\cos(A-B)]$ | 化积为和 |
| $\sin A\sin B=-\frac12[\cos(A+B)-\cos(A-B)]$ | 化积为和 |

#### 5.5 根式与三角代换对应表

| 根式形式 | 推荐代换 | 原因 |
| :--- | :--- | :--- |
| $\sqrt{a^2-x^2}$ | $x=a\sin t$ | 利用 $1-\sin^2 t=\cos^2 t$ |
| $\sqrt{a^2+x^2}$ | $x=a\tan t$ | 利用 $1+\tan^2 t=\sec^2 t$ |
| $\sqrt{x^2-a^2}$ | $x=a\sec t$ | 利用 $\sec^2 t-1=\tan^2 t$ |

#### 5.6 Beta / Gamma 型识别公式

**Beta 函数：**
$$
B(p,q)=\int_0^1 x^{p-1}(1-x)^{q-1}dx=\frac{\Gamma(p)\Gamma(q)}{\Gamma(p+q)}
$$

**Gamma 函数：**
$$
\Gamma(s)=\int_0^{+\infty}x^{s-1}e^{-x}dx\quad (s>0)
$$

以及：
$$
\Gamma(n+1)=n!\quad (n\in \mathbb{N})
$$

**什么时候有用：**

| 结构 | 可能转化为 |
| :--- | :--- |
| $\int_0^1 x^{m}(1-x)^n dx$ | Beta 型 |
| $\int_0^{+\infty} x^m e^{-x}dx$ | Gamma 型 |
| $\int_0^{\frac\pi2}\sin^m x\cos^n x\,dx$ | 可与 Beta 函数联系 |

> ⚠️ 数一里通常不要求系统掌握特殊函数理论，但遇到这类形式要会“认型”。

### 六、做题时的快速识别技巧

| 看到的结构 | 第一反应 | 原因 |
| :--- | :--- | :--- |
| $u'(x)/u(x)$ | 直接写成 $\ln|u(x)|$ 型 | 最高频识别 |
| $1/(a^2+x^2)$ | 想 $\arctan$ | 标准反三角型 |
| $1/\sqrt{a^2-x^2}$ | 想 $\arcsin$ | 标准反三角型 |
| $1/\sqrt{x^2\pm a^2}$ | 想对数结果 | 高频补充公式 |
| $x^x, (f(x))^{g(x)}$ | 先取对数再求导 | 幂指函数 |
| $\int_0^a f(x)dx$ 且 $f(a-x)$ 更简单 | 用区间再现 | 减少计算 |
| $\int_0^{\frac\pi2}\sin^n xdx$ | 想华里士公式或递推 | 秒杀型 |
| 根式 $\sqrt{a^2-x^2},\sqrt{a^2+x^2},\sqrt{x^2-a^2}$ | 三角代换 | 固定套路 |
| 三角幂次积分 | 先看奇偶，再决定留一项还是降幂 | 比万能代换更快 |

### 七、避坑警示

> ⚠️ **补充公式的本质不是多背，而是会认。** 很多题难在认不出它其实就是标准结构。

> ⚠️ **区间再现公式只能在换元后区间能回到原区间时发挥最大作用。**

> ⚠️ **华里士公式只对特定区间 $\left[0,\frac\pi2\right]$ 的三角幂积分最直接。** 不要乱套到一般区间。

> ⚠️ **$\ln|u(x)|$ 的绝对值不能随便丢。**

> ⚠️ **幂指函数求导别直接把指数搬下来。** 那是普通幂函数，不是 $u(x)^{v(x)}$。

> ⚠️ **遇到根式积分别硬展开。** 优先查它是不是三角代换标准型。
