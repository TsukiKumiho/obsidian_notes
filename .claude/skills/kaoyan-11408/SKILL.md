## 高数公式参考速查（来自知识库）

处理高数相关问题时的内部速查：

### 极限
- 两个重要极限：$\lim_{x\to 0} \frac{\sin x}{x} = 1$，$\lim_{x\to\infty}(1+\frac{1}{x})^x = e$
- $1^\infty$ 型通用公式：$\lim [f(x)]^{g(x)} = e^{\lim [f(x)-1]g(x)}$
- 等价无穷小（$x\to 0$）：$x \sim \sin x \sim \tan x \sim \arcsin x \sim \arctan x$
- 增长速率：$\ln x \ll x^\alpha \ll a^x \ll x! \ll x^x$

### 中值定理
- 罗尔定理 → 拉格朗日 → 柯西 → 泰勒，一脉相承
- $f(a)=f(b)$ 优先罗尔，否则构造辅助函数用拉格朗日

### 积分
- 凑微分优先级：反→对→幂→指→三
- 定积分换元三要素：换元必换限、不用回代、注意单调性
- 变限积分求导：$\frac{d}{dx}\int_{a(x)}^{b(x)}f(t)dt = f(b(x))b'(x) - f(a(x))a'(x)$

## 避坑警示

> ⚠️ 可导必连续，连续不一定可导（反例：$|x|$ 在 $x=0$）
> ⚠️ 偏导数存在不一定可微
> ⚠️ 矩阵乘法不满足交换律，$(AB)^{-1}=B^{-1}A^{-1}$ 注意顺序
> ⚠️ 二次型矩阵必须用实对称矩阵，$x_i x_j$ 系数对半分
> ⚠️ $1^\infty$ 型极限不能直接用 $e$ 代入，必须用 $e^{\lim [f(x)-1]g(x)}$
> ⚠️ 定积分换元必须同步更换积分限
> ⚠️ 格林公式的 $L$ 需取正向（逆时针）

### 出题原则

#### 选题方向（真题导向）

每日一题的选题**必须以考研数学一真题为参照系**，遵循以下优先原则：

| 优先级 | 题目类型 | 示例 |
| :---: | :--- | :--- |
| **P0** | 大纲内标准方法 + 高计算量 | 有理函数部分分式求不定积分 / 闭区域二元最值全程讨论 / 分段函数定积分 |
| **P1** | 大纲内标准方法 + 多知识融合 | 先换元再分部再对称性 / 中值定理 + 积分不等式联立 / 极坐标变换 + 分段积分 |
| **P2** | 中值定理证明题（辅助函数构造） | 含 $f'(\xi)$ 与端点值 / 含定积分的等式证明 / 二阶导不等式 |
| **P3** | 概念辨析与反例构造 | 可导与连续关系 / 偏导存在与可微关系 / 极值判别条件失效 |

#### 选题红线（禁止出现的内容）

以下类型**不得**作为每日一题的选题，因其超出考研数学一大纲范围或偏离真题风格：

| 禁止类型 | 原因 | 反例 |
| :--- | :--- | :--- |
| 数学竞赛技巧 | 考研不考 | Vieta 递推三角闭式、Stolz 定理求和极限 |
| 数学分析深度结论 | 超纲 | Thomae 函数可积性、$C^\infty$ 非实解析（扁平函数） |
| 高等工具依赖 | 超纲 | Stirling 公式、Wallis 乘积极限、Feynman 参变求导 |
| Gamma/Beta 函数 | 超纲 | $\int_0^1 x^m(\ln x)^n dx$ 型参数积分 |
| 单靠奇巧而无计算量的题 | 脱离真题风格 | 一眼看出答案的"神来之笔"型 |

#### 难度定义（真题参照）

| 等级 | 对应真题难度 | 特征 |
| :--- | :--- | :--- |
| **困难** | 真题解答题第 18-19 题 | 需要 3-5 步推理，涉及 2 个以上知识点交叉 |
| **地狱难度** | 真题压轴题（第 20 题）或略高于真题 | 需要构造辅助函数、多个中值定理联用、或闭区域最值全流程 |

#### 通性原则

- 题目必须为**原创或改编**，不得照搬完整考研真题
- 各题之间考点不重复，覆盖不同章节
- 连续多天的题目难度整体呈**递进趋势**，但需在真题框架内递进
- 解析力求**简洁但有巧思**，强调"柳暗花明"的解题切入角度
- **思路溯源原则**：对于解法中「很难想到」的关键步骤（如辅助函数构造的灵感来源、换元思路的形成过程等），必须在解析中新增 **「思路溯源」** 段落（置于正式解法之前），用**分步推导**的方式说明：
  1. 从题目条件中**观察到了什么模式**让人联想到该技巧
  2. 该技巧背后**依赖的已知公式/恒等式/定理**是什么
  3. 为什么这个技巧对此类题型有**通用性**——将它提炼为可迁移的「思维定势」
