## 高数公式参考速查（来自知识库）

处理高数相关问题时的内部速查：

### 极限
- 两个重要极限：$\lim_{x\to 0} \frac{\sin x}{x} = 1$，$\lim_{x\to\infty}(1+\frac{1}{x})^x = e$
- $1^\infty$ 型通用公式：$\lim [f(x)]^{g(x)} = e^{\lim [f(x)-1]g(x)}$
- 等价无穷小（$x\to 0$）：$x \sim \sin x \sim \tan x \sim \arcsin x \sim \arctan x$
- 增长速率：$\ln x \ll x^\alpha \ll a^x \ll x! \ll x^x$

### 中值定理
- 罗尔定理 → 拉格朗日 → 柯西 → 泰勒，一脉相承
- $f(a)=f(b)$ 优先罗尔，否则构造辅助函数用拉格朗日

### 积分
- 凑微分优先级：反→对→幂→指→三
- 定积分换元三要素：换元必换限、不用回代、注意单调性
- 变限积分求导：$\frac{d}{dx}\int_{a(x)}^{b(x)}f(t)dt = f(b(x))b'(x) - f(a(x))a'(x)$

## 联网搜索规范

### 两层搜索策略

由于知乎、B站等考研核心社区普遍设有反爬机制，WebFetch 抓取正文**经常失败**。因此采用两层策略：

| 层级 | 条件 | 行为 |
| :--- | :--- | :--- |
| **A 层（理想）** | WebFetch 成功抓取正文 | 从正文提取技巧口诀、方法分类、例题 → 整合进文档 |
| **B 层（兜底）** | WebFetch 失败，仅 WebSearch 拿到标题+摘要 | 从标题/摘要确认选题方向与热门技巧 → 用模型自身知识库完成内容编写 |

> **关键原则**：B 层不是"失败"，而是"选题确认 + 自有知识编写"。标题足以告诉你社区在讨论哪些技巧（如"表格法""双元法""Euler代换"），具体内容由模型补充。

### 执行流程

```
创建专题 / 查询技巧
    │
    ├─ ① WebSearch：搜索知乎/B站/CSDN/博客园/贴吧 相关文章
    │     → 获取标题、URL、简短摘要
    │
    ├─ ② WebFetch：尝试抓取前 3-5 篇高赞文章正文
    │     ├─ 成功 → A 层处理：提取具体技巧与口诀
    │     └─ 失败 → B 层处理：标题确认方向 + 自有知识编写
    │
    ├─ ③ 链接验证：对搜索到的 URL 逐条用 WebFetch 验证
    │     → 能正常返回（即使是拦截页也算存在）→ 保留链接
    │     → 404/域名不存在 → 剔除
    │
    └─ ④ 输出时：在文档末尾或搜索说明中列出验证通过的来源链接
```

## 避坑警示

> ⚠️ 可导必连续，连续不一定可导（反例：$|x|$ 在 $x=0$）
> ⚠️ 偏导数存在不一定可微
> ⚠️ 矩阵乘法不满足交换律，$(AB)^{-1}=B^{-1}A^{-1}$ 注意顺序
> ⚠️ 二次型矩阵必须用实对称矩阵，$x_i x_j$ 系数对半分
> ⚠️ $1^\infty$ 型极限不能直接用 $e$ 代入，必须用 $e^{\lim [f(x)-1]g(x)}$
> ⚠️ 定积分换元必须同步更换积分限
> ⚠️ 格林公式的 $L$ 需取正向（逆时针）
> ⚠️ 幂级数逐项求导/积分后收敛半径不变，但端点敛散性可能改变，需单独检验
> ⚠️ 傅里叶级数在间断点处收敛于左右极限的平均值 $\frac{f(x^+)+f(x^-)}{2}$
> ⚠️ 正项级数比较判别法：大的收敛 ⇒ 小的收敛；小的发散 ⇒ 大的发散（方向勿搞反）
> ⚠️ 条件收敛的级数不可随意交换项的次序（Riemann 重排定理）

#### 通性原则

- 题目必须为**原创或改编**，不得照搬完整考研真题
- **避免与历史题目重复**：出题前必须扫描 `每日一题/` 目录下所有已有文件，确保今日题目在考点、函数形式、反例表达式上不与历史题目雷同（详见执行流程第 2 步）
- 各题之间考点不重复，覆盖不同章节
- 连续多天的题目难度整体呈**递进趋势**，但需在真题框架内递进
- 解析力求**简洁但有巧思**，强调"柳暗花明"的解题切入角度
- **思路溯源原则**：对于解法中「很难想到」的关键步骤（如辅助函数构造的灵感来源、换元思路的形成过程等），必须在解析中新增 **「思路溯源」** 段落（置于正式解法之前），用**分步推导**的方式说明：
  1. 从题目条件中**观察到了什么模式**让人联想到该技巧
  2. 该技巧背后**依赖的已知公式/恒等式/定理**是什么
  3. 为什么这个技巧对此类题型有**通用性**——将它提炼为可迁移的「思维定势」
- **答题规范原则**（强制）：**「解法」部分的书写必须符合考研数学一大题的答题标准**，具体要求如下：
  - ❌ **禁止出现内部思考语言**：不得出现「等等，重新检查」「我们再验证一下」「反思」「嗯」「让我们试试」或任何自言自语、中途纠正、试探性表述
  - ❌ **禁止出现元评论**：不得评价题目本身（如「此题是一个陷阱」「出题人想考察……」），不得出现教学口吻的旁白（如「聪明的同学会发现……」）
  - ❌ **禁止出现非确定语气**：不得使用「可能」「也许是」「大概」等模糊词汇描述已完成的推理步骤
  - ✅ **解法行文应一气呵成**：从已知条件出发，每一步推导有明确的数学依据（定理名/公式名/等价变形），步骤间用「由……得」「代入……」「即」「故」等规范连接词
  - ✅ **方程组/方程严格编号**：多方程时使用 (1)(2)(3) 编号，引用时说明由哪几个式子联立消元
  - ✅ **结论明确**：每道题的答案以带框结论 $\boxed{}$ 收尾，证明题以「证毕」收尾
  - ⚠️ **「思路溯源」与「解法」的职责分离**：
    - **思路溯源**：可包含直觉分析、试探性推导、技巧的通用性说明、背后的恒等式/公式来源——这是"如何想到"的部分
    - **解法**：必须是干净、线性、严密的正式解答——这是"写到答题卡上"的部分
    - **两者不可混淆**：解法中不得出现思路溯源的语气（如"我们观察到……这让人联想到……"），思路溯源中也不得出现完整的分步计算（应在解法中呈现）

## 每日一读模块

### 设计哲学：考研实战导向

每日一读的目标不是「精读每一篇文章」，而是**从每篇文章中筛选出真正能用于考研拿分的内容**。核心原则：

> **不是单词题，而是长难句题；不是背整本词典，而是背作文骨架句。**

考研英语阅读的本质是长难句拆解能力 + 学术议论文论证逻辑识别。因此每日一读的分析部分必须围绕以下 5 个拿分维度组织：
1. **阅读理解高频词**（按语义分类，标注重要度星级）
2. **翻译核心结构**（标注踩分点）
3. **作文万能句式**（可直接填充套用）
4. **长难句分析**（经典结构识别 + 骨架提取）
5. **学术议论文表达**（开头/论证/结尾模板）

### 触发条件
当用户说出 **`每日一读`** 时触发。

### 执行流程
1. **检查当日是否已有文件**：先列出 `每日一读/` 目录下的文件，若已存在 `YYYY-MM-DD.md`（当天日期），则告知用户今日阅读已生成，不再重复创建。
2. **若不存在，创建 `每日一读/` 文件夹**（如尚未创建）。
3. **生成阅读文件** `每日一读/YYYY-MM-DD.md`。

### 文件内容结构

参照模板文件 `/每日一读/2026-05-06.md` 的格式：

| 板块 | 内容要求 |
| :--- | :--- |
| **一、英文原文** | 约 300-350 词的英语文章（**上限 350 词**），题材为科技/哲学/社会/文化，难度对标考研英语一阅读 Text 3/4。确保语言地道、逻辑清晰，论证路径完整（现象→机制→例子→影响→结论）。 |
| **二、中文翻译** | 逐段对应的准确中文翻译，翻译风格参考考研英语一翻译题标准。 |
| **三、考研英语高频核心词（分类速记）** | **按语义类别分组**（观点/理论、产生/导致、复杂程度、重要程度、理解/分析、否定/限定、特殊短语），每组 3-6 个词。每个词包含：含义、**重要度星级**（★☆☆ ~ ★★★★★）、**真题语境**（从本文原句中摘取）。**不再**包含词根词缀拆解、联想记忆、派生词列表——这些不是拿分重点。每篇文章控制在 25-35 个核心词。 |
| **四、考研作文万能短语** | 10 个左右可直接套用的短语。每个包含：适用场景（原因分析/影响阐述/观点论证/让步转折）、可直接背诵的完整例句、**替代哪些低级表达**（如 `give rise to` 替代 `cause`）。这是作文提分的核心板块。 |
| **五、考研阅读长难句精析** | 选取 3-4 个**有代表性的经典结构**（What 主语从句、同位语从句 vs 定语从句、one that... 定义句式、not a matter of A but of B 等），而非逐句拆解。每个结构包含：**识别关键** → **结构骨架** → **翻译** → **提分要点**。目标是培养举一反三的结构识别能力。 |
| **六、考研翻译重点句** | 3-4 句，每句给出标准翻译 + **踩分点**标注（哪些词/结构是翻译题的得分关键）。 |
| **七、考研作文可直接套用的模板** | 从本文原句中提取可填充的句式框架，分为开头段/论证段/结尾段。每段模板可用 `[填充位]` 标注。结尾段优先提供「二元对立升华」型模板（适用于科技 vs 传统 / 个人 vs 集体 / 经济 vs 环境等话题）。 |
| **八、本文最值得背的 10 个表达** | 按「背了就能用」的性价比排序的精华清单，一页可复习完。 |
| **九、提分关键提醒** | 2-4 条针对本文的具体行动建议（不是泛泛的「多背单词」）。 |

### 出题原则
- 文章必须为**原创或深度改编**，不得直接复制已有文章
- 优先从**联网搜索**获取素材灵感（The Economist, Scientific American, Nature, Aeon 等科技/社科/哲学类文章），但需改写为原创内容
- **拒绝「炫技式学术词汇」**：只收录考研阅读/翻译/作文中真正高频的词和短语。低频学术词（如 ontological、extrapolation）即使出现在原文中，也只在必要时简要提及，不在核心词汇表中占位
- **长难句选「经典结构」而非「所有长句」**：目标不是穷举文中的长句，而是挑选具有可迁移性的语法结构，帮助用户举一反三
- **翻译要点融入翻译重点句的踩分点中**，不再单独设板块
- **仿写练习不再单独设板块**，作文模板板块已提供可填充的句式框架，用户可直接练习套用

```
          → 每组包含：问题编号（自增）、提问日期、问题原文、回答摘要
          → ⚠️ **严禁使用 cp / mv / Write（覆写模式）操作已有的周文件**
```

### 追加规则（强制）

> ⚠️ **最高优先级原则：已有问答文件只能追加，严禁覆写。** 写入前必须先用 Read 工具完整读取已有文件内容，确认已有 Q&A 完整保留后，再以追加方式写入新 Q&A。**绝对禁止**使用 `cp`、`mv`、`Write`（覆写模式）或任何可能覆盖已有内容的操作。

1. **识别科目与当前周**：判断问题属于哪门课 → 计算当前日期所在周的周一和周日日期。
2. **确定周文件**：目标路径 `408问答/[科目]/[周一]_to_[周日].md`。**必须先用 Glob 检查该文件是否已存在。**
3. **科目文件夹不存在** → 创建；**周文件不存在** → 创建并写入标题头 + Q1。
4. **周文件已存在** → **必须先用 Read 完整读取文件内容** → 确定最新 Q 编号 → 将已有内容 + 新 Q&A 一起写入（或使用 Edit 追加到末尾）。**严禁不经读取直接写入。**
5. **编号自增**：读取文件中最新 Q 编号，+1。
6. **日期标注**：每条 Q&A 标注提问日期。
7. **不覆盖历史**：追加模式，不修改已有 Q&A 内容。

```
  6. **Glob 检查周文件是否已存在**
```
