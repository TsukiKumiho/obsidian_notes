## 项目说明

这个仓库主要用于整理考研相关笔记与练习内容，核心载体是 Obsidian。
AI 的作用是辅助生成、整理和补充内容，不能替代系统学习，也不应被视为结论唯一正确的来源。

---

## AI 辅助能力

目前主要用于以下几类学习场景：

| 触发词 | 用途 | 说明 |
| :--- | :--- | :--- |
| `每日一题` | 生成数学练习 | 按当天生成题目与解析 |
| `每日一读` | 生成英语阅读 | 提供文章、翻译与重点表达 |
| `XX公式` / `XX定义` | 检索知识点 | 从现有笔记中查找并整理 |
| `XX技巧` / `怎么算` | 整理解题方法 | 用于归纳技巧与对比思路 |
| `这道题不会` | 错题分析 | 拆解卡点并给出参考解法 |
| `制定计划` | 学习安排参考 | 输出阶段性复习建议 |

## 使用方式

1. 用 Obsidian 打开本目录作为知识库。
2. 直接维护各类 Markdown 笔记。
3. 如需 AI 辅助，再通过 Claude Code 或 OpenCode 调用对应技能。
