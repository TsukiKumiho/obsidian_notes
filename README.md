## AI 助手功能

本项目集成了一个专业的 **考研督学与资料整理 AI 助手**，支持以下触发指令：

| 触发词 | 功能 | 说明 |
| :--- | :--- | :--- |
| `每日一题` | 生成当日数学题集 | 20题/天（极限×5 + 微分×5 + 积分×5 + 多元×3 + 概念×2），困难/地狱难度，附完整解析 |
| `每日一读` | 生成当日英语阅读 | 英文原文 + 中文翻译 + 词汇解析 + 长难句拆解 + 仿写练习 |
| `XX公式` / `XX定义` | 检索知识库 | 自动查找 `高数基本公式.md` / `线性代数基本公式.md` 并解释 |
| `XX技巧` / `怎么算` | 解题技巧索引 | 联网搜索 + 本地知识库，整理技巧对比表 |
| `这道题不会` | 错题/难题分析 | 拆解卡点 → 关联同类题 → 生成变体题 |
| `制定计划` / `剩下X天` | 复习进度规划 | 输出四科日程表 + 阶段里程碑 |
| `/s 问题` | 强制联网搜索 | 优先联网搜索后再整理输出 |

### 每日一题 格式示例

每道题包含：
- 题目描述（LaTeX 数学公式）
- 难度标注（困难 / 地狱难度）
- **一题多解**（如适用，标注「奇思妙想」「柳暗花明」等解法名）
- 完整解析步骤 + 最终答案
- 当日要点总结表（技巧速记口诀）

### 每日一读 格式示例

每篇文章包含：
- 英文原文（300-400词，题材：科技/哲学/社会）
- 逐段中文翻译（考研英语一标准）
- 核心词汇表（含词性、释义、记忆提示）
- 长难句解析（句子骨架 → 树形拆解 → 翻译技巧）
- 仿写练习（句式模板 + 示例句）

## 使用场景

1. **日常刷题**：每天打开 Obsidian，输入 `每日一题` 触发 AI 生成当日 20 道数学题
2. **英语提升**：输入 `每日一读` 获取当日英语阅读材料，积累词汇与长难句分析能力
3. **公式速查**：输入 `罗尔定理` 或 `矩阵求逆公式` 自动检索知识库
4. **错题分析**：拍下错题照片，输入 `这道题不会` 获取分步解析和变体题
5. **进度管理**：输入 `剩余100天怎么安排` 获取四科日程表
