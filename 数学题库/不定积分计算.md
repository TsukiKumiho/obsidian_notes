## 一、基本积分公式与简单变形（第 1-20 题）

### 题目

1. $\displaystyle \int (3x^4 - 2x^3 + 5x - 1)\,dx$

2. $\displaystyle \int \left( \sqrt[3]{x} + \frac{2}{\sqrt{x}} \right) dx$

3. $\displaystyle \int \frac{x^2 + 2x + 1}{x^2}\,dx$

4. $\displaystyle \int \frac{(x-1)^3}{x^2}\,dx$

5. $\displaystyle \int 2^x \cdot 3^{2x}\,dx$

6. $\displaystyle \int \frac{2 \cdot 3^x - 5 \cdot 2^x}{3^x}\,dx$

7. $\displaystyle \int \tan^2 x\,dx$

8. $\displaystyle \int \frac{\cos 2x}{\cos x - \sin x}\,dx$

9. $\displaystyle \int \frac{1}{1+\cos 2x}\,dx$

10. $\displaystyle \int \frac{\cos 2x}{\sin^2 x \cos^2 x}\,dx$

11. $\displaystyle \int \sin^2 \frac{x}{2}\,dx$

12. $\displaystyle \int \frac{e^{3x}+1}{e^x+1}\,dx$

13. $\displaystyle \int \frac{x^4}{1+x^2}\,dx$

14. $\displaystyle \int \frac{dx}{\sqrt{4-x^2}}$

15. $\displaystyle \int \frac{dx}{9+x^2}$

16. $\displaystyle \int \frac{dx}{x\sqrt{x^2-1}}$

17. $\displaystyle \int \frac{dx}{x^2-4}$

18. $\displaystyle \int \sqrt{x\sqrt{x\sqrt{x}}}\,dx$

19. $\displaystyle \int (\sin x + \cos x)^2\,dx$

20. $\displaystyle \int \frac{\sin^3 x + \cos^3 x}{\sin x + \cos x}\,dx$

### 答案与解析

1. $\displaystyle \frac{3}{5}x^5 - \frac{1}{2}x^4 + \frac{5}{2}x^2 - x + C$

2. $\displaystyle \frac{3}{4}x^{4/3} + 4x^{1/2} + C$

3. $\displaystyle \int \left(1 + \frac{2}{x} + \frac{1}{x^2}\right)dx = x + 2\ln|x| - \frac{1}{x} + C$

4. $\displaystyle \int \left(x - 3 + \frac{3}{x} - \frac{1}{x^2}\right)dx = \frac{x^2}{2} - 3x + 3\ln|x| + \frac{1}{x} + C$

5. $\displaystyle \int 2^x \cdot 9^x\,dx = \int 18^x\,dx = \frac{18^x}{\ln 18} + C$

6. $\displaystyle \int \left(2 - 5 \cdot \left(\frac{2}{3}\right)^x\right)dx = 2x - 5 \cdot \frac{(2/3)^x}{\ln(2/3)} + C$

7. $\displaystyle \int (\sec^2 x - 1)dx = \tan x - x + C$

8. $\displaystyle \frac{\cos 2x}{\cos x - \sin x} = \frac{\cos^2 x - \sin^2 x}{\cos x - \sin x} = \cos x + \sin x$，故积分为 $\sin x - \cos x + C$

9. $\displaystyle 1+\cos 2x = 2\cos^2 x$，故 $\int \frac{1}{2}\sec^2 x\,dx = \frac{1}{2}\tan x + C$

10. $\displaystyle \cos 2x = \cos^2 x - \sin^2 x$，故 $\int \left(\csc^2 x - \sec^2 x\right)dx = -\cot x - \tan x + C$

11. $\displaystyle \int \frac{1-\cos x}{2}\,dx = \frac{1}{2}(x - \sin x) + C$

12. $\displaystyle e^{3x}+1 = (e^x+1)(e^{2x}-e^x+1)$，故 $\int (e^{2x} - e^x + 1)dx = \frac{1}{2}e^{2x} - e^x + x + C$

13. $\displaystyle \frac{x^4}{1+x^2} = x^2 - 1 + \frac{1}{1+x^2}$，故 $\frac{x^3}{3} - x + \arctan x + C$

14. $\displaystyle \int \frac{dx}{\sqrt{4-x^2}} = \arcsin\frac{x}{2} + C$

15. $\displaystyle \frac{1}{3}\arctan\frac{x}{3} + C$

16. 令 $x = \sec t$，$\displaystyle \int \frac{\sec t \tan t}{\sec t \tan t}dt = t + C = \arccos\frac{1}{x} + C$；或直接 $\displaystyle \arcsec|x| + C$

17. $\displaystyle \frac{1}{4}\ln\left|\frac{x-2}{x+2}\right| + C$

18. $x\sqrt{x\sqrt{x\sqrt{x}}} = x \cdot x^{1/2} \cdot x^{1/4} \cdot x^{1/8} = x^{15/8}$，故 $\frac{8}{23}x^{23/8} + C$

19. $(\sin x + \cos x)^2 = 1 + \sin 2x$，故 $x - \frac{1}{2}\cos 2x + C$

20. $\sin^3 x + \cos^3 x = (\sin x + \cos x)(\sin^2 x - \sin x \cos x + \cos^2 x) = (\sin x + \cos x)(1 - \sin x \cos x)$，故 $\int (1 - \sin x \cos x)dx = x + \frac{1}{2}\cos^2 x + C$（或 $x - \frac{1}{4}\cos 2x + C$）

## 二、凑微分法（第 21-40 题）

### 题目

21. $\displaystyle \int \frac{\ln x}{x}\,dx$

22. $\displaystyle \int \frac{dx}{x(1+2\ln x)}$

23. $\displaystyle \int \frac{dx}{x(4-\ln^2 x)}$

24. $\displaystyle \int \frac{e^x}{1+e^x}\,dx$

25. $\displaystyle \int \frac{dx}{e^x + e^{-x}}$

26. $\displaystyle \int \frac{e^{2x}}{1+e^x}\,dx$

27. $\displaystyle \int x^2 e^{x^3}\,dx$

28. $\displaystyle \int x\sqrt{1-x^2}\,dx$

29. $\displaystyle \int \frac{x}{\sqrt{1-4x^2}}\,dx$

30. $\displaystyle \int \frac{x^3}{\sqrt{1+x^2}}\,dx$

31. $\displaystyle \int \sin^3 x \cos x\,dx$

32. $\displaystyle \int \frac{\sin x}{1+\cos x}\,dx$

33. $\displaystyle \int \frac{\cos x}{1+\sin^2 x}\,dx$

34. $\displaystyle \int \frac{\sin x \cos x}{1+\sin^4 x}\,dx$

35. $\displaystyle \int \frac{\arcsin x}{\sqrt{1-x^2}}\,dx$

36. $\displaystyle \int \frac{\arctan x}{1+x^2}\,dx$

37. $\displaystyle \int \frac{dx}{x(1+x^4)}$

38. $\displaystyle \int \frac{x}{1+x^4}\,dx$

39. $\displaystyle \int \frac{dx}{\sqrt{x}(1+x)}$

40. $\displaystyle \int \frac{e^x(1+e^x)}{\sqrt{1-e^{2x}}}\,dx$

### 答案与解析

21. $\displaystyle \int \ln x\,d(\ln x) = \frac{1}{2}\ln^2 x + C$

22. $\displaystyle \frac{1}{2}\int \frac{d(1+2\ln x)}{1+2\ln x} = \frac{1}{2}\ln|1+2\ln x| + C$

23. $\displaystyle \int \frac{d(\ln x)}{4-\ln^2 x} = \frac{1}{4}\ln\left|\frac{2+\ln x}{2-\ln x}\right| + C$

24. $\displaystyle \int \frac{d(e^x+1)}{e^x+1} = \ln(1+e^x) + C$

25. $\displaystyle \int \frac{e^x}{1+e^{2x}}\,dx = \int \frac{d(e^x)}{1+(e^x)^2} = \arctan(e^x) + C$

26. $\displaystyle \int \frac{e^x \cdot e^x}{1+e^x}\,dx$，令 $u=e^x$，则 $\int \frac{u}{1+u}\,du = \int \left(1 - \frac{1}{1+u}\right)du = u - \ln|1+u| + C = e^x - \ln(1+e^x) + C$

27. $\displaystyle \frac{1}{3}\int e^{x^3}d(x^3) = \frac{1}{3}e^{x^3} + C$

28. $\displaystyle -\frac{1}{2}\int \sqrt{1-x^2}\,d(1-x^2) = -\frac{1}{3}(1-x^2)^{3/2} + C$

29. $\displaystyle -\frac{1}{8}\int \frac{d(1-4x^2)}{\sqrt{1-4x^2}} = -\frac{1}{4}\sqrt{1-4x^2} + C$

30. 令 $u = 1+x^2$，$x^2 = u-1$，$x\,dx = \frac{1}{2}du$<br>$\displaystyle \frac{1}{2}\int \frac{u-1}{\sqrt{u}}\,du = \frac{1}{2}\int (u^{1/2} - u^{-1/2})du = \frac{1}{3}u^{3/2} - u^{1/2} + C = \frac{1}{3}(1+x^2)^{3/2} - \sqrt{1+x^2} + C$

31. $\displaystyle \int \sin^3 x\,d(\sin x) = \frac{1}{4}\sin^4 x + C$

32. $\displaystyle -\int \frac{d(\cos x+1)}{\cos x+1} = -\ln|1+\cos x| + C$

33. $\displaystyle \int \frac{d(\sin x)}{1+\sin^2 x} = \arctan(\sin x) + C$

34. $\displaystyle \frac{1}{2}\int \frac{d(\sin^2 x)}{1+(\sin^2 x)^2} = \frac{1}{2}\arctan(\sin^2 x) + C$

35. $\displaystyle \int \arcsin x\,d(\arcsin x) = \frac{1}{2}(\arcsin x)^2 + C$

36. $\displaystyle \int \arctan x\,d(\arctan x) = \frac{1}{2}(\arctan x)^2 + C$

37. $\displaystyle \int \frac{x^3}{x^4(1+x^4)}\,dx = \frac{1}{4}\int \frac{d(x^4)}{x^4(1+x^4)} = \frac{1}{4}\int \left(\frac{1}{x^4} - \frac{1}{1+x^4}\right)d(x^4)$<br>$= \frac{1}{4}\ln\frac{x^4}{1+x^4} + C$

38. $\displaystyle \frac{1}{2}\int \frac{d(x^2)}{1+(x^2)^2} = \frac{1}{2}\arctan(x^2) + C$

39. 令 $t = \sqrt{x}$，$x = t^2$，$dx = 2t\,dt$<br>$\displaystyle \int \frac{2t\,dt}{t(1+t^2)} = 2\int \frac{dt}{1+t^2} = 2\arctan t + C = 2\arctan\sqrt{x} + C$

40. 令 $u = e^x$，$\displaystyle \int \frac{u(1+u)}{\sqrt{1-u^2}}\cdot\frac{du}{u} = \int \frac{1+u}{\sqrt{1-u^2}}\,du = \arcsin u - \sqrt{1-u^2} + C$<br>$= \arcsin(e^x) - \sqrt{1-e^{2x}} + C$

## 三、分部积分法（第 41-60 题）

### 题目

41. $\displaystyle \int x e^{2x}\,dx$

42. $\displaystyle \int x^2 \cos x\,dx$

43. $\displaystyle \int x \ln x\,dx$

44. $\displaystyle \int \ln x\,dx$

45. $\displaystyle \int x^2 \ln x\,dx$

46. $\displaystyle \int \frac{\ln x}{x^2}\,dx$

47. $\displaystyle \int \arctan x\,dx$

48. $\displaystyle \int \arcsin x\,dx$

49. $\displaystyle \int x \arctan x\,dx$

50. $\displaystyle \int x \sin x \cos x\,dx$

51. $\displaystyle \int e^x \sin x\,dx$

52. $\displaystyle \int e^x \cos 2x\,dx$

53. $\displaystyle \int x^2 e^x\,dx$

54. $\displaystyle \int (\ln x)^2\,dx$

55. $\displaystyle \int \frac{x e^x}{(1+x)^2}\,dx$

56. $\displaystyle \int x \sin^2 x\,dx$

57. $\displaystyle \int \frac{x^2 \arctan x}{1+x^2}\,dx$

58. $\displaystyle \int \cos(\ln x)\,dx$

59. $\displaystyle \int \frac{\ln(\sin x)}{\sin^2 x}\,dx$

60. $\displaystyle \int x \tan^2 x\,dx$

### 答案与解析

41. $\displaystyle \frac{1}{2}x e^{2x} - \frac{1}{4}e^{2x} + C$

42. $\displaystyle x^2\sin x + 2x\cos x - 2\sin x + C$

43. $\displaystyle \frac{1}{2}x^2\ln x - \frac{1}{4}x^2 + C$

44. $\displaystyle x\ln x - x + C$

45. $\displaystyle \frac{1}{3}x^3\ln x - \frac{1}{9}x^3 + C$

46. 令 $u = \ln x$，$dv = x^{-2}dx$，$\displaystyle -\frac{\ln x}{x} - \int \left(-\frac{1}{x^2}\right)dx = -\frac{\ln x + 1}{x} + C$

47. $\displaystyle x\arctan x - \frac{1}{2}\ln(1+x^2) + C$

48. $\displaystyle x\arcsin x + \sqrt{1-x^2} + C$

49. $\displaystyle \frac{x^2+1}{2}\arctan x - \frac{x}{2} + C$

50. $\displaystyle \int \frac{1}{2}x\sin 2x\,dx = -\frac{x}{4}\cos 2x + \frac{1}{8}\sin 2x + C$

51. $\displaystyle \frac{e^x}{2}(\sin x - \cos x) + C$（两次分部积分后还原）

52. $\displaystyle \frac{e^x}{5}(\cos 2x + 2\sin 2x) + C$

53. $\displaystyle e^x(x^2 - 2x + 2) + C$（两次分部）

54. 令 $u = (\ln x)^2$，$dv = dx$，$\displaystyle x(\ln x)^2 - 2x\ln x + 2x + C$

55. 令 $u = x e^x$，$dv = \frac{dx}{(1+x)^2}$<br>$\displaystyle -\frac{x e^x}{1+x} + \int e^x\,dx = -\frac{x e^x}{1+x} + e^x + C = \frac{e^x}{1+x} + C$

56. $\displaystyle \int x \cdot \frac{1-\cos 2x}{2}\,dx = \frac{x^2}{4} - \frac{x}{4}\sin 2x - \frac{1}{8}\cos 2x + C$

57. $\displaystyle \int \arctan x\left(1 - \frac{1}{1+x^2}\right)dx = x\arctan x - \frac{1}{2}\ln(1+x^2) - \frac{1}{2}(\arctan x)^2 + C$

58. 令 $t = \ln x$，$x = e^t$，$\int e^t\cos t\,dt = \frac{e^t}{2}(\cos t + \sin t) + C = \frac{x}{2}[\cos(\ln x) + \sin(\ln x)] + C$

59. 令 $u = \ln(\sin x)$，$dv = \csc^2 x\,dx$，$du = \cot x\,dx$，$v = -\cot x$<br>$\displaystyle -\cot x \ln(\sin x) + \int \cot^2 x\,dx = -\cot x \ln(\sin x) + \int (\csc^2 x - 1)dx$<br>$= -\cot x \ln(\sin x) - \cot x - x + C$

60. $\int x(\sec^2 x - 1)dx = \int x\,d(\tan x) - \frac{x^2}{2} = x\tan x + \ln|\cos x| - \frac{x^2}{2} + C$

## 四、有理函数积分（第 61-75 题）

### 题目

61. $\displaystyle \int \frac{dx}{x^2 - 5x + 6}$

62. $\displaystyle \int \frac{x}{x^2 - 5x + 6}\,dx$

63. $\displaystyle \int \frac{2x+3}{(x-1)(x+2)}\,dx$

64. $\displaystyle \int \frac{dx}{x^3 - 1}$

65. $\displaystyle \int \frac{x^2 + 1}{x(x-1)^2}\,dx$

66. $\displaystyle \int \frac{dx}{x(x^2+1)}$

67. $\displaystyle \int \frac{x^2}{x^2-3x+2}\,dx$

68. $\displaystyle \int \frac{dx}{x^4 - 1}$

69. $\displaystyle \int \frac{x^3}{x^2+1}\,dx$

70. $\displaystyle \int \frac{dx}{x^3 + x}$

71. $\displaystyle \int \frac{x+1}{x^2+4x+5}\,dx$

72. $\displaystyle \int \frac{dx}{(x^2+1)(x^2+4)}$

73. $\displaystyle \int \frac{x^2+x+1}{(x+1)^2(x+2)}\,dx$

74. $\displaystyle \int \frac{dx}{x^3 + 8}$

75. $\displaystyle \int \frac{x^4}{x^4-1}\,dx$

### 答案与解析

61. $\displaystyle \frac{1}{x-3} - \frac{1}{x-2}$，故 $\ln\left|\frac{x-3}{x-2}\right| + C$

62. $\displaystyle \frac{x}{(x-2)(x-3)} = \frac{-2}{x-2} + \frac{3}{x-3}$，故 $-2\ln|x-2| + 3\ln|x-3| + C$

63. $\displaystyle \frac{2x+3}{(x-1)(x+2)} = \frac{5/3}{x-1} + \frac{1/3}{x+2}$，故 $\frac{5}{3}\ln|x-1| + \frac{1}{3}\ln|x+2| + C$

64. $\displaystyle \frac{1}{x^3-1} = \frac{1}{(x-1)(x^2+x+1)} = \frac{1/3}{x-1} - \frac{x+2}{3(x^2+x+1)}$<br>$= \frac{1}{3}\ln|x-1| - \frac{1}{6}\ln(x^2+x+1) - \frac{1}{\sqrt{3}}\arctan\frac{2x+1}{\sqrt{3}} + C$

65. $\displaystyle \frac{x^2+1}{x(x-1)^2} = \frac{1}{x} + \frac{2}{(x-1)^2}$，故 $\ln|x| - \frac{2}{x-1} + C$

66. $\displaystyle \frac{1}{x(x^2+1)} = \frac{1}{x} - \frac{x}{x^2+1}$，故 $\ln|x| - \frac{1}{2}\ln(x^2+1) + C$

67. $\displaystyle 1 + \frac{3x-2}{(x-1)(x-2)} = 1 + \frac{-1}{x-1} + \frac{4}{x-2}$，故 $x - \ln|x-1| + 4\ln|x-2| + C$

68. $\displaystyle \frac{1}{x^4-1} = \frac{1/2}{x^2-1} - \frac{1/2}{x^2+1} = \frac{1/4}{x-1} - \frac{1/4}{x+1} - \frac{1/2}{x^2+1}$<br>故 $\frac{1}{4}\ln\left|\frac{x-1}{x+1}\right| - \frac{1}{2}\arctan x + C$

69. $\displaystyle \frac{x^3}{x^2+1} = x - \frac{x}{x^2+1}$，故 $\frac{x^2}{2} - \frac{1}{2}\ln(x^2+1) + C$

70. $\displaystyle \frac{1}{x(x^2+1)} = \frac{1}{x} - \frac{x}{x^2+1}$，故 $\ln|x| - \frac{1}{2}\ln(x^2+1) + C$<br>（同第66题，但分母 $x^3+x=x(x^2+1)$）

71. $\displaystyle \int \frac{x+1}{(x+2)^2+1}\,dx$，令 $u = x+2$，$x+1 = u-1$<br>$\displaystyle \int \frac{u-1}{u^2+1}\,du = \frac{1}{2}\ln(u^2+1) - \arctan u + C$<br>$= \frac{1}{2}\ln(x^2+4x+5) - \arctan(x+2) + C$

72. $\displaystyle \frac{1}{(x^2+1)(x^2+4)} = \frac{1/3}{x^2+1} - \frac{1/3}{x^2+4}$<br>故 $\frac{1}{3}\arctan x - \frac{1}{6}\arctan\frac{x}{2} + C$

73. $\displaystyle \frac{x^2+x+1}{(x+1)^2(x+2)} = \frac{-1}{x+1} + \frac{1}{(x+1)^2} + \frac{2}{x+2}$<br>故 $-\ln|x+1| - \frac{1}{x+1} + 2\ln|x+2| + C$

74. $\displaystyle \frac{1}{x^3+8} = \frac{1}{(x+2)(x^2-2x+4)} = \frac{1/12}{x+2} - \frac{x-4}{12(x^2-2x+4)}$<br>$= \frac{1}{12}\ln|x+2| - \frac{1}{24}\ln(x^2-2x+4) + \frac{1}{4\sqrt{3}}\arctan\frac{x-1}{\sqrt{3}} + C$

75. $\displaystyle \frac{x^4}{x^4-1} = 1 + \frac{1}{x^4-1}$，第二部分同第68题<br>故 $x + \frac{1}{4}\ln\left|\frac{x-1}{x+1}\right| - \frac{1}{2}\arctan x + C$

## 五、三角有理式积分（第 76-90 题）

### 题目

76. $\displaystyle \int \sin^3 x\,dx$

77. $\displaystyle \int \cos^4 x\,dx$

78. $\displaystyle \int \tan^3 x\,dx$

79. $\displaystyle \int \sec^4 x\,dx$

80. $\displaystyle \int \frac{dx}{1+\sin x}$

81. $\displaystyle \int \frac{dx}{2+\cos x}$

82. $\displaystyle \int \frac{\sin x}{1+\sin x}\,dx$

83. $\displaystyle \int \frac{dx}{\sin x \cos x}$

84. $\displaystyle \int \frac{dx}{\sin x + \cos x}$

85. $\displaystyle \int \sin^2 x \cos^3 x\,dx$

86. $\displaystyle \int \frac{dx}{3+\sin^2 x}$

87. $\displaystyle \int \frac{\sin x \cos x}{\sin x + \cos x}\,dx$

88. $\displaystyle \int \frac{\sin^2 x}{1+\cos^2 x}\,dx$

89. $\displaystyle \int \sec^3 x\,dx$

90. $\displaystyle \int \frac{dx}{\sin^3 x}$

### 答案与解析

76. $\displaystyle \int (1-\cos^2 x)\sin x\,dx = -\cos x + \frac{1}{3}\cos^3 x + C$

77. $\displaystyle \cos^4 x = \left(\frac{1+\cos 2x}{2}\right)^2 = \frac{1}{4} + \frac{\cos 2x}{2} + \frac{1+\cos 4x}{8}$<br>$= \frac{3}{8}x + \frac{1}{4}\sin 2x + \frac{1}{32}\sin 4x + C$

78. $\displaystyle \int \tan x(\sec^2 x - 1)dx = \int \tan x\,d(\tan x) - \int \tan x\,dx$<br>$= \frac{1}{2}\tan^2 x + \ln|\cos x| + C$

79. $\displaystyle \int (1+\tan^2 x)\sec^2 x\,dx = \int (1+\tan^2 x)d(\tan x) = \tan x + \frac{1}{3}\tan^3 x + C$

80. $\displaystyle \int \frac{1-\sin x}{\cos^2 x}\,dx = \int (\sec^2 x - \tan x \sec x)dx = \tan x - \sec x + C$

81. 万能公式 $t = \tan\frac{x}{2}$，$\cos x = \frac{1-t^2}{1+t^2}$，$dx = \frac{2dt}{1+t^2}$<br>$\displaystyle \int \frac{2dt}{2(1+t^2)+(1-t^2)} = \int \frac{2dt}{3+t^2} = \frac{2}{\sqrt{3}}\arctan\frac{t}{\sqrt{3}} + C$<br>$= \frac{2}{\sqrt{3}}\arctan\left(\frac{\tan\frac{x}{2}}{\sqrt{3}}\right) + C$

82. $\displaystyle \int \left(1 - \frac{1}{1+\sin x}\right)dx = x - \tan x + \sec x + C$（利用第80题结果）

83. $\displaystyle \int \frac{2}{\sin 2x}\,dx = \int \csc 2x\,d(2x) = \ln|\csc 2x - \cot 2x| + C = \ln|\tan x| + C$

84. $\displaystyle \frac{1}{\sqrt{2}}\int \frac{dx}{\sin(x+\frac{\pi}{4})} = \frac{1}{\sqrt{2}}\ln\left|\tan\left(\frac{x}{2}+\frac{\pi}{8}\right)\right| + C$

85. $\displaystyle \int \sin^2 x(1-\sin^2 x)\cos x\,dx = \int (\sin^2 x - \sin^4 x)d(\sin x) = \frac{1}{3}\sin^3 x - \frac{1}{5}\sin^5 x + C$

86. $\displaystyle \int \frac{dx}{3+\sin^2 x} = \int \frac{dx}{3 + \frac{1-\cos 2x}{2}} = \int \frac{2dx}{7-\cos 2x}$<br>令 $t = \tan x$，用万能公式得 $\displaystyle \frac{1}{\sqrt{3}}\arctan\left(\frac{2\tan x}{\sqrt{3}}\right) + C$

87. 令 $u = \sin x + \cos x$，则 $(\sin x + \cos x)^2 = 1 + \sin 2x = u^2$，$\sin x \cos x = \frac{u^2-1}{2}$<br>$\displaystyle \frac{1}{2}\int \frac{u^2-1}{u}\cdot\frac{du}{\cos x - \sin x}$，注意到 $du = (\cos x - \sin x)dx$<br>$\displaystyle = \frac{1}{2}\int \left(u - \frac{1}{u}\right)du = \frac{1}{4}u^2 - \frac{1}{2}\ln|u| + C$<br>$= \frac{1}{4}(\sin x + \cos x)^2 - \frac{1}{2}\ln|\sin x + \cos x| + C$

88. $\displaystyle \int \frac{1-\cos^2 x}{1+\cos^2 x}\,dx = \int \left(\frac{2}{1+\cos^2 x} - 1\right)dx$<br>$= 2\int \frac{dx}{1+\cos^2 x} - x$<br>令 $t = \tan x$，$1+\cos^2 x = 1 + \frac{1}{1+t^2} = \frac{2+t^2}{1+t^2}$<br>$= \sqrt{2}\arctan\left(\frac{\tan x}{\sqrt{2}}\right) - x + C$

89. $\displaystyle \int \sec x \cdot \sec^2 x\,dx$，分部：$u = \sec x$，$dv = \sec^2 x dx$<br>$= \sec x \tan x - \int \sec x \tan^2 x\,dx = \sec x \tan x - \int \sec x(\sec^2 x-1)dx$<br>$= \sec x \tan x - \int \sec^3 x\,dx + \int \sec x\,dx$<br>移项得 $\displaystyle 2\int \sec^3 x\,dx = \sec x\tan x + \ln|\sec x + \tan x| + C$<br>$\displaystyle \int \sec^3 x\,dx = \frac{1}{2}\sec x\tan x + \frac{1}{2}\ln|\sec x + \tan x| + C$

90. $\displaystyle \int \csc^3 x\,dx$，分部类似：$u = \csc x$，$dv = \csc^2 x dx$<br>$= -\csc x\cot x - \int \csc x\cot^2 x\,dx = -\csc x\cot x - \int \csc x(\csc^2 x - 1)dx$<br>$= -\csc x\cot x - \int \csc^3 x\,dx + \int \csc x\,dx$<br>移项得 $\displaystyle \int \csc^3 x\,dx = -\frac{1}{2}\csc x\cot x + \frac{1}{2}\ln\left|\tan\frac{x}{2}\right| + C$

## 六、综合技巧与难题（第 91-100 题）

### 题目

91. $\displaystyle \int \frac{x e^x}{\sqrt{e^x-1}}\,dx$

92. $\displaystyle \int \frac{dx}{x\sqrt{x^2+x+1}}$

93. $\displaystyle \int \frac{x+\sin x}{1+\cos x}\,dx$

94. $\displaystyle \int e^x\left(\frac{1-x}{1+x^2}\right)^2 dx$

95. $\displaystyle \int \frac{dx}{\sin x \cos^2 x}$

96. $\displaystyle \int \frac{x^2+1}{x\sqrt{x^4+1}}\,dx$

97. $\displaystyle \int \sqrt{\frac{1+x}{1-x}}\,dx$

98. $\displaystyle \int \frac{\arctan e^x}{e^x}\,dx$

99. $\displaystyle \int \frac{dx}{x + \sqrt{1-x^2}}$

100. $\displaystyle \int \sqrt{\tan x}\,dx$

### 答案与解析

91. 令 $\sqrt{e^x-1} = t$，$e^x = t^2+1$，$x = \ln(t^2+1)$，$dx = \frac{2t}{t^2+1}dt$<br>$\displaystyle \int \frac{(t^2+1) \cdot \ln(t^2+1)}{t} \cdot \frac{2t}{t^2+1}\,dt = 2\int \ln(t^2+1)dt$<br>$= 2t\ln(t^2+1) - 2\int \frac{2t^2}{t^2+1}dt = 2t\ln(t^2+1) - 4t + 4\arctan t + C$<br>$= 2\sqrt{e^x-1}\ln e^x - 4\sqrt{e^x-1} + 4\arctan\sqrt{e^x-1} + C$<br>$= 2x\sqrt{e^x-1} - 4\sqrt{e^x-1} + 4\arctan\sqrt{e^x-1} + C$

92. 令 $x = \frac{1}{t}$（倒代换），$dx = -\frac{1}{t^2}dt$<br>$\displaystyle \int \frac{-dt/t^2}{\frac{1}{t}\sqrt{\frac{1}{t^2}+\frac{1}{t}+1}} = -\int \frac{dt}{\sqrt{1+t+t^2}}$<br>$= -\ln\left|t+\frac{1}{2}+\sqrt{t^2+t+1}\right| + C = -\ln\left|\frac{1}{x}+\frac{1}{2}+\sqrt{\frac{1}{x^2}+\frac{1}{x}+1}\right| + C$

93. $\displaystyle \int \frac{x}{1+\cos x}\,dx + \int \frac{\sin x}{1+\cos x}\,dx$<br>第二部分：$\displaystyle \int \frac{-d(\cos x)}{1+\cos x} = -\ln(1+\cos x) + C$<br>第一部分：$\displaystyle \int \frac{x}{1+\cos x} = \int \frac{x}{2\cos^2\frac{x}{2}}dx = \int \frac{x}{2}\sec^2\frac{x}{2}dx$<br>分部 $= x\tan\frac{x}{2} - \int \tan\frac{x}{2}dx = x\tan\frac{x}{2} + 2\ln|\cos\frac{x}{2}| + C$<br>$\displaystyle \int \frac{x+\sin x}{1+\cos x}\,dx = x\tan\frac{x}{2} + 2\ln|\cos\frac{x}{2}| - \ln(1+\cos x) + C$

94. $\displaystyle \left(\frac{1-x}{1+x^2}\right)^2 = \frac{1-2x+x^2}{(1+x^2)^2}$<br>$\displaystyle \int e^x\frac{1}{(1+x^2)^2}$ 非常规，观察到 $\frac{d}{dx}\left(\frac{1}{1+x^2}\right) = -\frac{2x}{(1+x^2)^2}$<br>尝试 $\displaystyle \left(\frac{1-x}{1+x^2}\right)^2 = \frac{d}{dx}\left(\frac{ax+b}{1+x^2}\right)$ 的形式<br>经检验：$\displaystyle \int e^x\left(\frac{1-x}{1+x^2}\right)^2 dx = e^x \cdot \frac{1-x}{1+x^2} + C$<br>（验证：求导 $\frac{d}{dx}\left(e^x\frac{1-x}{1+x^2}\right) = e^x\left[\frac{1-x}{1+x^2} + \frac{-1(1+x^2)-(1-x)(2x)}{(1+x^2)^2}\right] = e^x\frac{(1-x)^2}{(1+x^2)^2} = e^x\left(\frac{1-x}{1+x^2}\right)^2$）

95. $\displaystyle \int \frac{dx}{\sin x \cos^2 x} = \int \frac{\sin^2 x + \cos^2 x}{\sin x \cos^2 x}\,dx = \int \frac{\sin x}{\cos^2 x}\,dx + \int \frac{dx}{\sin x}$<br>$= \frac{1}{\cos x} + \ln\left|\tan\frac{x}{2}\right| + C = \sec x + \ln|\csc x - \cot x| + C$

96. $\displaystyle \int \frac{x^2}{x\sqrt{x^4+1}}\,dx + \int \frac{1}{x\sqrt{x^4+1}}\,dx$<br>第一部分：$\int \frac{x}{\sqrt{x^4+1}}\,dx = \frac{1}{2}\int \frac{d(x^2)}{\sqrt{(x^2)^2+1}} = \frac{1}{2}\ln(x^2 + \sqrt{x^4+1}) + C_1$<br>第二部分：令 $x = \frac{1}{t}$，$= -\frac{1}{2}\ln(t^2 + \sqrt{1+t^4}) + C_2 = \frac{1}{2}\ln\frac{x^2}{1+\sqrt{1+x^4}} + C_2$（难）

97. 令 $x = \cos 2t$（$t \in [0,\frac{\pi}{2}]$），$dx = -2\sin 2t\,dt$<br>$\displaystyle \sqrt{\frac{1+x}{1-x}} = \sqrt{\frac{1+\cos 2t}{1-\cos 2t}} = \sqrt{\frac{2\cos^2 t}{2\sin^2 t}} = \cot t$<br>$\displaystyle \int \cot t \cdot (-2\sin 2t)dt = -4\int \cot t \cdot \sin t \cos t\,dt = -4\int \cos^2 t\,dt$<br>$= -2\int (1+\cos 2t)dt = -2t - \sin 2t + C$<br>$= -\arccos x - \sqrt{1-x^2} + C$（$\sin 2t = \sqrt{1-x^2}$）<br>或写为 $\arcsin x - \sqrt{1-x^2} + C'$

98. 令 $u = \arctan e^x$，$dv = e^{-x}dx$<br>$= -e^{-x}\arctan e^x + \int e^{-x} \cdot \frac{e^x}{1+e^{2x}}dx = -e^{-x}\arctan e^x + \int \frac{dx}{1+e^{2x}}$<br>$= -e^{-x}\arctan e^x + \int \frac{e^{-2x}dx}{e^{-2x}+1} = -e^{-x}\arctan e^x - \frac{1}{2}\ln(1+e^{-2x}) + C$<br>$= -e^{-x}\arctan e^x + x - \frac{1}{2}\ln(1+e^{2x}) + C$

99. 令 $x = \sin t$（$t \in [-\frac{\pi}{2},\frac{\pi}{2}]$），$dx = \cos t\,dt$<br>$\displaystyle \int \frac{\cos t\,dt}{\sin t + \cos t}$<br>$= \frac{1}{2}\int \frac{(\sin t + \cos t) + (\cos t - \sin t)}{\sin t + \cos t}dt$<br>$= \frac{1}{2}\int dt + \frac{1}{2}\int \frac{d(\sin t + \cos t)}{\sin t + \cos t}$<br>$= \frac{t}{2} + \frac{1}{2}\ln|\sin t + \cos t| + C$<br>$= \frac{1}{2}\arcsin x + \frac{1}{2}\ln|x + \sqrt{1-x^2}| + C$

100. 令 $\sqrt{\tan x} = t$，$\tan x = t^2$，$\sec^2 x\,dx = 2t\,dt$，$dx = \frac{2t}{1+t^4}dt$<br>$\displaystyle \int t \cdot \frac{2t}{1+t^4}dt = 2\int \frac{t^2}{1+t^4}dt$<br>$= 2\int \frac{t^2}{(t^2+\sqrt{2}t+1)(t^2-\sqrt{2}t+1)}dt$<br>部分分式分解后得：<br>$\displaystyle \frac{1}{\sqrt{2}}\arctan(\sqrt{2\tan x}+1) - \frac{1}{\sqrt{2}}\arctan(1-\sqrt{2\tan x}) + \frac{1}{2\sqrt{2}}\ln\left|\frac{\tan x - \sqrt{2\tan x}+1}{\tan x + \sqrt{2\tan x}+1}\right| + C$
