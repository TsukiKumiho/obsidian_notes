# 数据的表示与运算 | 计组

## 一、常用 2 的幂次速查

### 必记：K/M/G/T 精确值

| $2^n$ | 精确值 | 记法 | 408 常考场景 |
|:---:|:---|:---|:---|
| $2^{10}$ | 1,024 | **1 K** | 1 KB = $2^{10}$ B；Cache 容量 |
| $2^{20}$ | 1,048,576 | **1 M** | 1 MB = $2^{20}$ B；20 根地址线 |
| $2^{30}$ | 1,073,741,824 | **1 G** | 1 GB = $2^{30}$ B；30 根地址线 |
| $2^{40}$ | ≈ 1.1×10¹² | **1 T** | 1 TB = $2^{40}$ B；40 位虚拟地址 |

### 常见地址宽度与寻址空间

| 地址线数 | 寻址空间 | 典型考题 |
|:---:|:---|:---|
| 12 位 | $2^{12}$ = 4 KB | 页内偏移位数 |
| 16 位 | $2^{16}$ = 64 KB | 16 位地址总线 |
| 20 位 | $2^{20}$ = 1 MB | 8086 实模式段地址 ×16 + 偏移 |
| 24 位 | $2^{24}$ = 16 MB | 24 位物理地址 |
| 32 位 | $2^{32}$ = 4 GB | 32 位 CPU 最大寻址 |
| 48 位 | $2^{48}$ = 256 TB | x86-64 虚拟地址（高位未用） |
| 64 位 | $2^{64}$ | 64 位理论寻址上限 |

### 常见页大小与 Cache 行大小

| $2^n$ | 值 | 典型用途 |
|:---:|:---|:---|
| $2^6$ | 64 B | Cache 行大小（最常考） |
| $2^{12}$ | 4 KB | 标准页大小；12 位页内偏移 |
| $2^{14}$ | 16 KB | L1 Cache 常见容量 |
| $2^{15}$ | 32 KB | L1/L2 Cache 常见容量 |
| $2^{16}$ | 64 KB | L1 Cache 上限 |
| $2^{17}$ | 128 KB | L2 Cache |
| $2^{18}$ | 256 KB | L2 Cache |
| $2^{19}$ | 512 KB | L2/L3 Cache |
| $2^{20}$ | 1 MB | L3 Cache |

### 机器字长关键值

| $2^n$ | 值 | 场景 |
|:---:|:---|:---|
| $2^3$ | 8 | 1 Byte = 8 bit；8 位机 |
| $2^4$ | 16 | 16 位机；半字 |
| $2^5$ | 32 | 32 位机；单精度浮点位宽 |
| $2^6$ | 64 | 64 位机；双精度浮点位宽 |
| $2^7$ | 128 | SSE 寄存器宽度 |

## 二、浮点数相关负次幂（IEEE 754 必记）

| $2^{-n}$ | 精确值 | 十进制近似 | 408 中的含义 |
|:---:|:---|:---|:---|
| $2^{-1}$ | $\frac{1}{2}$ | 0.5 | 规格化尾数隐含位 |
| $2^{-23}$ | $\frac{1}{2^{23}}$ | ≈ $1.19 \times 10^{-7}$ | **单精度**尾数 23 位；约 7 位十进制有效 |
| $2^{-52}$ | $\frac{1}{2^{52}}$ | ≈ $2.22 \times 10^{-16}$ | **双精度**尾数 52 位；约 15-16 位十进制有效 |
| $2^{-126}$ | — | ≈ $1.18 \times 10^{-38}$ | 单精度规格化最小正数 |
| $2^{-1022}$ | — | ≈ $2.23 \times 10^{-308}$ | 双精度规格化最小正数 |

> 📌 **记忆技巧**：单精度的关键数都在 $-126 \sim +127$ 附近（8 位阶码，偏置 127）；双精度的关键数在 $-1022 \sim +1023$ 附近（11 位阶码，偏置 1023）。

## 三、乘除法中的 2 的幂特例

| 操作 | 硬件实现 | 含义 |
|:---|:---|:---|
| 左移 1 位 | `x << 1` | $x \times 2$ |
| 左移 $n$ 位 | `x << n` | $x \times 2^n$ |
| 右移 1 位（逻辑） | `x >> 1` | $x \div 2$（无符号） |
| 右移 $n$ 位 | `x >> n` | $x \div 2^n$ |
| 取低 $n$ 位 | `x & (2^n - 1)` | $x \bmod 2^n$ |
| 按 2 的幂对齐 | `(x + 2^n - 1) & ~(2^n - 1)` | 向上取整到 $2^n$ 的倍数 |

> ⚠️ 算术右移（补符号位）对负数除法结果**向下取整**（C99 之前未定义），与直接除法语义略有不同。
