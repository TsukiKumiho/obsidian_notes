# 计算机组成原理 | 乘除运算原理与电路

> 核心问题：计算机如何用加减法与移位实现乘除？运算电路的结构是怎样的？

---

## 一、乘法运算原理

### 1.1 笔算乘法的二进制启示

十进制 $13 \times 11 = 13 \times 1 + 13 \times 10 = 143$。

二进制更为简单——**乘数的每一位要么是 0 要么是 1**，所以每一步只需判断「加还是不加」被乘数，然后移位。

以 $1011 \times 1101$（即 $11 \times 13$）为例：

```
        1 0 1 1   (被乘数)
    ×   1 1 0 1   (乘数)
    -----------
        1 0 1 1   ← 乘数最低位=1，加被乘数
      0 0 0 0     ← 乘数次低位=0，加0（注意移位对齐）
    1 0 1 1       ← 乘数第3位=1
  1 0 1 1         ← 乘数最高位=1
  ---------------
  1 0 0 0 1 1 1 1
```

**计算机的核心循环**：移位 → 判断乘数当前位 → 加法（或不加） → 重复。

### 1.2 原码一位乘法

| 要素 | 说明 |
| :--- | :--- |
| **符号位** | 单独处理：$P_s = X_s \oplus Y_s$（异或） |
| **数值部分** | 取绝对值相乘 |
| **核心循环** | 乘数末位 = 1 → 部分积 + 被乘数；乘数末位 = 0 → 部分积 + 0；然后**部分积右移一位，乘数右移一位** |

**运算流程**（$n$ 位数值位）：

```
初始化：部分积 = 0，乘数放在右移寄存器中
重复 n 次：
  ① 判别乘数最低位
     - 若为 1：部分积 = 部分积 + 被乘数
     - 若为 0：部分积不变
  ② 部分积与乘数联合右移一位（部分积的最高位移入乘数腾出的高位）
结果：部分积与乘数合并即为 2n 位乘积
```

**例题**：$X = +0.1011$（原码），$Y = -0.1101$（原码），用原码一位乘法求 $[X \cdot Y]_原$。

符号：$P_s = 0 \oplus 1 = 1$（负）。数值相乘：

|  步骤  | 部分积                  | 乘数       | 说明     |
| :--: | :------------------- | :------- | :----- |
|  初始  | $0.0000$             | $1101$   |        |
|  1   | $+0.1011$ → $0.1011$ |          | 乘数末位=1 |
| → 右移 | $0.0101$             | $1\;110$ |        |
|  2   | $+0.0000$ → $0.0101$ |          | 乘数末位=0 |
| → 右移 | $0.0010$             | $11\;11$ |        |
|  3   | $+0.1011$ → $0.1101$ |          | 乘数末位=1 |
| → 右移 | $0.0110$             | $111\;1$ |        |
|  4   | $+0.1011$ → $1.0001$ |          | 乘数末位=1 |
| → 右移 | $0.1000$             | $1111$   |        |

数值积 = $0.10001111$。加上符号位：$[X \cdot Y]_原 = 1.10001111$。

### 1.3 补码一位乘法（Booth 算法）

**为什么需要 Booth 算法**：补码表示的负数不能直接套用原码乘法。Booth 算法使符号位也参与运算。

| 要素 | 说明 |
| :--- | :--- |
| **符号位** | 参与运算，不单独处理 |
| **核心判断** | 考察乘数**末位 $y_n$ + 附加位 $y_{n+1}$** 的差值 |
| **操作次数** | $n+1$ 次循环（比原码多一次） |

**Booth 规则表**：

| $y_n$ | $y_{n+1}$ | 差值 $(y_{n+1}-y_n)$ | 部分积操作 |
| :---: | :---: | :---: | :--- |
| 0 | 0 | 0 | +0 |
| 0 | 1 | +1 | $+[X]_补$ |
| 1 | 0 | -1 | $+[-X]_补$ |
| 1 | 1 | 0 | +0 |

> **口诀**：$01$ 加 $[X]_补$，$10$ 加 $[-X]_补$，$00$ 和 $11$ 不动。

**运算流程**（$n+1$ 步）：

```
初始化：部分积 = 0，乘数末尾附加位 y_{n+1} = 0
重复 n+1 次：
  ① 根据 (y_n, y_{n+1}) 查表，部分积执行相应的加/减操作
  ② 部分积与乘数（含附加位）联合算术右移一位（高位补符号位）
最终：部分积与乘数高 n 位合并即为 [X×Y]_补，共 2n+1 位（最高位为符号）
```

> **Booth 算法的核心思想**：在乘数中连续一串 1 的中间不操作，只在边界处（0→1 或 1→0）一次完成累加/减。乘数中 1 越密集，Booth 算法的优势越明显。

## 二、除法运算原理

### 2.1 笔算除法的启示

除法本质：**被除数反复减去除数**，看能减多少次。二进制下每次上商只能是 0 或 1。

**关键矛盾**：减完若余数为负（上商 0），怎么处理？

### 2.2 原码恢复余数除法

| 要素 | 说明 |
| :--- | :--- |
| **符号位** | 单独处理：$Q_s = X_s \oplus Y_s$ |
| **核心操作** | 余数 − 除数 → 余数 ≥ 0 则上商 1；余数 < 0 则上商 0 且**恢复余数**（加回除数） |
| **缺点** | 上商 0 时多了一次加法（恢复余数），速度慢且步数不规整 |

**流程**：

```
初始化：余数寄存器 = 被除数（高位补0，扩展为 2n 位）
重复 n 次：
  ① 余数左移一位
  ② 余数 = 余数 − 除数
  ③ 判别：
     若余数 ≥ 0 → 上商 1
     若余数 < 0 → 上商 0，且余数 = 余数 + 除数（恢复）
```

### 2.3 原码不恢复余数除法（加减交替法）

**改进思路**：上商 0 时**不恢复余数**，将负余数留到下一步，通过改变下一步的操作（加法代替减法）来修正。

| 当前上商 | 本步操作 | 下一步应做 |
| :---: | :--- | :--- |
| 1 | 余数 − 除数 | 余数左移后 − 除数 |
| 0 | 余数 − 除数（余数变负） | 余数左移后 **+** 除数 |

> **核心规律**："**上商 1 下一步减，上商 0 下一步加**"

**流程**（$n$ 位数值）：

```
初始化：余数 = 被除数（扩展为 2n 位），先试减一次
若余数 ≥ 0 → 溢出，无法用 n 位商表示
若余数 < 0 → 上商 0，余数 = 余数 + 除数（恢复第一次）

重复 n−1 次：
  ① 余数左移一位
  ② 若上次上商 1 → 余数 = 余数 − 除数
     若上次上商 0 → 余数 = 余数 + 除数
  ③ 判别新余数符号：
     余数 ≥ 0 → 上商 1；余数 < 0 → 上商 0

最后一步：若最终余数 < 0，需恢复一次（加回除数），得到正确的正余数
```

| | 恢复余数法 | 不恢复余数法 |
| :--- | :---: | :---: |
| 上商 0 时操作数 | 多一次加法（恢复） | 不多，下一步操作改为加 |
| 每步操作次数 | 不固定 | **固定为 1 次加减** |
| 速度 | 较慢 | 较快 |
| 实用性 | 基础教学 | **实际主流方案** |

### 2.4 补码除法（加减交替法）

与补码乘法同理，**符号位参与运算**，商符由运算自动生成。

| 步骤 | 操作规则 |
| :--- | :--- |
| **第一步试算** | 被除数与除数同号 → 余数 = 被除数 − 除数；异号 → 余数 = 被除数 + 除数 |
| **上商规则** | 余数与除数同号 → 上商 1；异号 → 上商 0 |
| **下一步操作** | 上商 1 → 余数左移后 **−** 除数；上商 0 → 余数左移后 **+** 除数 |
| **末位恒置 1** | 最后一位商恒置为 1（舍入处理，简化电路） |

## 三、乘除运算中的溢出判断

> 考研重点：定点数乘除运算的结果何时超出表示范围？如何通过硬件标志位检测？

### 3.1 乘法溢出判断

#### 3.1.1 定点小数乘法

对于 $n$ 位定点小数（1 位符号 + $n-1$ 位数值），两个数相乘的完整积为 $2n$ 位（双倍位长）。

**溢出条件**：若只取低 $n$ 位（或单字长）作为结果，则当积的高 $n$ 位**不全是符号位的扩展**时发生溢出。

| 情况     | 高 $n$ 位状态  | 是否溢出  |
| :----- | :--------- | :---: |
| 两正数相乘  | 全为 0       |   否   |
| 两正数相乘  | 不全为 0      | **是** |
| 两负数相乘  | 全为 1       |   否   |
| 两负数相乘  | 不全为 1      | **是** |
| 一正一负相乘 | 全为 1（符号扩展） |   否   |
| 一正一负相乘 | 不全为 1      | **是** |

> **判断方法**：积的高 $n$ 位与低 $n$ 位的符号位（即乘积的最高位与次高位）比较——若两者不同，则溢出。

**硬件实现**：使用**双符号位**（变形补码）。运算过程中保留两位符号位 $S_{s1}S_{s2}$：
- $S_{s1}S_{s2} = 00$ → 正数，无溢出
- $S_{s1}S_{s2} = 11$ → 负数，无溢出
- $S_{s1}S_{s2} = 01$ → **正溢**（结果 > 最大正数）
- $S_{s1}S_{s2} = 10$ → **负溢**（结果 < 最小负数）

溢出逻辑表达式：

$$
V = S_{s1} \oplus S_{s2}
$$

当 $V = 1$ 时，置溢出标志位。

#### 3.1.2 原码乘法溢出

原码乘法数值部分为绝对值相乘（$n-1$ 位），完整积为 $2n-2$ 位。

**溢出条件**：积的整数部分（高位）不全为 0。即第 $n-1$ 位（从最高数值位起第 $n-1$ 位）以上均为 0 则无溢出。

> ⚠️ 原码乘法中，$n$ 位 × $n$ 位 → $2n$ 位，若结果只保留 $n$ 位（截断高位），则需判断高位是否全为 0。

### 3.2 除法溢出判断

#### 3.2.1 定点小数除法

除法溢出发生在**商的绝对值 ≥ 1** 时（定点小数无法表示 ≥ 1 的值）。

**溢出条件**：

$$
|\text{被除数}| \geq |\text{除数}|
$$

即：被除数的高位部分 ≥ 除数。

**硬件检测**：不恢复余数除法的**第一次试减**即承担溢出检测功能：

| 第一次试减结果 | 含义 |
| :--- | :--- |
| 余数 ≥ 0 | **溢出**（商 ≥ 1，无法用定点小数表示） |
| 余数 < 0 | 正常，继续运算 |

> ⚠️ **被除数 = 除数** 时也溢出（商 = 1，超出定点小数最大值 $1 - 2^{-(n-1)}$）。

**补码除法的溢出判断**：

补码除法中，需额外检查一种特殊情况：当被除数为最大负数（如 $1.000\ldots0$，即 $-1$）而除数为 $-1$ 时，商为 $+1$，但补码无法表示 $+1$。此时：

| 被除数 | 除数 | 正确商 | 补码能否表示 | 处理 |
| :--- | :--- | :--- | :---: | :--- |
| $1.000\ldots0$ ($-1$) | $1.000\ldots0$ ($-1$) | $+1$ | 否 | **溢出** |
| 其他情况 | — | — | 按正常流程 | — |

#### 3.2.2 定点整数除法

对于 $n$ 位定点整数，若除数为 0，则发生**除零异常**（最严重的除法溢出）。硬件通常通过**中断**（除法错误异常）处理。

除零检测电路：在除法开始前，判断除数寄存器是否全为 0。

### 3.3 溢出处理机制

| 处理方式 | 说明 |
| :--- | :--- |
| **置标志位** | 在程序状态字（PSW/EFLAGS）中置溢出标志（OF），由后续指令（如 `JO`/`JNO`）判断分支 |
| **中断/异常** | 除零异常通常触发硬件中断（x86：除法错误 #DE 中断向量 0），由操作系统接管 |
| **饱和运算** | DSP/多媒体指令中常用：溢出时结果固定为最大正值或最小负值，而非回绕 |
| **双字长存储** | 乘法可将完整 $2n$ 位积存入两个寄存器（如 x86 的 `MUL`：`DX:AX`），从根本上避免溢出 |

### 3.4 考研常考题型

| 题型 | 典型设问 | 关键点 |
| :--- | :--- | :--- |
| **乘法溢出判定** | "下列哪组操作数相乘会发生溢出？" | 双符号位 $S_{s1} \oplus S_{s2} = 1$ |
| **除法溢出判定** | "判断该除法运算是否溢出" | 被除数高位 ≥ 除数 → 溢出 |
| **补码特殊溢出** | "补码除法中何种情况必然溢出？" | $-1 \div -1$（$1.00\ldots0 \div 1.00\ldots0$） |
| **综合应用题** | 给定 $X,Y$ 的补码，求 $X/Y$ 并判断是否溢出 | 先算第一次试减的余数符号 |

## 四、运算电路结构

### 4.1 乘法电路：带移位寄存器的基本结构

```
                       ┌──────────────┐
      被乘数 X ────────┤   n位加法器   │
                       └──────┬───────┘
                              │
              ┌───────────────┴───────────────┐
              │      部分积寄存器 P（n位）      │←→ 右移
              └───────────────────────────────┘
                              │
              ┌───────────────┴───────────────┐
              │       乘数寄存器 Y（n位）       │←→ 右移（与 P 联合移位）
              └───────────────────────────────┘
```

**工作过程**：
- 每个时钟周期：P 的内容送入加法器，与 X（或 0）相加
- 结果写回 P，然后 P 与 Y 联合右移一位
- Y 的最低位移出，用于控制下个周期的「加/不加」
- $n$ 个周期后，$2n$ 位乘积的高 $n$ 位在 P 中，低 $n$ 位在 Y 中

### 4.2 乘法电路：阵列乘法器（Array Multiplier）

用**全加器阵列**并行计算所有部分积之和，属于组合逻辑电路，一个时钟周期即可出结果。

**4 位 × 4 位阵列结构**：需要 $4 \times 4 = 16$ 个与门（生成部分积） + $4 \times 3 = 12$ 个全加器。

```
    被乘数:  X₃  X₂  X₁  X₀
    乘  数:  Y₃  Y₂  Y₁  Y₀
    ─────────────────────────
    第0行: X₃Y₀  X₂Y₀  X₁Y₀  X₀Y₀    ← 与门阵列
    第1行: X₃Y₁  X₂Y₁  X₁Y₁  X₀Y₁    ← 移位后送入 FA 行
    第2行: X₃Y₂  X₂Y₂  X₁Y₂  X₀Y₂    ← 继续累加
    第3行: X₃Y₃  X₂Y₃  X₁Y₃  X₀Y₃    ← 最后一行
    ─────────────────────────────────
    乘积:  P₇   P₆   P₅   P₄   P₃   P₂   P₁   P₀
```

| 硬件资源 | 数量 |
| :--- | :--- |
| 与门（生成部分积） | $n \times n$ |
| 全加器 | $n \times (n-1)$ |
| 时间延迟 | 行波进位：$O(n^2)$；先行进位：$O(n \log n)$ |

> 阵列乘法器速度快于移位乘法器，但硬件开销大（$O(n^2)$ 量级）。现代 CPU 在浮点单元中常采用此方案并配合流水线。

### 4.3 除法电路：不恢复余数除法器

```
                       ┌──────────────┐
      除数 Y ──────────┤  n位加减法器  │
                       └──────┬───────┘
                              │
              ┌───────────────┴───────────────┐
              │      余数寄存器 R（n+1位）      │←→ 左移
              └───────────────────────────────┘
                              │
              ┌───────────────┴───────────────┐
              │        商寄存器 Q（n位）        │←→ 左移（商从低位串行移入）
              └───────────────────────────────┘
```

**工作过程**：
- 每个时钟周期：根据上一步的商决定加或减
- R 的内容送入加减法器，与 Y 进行加/减运算
- 结果写回 R，判符号决定本位商
- R 与 Q 联合左移一位（R 的最低位来自 Q 移出的高位，Q 的最低位移入新商）
- $n$ 个周期后，商在 Q 中，余数在 R 的高 $n$ 位中

### 4.4 乘法右移 vs 除法左移

| 维度 | 乘法 | 除法 |
| :--- | :--- | :--- |
| **移位方向** | **右移** | **左移** |
| **推进方向** | 从低位向高位 | 从高位向低位 |
| **寄存器联动** | 部分积(P) + 乘数(Y) 联合右移 | 余数(R) + 商(Q) 联合左移 |
| **直觉理解** | 乘法越乘越高（向左增长），右移空出低位存结果 | 除法越除越低（向右收缩），左移空出高位供减法 |

## 五、全章总结对比表

| 维度 | 原码乘法 | Booth 乘法 | 恢复余数除法 | 不恢复余数除法 |
| :--- | :--- | :--- | :--- | :--- |
| **符号** | 异或，单独算 | 参与运算 | 异或，单独算 | 异或（补码则参与） |
| **核心操作** | 加/移 | 加/减/移 | 减/判/恢复/移 | 加减交替/移 |
| **循环次数** | $n$ | $n+1$ | $n$ | $n$ |
| **步数规整性** | 规整 | 规整 | 不规整 | **规整** |
| **移位方向** | 右移 | 算术右移 | 左移 | 左移 |
| **硬件核心** | 加法器+移位 | 加减法器+移位 | 加减法器+移位 | 加减法器+移位 |

### 避坑警示

> ⚠️ **Booth 算法须算术右移**：每次移位时高位补符号位（非简单补 0），否则负数乘法结果错误。
>
> ⚠️ **除法第一步必试减（溢出检测）**：不恢复余数法的第一步试减同时承担溢出检测——若余数 ≥ 0 则商 ≥ 1，定点小数无法表示（**溢出**）。这是考研高频考点。
>
> ⚠️ **补码除法的末位恒置 1**：为简化电路，补码除法最后一位商不经过判别，直接置 1。这引入了舍入误差，但在允许范围内。
>
> ⚠️ **移位方向不可混淆**：乘法用右移（从 LSB 开始），除法用左移（从 MSB 开始），两者本质相反。
>
> ⚠️ **阵列乘法器面积代价**：硬件规模随位宽 $n$ 以 $O(n^2)$ 增长，32 位乘法器需要约 $32 \times 31 = 992$ 个全加器。
>
> ⚠️ **双符号位判溢出**：$V = S_{s1} \oplus S_{s2}$，$V = 1$ 即溢出（01 = 正溢，10 = 负溢）。变形补码运算后直接看双符号位即可。
>
> ⚠️ **补码除法 −1 ÷ −1 必溢出**：被除数和除数均为 $1.000\ldots0$（即 −1）时，商的真值为 +1，超出补码定点小数表示范围，必溢出。
