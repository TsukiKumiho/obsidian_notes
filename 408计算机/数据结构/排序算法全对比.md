# 408 数据结构 | 排序算法全对比

> 涵盖十大排序算法的时间复杂度、空间复杂度、比较次数、移动次数、稳定性、分类与适用场景。

---

## 一、十大排序算法复杂度总表

| 排序算法          |     最好时间     |     平均时间     |     最坏时间     |     空间复杂度     | **稳定性** | 原地  |
| :------------ | :----------: | :----------: | :----------: | :-----------: | :-----: | :-: |
| **直接插入排序**    |    $O(n)$    |   $O(n^2)$   |   $O(n^2)$   |    $O(1)$     |    ✅    |  ✅  |
| **折半插入排序**    | $O(n\log n)$ |   $O(n^2)$   |   $O(n^2)$   |    $O(1)$     |    ✅    |  ✅  |
| **希尔排序**      |    $O(n)$    |    取决于增量     |    取决于增量     |    $O(1)$     |    ❌    |  ✅  |
| **冒泡排序**      |    $O(n)$    |   $O(n^2)$   |   $O(n^2)$   |    $O(1)$     |    ✅    |  ✅  |
| **快速排序**      | $O(n\log n)$ | $O(n\log n)$ |   $O(n^2)$   | $O(\log n)^*$ |    ❌    |  ✅  |
| **简单选择排序**    |   $O(n^2)$   |   $O(n^2)$   |   $O(n^2)$   |    $O(1)$     |    ❌    |  ✅  |
| **堆排序**       | $O(n\log n)$ | $O(n\log n)$ | $O(n\log n)$ |    $O(1)$     |    ❌    |  ✅  |
| **归并排序 (二路)** | $O(n\log n)$ | $O(n\log n)$ | $O(n\log n)$ |    $O(n)$     |    ✅    |  ❌  |
| **基数排序**      | $O(d(n+r))$  | $O(d(n+r))$  | $O(d(n+r))$  |    $O(r)$     |    ✅    |  ❌  |
| **计数排序**      |   $O(n+k)$   |   $O(n+k)$   |   $O(n+k)$   |   $O(n+k)$    |    ✅    |  ❌  |

> ^* 快速排序的空间复杂度来自递归栈：平均 $O(\log n)$，最坏 $O(n)$。
> $d$ = 关键字位数，$r$ = 基数，$k$ = 取值范围（计数排序）。

## 二、稳定性速记

| 稳定性 | 算法 | 记忆要点 |
| :---: | :--- | :--- |
| ✅ 稳定 | 直接插入、折半插入、冒泡、归并、基数、计数 | **"插冒归基"** — 不跨距离交换 |
| ❌ 不稳定 | 希尔、快排、选择、堆排 | **"希快选堆"** — 跨距离交换或跳跃选择 |

---

## 三、排序算法分类

| 分类 | 包含算法 | 共同特征 |
| :--- | :--- | :--- |
| **插入排序** | 直接插入、折半插入、希尔 | 逐步将元素插入到已排序部分 |
| **交换排序** | 冒泡、快速 | 通过两两交换完成排序 |
| **选择排序** | 简单选择、堆排序 | 每趟选出最值放到目标位置 |
| **归并排序** | 二路归并 | 分治 + 合并有序子序列 |
| **非比较排序** | 基数排序、计数排序 | 不直接比较元素大小，利用分布特征 |

---

## 四、排序算法适用场景推荐

| 场景 | 推荐算法 | 原因 |
| :--- | :--- | :--- |
| $n$ 很小 | 直接插入 | 常数因子小，简单高效 |
| $n$ 较大、要求稳定 | 归并排序 | 稳定 + $O(n\log n)$ |
| $n$ 较大、内存敏感 | 堆排序 | 原地 + $O(n\log n)$ |
| $n$ 较大、通用最快 | 快速排序 | 平均性能最优 |
| 数据基本有序 | 直接插入 / 冒泡 | 最好可达 $O(n)$ |
| 关键字范围有限 | 基数排序 / 计数排序 | 非比较，效率极高 |
| 需要稳定性 + 原地 | **折半插入** | 折半查找优化比较次数，仍稳定 |

## 五、排序算法比较次数 & 移动次数详解

> ⚡ **408 高频考点**：排序算法的比较次数与移动次数是选择题和简答题的常见考察点。以下按算法逐一列出。

### (1) 直接插入排序

| 情况 | 比较次数 | 移动次数 | 说明 |
| :--- | :---: | :---: | :--- |
| **最好**（正序） | $n-1$ | $0$ | 每趟比较 1 次即确定位置，无需移动 |
| **最坏**（逆序） | $\dfrac{(n+2)(n-1)}{2} \approx \dfrac{n^2}{2}$ | $\dfrac{(n+4)(n-1)}{2} \approx \dfrac{n^2}{2}$ | 每趟需与已排序全部元素比较并后移 |
| **平均** | $\approx \dfrac{n^2}{4}$ | $\approx \dfrac{n^2}{4}$ | 随机排列下约比较/移动一半 |

### (2) 折半插入排序

| 情况 | 比较次数 | 移动次数 | 说明 |
| :--- | :---: | :---: | :--- |
| **最好** | $O(n\log n)$ | $O(n)$ | 折半查找确定位置（比较少），已排好时无需移动 |
| **最坏** | $O(n\log n)$ | $O(n^2)$ | 比较次数被折半优化，但移动次数仍为平方级 |
| **平均** | $O(n\log n)$ | $O(n^2)$ | 比较与移动"脱钩"——折半优化只改变比较，不改变移动 |

> ⚠️ 折半插入排序减少了比较次数（$n^2 \to n\log n$），但**移动次数不变**（仍为 $O(n^2)$）。因此总时间复杂度仍为 $O(n^2)$。

### (3) 希尔排序

| 情况 | 比较次数 | 移动次数 | 说明 |
| :--- | :---: | :---: | :--- |
| **总复杂度** | 取决于增量序列 | 取决于增量序列 | 比较和移动均发生在各趟的"子插入排序"中 |
| **Hibbard 增量** | $O(n^{1.5})$ | $O(n^{1.5})$ | $d_k = 2^k - 1$ |
| **Sedgewick 增量** | $O(n^{1.3})$ | $O(n^{1.3})$ | 目前实践中较优的序列 |

> ⚠️ 希尔排序没有统一的比较/移动次数公式，考试中通常只要求知道"优于 $O(n^2)$"且"不稳定"。

### (4) 冒泡排序

| 情况         |           比较次数           |      移动次数（交换次数 × 3）       | 说明                      |
| :--------- | :----------------------: | :-----------------------: | :---------------------- |
| **最好**（正序） |          $n-1$           |            $0$            | 一趟比较无交换，标记判终止           |
| **最坏**（逆序） |   $\dfrac{n(n-1)}{2}$    |   $\dfrac{3n(n-1)}{2}$    | 每对相邻元素均需交换（1次交换 = 3次移动） |
| **平均**     | $\approx \dfrac{n^2}{4}$ | $\approx \dfrac{3n^2}{4}$ | —                       |

### (5) 快速排序

| 情况 | 比较次数 | 说明 |
| :--- | :---: | :--- |
| **最好** | $\approx n\log_2 n$ | 每次划分均分 |
| **平均** | $\approx 2n\ln n \approx 1.39\,n\log_2 n$ | 严格数学分析 |
| **最坏** | $\dfrac{n(n-1)}{2}$ | 每次划分为 $1$ 和 $n-1$（正序/逆序 + 固定基准） |

| 情况 | 移动/交换次数 | 说明 |
| :--- | :---: | :--- |
| **最好** | $\approx \dfrac{n}{3}\log_2 n$（交换次数） | 交换次数约为比较次数的 $1/3$ |
| **最坏** | $\approx \dfrac{n(n-1)}{2}$（交换次数） | 每对元素均需交换 |

> ⚠️ 快速排序的比较和移动发生在划分（Partition）过程中。每趟划分的比较次数约为子区间长度；交换次数取决于基准元素的位置。

### (6) 简单选择排序

| 情况 | 比较次数 | 移动次数 | 说明 |
| :--- | :---: | :---: | :--- |
| **所有情况** | $\dfrac{n(n-1)}{2}$ | — | **比较次数固定**，与输入无关 |
| **最好**（正序） | 同上 | $0$ | 每次发现已是最小，不交换 |
| **最坏**（逆序） | 同上 | $3(n-1)$ | 每趟均需交换（共 $n-1$ 次，每次 3 步移动） |

### (7) 堆排序

| 操作 | 比较次数 | 移动次数 |
| :--- | :---: | :---: |
| **建堆** | $\leq 4n$ | $O(n)$ |
| **每趟调整** | $\leq 2\log_2 n$ | $O(\log n)$ |
| **总计（$n-1$ 趟）** | $\leq 2n\log_2 n + O(n)$ | $O(n\log n)$ |

> 💡 建堆的比较次数上界 $4n$（而非直观的 $n\log n$）说明建堆的实际开销很低。

### (8) 归并排序（二路）

| 操作 | 比较次数 | 移动次数 | 说明 |
| :--- | :---: | :---: | :--- |
| **每层归并** | $\leq n$（至少 $n/2$） | $2n$ | $n$ 次读入辅助数组 + $n$ 次写回原数组 |
| **总计（$\log_2 n$ 层）** | $O(n\log n)$ | $O(n\log n)$ | 每层比较不超过 $n$，每层移动恰为 $2n$ |

> 💡 归并排序的移动次数是所有比较排序中**最稳定**的：严格 $2n\log_2 n$。比较次数在 $[n\log n/2,\; n\log n]$ 之间。

### (9) 基数排序

基数排序不直接比较关键字，而是通过"分配-收集"完成排序。其操作以**分配次数**和**收集次数**衡量：

| 操作 | 每趟次数 | 总次数（$d$ 趟） |
| :--- | :---: | :---: |
| **分配** | $n$ | $d \cdot n$ |
| **收集** | $r$ | $d \cdot r$ |
| **总计** | $n + r$ | $d(n + r)$ |

> 💡 $d$ = 关键字位数，$r$ = 基数（如十进制 $r=10$）。基数排序的比较次数为 $0$（不做比较），移动次数约为 $2dn$（分配 + 收集各一次移动）。

### (10) 计数排序

| 操作 | 次数 |
| :--- | :---: |
| **统计计数** | $n$（遍历原数组） |
| **累加计数** | $k$（遍历计数数组） |
| **放置元素** | $n$（再次遍历原数组） |

> 💡 比较次数为 $0$，移动总次数为 $2n + k$（读 $n$ + 写 $n$ + 累加遍历 $k$）。

## 六、比较与移动次数速查总表

| 排序算法 | 比较次数（最好） | 比较次数（最坏） | 移动次数（最好） | 移动次数（最坏） | 比较/移动独立性 |
| :--- | :---: | :---: | :---: | :---: | :--- |
| **直接插入** | $n-1$ | $\approx n^2/2$ | $0$ | $\approx n^2/2$ | 比较=移动 |
| **折半插入** | $O(n\log n)$ | $O(n\log n)$ | $O(n)$ | $O(n^2)$ | **比较<移动** |
| **冒泡** | $n-1$ | $n(n-1)/2$ | $0$ | $3n(n-1)/2$ | 比较=移动（正比） |
| **快速** | $\approx n\log n$ | $n(n-1)/2$ | $\approx \frac{n}{3}\log n$ | $n(n-1)/2$ | 移动<比较 |
| **简单选择** | $n(n-1)/2$ | $n(n-1)/2$ | $0$ | $3(n-1)$ | **比较>>移动** |
| **堆排序** | $O(n\log n)$ | $O(n\log n)$ | $O(n\log n)$ | $O(n\log n)$ | 同量级 |
| **归并** | $O(n\log n)$ | $O(n\log n)$ | $2n\log_2 n$ | $2n\log_2 n$ | 移动固定 |
| **基数** | $0$ | $0$ | $d(n+r)$ | $d(n+r)$ | 无比较 |
| **计数** | $0$ | $0$ | $2n+k$ | $2n+k$ | 无比较 |

> ⚠️ **关键差异**：简单选择排序的比较次数**恒为 $n(n-1)/2$**（不随输入改变），但移动次数极低（最多 $3(n-1)$）。这是选择题中常考的"比较次数与初始状态无关"的排序算法。
