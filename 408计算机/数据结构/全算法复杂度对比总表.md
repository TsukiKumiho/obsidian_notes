## 408 数据结构 | 全算法时间复杂度与空间复杂度对比总表

> 按章节分类，覆盖全书所有算法的复杂度对比。每个对比表区分存储结构 / 算法变体 / 最好-平均-最坏情况。

---

### 一、绪论 — 常见复杂度量级排序

| 复杂度          | 名称    | 常见情形举例                 |
| :----------- | :---- | :--------------------- |
| $O(1)$       | 常数阶   | 数组随机访问、栈/队列基本操作        |
| $O(\log n)$  | 对数阶   | 折半查找、平衡二叉树查找           |
| $O(n)$       | 线性阶   | 顺序查找、遍历线性表             |
| $O(n\log n)$ | 线性对数阶 | 快速排序(平均)、归并排序、堆排序      |
| $O(n^2)$     | 平方阶   | 简单选择排序、冒泡排序、直接插入排序(最坏) |
| $O(n^3)$     | 立方阶   | Floyd 算法、普通矩阵乘法        |
| $O(2^n)$     | 指数阶   | 某些暴力递归（如递归求斐波那契）       |
| $O(n!)$      | 阶乘阶   | 全排列问题                  |

> 排序：$O(1) < O(\log n) < O(n) < O(n\log n) < O(n^2) < O(n^3) < O(2^n) < O(n!) < O(n^n)$

### 二、线性表 — 顺序表 vs 链表

#### 2.1 基本操作复杂度对比

| 操作 | 顺序表 | 单链表 | 双向链表 | 备注 |
| :--- | :---: | :---: | :---: | :--- |
| **按位查找** | $O(1)$ | $O(n)$ | $O(n)$ | 顺序表可直接计算地址 |
| **按值查找** | $O(n)$ | $O(n)$ | $O(n)$ | 均需遍历比较 |
| **插入**（已知前驱） | $O(n)$ | $O(1)$ | $O(1)$ | 顺序表需移动元素 |
| **插入**（未知位置） | $O(n)$ | $O(n)$ | $O(n)$ | 先查找 + 再插入 |
| **删除**（已知前驱） | $O(n)$ | $O(1)$ | $O(1)$ | 顺序表需移动元素 |
| **删除**（未知位置） | $O(n)$ | $O(n)$ | $O(n)$ | 先查找 + 再删除 |
| **删除当前结点** | $O(n)$ | $O(n)$ / $O(1)^*$ | $O(1)$ | ^*单链表可通过"复制后继再删后继"做到 $O(1)$，但不能删尾结点 |

#### 2.2 空间复杂度对比

| 存储结构 | 空间复杂度 | 存储密度 | 说明 |
| :--- | :---: | :---: | :--- |
| **顺序表** | $O(n)$ | 高（≈1） | 仅存数据，无指针开销 |
| **单链表** | $O(n)$ | 较低 | 每个结点额外存 1 个指针 |
| **双向链表** | $O(n)$ | 更低 | 每个结点额外存 2 个指针 |
| **静态链表** | $O(n)$ | 中等 | 用数组下标模拟指针 |

### 三、栈、队列、数组

#### 3.1 栈 — 顺序栈 vs 链栈

| 操作 | 顺序栈 | 链栈 | 备注 |
| :--- | :---: | :---: | :--- |
| 入栈 (push) | $O(1)$ | $O(1)$ | 仅在栈顶操作 |
| 出栈 (pop) | $O(1)$ | $O(1)$ | 仅在栈顶操作 |
| 读栈顶 (top) | $O(1)$ | $O(1)$ | — |
| 判空 | $O(1)$ | $O(1)$ | — |
| 空间复杂度 | $O(n)$ | $O(n)$ | 链栈多了指针开销 |

> ⚠️ 共享栈（两栈对向增长）：各操作仍为 $O(1)$，空间利用率高于两个独立顺序栈。

#### 3.2 队列 — 顺序队列 vs 循环队列 vs 链队列

| 操作 | 顺序队列 | 循环队列 | 链队列 |
| :--- | :---: | :---: | :---: |
| 入队 (enqueue) | $O(1)$ | $O(1)$ | $O(1)$ |
| 出队 (dequeue) | $O(1)$ | $O(1)$ | $O(1)$ |
| 取队头 | $O(1)$ | $O(1)$ | $O(1)$ |
| 判空 | $O(1)$ | $O(1)$ | $O(1)$ |
| 空间复杂度 | $O(n)$ | $O(n)$ | $O(n)$ |
| 假溢出问题 | **存在** | **不存在** | 不存在 |

#### 3.3 数组地址计算与矩阵压缩存储

| 操作 / 结构 | 时间复杂度 | 空间复杂度 | 说明 |
| :--- | :---: | :---: | :--- |
| 一维数组按下标访问 | $O(1)$ | $O(n)$ | 直接地址计算 |
| 二维数组按行优先访问 | $O(1)$ | $O(mn)$ | $LOC[i][j]=LOC[0][0]+(i\times n+j)\times L$ |
| 对称矩阵压缩存储 | $O(1)$ | $\approx O(n^2/2)$ | 只存上三角或下三角 |
| 三角矩阵压缩存储 | $O(1)$ | $\approx O(n^2/2)$ | 加上存储常量的 1 个单元 |
| 三对角矩阵压缩存储 | $O(1)$ | $\approx O(3n)$ | 三对角元素映射到一维数组 |

### 四、串 — 模式匹配算法

#### 4.1 对比总表

| 算法 | 最好时间 | 平均时间 | 最坏时间 | 空间复杂度 | 主串是否回退 |
| :--- | :---: | :---: | :---: | :---: | :---: |
| **朴素模式匹配** (BF) | $O(m)$ | $O(nm)$ | $O(nm)$ | $O(1)$ | 是 |
| **KMP 算法** | $O(n)$ | $O(n+m)$ | $O(n+m)$ | $O(m)$ (存 `next` 数组) | 否 |
| **KMP 改进版** (nextval) | $O(n)$ | $O(n+m)$ | $O(n+m)$ | $O(m)$ | 否 |

> 其中 $n$ = 主串长度，$m$ = 模式串长度

#### 4.2 `next` 数组手工推导

| 步骤  | 含义                                                             |
| :-: | :------------------------------------------------------------- |
|  ①  | 对每个前缀，找出最长相等前后缀长度（不能是前缀本身）                                     |
|  ②  | 按教材定义的移位规则转为 `next[j]`（常见：`next[1]=0`，其他 = 最长相等前后缀长度 + 1）      |
|  ③  | 若 $P[next[j]] = P[j]$，则 `nextval[j] = nextval[next[j]]`，避免重复比较 |

### 五、树与二叉树

#### 5.1 二叉树遍历（$n$ 个结点）

| 遍历方式 | 时间复杂度 | 空间复杂度（递归栈） | 常用实现 |
| :--- | :---: | :---: | :--- |
| **前序遍历** (根→左→右) | $O(n)$ | $O(h)$，最坏 $O(n)$ | 递归 / 栈 |
| **中序遍历** (左→根→右) | $O(n)$ | $O(h)$，最坏 $O(n)$ | 递归 / 栈 |
| **后序遍历** (左→右→根) | $O(n)$ | $O(h)$，最坏 $O(n)$ | 递归 / 栈 |
| **层序遍历** (BFS) | $O(n)$ | $O(w)$，最坏 $O(n)$ | 队列 |

> $h$ = 树高，$w$ = 树的最大宽度（最宽层的结点数）

#### 5.2 二叉树存储结构空间对比

| 存储方式 | 空间复杂度 | 适用场景 | 缺陷 |
| :--- | :---: | :--- | :--- |
| **顺序存储** | $O(2^h)$ | 完全二叉树 | 一般二叉树浪费严重 |
| **二叉链表** | $O(2n)$ | 通用 | 每个结点有 2 个指针域 |
| **三叉链表** | $O(3n)$ | 需要快速找双亲 | 额外多 1 个双亲指针 |
| **线索二叉树** | $O(2n)$ | 需要按遍历次序快速找前驱/后继 | 结构比普通链表稍复杂 |

#### 5.3 树、森林、二叉树的转换

| 操作 | 时间复杂度 | 空间复杂度 | 说明 |
| :--- | :---: | :---: | :--- |
| 树 → 二叉树 | $O(n)$ | $O(n)$ | 长子作左孩子，兄弟作右孩子 |
| 森林 → 二叉树 | $O(n)$ | $O(n)$ | 每棵树先转换，再串联根的右子树 |
| 二叉树 → 树/森林 | $O(n)$ | $O(n)$ | 逆过程 |

#### 5.4 哈夫曼树 (Huffman Tree)

| 项目 | 复杂度 / 值 | 说明 |
| :--- | :---: | :--- |
| **构建哈夫曼树**（$n$ 个叶结点） | $O(n\log n)$ | 每次选两个最小权值合并，可用小顶堆优化 |
| **空间复杂度** | $O(n)$ | 共有 $2n-1$ 个结点（包括内部结点） |
| **哈夫曼编码总长度** | $\sum w_i l_i$ | 带权路径长度 WPL |
| **单次编码/解码** | $O(L)$ | $L$ = 编码长度（路径深度） |

#### 5.5 并查集 (Disjoint Set Union)

| 操作 | 朴素实现 | 按秩合并 + 路径压缩 |
| :--- | :---: | :---: |
| **初始化** (MakeSet) | $O(n)$ | $O(n)$ |
| **查找** (Find) | $O(n)$ | $O(\alpha(n))$ ≈ $O(1)$ |
| **合并** (Union) | $O(n)$ | $O(\alpha(n))$ ≈ $O(1)$ |
| **空间复杂度** | $O(n)$ | $O(n)$ |

> $\alpha(n)$ 为反阿克曼函数，增长极慢，在实际范围内可视为常数。

### 六、图

#### 6.1 存储结构空间复杂度

| 存储方式 | 无向图 | 有向图 | 适用场景 |
| :--- | :---: | :---: | :--- |
| **邻接矩阵** | $O(\vert V\vert ^2)$ | $O(\vert V\vert ^2)$ | 稠密图 |
| **邻接表** | $O(\vert V\vert +\vert E\vert )$ | $O(\vert V\vert +\vert E\vert )$ | 稀疏图 |
| **逆邻接表** | — | $O(\vert V\vert +\vert E\vert )$ | 有向图快速找入边 |
| **十字链表** | — | $O(\vert V\vert +\vert E\vert )$ | 有向图出入度兼顾 |
| **邻接多重表** | $O(\vert V\vert +\vert E\vert )$ | — | 无向图边的删除操作友好 |

#### 6.2 图的遍历 — DFS & BFS

| 遍历算法 | 存储结构 | 时间复杂度 | 空间复杂度 | 辅助结构 |
| :--- | :--- | :---: | :---: | :--- |
| **DFS** | 邻接矩阵 | $O(\vert V\vert ^2)$ | $O(\vert V\vert )$ | 递归栈（深度） |
| **DFS** | 邻接表 | $O(\vert V\vert +\vert E\vert )$ | $O(\vert V\vert )$ | 递归栈（深度） |
| **BFS** | 邻接矩阵 | $O(\vert V\vert ^2)$ | $O(\vert V\vert )$ | 队列（宽度） |
| **BFS** | 邻接表 | $O(\vert V\vert +\vert E\vert )$ | $O(\vert V\vert )$ | 队列（宽度） |

> ⚠️ BFS 求无权图最短路径只是特例，不等于 BFS = 最短路算法。

#### 6.3 最小生成树 (MST)

| 算法 | 时间复杂度（邻接表+堆) | 时间复杂度（邻接矩阵) | 空间复杂度 | 核心思想 | 适用图类型 |
| :--- | :---: | :---: | :---: | :--- | :--- |
| **Prim** | $O(\vert E\vert \log\vert V\vert )$ | $O(\vert V\vert ^2)$ | $O(\vert V\vert )$ | 点集扩张 | 稠密图 ($\vert E\vert$ 大) |
| **Kruskal** | $O(\vert E\vert \log\vert E\vert )$ | $O(\vert E\vert \log\vert E\vert )$ | $O(\vert V\vert )$ (并查集) | 边集选择 | 稀疏图 ($\vert E\vert$ 小) |

> ⚠️ 最小生成树要求：**连通无向带权图**；边数为 $\vert V\vert -1$。

#### 6.4 最短路径

| 算法 | 解决的问题 | 时间复杂度 | 空间复杂度 | 允许负权边 | 核心思想 |
| :--- | :--- | :---: | :---: | :---: | :--- |
| **Dijkstra** | 单源最短路 | $O(\vert V\vert ^2)$ / $O(\vert E\vert \log\vert V\vert )$ (堆优化) | $O(\vert V\vert )$ | ❌ | 贪心：每次确定离源点最近的顶点 |
| **Floyd** | 所有顶点对最短路 | $O(\vert V\vert ^3)$ | $O(\vert V\vert ^2)$ | ✅ | 动态规划：逐步引入中转顶点 |
| **BFS**（无权图） | 单源最短路（边权=1） | $O(\vert V\vert +\vert E\vert )$ | $O(\vert V\vert )$ | ❌ | 层序遍历 |

> ⚠️ Dijkstra **不能处理负权边**（经典易错考点），但图中可有回路。
> ⚠️ Floyd 允许负权边，但**不允许负权回路**。

#### 6.5 拓扑排序 & 关键路径（AOV / AOE 网）

| 算法 | 存储结构 | 时间复杂度 | 空间复杂度 | 辅助结构 | 前提条件 |
| :--- | :--- | :---: | :---: | :--- | :--- |
| **拓扑排序** | 邻接表 | $O(\vert V\vert +\vert E\vert )$ | $O(\vert V\vert )$ | 栈/队列 + `indegree[]` | DAG（有向无环图） |
| **拓扑排序** | 邻接矩阵 | $O(\vert V\vert ^2)$ | $O(\vert V\vert )$ | 栈/队列 + `indegree[]` | DAG |
| **关键路径** | 邻接表 | $O(\vert V\vert +\vert E\vert )$ | $O(\vert V\vert )$ | `ve[]`, `vl[]` | AOE 网（DAG + 边有权值） |

> ⚠️ 关键路径 = 从源点到汇点的最长路径；关键活动的时间余量（松弛时间）= 0。

### 七、查找

#### 7.1 线性表查找

| 查找算法 | 最好时间 | 平均时间 | 最坏时间 | 空间复杂度 | 要求有序 | 存储要求 |
| :--- | :---: | :---: | :---: | :---: | :---: | :--- |
| **顺序查找** | $O(1)$ | $O(n)$ | $O(n)$ | $O(1)$ | 否 | 任意 |
| **折半查找** (二分) | $O(1)$ | $O(\log n)$ | $O(\log n)$ | $O(1)$ | 是 | 顺序存储 + 随机访问 |
| **分块查找** (索引查找) | $O(\log b + s)$ | $O(\sqrt{n})^*$ | $O(b+s)$ | $O(b)$ (索引表) | 块间有序 | 顺序存储 |

> $b$ = 块数，$s$ = 每块大小；$^*$当 $b=s=\sqrt{n}$ 时取得最优。

#### 7.2 二叉排序树 (BST) & 平衡二叉树 (AVL)

| 操作 | BST（平均） | BST（最坏） | AVL（最坏） | 说明 |
| :--- | :---: | :---: | :---: | :--- |
| **查找** | $O(\log n)$ | $O(n)$ | $O(\log n)$ | BST 退化成链表时最坏 |
| **插入** | $O(\log n)$ | $O(n)$ | $O(\log n)$ | AVL 插入后需旋转调整 |
| **删除** | $O(\log n)$ | $O(n)$ | $O(\log n)$ | AVL 删除后可能需多次旋转 |
| **空间复杂度** | $O(n)$ | $O(n)$ | $O(n)$ | 链式存储 |

> ⚠️ AVL：任一结点左右子树高度差 ≤ 1。四种失衡：LL / RR（单旋）、LR / RL（双旋）。

#### 7.3 BST vs AVL 对比

| 对比维度 | BST | AVL |
| :--- | :--- | :--- |
| 平衡要求 | 无（左小右大即可） | 必须平衡（高度差 ≤ 1） |
| 查找效率稳定性 | 可能退化到 $O(n)$ | 始终 $O(\log n)$ |
| 插入删除代价 | 仅修改指针 | 修改指针 + 可能需要旋转 |
| 适用场景 | 动态变化不频繁 | 查找频率远高于插入删除 |

#### 7.4 B 树 & B+ 树（$n$ 个关键字）

| 操作 | B 树 | B+ 树 | 说明 |
| :--- | :---: | :---: | :--- |
| **查找** | $O(\log_m n)$ | $O(\log_m n)$ | $m$ 为阶数 |
| **插入** | $O(\log_m n)$ | $O(\log_m n)$ | 可能引起结点的分裂 |
| **删除** | $O(\log_m n)$ | $O(\log_m n)$ | 可能引起结点的合并 |
| **空间复杂度** | $O(n)$ | $O(n)$ | — |
| **范围查找** | 需中序遍历 | 高效（叶结点顺序相连） | B+ 树的核心优势 |

> B 树 vs B+ 树核心区别：
> - B 树：关键字分布在所有结点中，叶结点不存指针。
> - B+ 树：所有关键字最终都出现在叶结点中；非叶结点仅作索引；叶结点间用指针顺序相连。

#### 7.5 散列表 (Hash Table)

| 操作 | 理想（无冲突） | 实际平均 | 最坏 | 说明 |
| :--- | :---: | :---: | :---: | :--- |
| **查找** | $O(1)$ | 取决于装填因子 $\alpha$ | $O(n)$ | 冲突严重时退化 |
| **插入** | $O(1)$ | $O(1)$ 平均 | $O(n)$ | 开放定址寻找空位 |
| **删除** | $O(1)$ | $O(1)$ 平均 | $O(n)$ | 开放定址需特殊标记 |
| **空间复杂度** | $O(m)$ | $O(m)$ | $O(m)$ | $m$ = 散列表长度 |

> 装填因子 $\alpha = \frac{\text{表中记录数}}{\text{散列表长度}}$，$\alpha$ 越大，冲突概率越高。

#### 7.6 红黑树 (Red-Black Tree)

| 操作 | 时间复杂度 | 空间复杂度 | 说明 |
| :--- | :---: | :---: | :--- |
| 查找 | $O(\log n)$ | $O(n)$ | 弱于 AVL 的严格平衡，但插入删除旋转更少 |
| 插入 | $O(\log n)$ | $O(n)$ | 最多 2 次旋转 |
| 删除 | $O(\log n)$ | $O(n)$ | 最多 3 次旋转 |

### 八、速查口诀

```
线性表：顺序查位 O(1)，链表插删 O(1)（已知前驱）
栈队列：入出入出均为 1，空间顺序与链式无大差
串匹配：朴素 mn，KMP 是 n+m
二叉树：遍历 O(n)，递归栈最深 O(n)
图遍历：矩阵 V²，邻接表 V+E
MST：    Prim 适合稠密，Kruskal 适合稀疏
最短路：Dijk 禁负权，Floyd 三重 V³
查找：   BST 可能退化，AVL 强制平衡
排序：   插冒归基稳，希快选堆不稳
排序比较：插入移动最相关，选择比较永不变
         折半比较被优化，移动依然 O(n²)
```
