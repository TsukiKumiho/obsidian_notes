# 单调有界准则 | 极限专题

> **单调有界准则**：单调递增（递减）且有上（下）界的数列必收敛。
>
> **适用场景**：数列由递推式 $x_{n+1}=f(x_n)$ 定义，证明其收敛并求极限。泰勒展开和定积分定义对此类题无效。

---

## 一、标准流程

```
递推数列 {x_n}, x_{n+1} = f(x_n)
    │
    ├── ① 证单调
    │   ├── 作差：x_{n+1} - x_n
    │   ├── 作比：x_{n+1} / x_n（全正项时）
    │   └── 函数单调性：f(x) 单调 + 初值关系
    │
    ├── ② 证有界
    │   ├── 数学归纳法
    │   └── 函数值域分析
    │
    └── ③ 极限存在 → 对递推式两边取极限 → 解方程
        L = f(L) → 解出 L
```

---

## 二、题型分类

### 题型一：标准递推型

#### 题 1 【基础】

设 $x_1 = 1$，$x_{n+1} = \sqrt{2 + x_n}$。证明 $\{x_n\}$ 收敛并求极限。

**解法**：

**有界性**：$x_1 = 1 < 2$。假设 $x_n < 2$，则 $x_{n+1} = \sqrt{2+x_n} < \sqrt{2+2} = 2$。归纳得 $x_n < 2$（$\forall n$）。显然 $x_n > 0$。

**单调性**：$x_2 = \sqrt{3} > 1 = x_1$。假设 $x_n > x_{n-1}$，则

$$
x_{n+1} - x_n = \sqrt{2+x_n} - \sqrt{2+x_{n-1}}
= \frac{x_n - x_{n-1}}{\sqrt{2+x_n} + \sqrt{2+x_{n-1}}} > 0
$$

归纳得 $x_{n+1} > x_n$，$\{x_n\}$ 单调递增。

**求极限**：极限存在，设为 $L$。$L = \sqrt{2+L}$，平方得 $L^2 = 2+L$，$L^2 - L - 2 = 0$，$L = 2$ 或 $L = -1$。$x_n > 0$ 故 $L = 2$。

**答案**：$2$

---

#### 题 2 【基础】

设 $x_1 = \sqrt{2}$，$x_{n+1} = \sqrt{2x_n}$。证明收敛并求极限。

**解法**：

**有界性**：$x_1 = \sqrt{2} < 2$。假设 $x_n < 2$，$x_{n+1} = \sqrt{2x_n} < \sqrt{4} = 2$。归纳得 $x_n < 2$。

**单调性**：$x_2 = \sqrt{2\sqrt{2}} > \sqrt{2} = x_1$（因 $2\sqrt{2} > 2$，$\sqrt{2\sqrt{2}} > \sqrt{2}$）。

一般性：$x_{n+1}^2 = 2x_n$，$x_n^2 = 2x_{n-1}$。$x_{n+1}^2 - x_n^2 = 2(x_n - x_{n-1})$。$x_n$ 单调增可归纳。

**求极限**：$L = \sqrt{2L}$，$L^2 = 2L$，$L = 2$（$L = 0$ 舍去）。

**答案**：$2$

---

#### 题 3 【进阶 — 含分数型】

设 $x_1 = 1$，$x_{n+1} = 1 + \dfrac{1}{1 + x_n}$。证明收敛并求极限。

**解法**：

**有界**：$x_n > 0$ 显然，$x_{n+1} = 1 + \frac{1}{1+x_n} < 1 + 1 = 2$。

**单调性需分析**：计算 $x_1=1$，$x_2=3/2$，$x_3=1+1/(5/2)=7/5$，$x_4=1+1/(12/5)=17/12$。

观察：$x_1 < x_3 < \cdots$（奇子列递增），$x_2 > x_4 > \cdots$（偶子列递减）。但此处可化简：设 $L = 1 + \frac{1}{1+L}$，$L(1+L) = 1+L+1$，$L^2 = 2$，$L = \sqrt{2}$。

更简单的做法：注意到 $x_{n+1} = \frac{2+x_n}{1+x_n}$，作函数 $f(x) = \frac{2+x}{1+x}$。$f'(x) = -\frac{1}{(1+x)^2} < 0$，$f$ 单调递减。由压缩映射原理或累次代入可证收敛于 $\sqrt{2}$。

**答案**：$\sqrt{2}$

---

### 题型二：数学归纳证有界 + 函数单调证数列单调

#### 题 4 【进阶】

设 $x_1 = 1$，$x_{n+1} = \dfrac{x_n}{2} + \dfrac{1}{x_n}$。证明收敛并求极限。

**解法**：

**有界性**：$x_{n+1} = \frac{x_n}{2} + \frac{1}{x_n} \geq 2\sqrt{\frac{x_n}{2} \cdot \frac{1}{x_n}} = \sqrt{2}$（基本不等式）。下界 $\sqrt{2}$ 对一切 $n \geq 2$ 成立。

**单调性**（$n \geq 2$）：$x_{n+1} - x_n = \frac{1}{x_n} - \frac{x_n}{2} = \frac{2-x_n^2}{2x_n} \leq 0$（因 $x_n \geq \sqrt{2}$）。故从 $n=2$ 起单调递减。

**求极限**：$L = \frac{L}{2} + \frac{1}{L}$，$\frac{L}{2} = \frac{1}{L}$，$L^2 = 2$，$L = \sqrt{2}$。

> 💡 本题 $f(x) = x/2 + 1/x$，是 Newton 迭代求 $\sqrt{2}$ 的经典形式。

**答案**：$\sqrt{2}$

---

### 题型三：先证有界再证单调 — 有界 $\to$ 单调

#### 题 5 【困难】

设 $x_1 = 1$，$x_{n+1} = \sin x_n$。证明收敛并求极限。

**解法**：

**有界性**：$0 < x_n \leq 1$（归纳）。$\sin x \in (0,1]$ 当 $x \in (0,1]$ 时成立。

**单调性**：$\sin x < x$（$x > 0$），故 $x_{n+1} = \sin x_n < x_n$。$\{x_n\}$ 严格递减。

**求极限**：极限 $L$ 满足 $L = \sin L$。$\sin x = x$ 的唯一非零解在 $x=0$（$\sin x < x$ 当 $x > 0$）。故 $L = 0$。

**答案**：$0$

## 三、常见递推形式速查

| 递推形式 | 不动点方程 | 常见极限 |
| :--- | :--- | :--- |
| $x_{n+1} = \sqrt{a + x_n}$ | $L^2 = a + L$ | $(1+\sqrt{1+4a})/2$ |
| $x_{n+1} = \sqrt{a x_n}$ | $L^2 = aL$ | $a$（$a>0$） |
| $x_{n+1} = \frac{x_n}{2} + \frac{a}{2x_n}$ | $L = L/2 + a/(2L)$ | $\sqrt{a}$ |
| $x_{n+1} = \frac{a + x_n}{1 + x_n}$ | $L(1+L) = a + L$ | $\sqrt{a}$ 或 $-\sqrt{a}$ |
| $x_{n+1} = \sin x_n$ | $L = \sin L$ | $0$ |

## 四、自测练习

### 练习 1
设 $x_1 = 1$，$x_{n+1} = \dfrac{3(1+x_n)}{3+x_n}$。证明收敛并求极限。

### 练习 2
设 $x_1 = 2$，$x_{n+1} = \dfrac{1}{2}\!\left(x_n + \dfrac{2}{x_n}\right)$。证明收敛并求极限。

### 练习 3
设 $x_1 = 1$，$x_{n+1} = 1 + \dfrac{x_n}{1+x_n}$。证明收敛并求极限。

### 练习 4
设 $x_1 = \dfrac{\pi}{2}$，$x_{n+1} = \cos x_n$。证明收敛并求极限。

---

## 五、答案

**练习 1**：$L = \frac{3(1+L)}{3+L} \Rightarrow L^2 = 3 \Rightarrow L = \sqrt{3}$。

**练习 2**：Newton 迭代求 $\sqrt{2}$，$L = \sqrt{2}$。

**练习 3**：$L = 1 + \frac{L}{1+L} \Rightarrow L^2 - L - 1 = 0 \Rightarrow L = \frac{1+\sqrt{5}}{2}$（黄金比例）。

**练习 4**：$\cos x < x$（$x > 0$），递减有下界 $0$。$L = \cos L$，唯一解 $L \approx 0.739$（Dottie 数），考研中通常只要求证收敛，不需求精确值。
