## 一、核心定义

### 1.1 数列极限 — $\varepsilon$-$N$ 定义

> **定义**：设 $\{x_n\}$ 为一数列，$a$ 为常数。若对于任意给定的正数 $\varepsilon$（无论多么小），总存在正整数 $N$，使得当 $n > N$ 时，恒有 $|x_n - a| < \varepsilon$，则称 $a$ 为数列 $\{x_n\}$ 的极限，记作
> $$\lim_{n\to\infty} x_n = a \quad \text{或} \quad x_n \to a\;(n\to\infty)$$
> 此时称数列 $\{x_n\}$ **收敛**于 $a$；否则称数列**发散**。

**逻辑符号表述**：

$$\lim_{n\to\infty} x_n = a \;\Longleftrightarrow\; \forall\varepsilon>0,\; \exists N\in\mathbb{N}^+,\; \forall n>N:\; |x_n-a|<\varepsilon$$

**定义的三要素**（按量词顺序理解）：

| 量词 | 含义 | 关键洞察 |
| :--- | :--- | :--- |
| $\forall\varepsilon>0$ | 误差可以任意小 | $\varepsilon$ 是**由对方（质疑者）任意给定**的，不是你能选的 |
| $\exists N\in\mathbb{N}^+$ | 存在一个阈值 $N$ | $N$ 是**你（证明者）找到**的，通常 $N = N(\varepsilon)$，依赖 $\varepsilon$ |
| $\forall n>N$ | 第 $N$ 项之后的所有项 | 只有**有限项**（前 $N$ 项）可能不满足误差要求 |

> ⚠️ **常见误区**：$N$ 是 $\varepsilon$ 的函数（$\varepsilon$ 越小 → $N$ 越大），但 $N$ 不唯一——任何比找到的 $N$ 更大的正整数都可以当 $N$。

**几何意义**：对于任意给定的 $\varepsilon$ 邻域 $(a-\varepsilon, a+\varepsilon)$，数列至多只有**有限项**（前 $N$ 项）落在该邻域之外，从第 $N+1$ 项起全部落入邻域内。

```
                    a-ε        a        a+ε
                     |         |         |
    x₁ x₃  x₂  ...  |  x_{N+1} x_{N+2} ... → 全部在此区间内
    (有限项在外面)    |     (无限项在内部)
```

**数列发散的精确定义**：

$$\lim_{n\to\infty} x_n \neq a \;\Longleftrightarrow\; \exists\varepsilon_0>0,\; \forall N\in\mathbb{N}^+,\; \exists n>N:\; |x_n-a| \geq \varepsilon_0$$

**无界即发散**：若无界，则必发散（但发散不一定无界，如 $x_n = (-1)^n$）。

### 1.2 函数极限 — $\varepsilon$-$\delta$ 定义

函数极限共有**六种**情况，按自变量趋向分为两大类：

#### 第一类：$x \to x_0$（自变量趋于有限值）

| 极限类型 | 精确定义 | 逻辑表述 |
| :--- | :--- | :--- |
| $\displaystyle\lim_{x\to x_0}f(x)=A$ | $\forall\varepsilon>0,\;\exists\delta>0$，当 $0<|x-x_0|<\delta$ 时，$|f(x)-A|<\varepsilon$ | 双侧极限 |
| $\displaystyle\lim_{x\to x_0^+}f(x)=A$ | $\forall\varepsilon>0,\;\exists\delta>0$，当 $0<x-x_0<\delta$ 时，$|f(x)-A|<\varepsilon$ | 右极限 |
| $\displaystyle\lim_{x\to x_0^-}f(x)=A$ | $\forall\varepsilon>0,\;\exists\delta>0$，当 $-\delta<x-x_0<0$ 时，$|f(x)-A|<\varepsilon$ | 左极限 |

> **关键细节**：$0<|x-x_0|<\delta$ 中的 $0<$ 表示**不要求 $f(x_0)$ 有定义**，极限与函数在 $x_0$ 处的值无关。

**左右极限与双侧极限的关系**：

$$\lim_{x\to x_0}f(x)=A \;\Longleftrightarrow\; \lim_{x\to x_0^+}f(x) = \lim_{x\to x_0^-}f(x) = A$$

即双侧极限存在 ⟺ 左右极限均存在且相等。

#### 第二类：$x \to \infty$（自变量趋于无穷）

| 极限类型 | 精确定义 | 逻辑表述 |
| :--- | :--- | :--- |
| $\displaystyle\lim_{x\to +\infty}f(x)=A$ | $\forall\varepsilon>0,\;\exists X>0$，当 $x>X$ 时，$|f(x)-A|<\varepsilon$ | 用 $X$ 而非 $\delta$ |
| $\displaystyle\lim_{x\to -\infty}f(x)=A$ | $\forall\varepsilon>0,\;\exists X>0$，当 $x<-X$ 时，$|f(x)-A|<\varepsilon$ | — |
| $\displaystyle\lim_{x\to \infty}f(x)=A$ | $\forall\varepsilon>0,\;\exists X>0$，当 $|x|>X$ 时，$|f(x)-A|<\varepsilon$ | $x\to\infty$ 即 $|x|\to+\infty$ |

#### 汇总对照表

| 趋向 | 邻域类型 | 存在性参数 | 条件不等式 |
| :--- | :--- | :---: | :--- |
| $x\to x_0$ | 去心 $\delta$ 邻域 | $\delta$ | $0<|x-x_0|<\delta$ |
| $x\to x_0^+$ | 右半 $\delta$ 邻域 | $\delta$ | $0<x-x_0<\delta$ |
| $x\to x_0^-$ | 左半 $\delta$ 邻域 | $\delta$ | $-\delta<x-x_0<0$ |
| $x\to +\infty$ | 正无穷邻域 | $X$ | $x>X$ |
| $x\to -\infty$ | 负无穷邻域 | $X$ | $x<-X$ |
| $x\to \infty$ | 无穷远邻域 | $X$ | $|x|>X$ |

---

### 1.3 无穷小与无穷大的精确定义

**无穷小**：
$$\lim f(x)=0 \;\Longleftrightarrow\; \forall\varepsilon>0,\;\exists\delta>0,\; \text{当 }0<|x-x_0|<\delta \text{ 时},\; |f(x)|<\varepsilon$$

**无穷大**（以 $x\to x_0$ 为例）：
$$\lim_{x\to x_0} f(x)=\infty \;\Longleftrightarrow\; \forall M>0,\;\exists\delta>0,\; \text{当 }0<|x-x_0|<\delta \text{ 时},\; |f(x)|>M$$

| 类型 | 量词变化 | 不等式方向 |
| :--- | :--- | :--- |
| 无穷小 | $\forall\varepsilon>0$ | $|f(x)|<\varepsilon$ |
| 正无穷大 | $\forall M>0$ | $f(x)>M$ |
| 负无穷大 | $\forall M>0$ | $f(x)<-M$ |
| 无穷大 | $\forall M>0$ | $|f(x)|>M$ |

---

### 1.4 极限的基本性质（可由定义证明）

| 性质 | 内容 | 适用条件 |
| :--- | :--- | :--- |
| **唯一性** | 若极限存在，则极限值唯一 | 所有收敛情形 |
| **局部有界性** | 若 $\lim_{x\to x_0}f(x)=A$，则 $\exists\delta>0, M>0$，使 $0<|x-x_0|<\delta$ 时 $|f(x)|\leq M$ | $x\to x_0$ 型 |
| **局部保号性** | 若 $\lim_{x\to x_0}f(x)=A>0$，则 $\exists\delta>0$，使 $0<|x-x_0|<\delta$ 时 $f(x)>0$ | $x\to x_0$ 型 |
| **保序性** | 若 $\lim f(x)=A$，$\lim g(x)=B$，且 $A<B$，则在某去心邻域内 $f(x)<g(x)$ | — |
| **迫敛性** | 若 $g(x)\leq f(x)\leq h(x)$ 且 $\lim g=\lim h=A$，则 $\lim f=A$ | 即夹逼准则 |

## 二、题型分类与精析

### 题型 1：用 $\varepsilon$-$N$ 定义证明数列极限

#### 例题 1（基础）— 证明 $\displaystyle\lim_{n\to\infty}\frac{1}{n}=0$

**思路溯源**：
1. 目标：对 $\forall\varepsilon>0$，找到 $N$ 使 $n>N$ 时 $|\frac{1}{n}-0|<\varepsilon$
2. 从目标不等式反解 $N$：$|\frac{1}{n}|<\varepsilon \iff n>\frac{1}{\varepsilon}$
3. 取 $N = \left[\frac{1}{\varepsilon}\right] + 1$（取整加一确保 $N\in\mathbb{N}^+$ 且 $N > \frac{1}{\varepsilon}$）
4. 验证：当 $n>N$ 时，$n>\frac{1}{\varepsilon}$，故 $|\frac{1}{n}|<\varepsilon$ ✓

**解法**：

$\forall\varepsilon>0$，取 $N = \left[\frac{1}{\varepsilon}\right] + 1$。

当 $n > N$ 时，有 $n > \frac{1}{\varepsilon}$，故
$$\left|\frac{1}{n} - 0\right| = \frac{1}{n} < \varepsilon$$

由数列极限的 $\varepsilon$-$N$ 定义，$\displaystyle\lim_{n\to\infty}\frac{1}{n}=0$。$\quad\square$

---

#### 例题 2（基础）— 证明 $\displaystyle\lim_{n\to\infty}\frac{n}{n+1}=1$

**思路溯源**：
1. $|\frac{n}{n+1} - 1| = |\frac{-1}{n+1}| = \frac{1}{n+1}$
2. 放缩：$\frac{1}{n+1} < \frac{1}{n}$，只需 $\frac{1}{n}<\varepsilon$，即 $n>\frac{1}{\varepsilon}$

**解法**：

$\forall\varepsilon>0$，取 $N = \left[\frac{1}{\varepsilon}\right] + 1$。

当 $n > N$ 时，
$$\left|\frac{n}{n+1} - 1\right| = \left|\frac{n - (n+1)}{n+1}\right| = \frac{1}{n+1} < \frac{1}{n} < \varepsilon$$

故 $\displaystyle\lim_{n\to\infty}\frac{n}{n+1}=1$。$\quad\square$

---

#### 例题 3（进阶）— 证明 $\displaystyle\lim_{n\to\infty}\frac{2n^2+1}{n^2+n}=2$

**思路溯源**：
1. 目标表达式：$\left|\frac{2n^2+1}{n^2+n} - 2\right| = \left|\frac{2n^2+1 - 2n^2 - 2n}{n^2+n}\right| = \frac{|1-2n|}{n^2+n}$
2. 当 $n$ 充分大时（$n>1$），$|1-2n| = 2n-1 < 2n$，分母 $n^2+n > n^2$
3. 放缩：$\frac{|1-2n|}{n^2+n} < \frac{2n}{n^2} = \frac{2}{n}$
4. 只需 $\frac{2}{n}<\varepsilon$，即 $n>\frac{2}{\varepsilon}$

**解法**：

$\forall\varepsilon>0$，取 $N = \max\left\{\left[\frac{2}{\varepsilon}\right] + 1,\; 1\right\}$。

当 $n > N$ 时（此时 $n>1$），
$$\left|\frac{2n^2+1}{n^2+n} - 2\right| = \frac{|1-2n|}{n^2+n} = \frac{2n-1}{n^2+n} < \frac{2n}{n^2} = \frac{2}{n} < \varepsilon$$

故 $\displaystyle\lim_{n\to\infty}\frac{2n^2+1}{n^2+n}=2$。$\quad\square$

---

#### 例题 4（进阶）— 证明 $\displaystyle\lim_{n\to\infty} q^n = 0\;(|q|<1)$

**思路溯源**：
1. 目标：$|q^n - 0| = |q|^n < \varepsilon$
2. 取对数：$n\ln|q| < \ln\varepsilon$。注意 $|q|<1$ 时 $\ln|q| < 0$，不等式方向要反转
3. $n > \frac{\ln\varepsilon}{\ln|q|}$（因为除以负数）
4. 为免负号混乱，令 $h = \frac{1}{|q|} > 1$，则 $|q|^n = \frac{1}{h^n}$，只需 $h^n > \frac{1}{\varepsilon}$

**解法**：

$q=0$ 时显然成立。设 $0<|q|<1$，令 $h = \frac{1}{|q|} > 1$，记 $h = 1 + \lambda$（$\lambda > 0$）。

由二项式展开：$h^n = (1+\lambda)^n \geq 1 + n\lambda > n\lambda$

对于 $\forall\varepsilon>0$，取 $N = \left[\frac{1}{\lambda\varepsilon}\right] + 1$。

当 $n > N$ 时，
$$|q^n - 0| = |q|^n = \frac{1}{h^n} < \frac{1}{n\lambda} < \varepsilon$$

故 $\displaystyle\lim_{n\to\infty}q^n = 0\;(|q|<1)$。$\quad\square$

### 题型 2：用 $\varepsilon$-$\delta$ 定义证明函数极限

#### 例题 5（基础）— 证明 $\displaystyle\lim_{x\to 1}(2x+1)=3$

**思路溯源**：
1. $|(2x+1)-3| = |2x-2| = 2|x-1|$
2. 需 $2|x-1|<\varepsilon$，即 $|x-1|<\frac{\varepsilon}{2}$
3. 取 $\delta = \frac{\varepsilon}{2}$

**解法**：

$\forall\varepsilon>0$，取 $\delta = \frac{\varepsilon}{2}$。

当 $0 < |x-1| < \delta$ 时，
$$|(2x+1) - 3| = |2x-2| = 2|x-1| < 2\cdot\frac{\varepsilon}{2} = \varepsilon$$

故 $\displaystyle\lim_{x\to 1}(2x+1)=3$。$\quad\square$

---

#### 例题 6（基础）— 证明 $\displaystyle\lim_{x\to 2}x^2 = 4$

**思路溯源**：
1. $|x^2-4| = |x-2|\cdot|x+2|$
2. $|x+2|$ 在 $x\to 2$ 附近大约为 $4$，需限制 $|x-2|$ 的范围以控制 $|x+2|$
3. 先限制 $\delta \leq 1$，则 $|x-2|<1 \implies 1<x<3 \implies 3<x+2<5 \implies |x+2|<5$
4. 在 $\delta\leq 1$ 约束下，$|x^2-4| < 5|x-2|$，需 $5|x-2|<\varepsilon$，即 $|x-2|<\frac{\varepsilon}{5}$
5. 取 $\delta = \min\{1,\frac{\varepsilon}{5}\}$（同时满足两个约束）

**解法**：

$\forall\varepsilon>0$，取 $\delta = \min\left\{1,\;\frac{\varepsilon}{5}\right\}$。

当 $0 < |x-2| < \delta$ 时：
- 由 $\delta \leq 1$ 知 $|x-2|<1$，故 $1<x<3$，于是 $|x+2| < 5$；
- 由 $\delta \leq \frac{\varepsilon}{5}$ 知 $|x-2| < \frac{\varepsilon}{5}$。

从而
$$|x^2 - 4| = |x-2|\cdot|x+2| < \frac{\varepsilon}{5}\cdot 5 = \varepsilon$$

故 $\displaystyle\lim_{x\to 2}x^2 = 4$。$\quad\square$

> ⚠️ **核心技巧**：当目标表达式含 $|x-x_0|$ 与另一因子的乘积时，先限制 $|x-x_0|$ 的范围（如 $\delta\leq 1$），**锁定**另一因子的上界，再将 $|x-x_0|$ 缩小到满足 $\varepsilon$ 要求。最终 $\delta$ 取两者的最小值。

---

#### 例题 7（进阶）— 证明 $\displaystyle\lim_{x\to 0}x\sin\frac{1}{x}=0$

**思路溯源**：
1. $|x\sin\frac{1}{x} - 0| = |x|\cdot|\sin\frac{1}{x}| \leq |x|$（因为 $|\sin(\cdot)|\leq 1$）
2. 只需 $|x|<\varepsilon$，取 $\delta=\varepsilon$ 即可
3. 此题特殊之处：不需求 $|\sin\frac{1}{x}|$ 的精确值，直接放大到 $1$

**解法**：

$\forall\varepsilon>0$，取 $\delta = \varepsilon$。

当 $0 < |x-0| < \delta$ 时，
$$\left|x\sin\frac{1}{x} - 0\right| = |x|\cdot\left|\sin\frac{1}{x}\right| \leq |x| < \varepsilon$$

故 $\displaystyle\lim_{x\to 0}x\sin\frac{1}{x}=0$。$\quad\square$

---

#### 例题 8（综合）— 证明 $\displaystyle\lim_{x\to 0}\frac{\sqrt{1+x}-1}{x}=\frac{1}{2}$

**思路溯源**：
1. 分子有理化：$\frac{\sqrt{1+x}-1}{x} = \frac{(1+x)-1}{x(\sqrt{1+x}+1)} = \frac{1}{\sqrt{1+x}+1}$
2. 目标：$\left|\frac{1}{\sqrt{1+x}+1} - \frac{1}{2}\right| = \frac{|1-\sqrt{1+x}|}{2(\sqrt{1+x}+1)}$
3. $|1-\sqrt{1+x}| = \left|\frac{(1-\sqrt{1+x})(1+\sqrt{1+x})}{1+\sqrt{1+x}}\right| = \frac{|x|}{1+\sqrt{1+x}}$
4. 代入：$= \frac{|x|}{2(\sqrt{1+x}+1)(1+\sqrt{1+x})}$
5. 限制 $|x|<1$：此时 $0<\sqrt{1+x}<\sqrt{2}$，分母 $>2\cdot 1\cdot 1 = 2$
6. 放缩：$< \frac{|x|}{2}$，只需 $|x|<2\varepsilon$，取 $\delta = \min\{1, 2\varepsilon\}$

**解法**：

$\forall\varepsilon>0$，取 $\delta = \min\{1,\;2\varepsilon\}$。

当 $0<|x|<\delta$ 时（此时 $|x|<1$，故 $0<\sqrt{1+x}<\sqrt{2}$，从而 $\sqrt{1+x}+1>1$）：

$$\left|\frac{\sqrt{1+x}-1}{x} - \frac{1}{2}\right| = \left|\frac{1}{\sqrt{1+x}+1} - \frac{1}{2}\right| = \frac{|1-\sqrt{1+x}|}{2(\sqrt{1+x}+1)}$$

$$= \frac{|x|}{2(\sqrt{1+x}+1)(1+\sqrt{1+x})} < \frac{|x|}{2\cdot 1\cdot 1} = \frac{|x|}{2} < \frac{2\varepsilon}{2} = \varepsilon$$

故 $\displaystyle\lim_{x\to 0}\frac{\sqrt{1+x}-1}{x}=\frac{1}{2}$。$\quad\square$

### 题型 3：用定义证明极限不存在

#### 例题 9 — 证明 $\displaystyle\lim_{x\to 0}\sin\frac{1}{x}$ 不存在

**思路溯源**：
利用海涅定理（归结原则）：$\lim_{x\to 0}f(x)$ 存在 ⟺ 对任意趋于 $0$ 的数列 $\{x_n\}$，$\lim_{n\to\infty}f(x_n)$ 存在且相等。取两个趋于 $0$ 但 $f$ 值不同的子列即可。

**解法**：

取 $x_n = \frac{1}{2n\pi}$，则 $x_n \to 0$（$n\to\infty$），$\sin\frac{1}{x_n} = \sin(2n\pi) = 0 \to 0$。

取 $y_n = \frac{1}{2n\pi + \frac{\pi}{2}}$，则 $y_n \to 0$（$n\to\infty$），$\sin\frac{1}{y_n} = \sin\left(2n\pi + \frac{\pi}{2}\right) = 1 \to 1$。

两子列趋于不同极限（$0 \neq 1$），由海涅定理，$\displaystyle\lim_{x\to 0}\sin\frac{1}{x}$ 不存在。$\quad\square$

### 题型 4：用定义证明极限性质

#### 例题 10 — 证明极限的唯一性

**命题**：若 $\displaystyle\lim_{n\to\infty}x_n = a$ 且 $\displaystyle\lim_{n\to\infty}x_n = b$，则 $a = b$。

**思路溯源**：
反证法。假设 $a \neq b$，取 $\varepsilon = \frac{|a-b|}{2} > 0$。若 $|x_n-a|<\varepsilon$ 且 $|x_n-b|<\varepsilon$，则 $x_n$ 同时在 $a$ 和 $b$ 的 $\varepsilon$ 邻域内——但这两个邻域不相交（因为 $\varepsilon = |a-b|/2$）。矛盾。

**解法**：

假设 $a \neq b$，则 $|a-b| > 0$。取 $\varepsilon_0 = \frac{|a-b|}{2} > 0$。

由 $\lim x_n = a$，$\exists N_1$，当 $n>N_1$ 时 $|x_n-a| < \varepsilon_0$。

由 $\lim x_n = b$，$\exists N_2$，当 $n>N_2$ 时 $|x_n-b| < \varepsilon_0$。

取 $N = \max\{N_1, N_2\}$，当 $n > N$ 时两不等式同时成立。于是：
$$|a-b| = |(a-x_n) + (x_n-b)| \leq |x_n-a| + |x_n-b| < 2\varepsilon_0 = |a-b|$$

推得 $|a-b| < |a-b|$，矛盾。故 $a = b$。$\quad\square$

## 三、方法总结表

### 3.1 证明极限存在的通用流程

| 步骤 | $\varepsilon$-$N$（数列） | $\varepsilon$-$\delta$（函数） |
| :---: | :--- | :--- |
| ① | 写出 $|x_n - a|$ | 写出 $|f(x) - A|$ |
| ② | 化简、放大（使表达式更简单） | 化简、放大 |
| ③ | 解不等式 $|x_n-a|<\varepsilon$ 推出 $n > g(\varepsilon)$ | 尝试提取 $|x-x_0|$ 因子，其余部分用 $\delta$ 限制 |
| ④ | 取 $N = [g(\varepsilon)] + 1$ | 限制 $|x-x_0|<1$（或其他常数），将其他因子放大为常数 $M$ |
| ⑤ | 验证 $n>N \implies |x_n-a|<\varepsilon$ | 令 $\delta = \min\{1,\; \varepsilon/M\}$，验证 |
| ⑥ | 结论：由定义，极限成立 | 结论：由定义，极限成立 |

### 3.2 常见放缩技巧

| 目标形式 | 放缩手段 | 示例 |
| :--- | :--- | :--- |
| 分式放大 | 分母变小、分子变大 | $\frac{n+1}{n^2+1} < \frac{2n}{n^2} = \frac{2}{n}$（$n>1$ 时） |
| 根式处理 | 有理化（分子/分母） | $|\sqrt{n+1}-\sqrt{n}| = \frac{1}{\sqrt{n+1}+\sqrt{n}} < \frac{1}{2\sqrt{n}}$ |
| $|q|^n$ 型 | 利用 $(1+\lambda)^n \geq 1+n\lambda$ | $|q|^n < \frac{1}{n\lambda}$ |
| 含 $\sin/\cos$ | $|\sin(\cdot)|\leq 1$，$|\cos(\cdot)|\leq 1$ | $|x\sin\frac{1}{x}|\leq |x|$ |
| 含 $(1+x)^\alpha-1$ | 先有理化或利用等价无穷小思想 | 见例题 8 |

### 3.3 极限不存在的证明方法

| 方法 | 适用场景 | 操作 |
| :--- | :--- | :--- |
| **海涅定理（归结原则）** | 函数极限（尤其含 $\sin\frac{1}{x}$ 型） | 取两个趋于 $x_0$ 的数列，若函数值趋于不同极限，则原极限不存在 |
| **左右极限不相等** | $x\to x_0$ 型分段函数 | 分别求左右极限，若不相等则不存在 |
| **子列发散/趋于不同极限** | 数列 | 取两个子列，若趋于不同极限或发散，则原数列发散 |
| **无界性** | 数列/函数 | 若能证明无界，则极限不存在（发散） |

## 四、自测练习

**A 组 — 用 $\varepsilon$-$N$ 定义证明数列极限**

1. $\displaystyle\lim_{n\to\infty}\frac{3n-1}{2n+5} = \frac{3}{2}$

2. $\displaystyle\lim_{n\to\infty}\frac{\sqrt{n^2+1}}{n} = 1$

3. $\displaystyle\lim_{n\to\infty}\frac{\sin n}{n} = 0$

**B 组 — 用 $\varepsilon$-$\delta$ 定义证明函数极限**

4. $\displaystyle\lim_{x\to 3}(x^2 - 2x + 1) = 4$

5. $\displaystyle\lim_{x\to 0}\frac{x^2}{1+x^2} = 0$

6. $\displaystyle\lim_{x\to 1}\frac{x^2-1}{x-1} = 2$（注意：$x=1$ 不在定义域内）

**C 组 — 证明极限不存在**

7. 证明 $\displaystyle\lim_{x\to 0}\frac{|x|}{x}$ 不存在

8. 讨论数列 $x_n = (-1)^n + \frac{1}{n}$ 的敛散性，并用定义证明

**D 组 — 概念辨析**

9. 判断正误：若 $\forall\varepsilon>0$，总存在有限个 $n$ 使得 $|x_n-a|\geq\varepsilon$，则 $\lim x_n = a$。

10. 判断正误：「$\forall\varepsilon>0, \exists N>0$，当 $n>N$ 时 $|x_n-a|<2\varepsilon$」可以作为 $\lim x_n=a$ 的等价定义。

---

## 五、答案

### A 组

**1.** $|\frac{3n-1}{2n+5}-\frac{3}{2}| = |\frac{6n-2-6n-15}{2(2n+5)}| = \frac{17}{2(2n+5)} < \frac{17}{4n}$（$n\geq 1$ 时 $2n+5>n$）。取 $N=[\frac{17}{4\varepsilon}]+1$。

**2.** $|\frac{\sqrt{n^2+1}}{n}-1| = \frac{\sqrt{n^2+1}-n}{n} = \frac{1}{n(\sqrt{n^2+1}+n)}$。由于 $\sqrt{n^2+1}+n > 1$，故 $\frac{1}{n(\sqrt{n^2+1}+n)} < \frac{1}{n}$。取 $N=[\frac{1}{\varepsilon}]+1$ 即可。

**3.** $|\frac{\sin n}{n}| \leq \frac{1}{n} < \varepsilon$，取 $N=[\frac{1}{\varepsilon}]+1$。

### B 组

**4.** $|(x^2-2x+1)-4| = |x^2-2x-3| = |x-3|\cdot|x+1|$。限制 $|x-3|<1 \implies 2<x<4 \implies 3<x+1<5$，故 $|x+1|<5$。取 $\delta=\min\{1,\frac{\varepsilon}{5}\}$。

**5.** $|\frac{x^2}{1+x^2}| = \frac{x^2}{1+x^2} \leq x^2 < \varepsilon$（$|x|<\sqrt{\varepsilon}$）。取 $\delta=\sqrt{\varepsilon}$。

**6.** 当 $x\neq 1$ 时 $\frac{x^2-1}{x-1}=x+1$。$|(x+1)-2| = |x-1| < \varepsilon$，取 $\delta=\varepsilon$。

### C 组

**7.** $\lim_{x\to 0^+}\frac{|x|}{x} = \lim_{x\to 0^+}\frac{x}{x}=1$，$\lim_{x\to 0^-}\frac{|x|}{x} = \lim_{x\to 0^-}\frac{-x}{x}=-1$。左右极限不相等，故极限不存在。

**8.** 取子列 $x_{2k} = 1 + \frac{1}{2k} \to 1$，$x_{2k-1} = -1 + \frac{1}{2k-1} \to -1$。两子列趋于不同极限，故数列发散。

### D 组

**9.** ✅ 正确。「总存在有限个 $n$ 使得 $|x_n-a|\geq\varepsilon$」等价于「存在 $N$，当 $n>N$ 时 $|x_n-a|<\varepsilon$」。因为 $\varepsilon$ 是任意给定的，有限个超出范围的项可以取最大的一个作为 $N$。

**10.** ✅ 正确。令 $\varepsilon' = 2\varepsilon$，则条件变为 $\forall\varepsilon'>0, \exists N>0$，当 $n>N$ 时 $|x_n-a|<\varepsilon'$，这正是原始定义的写法（$\varepsilon$ 只是一个记号，$2\varepsilon$ 仍然是任意正数）。
