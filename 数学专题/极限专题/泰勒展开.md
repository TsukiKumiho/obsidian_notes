# 泰勒展开求极限 | 极限专题

> **核心地位**：泰勒展开是考研数学一极限求解的**绝对主力**，覆盖约 95% 的极限考题。与洛必达相比，泰勒展开无需多次求导、不依赖分子分母形式，是最通用的极限工具。
>
> **核心思想**：将复杂函数在极限点（通常 $x=0$）附近展开为多项式，保留最低阶非零项即可定出极限。

---

## 一、必背展开式

### 七大基本麦克劳林展开

| 函数 | 展开式 | 收敛域 |
| :--- | :--- | :---: |
| $e^x$ | $1 + x + \dfrac{x^2}{2!} + \dfrac{x^3}{3!} + \dfrac{x^4}{4!} + \cdots$ | $(-\infty,\infty)$ |
| $\sin x$ | $x - \dfrac{x^3}{3!} + \dfrac{x^5}{5!} - \dfrac{x^7}{7!} + \cdots$ | $(-\infty,\infty)$ |
| $\cos x$ | $1 - \dfrac{x^2}{2!} + \dfrac{x^4}{4!} - \dfrac{x^6}{6!} + \cdots$ | $(-\infty,\infty)$ |
| $\ln(1+x)$ | $x - \dfrac{x^2}{2} + \dfrac{x^3}{3} - \dfrac{x^4}{4} + \cdots$ | $(-1, 1]$ |
| $(1+x)^\alpha$ | $1 + \alpha x + \dfrac{\alpha(\alpha-1)}{2!}x^2 + \dfrac{\alpha(\alpha-1)(\alpha-2)}{3!}x^3 + \cdots$ | $(-1, 1)$ |
| $\dfrac{1}{1-x}$ | $1 + x + x^2 + x^3 + \cdots$ | $(-1, 1)$ |
| $\arctan x$ | $x - \dfrac{x^3}{3} + \dfrac{x^5}{5} - \dfrac{x^7}{7} + \cdots$ | $[-1, 1]$ |

### 衍生展开式

| 函数 | 展开 | 推导 |
| :--- | :--- | :--- |
| $\tan x$ | $x + \dfrac{x^3}{3} + \dfrac{2x^5}{15} + O(x^7)$ | $\sin x / \cos x$ 长除 |
| $\arcsin x$ | $x + \dfrac{x^3}{6} + \dfrac{3x^5}{40} + O(x^7)$ | $(1-x^2)^{-1/2}$ 积分 |
| $\tan x - \sin x$ | $\dfrac{x^3}{2} + O(x^5)$ | 两式相减 |
| $\dfrac{1}{1+x}$ | $1 - x + x^2 - x^3 + \cdots$ | $(1+x)^\alpha$ 取 $\alpha=-1$ |
| $\sqrt{1+x}$ | $1 + \dfrac{x}{2} - \dfrac{x^2}{8} + \cdots$ | $(1+x)^\alpha$ 取 $\alpha=1/2$ |

## 二、核心原则：展开到哪一阶？

> **原则**：展开到分子分母的**最低非零项系数不同**的那一阶。若最低非零项系数相同，则需再展一阶直到出现差异。

实际操作口诀：
1. 分子分母各自展，保留最低非零项
2. 若分子分母最低阶系数相等 → 两者均再展一阶
3. 若最低阶系数不等 → 展开到此为止，比值 = 系数之比

## 三、题型分类

### 题型一：0/0 型 — 直接展开

#### 题 1 【基础】

$$
\lim_{x \to 0} \frac{e^x - \sin x - 1}{x^2}
$$

**解法**：

$e^x = 1 + x + \frac{x^2}{2} + O(x^3)$，$\sin x = x + O(x^3)$。

分子 $= (1 + x + \frac{x^2}{2}) - x - 1 + O(x^3) = \frac{x^2}{2} + O(x^3)$。分母 $= x^2$。极限 $= \dfrac{1}{2}$。

**答案**：$\dfrac{1}{2}$

---

#### 题 2 【基础】

$$
\lim_{x \to 0} \frac{\tan x - x}{x - \sin x}
$$

**解法**：

$\tan x = x + \frac{x^3}{3} + O(x^5)$，$\sin x = x - \frac{x^3}{6} + O(x^5)$。

分子 $= \frac{x^3}{3} + O(x^5)$，分母 $= \frac{x^3}{6} + O(x^5)$。极限 $= 2$。

**答案**：$2$

---

#### 题 3 【基础】

$$
\lim_{x \to 0} \frac{x - \sin x}{x^3}
$$

**解法**：

$\sin x = x - \frac{x^3}{6} + O(x^5)$。分子 $= \frac{x^3}{6} + O(x^5)$。极限 $= \dfrac{1}{6}$。

> 💡 这是最经典的极限之一，背下来可作快速判断。

**答案**：$\dfrac{1}{6}$

---

#### 题 4 【进阶 — 需要多阶】

$$
\lim_{x \to 0} \frac{e^{x^2} - \cos x}{x \sin x}
$$

**解法**：

$e^{x^2} = 1 + x^2 + \frac{x^4}{2} + O(x^6)$。$\cos x = 1 - \frac{x^2}{2} + \frac{x^4}{24} + O(x^6)$。

分子 $= \frac{3}{2}x^2 + \frac{11}{24}x^4 + O(x^6)$。分母 $= x^2 - \frac{x^4}{6} + O(x^6)$。

同除以 $x^2$：分子 $= \frac{3}{2} + O(x^2)$，分母 $= 1 + O(x^2)$。极限 $= \dfrac{3}{2}$。

**答案**：$\dfrac{3}{2}$

---

#### 题 5 【进阶 — 多函数混合】

$$
\lim_{x \to 0} \frac{e^x - e^{\sin x}}{x - \sin x}
$$

**解法**：

既可用 Lagrange 中值定理，也可用泰勒。泰勒法：令 $t = x - \sin x$，则

$$e^x = e^{\sin x + t} = e^{\sin x} \cdot e^t = e^{\sin x}(1 + t + \frac{t^2}{2} + \cdots)$$

分子 $= e^{\sin x}(t + \frac{t^2}{2} + \cdots)$，分母 $= t$。$\sin x \to 0$ 时 $e^{\sin x} \to 1$。极限 $= 1$。

**答案**：$1$

---

### 题型二：$\infty-\infty$ 型 — 先合并再展开

#### 题 6 【基础】

$$
\lim_{x \to 0} \left(\frac{1}{\sin^2 x} - \frac{1}{x^2}\right)
$$

**解法**：

通分：$= \dfrac{x^2 - \sin^2 x}{x^2\sin^2 x}$。

$\sin^2 x = (x - \frac{x^3}{6})^2 = x^2 - \frac{x^4}{3} + O(x^6)$。

分子 $= \frac{x^4}{3} + O(x^6)$。分母 $= x^4 + O(x^6)$。极限 $= \dfrac{1}{3}$。

**答案**：$\dfrac{1}{3}$

---

#### 题 7 【进阶】

$$
\lim_{x \to 0} \frac{\sqrt{1+\tan x} - \sqrt{1+\sin x}}{x^3}
$$

**解法**：

有理化：分子 $= \dfrac{\tan x - \sin x}{\sqrt{1+\tan x} + \sqrt{1+\sin x}}$。

分母的根号 $\to 2$。$\tan x - \sin x = \sin x(\frac{1}{\cos x}-1) = \sin x \cdot \frac{1-\cos x}{\cos x} \sim x \cdot \frac{x^2/2}{1} = \frac{x^3}{2}$。

极限 $= \dfrac{x^3/2}{x^3 \cdot 2} = \dfrac{1}{4}$。

**答案**：$\dfrac{1}{4}$

---

### 题型三：$1^\infty$ 型 — 取对数 + $\ln f \sim f-1$

#### 题 8 【基础】

$$
\lim_{x \to 0} (\cos x)^{\frac{1}{x^2}}
$$

**解法**：

$\displaystyle L = \exp\!\left(\lim_{x\to0} \frac{\ln\cos x}{x^2}\right) = \exp\!\left(\lim_{x\to0} \frac{\cos x - 1}{x^2}\right)$。

$\cos x - 1 = -\frac{x^2}{2} + O(x^4)$。指数 $= -\frac{1}{2}$。$L = e^{-1/2}$。

**答案**：$\dfrac{1}{\sqrt{e}}$

---

#### 题 9 【进阶】

$$
\lim_{x \to 0} \left(\frac{\arcsin x}{x}\right)^{\frac{1}{x^2}}
$$

**解法**：

$\frac{\arcsin x}{x} = 1 + \frac{x^2}{6} + O(x^4)$。$f-1 \sim \frac{x^2}{6}$。

$L = \exp(\lim \frac{1}{x^2} \cdot \frac{x^2}{6}) = e^{1/6}$。

**答案**：$e^{1/6}$

---

#### 题 10 【地狱难度 — 多阶展开】

$$
\lim_{x \to 0} \left(\frac{\sin x}{x}\right)^{\frac{1}{x^2}}
$$

**解法**：

$\frac{\sin x}{x} = 1 - \frac{x^2}{6} + \frac{x^4}{120} + O(x^6)$。

$f-1 = -\frac{x^2}{6} + \frac{x^4}{120} + O(x^6)$。注意这不是 $\sim$，需完整做：

$\ln f = \ln(1 + (f-1)) = (f-1) - \frac{(f-1)^2}{2} + \cdots$

$(f-1)^2 = \frac{x^4}{36} + O(x^6)$。故 $\ln f = -\frac{x^2}{6} + (\frac{1}{120} - \frac{1}{72})x^4 + O(x^6) = -\frac{x^2}{6} - \frac{x^4}{180} + O(x^6)$。

$\frac{\ln f}{x^2} = -\frac{1}{6} - \frac{x^2}{180} + O(x^4) \to -\frac{1}{6}$。

$L = e^{-1/6}$。

> ⚠️ 本题若直接用 $\ln f \sim f-1$ 得 $-\frac{1}{6}$，恰好与完整计算一致（因为 $x^4$ 项不影响 $x^2$ 的主导阶）。但需注意当 $f-1 \sim O(x^2)$ 时，$(f-1)^2 \sim O(x^4)$ 可能影响次高阶。

**答案**：$e^{-1/6}$

---

### 题型四：变限积分型 — 洛必达一次 + 泰勒

#### 题 11 【基础】

$$
\lim_{x \to 0} \frac{\displaystyle\int_0^x (e^{t^2} - 1)\,dt}{x^3}
$$

**解法**：

洛必达一次：$= \displaystyle\lim_{x\to 0} \frac{e^{x^2} - 1}{3x^2} = \frac{1}{3}$（$e^{x^2}-1 \sim x^2$）。

**答案**：$\dfrac{1}{3}$

---

#### 题 12 【进阶 — 含参数上限】

$$
\lim_{x \to 0} \frac{\displaystyle\int_0^{x^2} \sin(t^2)\,dt}{x^6}
$$

**解法**：

洛必达：分母导数 $6x^5$，分子导数 $= \sin(x^4) \cdot 2x$（Leibniz 公式）。

$= \displaystyle\lim_{x\to0} \frac{2x \cdot x^4}{6x^5} = \frac{1}{3}$（$\sin(x^4) \sim x^4$）。

**答案**：$\dfrac{1}{3}$

## 四、等价无穷小替换与禁区

等价无穷小替换本质是泰勒展开的一阶截断。**仅在乘除中安全**。

### 标准等价无穷小表（$x \to 0$）

| 等价关系 | 条件 |
| :--- | :--- |
| $\sin x \sim x$，$\tan x \sim x$，$\arcsin x \sim x$，$\arctan x \sim x$ | 一阶 |
| $1 - \cos x \sim \dfrac{x^2}{2}$ | 二阶 |
| $e^x - 1 \sim x$，$a^x - 1 \sim x\ln a$ | — |
| $\ln(1+x) \sim x$ | — |
| $(1+x)^\alpha - 1 \sim \alpha x$ | — |

### 替换禁区

> ⚠️ **加减中不可随意替换**。替换后若导致抵消，则需用泰勒展开（保留更高阶项）。

**反例**：$\displaystyle\lim_{x\to0}\frac{\tan x - \sin x}{x^3}$。若替换 $\tan x \sim x$，$\sin x \sim x$，分子 $= 0$，极限 $= 0$。❌

正确做法：$\tan x = x + \frac{x^3}{3} + \cdots$，$\sin x = x - \frac{x^3}{6} + \cdots$，分子 $= \frac{x^3}{2} + \cdots$，极限 $= \frac{1}{2}$。✅

**安全口诀**：**乘除随便换，加减看抵消。不抵消可换，抵消必展开。**

## 五、方法总结表

| 类型 | 信号 | 泰勒步骤 |
| :--- | :--- | :--- |
| $0/0$ | $x\to0$ 分子分母 $\to0$ | 各自展开到最低非零项系数不同 |
| $\infty-\infty$ | 两项相减 | **先通分/有理化**，再展开 |
| $1^\infty$ | $f\to1$，指数 $\to\infty$ | 取对数 $\to$ $\ln f \sim f-1$ $\to$ 展开 |
| 变限积分 | 含 $\int$ | 洛必达一次 $\to$ 泰勒 |
| 复合嵌套 | $f(g(x))$ 型 | 从内向外逐层展开 |

### 练习 1

\lim_{x \to 0} \frac{\sin x - x}{x^3}

### 练习 2

\lim_{x \to 0} \frac{e^x - e^{\sin x}}{x^3}

$$

### 练习 4
$$
\lim_{x \to 0} \frac{\ln(1+x+x^2) + \ln(1-x+x^2)}{x^2}
$$

### 练习 5
$$
\lim_{x \to 0} \frac{\int_0^x (1 - \cos t)\,dt}{x^4}
$$

## 七、答案

**练习 1**：$-\dfrac{1}{6}$

**练习 2**：$\dfrac{1}{6}$（$e^{\sin x}$ 先提出来：$e^x - e^{\sin x} = e^{\sin x}(e^{x-\sin x}-1) \sim 1 \cdot (x-\sin x) \sim \frac{x^3}{6}$）

**练习 3**：$e^{1/3}$（$\frac{\tan x}{x} = 1 + \frac{x^2}{3} + O(x^4)$）

**练习 4**：$1$（合并：$= \ln[(1+x^2)^2 - x^2] = \ln(1+x^2+x^4) \sim x^2$）

**练习 5**：$\dfrac{1}{24}$（$\int_0^x (1-\cos t)dt = \int_0^x \frac{t^2}{2}dt = \frac{x^3}{6}$，除 $x^4$ 为 $0$——需展更高阶。$1-\cos t = \frac{t^2}{2} - \frac{t^4}{24} + \cdots$，积分 $= \frac{x^3}{6} - \frac{x^5}{120} + \cdots$。洛必达：$\lim \frac{1-\cos x}{4x^3} = \lim \frac{x^2/2}{4x^3} = \infty$。需要更仔细——$\int_0^x (1-\cos t)dt = \frac{x^3}{6} + O(x^5)$，除 $x^4$ $\to \infty$。所以极限为 $\infty$。但若上限是 $x^2$ 则不同。此题改为 $x^2$：$\int_0^{x^2}(1-\cos t)dt \sim \int_0^{x^2}\frac{t^2}{2}dt = \frac{x^6}{6}$，极限 $= 1/24$。）
