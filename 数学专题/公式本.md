# 数学公式本

---

## 反三角函数

### 定义域与值域

| 函数 | 定义域 | 值域 |
|:---|:---|:---|
| $\arcsin x$ | $[-1,1]$ | $[-\frac{\pi}{2},\frac{\pi}{2}]$ |
| $\arccos x$ | $[-1,1]$ | $[0,\pi]$ |
| $\arctan x$ | $\mathbb{R}$ | $(-\frac{\pi}{2},\frac{\pi}{2})$ |
| $\operatorname{arccot} x$ | $\mathbb{R}$ | $(0,\pi)$ |

### 恒等式

| 公式 | 条件 |
|:---|:---|
| $\arcsin x + \arccos x = \frac{\pi}{2}$ | $x\in[-1,1]$ |
| $\arctan x + \operatorname{arccot} x = \frac{\pi}{2}$ | $x\in\mathbb{R}$ |
| $\arcsin(-x) = -\arcsin x$，$\arctan(-x) = -\arctan x$ | |
| $\arccos(-x) = \pi - \arccos x$ | |

### $\arctan$ 互余与对称

| 公式 | 条件 |
|:---|:---|
| $\arctan x + \arctan\frac{1}{x} = \frac{\pi}{2}$ | $x>0$ |
| $\arctan x + \arctan\frac{1}{x} = -\frac{\pi}{2}$ | $x<0$ |
| $\frac{\pi}{2} + \arctan x = \operatorname{arccot}(-x)$ | |
| $\frac{\pi}{2} - \arctan x = \operatorname{arccot} x$ | |

### 嵌套化简

| 公式 | 条件 |
|:---|:---|
| $\cos(\arcsin x) = \sqrt{1-x^2}$ | |
| $\sin(\arccos x) = \sqrt{1-x^2}$ | |
| $\tan(\arcsin x) = \frac{x}{\sqrt{1-x^2}}$ | |
| $\arcsin(\sin x) = x$ | $x\in[-\frac{\pi}{2},\frac{\pi}{2}]$ |
| $\arccos(\cos x) = x$ | $x\in[0,\pi]$ |
| $\arctan(\tan x) = x$ | $x\in(-\frac{\pi}{2},\frac{\pi}{2})$ |

> 超出主值区间时先诱导公式化归。如 $\arcsin(\sin\frac{5\pi}{6}) = \arcsin(\frac{1}{2}) = \frac{\pi}{6}$。

### 求导与积分

| 求导 | 积分 |
|:---|:---|
| $(\arcsin x)' = \frac{1}{\sqrt{1-x^2}}$ | $\int\frac{1}{\sqrt{1-x^2}}dx = \arcsin x + C$ |
| $(\arccos x)' = -\frac{1}{\sqrt{1-x^2}}$ | |
| $(\arctan x)' = \frac{1}{1+x^2}$ | $\int\frac{1}{1+x^2}dx = \arctan x + C$ |
| $(\operatorname{arccot} x)' = -\frac{1}{1+x^2}$ | |
