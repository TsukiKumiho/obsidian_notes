# 变限积分 | 积分专题

> **核心公式**：$\displaystyle\frac{d}{dx}\int_{a(x)}^{b(x)} f(t)\,dt = f(b(x))\,b'(x) - f(a(x))\,a'(x)$
> **核心思想**：变限积分定义了一个**函数**——它把积分上限（或下限）作为自变量，积分值随上限变化。这个函数的导数恰好是**被积函数在上限处的取值**（乘以上限的导数）。
> **三大应用**：求极限（$\frac{0}{0}$ 型用洛必达）· 求导与极值 · 积分方程。

---

## 一、核心公式与推导

### 1.1 变上限积分求导公式

设 $f(x)$ 在 $[a,b]$ 上连续，则

$$
\boxed{\Phi(x) = \int_a^x f(t)\,dt \quad\Rightarrow\quad \Phi'(x) = f(x)}
$$

即：**变上限积分对上限求导 = 被积函数在上限处的值**。

**推导**（导数定义）：

$$
\Phi'(x) = \lim_{\Delta x \to 0} \frac{\Phi(x+\Delta x) - \Phi(x)}{\Delta x}
= \lim_{\Delta x \to 0} \frac{1}{\Delta x}\int_x^{x+\Delta x} f(t)\,dt
$$

由积分中值定理，$\exists \xi \in [x, x+\Delta x]$ 使 $\int_x^{x+\Delta x} f(t)dt = f(\xi)\Delta x$。故 $\Phi'(x) = \lim_{\Delta x\to 0} f(\xi) = f(x)$。

### 1.2 一般形式（Leibniz 公式）

$$
\boxed{\frac{d}{dx}\int_{a(x)}^{b(x)} f(t)\,dt = f(b(x))\,b'(x) - f(a(x))\,a'(x)}
$$

**直观理解**：
- 上限变化 $b'(x)$ → 贡献 $f(b(x)) \cdot b'(x)$（正）
- 下限变化 $a'(x)$ → 贡献 $f(a(x)) \cdot a'(x)$（**负**，因为下限增大会缩小积分区间）

### 1.3 被积函数含 $x$ 的情形

$$
\frac{d}{dx}\int_{a(x)}^{b(x)} f(x,t)\,dt
$$

此情形需将被积函数中的 $x$ 提到积分号外，或作换元消除 $x$。

---

### ★ 必背专题：变限积分求导的常见题型与陷阱

> ⚡ 变限积分是最容易**因粗心而失分**的考点之一。以下三类情况必须烂熟于心。

#### 类型速判表

| 情形 | 处理策略 | 示例 |
| :--- | :--- | :--- |
| 仅上/下限含 $x$，被积函数纯 $t$ | 直接套公式 | $\frac{d}{dx}\int_0^x \sin t\,dt = \sin x$ |
| 上/下限为 $x$ 的函数 | 链式法则 | $\frac{d}{dx}\int_0^{x^2} e^t dt = e^{x^2} \cdot 2x$ |
| 被积函数含 $x$ 和 $t$ | **先提出 $x$** 或换元 | $\frac{d}{dx}\int_0^x x f(t)dt = x f(x) + \int_0^x f(t)dt$ |
| 积分上限是常数，下限是变量 | 注意**负号** | $\frac{d}{dx}\int_x^1 \cos t\,dt = -\cos x$ |

> ⚠️ **最高频错误**：$\frac{d}{dx}\int_0^x x f(t)dt$ 直接套公式得 $x f(x)$——**错！** 被积函数中的 $x$ 也参与求导，必须先用乘法法则拆开。

## 二、题型分类与精析

### 题型 1：变限积分的基本求导

**特征**：直接求导或求高阶导数。

#### 例题 1.1（基础）

设 $\Phi(x) = \int_0^x t\sin t\,dt$，求 $\Phi'(x)$ 和 $\Phi''(x)$。

**解**：

$\Phi'(x) = x\sin x$（直接套公式）。

$\Phi''(x) = \sin x + x\cos x$（乘积求导）。

#### 例题 1.2（进阶·上限为函数）

设 $\Phi(x) = \int_0^{x^2} \frac{\sin t}{t} dt$，求 $\Phi'(x)$。

**解**：

$$
\Phi'(x) = \frac{\sin(x^2)}{x^2} \cdot 2x = \frac{2\sin(x^2)}{x}
$$

#### 例题 1.3（进阶·被积函数含 $x$）

设 $\Phi(x) = \int_0^x (x-t) f(t) dt$，求 $\Phi'(x)$。

**思路溯源**：被积函数中同时含有 $x$ 和 $t$。将 $x$ 视为常量提到积分号外（对 $t$ 积分时 $x$ 是参数）。

**解**：

$$
\Phi(x) = x\int_0^x f(t) dt - \int_0^x t f(t) dt
$$

$$
\begin{aligned}
\Phi'(x) &= 1\cdot\int_0^x f(t) dt + x\cdot f(x) - x f(x) \\
&= \int_0^x f(t) dt
\end{aligned}
$$

> 💡 第二项 $x f(x)$ 和第三项 $-x f(x)$ 恰好抵消！$\Phi'(x) = \int_0^x f(t)dt$。

### 题型 1：基本求导与高阶导数

#### 例题 1.1（基础）

设 $\Phi(x) = \int_0^x t\sin t\,dt$，求 $\Phi'(x)$ 和 $\Phi''(x)$。

**解**：

$\Phi'(x) = x\sin x$，$\Phi''(x) = \sin x + x\cos x$。

#### 例题 1.2（进阶·上限为函数）

设 $\Phi(x) = \int_0^{x^2} \frac{\sin t}{t} dt$，求 $\Phi'(x)$。

**解**：

$$
\Phi'(x) = \frac{\sin(x^2)}{x^2} \cdot 2x = \frac{2\sin(x^2)}{x}
$$

#### 例题 1.3（进阶·被积函数含 $x$）

设 $\Phi(x) = \int_0^x (x-t) f(t) dt$，求 $\Phi'(x)$。

**思路溯源**：$(x-t)$ 含 $x$——在积 $t$ 时 $x$ 是参数，可拆开提出。

**解**：

$$
\Phi(x) = x\int_0^x f(t) dt - \int_0^x t f(t) dt
$$

$$
\Phi'(x) = \int_0^x f(t) dt + x f(x) - x f(x) = \int_0^x f(t) dt
$$

> 💡 两项含 $x f(x)$ 恰好抵消！$\Phi'(x) = \int_0^x f(t)dt$。这一结论在积分方程中极常用。

### 题型 2：变限积分求极限（洛必达法）

**特征**：$\frac{0}{0}$ 型极限，分子或分母含变限积分。**标准武器：洛必达 + 等价无穷小**。

#### 例题 2.1（基础·一次洛必达）

求 $\displaystyle\lim_{x\to 0} \frac{\int_0^x \sin(t^2) dt}{x^3}$。

**思路溯源**：$x\to 0$ 时分子 $\to 0$，$\frac{0}{0}$ → 洛必达 → 等价无穷小替换。

**解**：

$$
\lim_{x\to 0} \frac{\int_0^x \sin(t^2) dt}{x^3}
= \lim_{x\to 0} \frac{\sin(x^2)}{3x^2}
= \lim_{x\to 0} \frac{x^2}{3x^2}
= \frac{1}{3}
$$

#### 例题 2.2（进阶·需泰勒展开辅助）

求 $\displaystyle\lim_{x\to 0} \frac{\int_0^x e^{t^2} dt - x}{x^3}$。

**思路溯源**：$\frac{0}{0}$ 型（$x\to 0$ 时分子 $\to 0$）。洛必达一次后仍为 $\frac{0}{0}$，用泰勒展开 $e^{x^2} = 1 + x^2 + O(x^4)$。

**解**：

洛必达：$\lim_{x\to 0} \frac{e^{x^2} - 1}{3x^2} = \lim_{x\to 0} \frac{(1+x^2+O(x^4)) - 1}{3x^2} = \frac{1}{3}$

**解法二（不用洛必达，直接泰勒）**：

$\int_0^x e^{t^2} dt = \int_0^x (1+t^2+O(t^4))dt = x + \frac{x^3}{3} + O(x^5)$

分子 $= (x + x^3/3) - x = x^3/3 + O(x^5)$。$\lim = \frac{1/3}{1} = \frac{1}{3}$。

#### 例题 2.3（综合·被积函数含 $x$）

求 $\displaystyle\lim_{x\to 0} \frac{\int_0^x t f(t) dt}{x\int_0^x f(t) dt}$，其中 $f(0) > 0$。

**思路溯源**：$\frac{0}{0}$ 型 → 洛必达。分母是两个 $x$ 的函数乘积，求导用乘法法则。

**解**：

洛必达：

分子导数 $= x f(x)$。

分母导数 $= 1\cdot\int_0^x f(t) dt + x\cdot f(x) = \int_0^x f(t) dt + x f(x)$。

$$
\text{极限} = \lim_{x\to 0} \frac{x f(x)}{\int_0^x f(t) dt + x f(x)} = \lim_{x\to 0} \frac{f(x)}{\frac{1}{x}\int_0^x f(t) dt + f(x)}
$$

$\lim_{x\to 0} \frac{1}{x}\int_0^x f(t) dt = f(0)$（由导数定义）。故极限 $= \frac{f(0)}{f(0)+f(0)} = \frac{1}{2}$。

### 题型 3：变限积分函数的单调性与极值

**特征**：讨论 $\Phi(x) = \int_a^x f(t) dt$ 的单调性/极值。

#### 例题 3.1

求 $F(x) = \int_0^x (t^2-1)e^{-t^2} dt$ 的单调区间与极值。

**思路溯源**：$F'(x) = (x^2-1)e^{-x^2}$。由于 $e^{-x^2} > 0$ 恒成立，符号由 $x^2-1$ 决定。

**解**：

$F'(x) = (x^2-1)e^{-x^2}$。

- $x < -1$：$x^2-1 > 0$ → $F'(x) > 0$ → 单调递增
- $-1 < x < 1$：$x^2-1 < 0$ → $F'(x) < 0$ → 单调递减
- $x > 1$：$x^2-1 > 0$ → $F'(x) > 0$ → 单调递增

$x=-1$ 为极大值点，$x=1$ 为极小值点。

### 题型 4：积分方程（含变限积分的等式）

**特征**：等式中含有变限积分，需要求 $f(x)$ 的表达式。**核心手法：两边求导化为微分方程**。

#### 例题 4.1

已知 $f(x)$ 连续，且 $\int_0^x f(t) dt = x f(x) - x^2$，求 $f(x)$。

**思路溯源**：两边对 $x$ 求导，将积分方程化为微分方程。

**解**：

两边求导：$f(x) = f(x) + x f'(x) - 2x$。

化简：$x f'(x) = 2x$。当 $x \neq 0$ 时 $f'(x) = 2$。

故 $f(x) = 2x + C$。

代入原方程验证：$\int_0^x (2t+C)dt = x^2 + Cx$，右边 $x(2x+C) - x^2 = x^2 + Cx$。恒成立，$C$ 任意。

> 📌 注意求导后解出的通解需要**代回原积分方程验证**——求导可能引入额外解。

## 一、核心公式与推导

### 1.1 基本求导公式

设 $f(x)$ 在 $[a,b]$ 上连续，则

$$

**推导**：

$$
\Phi'(x) = \lim_{\Delta x \to 0} \frac{1}{\Delta x}\int_x^{x+\Delta x} f(t)\,dt
= \lim_{\Delta x \to 0} f(\xi) = f(x) \quad (\xi \in [x, x+\Delta x])
$$

### 1.2 一般 Leibniz 公式

$$
\boxed{\frac{d}{dx}\int_{a(x)}^{b(x)} f(t)\,dt = f(b(x))\,b'(x) - f(a(x))\,a'(x)}

### 题型 5：变限积分函数的奇偶性

| $f(x)$ 的性质 | $\Phi(x) = \int_0^x f(t)dt$ 的性质 |
| :---: | :---: |
| $f$ 是**奇**函数 | $\Phi$ 是**偶**函数 |
| $f$ 是**偶**函数 | $\Phi$ 是**奇**函数 |
| $f$ 以 $T$ 为周期 | $\Phi$ 以 $T$ 为周期 $\iff$ $\int_0^T f = 0$ |

**推导**（以 $f$ 奇为例）：

$\Phi(-x) = \int_0^{-x} f(t)dt \xrightarrow{t=-u} \int_0^x f(-u)(-du) = \int_0^x (-f(u))(-du) = \Phi(x)$。

#### 例题 5.1

设 $f(x)$ 为连续的偶函数，判断 $F(x) = \int_0^x tf(t) dt$ 的奇偶性。

**思路溯源**：$t$ 是奇函数，$f(t)$ 是偶函数，$tf(t)$ 是奇函数。奇函数的变上限积分（$0$ 到 $x$）是偶函数。

**解**：$F(x)$ 是偶函数。

验证：$F(-x) = \int_0^{-x} tf(t)dt$，令 $t=-u$，$= \int_0^x (-u)f(-u)(-du) = \int_0^x uf(u)du = F(x)$。

> **核心公式**：$\displaystyle\frac{d}{dx}\int_{a(x)}^{b(x)} f(t)\,dt = f(b(x))\,b'(x) - f(a(x))\,a'(x)$
> **核心思想**：变限积分定义了一个**函数**——积分值随上限/下限变化。其导数恰好是**被积函数在限处的值**（乘以限的导数）。
> **三大应用**：求极限（洛必达）· 求导与极值 · 积分方程。

## 一、核心公式与推导

### 1.1 基本求导公式

设 $f(x)$ 连续，则

$$
\boxed{\Phi(x) = \int_a^x f(t)\,dt \quad\Rightarrow\quad \Phi'(x) = f(x)}
$$

### 1.2 一般 Leibniz 公式

$$
\boxed{\frac{d}{dx}\int_{a(x)}^{b(x)} f(t)\,dt = f(b(x))\,b'(x) - f(a(x))\,a'(x)}
$$

---

### ★ 必背专题：三种常见情形及处理策略

| 情形 | 示例 | 正确操作 | 常见错误 |
| :--- | :--- | :--- | :--- |
| 限含 $x$，被积函数纯 $t$ | $\frac{d}{dx}\int_0^{x^2} \sin t\,dt$ | 套公式 → $\sin(x^2)\cdot 2x$ | 忘乘 $2x$ |
| 下限含 $x$ | $\frac{d}{dx}\int_x^1 \cos t\,dt$ | $-\cos x$（**负号！**） | 忘写负号 |
| **被积函数同时含 $x,t$** | $\frac{d}{dx}\int_0^x x f(t)dt$ | 先提 $x$：$\frac{d}{dx}[x\int_0^x f] = \int_0^x f + x f(x)$ | 直接套 → $xf(x)$（错！） |

> 📌 **核心结论**（极高频）：$\displaystyle\frac{d}{dx}\int_0^x (x-t)f(t)dt = \int_0^x f(t)dt$

## 二、题型分类与精析

---

### 题型 1：基本求导与高阶导数

#### 例题 1.1（基础）

设 $\Phi(x) = \int_0^x t\sin t\,dt$，求 $\Phi'(x)$ 和 $\Phi''(x)$。

**解**：$\Phi'(x) = x\sin x$，$\Phi''(x) = \sin x + x\cos x$。

#### 例题 1.2（进阶·上限为函数）

设 $\Phi(x) = \int_0^{x^2} \frac{\sin t}{t} dt$，求 $\Phi'(x)$。

**解**：$\Phi'(x) = \frac{\sin(x^2)}{x^2} \cdot 2x = \frac{2\sin(x^2)}{x}$。

#### 例题 1.3（进阶·被积函数含 $x$）

设 $\Phi(x) = \int_0^x (x-t) f(t) dt$，求 $\Phi'(x)$。

**思路溯源**：$(x-t)$ 含 $x$→ 拆开：$\Phi(x) = x\int_0^x f dt - \int_0^x tf(t) dt$。

**解**：

$$
\Phi'(x) = \int_0^x f(t) dt + x f(x) - x f(x) = \int_0^x f(t) dt
$$

> 💡 $x f(x)$ 项恰好抵消——这是积分方程中**最高频**的中间结论。

---

### 题型 2：变限积分求极限（洛必达法）

**标准流程**：识别 $\frac{0}{0}$ 型 → 洛必达求导 → 等价无穷小替换简化。

#### 例题 2.1（基础）

求 $\displaystyle\lim_{x\to 0} \frac{\int_0^x \sin(t^2) dt}{x^3}$。

**解**：

$$
\lim_{x\to 0} \frac{\int_0^x \sin(t^2) dt}{x^3}
= \lim_{x\to 0} \frac{\sin(x^2)}{3x^2}
= \frac{1}{3}
$$

#### 例题 2.2（进阶·泰勒展开法）

求 $\displaystyle\lim_{x\to 0} \frac{\int_0^x e^{t^2} dt - x}{x^3}$。

**解法一（泰勒展开·最快）**：

$e^{t^2} = 1 + t^2 + O(t^4)$，$\int_0^x e^{t^2} dt = x + \frac{x^3}{3} + O(x^5)$。

分子 $= \frac{x^3}{3} + O(x^5)$。极限 $= \frac{1}{3}$。

**解法二（洛必达+等价替换）**：

洛必达：$\lim \frac{e^{x^2}-1}{3x^2}$。$e^{x^2}-1 \sim x^2$ → $\frac{1}{3}$。

#### 例题 2.3（综合·两次洛必达）

求 $\displaystyle\lim_{x\to 0} \frac{\int_0^x (x-t)f(t) dt}{x\int_0^x f(t) dt}$，其中 $f(0) \neq 0$，$f$ 连续可导。

**思路溯源**：$\frac{0}{0}$ 型。利用 $\frac{d}{dx}\int_0^x (x-t)f(t)dt = \int_0^x f(t)dt$。

**解**（两次洛必达）：

第一次：$\frac{\int_0^x f(t) dt}{\int_0^x f(t) dt + x f(x)}$（仍 $\frac{0}{0}$）。

第二次：分子导数 $= f(x)$，分母导数 $= f(x) + f(x) + x f'(x) = 2f(x) + x f'(x)$。

$$
\lim = \frac{f(0)}{2f(0) + 0} = \frac{1}{2}
$$

### 题型 3：变限积分函数的单调性与极值

#### 例题 3.1

求 $F(x) = \int_0^x (t^2-1)e^{-t^2} dt$ 的单调区间与极值。

**思路溯源**：$F'(x) = (x^2-1)e^{-x^2}$。$e^{-x^2}>0$，符号由 $x^2-1$ 决定。

**解**：

| 区间 | $F'(x)$ | 单调性 |
| :--- | :---: | :--- |
| $(-\infty, -1)$ | $+$ | 递增 |
| $(-1, 1)$ | $-$ | 递减 |
| $(1, +\infty)$ | $+$ | 递增 |

极大值点 $x=-1$，极小值点 $x=1$。

---

### 题型 4：积分方程（两边求导化为微分方程）

#### 例题 4.1

$f(x)$ 连续，$\int_0^x f(t) dt = x f(x) - x^2$，求 $f(x)$。

**解**：

求导：$f(x) = f(x) + x f'(x) - 2x$ → $f'(x) = 2$（$x\neq 0$）。

$f(x) = 2x + C$。代回验证：$C$ 任意均满足。

> ⚠️ 求导可能扩大解集，**必须代回原方程验证**。

#### 例题 4.2（进阶·两次求导）

$f$ 可导，$f(0)=0$，$\int_0^x (x-t)f(t) dt = \sin x - x$，求 $f(x)$。

**解**：

第一次求导（利用 $\frac{d}{dx}\int_0^x (x-t)f = \int_0^x f$）：$\int_0^x f(t) dt = \cos x - 1$。

第二次求导：$f(x) = -\sin x$。验证 $f(0)=0$ 满足。

### 题型 5：变限积分函数的奇偶性

| $f(x)$ 性质 | $\Phi(x)=\int_0^x f(t)dt$ 性质 |
| :---: | :---: |
| $f$ 奇 | $\Phi$ **偶** |
| $f$ 偶 | $\Phi$ **奇** |
| $f$ 以 $T$ 为周期 | $\Phi$ 以 $T$ 为周期 $\iff$ $\int_0^T f=0$ |

#### 例题 5.1

设 $f(x)$ 为连续的偶函数，判断 $F(x)=\int_0^x tf(t)dt$ 的奇偶性。

**思路溯源**：$t$ 奇 × $f(t)$ 偶 → $tf(t)$ 奇。奇函数的 0 到 $x$ 积分是偶函数。

**解**：$F$ 是偶函数（验证：$F(-x) \xrightarrow{t=-u} F(x)$）。

| 方法 | 适用场景 | 关键点 |
| :--- | :--- | :--- |
| **直接求导** | 被积函数纯 $t$ | 限是 $x$ 的函数时**勿忘链式法则** |

| **奇偶性传递** | 判断变限积分函数的对称性 | 从 0 积分：奇→偶，偶→奇 |

### 附录 A：自测练习答案

**练习 1**：

$\Phi'(x) = e^{-x^4} \cdot 2x - e^{-x^2} \cdot 1 = 2x e^{-x^4} - e^{-x^2}$

**练习 2**：

洛必达：$\lim \frac{\arctan x}{2x} = \frac{1}{2}$（$\arctan x \sim x$）

**练习 3**：

$1-\cos t \sim \frac{t^2}{2}$。$\int_0^x (x-t)\frac{t^2}{2} dt = \frac{1}{2} \int_0^x (xt^2 - t^3) dt = \frac{1}{2}(\frac{x^4}{3} - \frac{x^4}{4}) = \frac{x^4}{24}$。

极限 $= \frac{1}{24}$。

**练习 4**：

两边求导：$x f(x) = \int_0^x f(t) dt + 3x^2$。

再求导：$f(x) + x f'(x) = f(x) + 6x$ → $f'(x) = 6$。

$f(x) = 6x + C$，$f(0)=0$ 得 $C=0$。$f(x)=6x$。代回验证成立。

**练习 5**：

求导：$f(x) = \frac{1}{2}f(x) + \frac{1}{2}x f'(x)$ → $\frac{1}{2}f(x) = \frac{1}{2}x f'(x)$ → $f(x) = x f'(x)$。

分离变量：$\frac{f'(x)}{f(x)} = \frac{1}{x}$ → $\ln|f(x)| = \ln|x| + C$ → $f(x) = Cx$。

$f(0)=0$ 自动满足，$C$ 任意常数。
