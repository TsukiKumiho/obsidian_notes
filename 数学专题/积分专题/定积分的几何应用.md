# 定积分的几何应用 | 积分专题

> **核心内容**：利用定积分计算平面图形面积、旋转体体积、曲线弧长和旋转曲面面积。
> **核心思想**：微元法——在每个微小区间上，以直代曲、以不变代变，写出微元 $dA/dV/ds/dS$，再积分。
> **关键技巧**：正确选择积分变量 → 正确写出微元 → 确定积分限。

---

## 一、核心公式速查

### 1.1 平面图形面积

| 坐标系 | 公式 | 适用情形 |
| :--- | :--- | :--- |
| **直角坐标（x 型）** | $\displaystyle A = \int_a^b [f(x) - g(x)] dx$ | 上下曲线围成 |
| **直角坐标（y 型）** | $\displaystyle A = \int_c^d [\varphi(y) - \psi(y)] dy$ | 左右曲线围成 |
| **参数方程** | $\displaystyle A = \int_{t_1}^{t_2} y(t)x'(t) dt$ | $x=x(t), y=y(t)$ |
| **极坐标** | $\displaystyle A = \frac{1}{2}\int_{\alpha}^{\beta} r^2(\theta) d\theta$ | $r = r(\theta)$ |

### 1.2 旋转体体积

| 方法 | 公式 | 适用条件 |
| :--- | :--- | :--- |
| **圆盘法（绕 x 轴）** | $\displaystyle V = \pi\int_a^b [f(x)]^2 dx$ | 曲线绕 x 轴 |
| **圆盘法（绕 y 轴·x 型）** | $\displaystyle V = \pi\int_a^b [f(x)]^2 dx$ 换元 | 一般不建议，用 y 型或柱壳法 |
| **圆盘法（绕 y 轴·y 型）** | $\displaystyle V = \pi\int_c^d [g(y)]^2 dy$ | $x=g(y)$ 绕 y 轴 |
| **垫圈法（绕 x 轴）** | $\displaystyle V = \pi\int_a^b \left([f(x)]^2 - [g(x)]^2\right) dx$ | 两曲线间区域绕 x 轴 |
| **柱壳法（绕 y 轴）** | $\displaystyle V = 2\pi\int_a^b x[f(x)-g(x)] dx$ | 两曲线间区域绕 y 轴 |
| **截面法** | $\displaystyle V = \int_a^b A(x) dx$ | 已知垂直截面面积 |

### 1.3 曲线弧长

| 坐标系 | 公式 |
| :--- | :--- |
| **直角坐标** $y=f(x)$ | $\displaystyle s = \int_a^b \sqrt{1 + [f'(x)]^2} dx$ |
| **参数方程** $x=x(t), y=y(t)$ | $\displaystyle s = \int_{t_1}^{t_2} \sqrt{[x'(t)]^2 + [y'(t)]^2} dt$ |
| **极坐标** $r=r(\theta)$ | $\displaystyle s = \int_{\alpha}^{\beta} \sqrt{r^2(\theta) + [r'(\theta)]^2} d\theta$ |

### 1.4 旋转曲面面积（侧面积）

| 旋转轴 | 公式（$y=f(x) \geq 0$ 绕 x 轴） |
| :--- | :--- |
| **绕 x 轴** | $\displaystyle S = 2\pi\int_a^b f(x)\sqrt{1 + [f'(x)]^2} dx$ |
| **绕 y 轴**（$x=g(y) \geq 0$） | $\displaystyle S = 2\pi\int_c^d g(y)\sqrt{1 + [g'(y)]^2} dy$ |

> 📌 参数方程和极坐标下的旋转面面积公式由上述公式经换元即可得到，考研一般考直角坐标形式。

### ★ 必背专题：选积分变量的决策树

> ⚡ 面积/体积题中，选错积分变量会导致积分极其困难甚至无法计算。按此决策树判断：

```
图形边界主要由什么给出？
    │
    ├─ 上/下边界是 x 的显函数 → 对 x 积分（x 型）
    │   例：y = x², y = 2-x → 对 x 积分
    │
    ├─ 左/右边界是 y 的显函数 → 对 y 积分（y 型）
    │   例：x = y², x = 2-y → 对 y 积分
    │
    ├─ 绕 x 轴旋转 → 圆盘法对 x（或垫圈法）
    │   绕 y 轴旋转 → 优先柱壳法对 x（避免反解函数）
    │
    └─ 极坐标方程明显 → 用极坐标面积公式
```

### 题型 1：平面图形面积

#### 例题 1.1（基础·直角坐标 x 型）

求曲线 $y = x^2$ 与 $y = \sqrt{x}$ 所围图形的面积。

**思路溯源**：交点：$x^2 = \sqrt{x} \Rightarrow x^4 = x \Rightarrow x(x^3-1)=0$ → $x=0,1$。

在 $[0,1]$ 上，$\sqrt{x} \geq x^2$。取 x 型积分。

**解**：

$$
A = \int_0^1 (\sqrt{x} - x^2) dx = \left[\frac{2}{3}x^{3/2} - \frac{x^3}{3}\right]_0^1 = \frac{2}{3} - \frac{1}{3} = \frac{1}{3}
$$

#### 例题 1.2（进阶·y 型更优）

求 $y^2 = 2x$ 与 $y = x-4$ 所围图形的面积。

**思路溯源**：交点：$(y+4)^2/4 = 2x$ → 代 $x = y^2/2$ 入 $y = x-4$：

$y = y^2/2 - 4 \Rightarrow y^2 - 2y - 8 = 0 \Rightarrow (y-4)(y+2)=0$ → $y = -2, 4$。

若对 x 积分，需分段（因为下边界在 $x=2$ 处切换）。**对 y 积分更优**——右边界 $x = y+4$，左边界 $x = y^2/2$。

**解**：

$$
\begin{aligned}
A &= \int_{-2}^4 \left[(y+4) - \frac{y^2}{2}\right] dy \\
&= \left[\frac{y^2}{2} + 4y - \frac{y^3}{6}\right]_{-2}^4 \\
&= \left(8 + 16 - \frac{64}{6}\right) - \left(2 - 8 + \frac{8}{6}\right) \\
&= \left(24 - \frac{64}{6}\right) - \left(-6 + \frac{8}{6}\right) \\
&= 24 - \frac{64}{6} + 6 - \frac{8}{6} = 30 - \frac{72}{6} = 30 - 12 = 18
\end{aligned}
$$

#### 例题 1.3（综合·极坐标面积）

求心形线 $r = 1 + \cos\theta$ 所围图形的面积。

**思路溯源**：这是经典的极坐标图形。心形线关于极轴对称，总面积为上半的 2 倍（$\theta$ 从 $0$ 到 $\pi$）。

**解**：

$$
\begin{aligned}
A &= 2 \cdot \frac{1}{2}\int_0^\pi (1+\cos\theta)^2 d\theta
= \int_0^\pi (1 + 2\cos\theta + \cos^2\theta) d\theta \\[4pt]
&= \int_0^\pi \left(1 + 2\cos\theta + \frac{1+\cos 2\theta}{2}\right) d\theta \\[4pt]
&= \int_0^\pi \left(\frac{3}{2} + 2\cos\theta + \frac{\cos 2\theta}{2}\right) d\theta \\[4pt]
&= \left[\frac{3}{2}\theta + 2\sin\theta + \frac{\sin 2\theta}{4}\right]_0^\pi \\[4pt]
&= \frac{3\pi}{2}
\end{aligned}
$$

#### 例题 1.4（综合·参数方程面积）

求椭圆 $\displaystyle\frac{x^2}{a^2} + \frac{y^2}{b^2} = 1$ 的面积（$a,b>0$）。

**解法一（参数方程）**：

令 $x = a\cos t$，$y = b\sin t$（$t$ 从 $0$ 到 $2\pi$）。由面积公式 $A = \int_{t_1}^{t_2} y(t)x'(t) dt$：

$$
\begin{aligned}
A &= \int_0^{2\pi} b\sin t \cdot (-a\sin t) dt = ab\int_0^{2\pi} \sin^2 t\,dt \\[4pt]
&= ab\int_0^{2\pi} \frac{1-\cos 2t}{2} dt = ab\left[\frac{t}{2} - \frac{\sin 2t}{4}\right]_0^{2\pi} = \pi ab
\end{aligned}
$$

**解法二（直角坐标 y 型对称）**：

由对称性，$A = 4\int_0^a \frac{b}{a}\sqrt{a^2-x^2}\,dx$。令 $x = a\sin\theta$，得 $A = \pi ab$。

> 💡 参数方程法绕开了根号，计算最简洁。

#### 例题 1.5（综合·双纽线极坐标面积）

求双纽线 $r^2 = a^2 \cos 2\theta$（$a>0$）所围图形的总面积。

**思路溯源**：$\cos 2\theta \geq 0 \Rightarrow \theta \in [-\pi/4, \pi/4] \cup [3\pi/4, 5\pi/4]$。由对称性，总面积 $= 4 \times$ 第一象限部分的面积。

**解**：

$$
\begin{aligned}
A &= 4 \cdot \frac{1}{2}\int_0^{\pi/4} a^2 \cos 2\theta\,d\theta
= 2a^2\int_0^{\pi/4} \cos 2\theta\,d\theta \\[4pt]
&= 2a^2\left[\frac{\sin 2\theta}{2}\right]_0^{\pi/4}
= a^2
\end{aligned}
$$

### 题型 2：旋转体体积

#### 例题 2.1（基础·圆盘法绕 x 轴）

求 $y = \sin x$（$0 \leq x \leq \pi$）绕 x 轴旋转所得体积。

**解**：

$$
V = \pi\int_0^\pi \sin^2 x\,dx = \pi\int_0^\pi \frac{1-\cos 2x}{2} dx = \frac{\pi}{2}\left[x - \frac{\sin 2x}{2}\right]_0^\pi = \frac{\pi^2}{2}
$$

#### 例题 2.2（进阶·垫圈法）

求 $y = x^2$ 与 $y = \sqrt{x}$ 所围区域绕 x 轴旋转的体积。

**思路溯源**：两曲线交于 $x=0,1$。在 $[0,1]$ 上 $\sqrt{x} \geq x^2$。垫圈法：大圆 $R(x)=\sqrt{x}$，小圆 $r(x)=x^2$。

**解**：

$$
\begin{aligned}
V &= \pi\int_0^1 \left[(\sqrt{x})^2 - (x^2)^2\right] dx
= \pi\int_0^1 (x - x^4) dx \\[4pt]
&= \pi\left[\frac{x^2}{2} - \frac{x^5}{5}\right]_0^1
= \pi\left(\frac{1}{2} - \frac{1}{5}\right)
= \frac{3\pi}{10}
\end{aligned}
$$

#### 例题 2.3（综合·柱壳法 vs 圆盘法）

求 $y = x^2$（$0 \leq x \leq 1$）与 $y=0$ 所围区域绕 y 轴旋转的体积。

**解法一（柱壳法·推荐）**：

柱壳半径 $x$，高度 $x^2$，厚度 $dx$。

$$
V = 2\pi\int_0^1 x \cdot x^2 dx = 2\pi\left[\frac{x^4}{4}\right]_0^1 = \frac{\pi}{2}
$$

**解法二（圆盘法·y 型）**：

反解 $x = \sqrt{y}$。绕 y 轴，$y$ 从 $0$ 到 $1$。

$$
V = \pi\int_0^1 (\sqrt{y})^2 dy = \pi\int_0^1 y\,dy = \pi\left[\frac{y^2}{2}\right]_0^1 = \frac{\pi}{2}
$$

> 💡 两种方法结果一致。当反解函数较复杂时，**柱壳法无需反解**，优势明显。

#### 例题 2.4（截面法）

一立体底面是半径为 $r$ 的圆，垂直于 x 轴的截面都是等边三角形。求体积。

**思路溯源**：圆的方程 $x^2+y^2=r^2$。在位置 $x$ 处，截面等边三角形的边长 $= 2\sqrt{r^2-x^2}$，面积 $= \frac{\sqrt{3}}{4}(2\sqrt{r^2-x^2})^2 = \sqrt{3}(r^2-x^2)$。

**解**：

$$
V = \int_{-r}^r \sqrt{3}(r^2-x^2) dx = 2\sqrt{3}\int_0^r (r^2-x^2) dx = 2\sqrt{3}\left[r^2 x - \frac{x^3}{3}\right]_0^r = \frac{4\sqrt{3}}{3}r^3
$$

### 题型 3：曲线弧长

#### 例题 3.1（基础）

求悬链线 $y = \frac{a}{2}(e^{x/a} + e^{-x/a})$ 从 $x=0$ 到 $x=a$ 的弧长。

**解**：

$y' = \frac{1}{2}(e^{x/a} - e^{-x/a})$。

$1 + (y')^2 = 1 + \frac{1}{4}(e^{2x/a} - 2 + e^{-2x/a}) = \frac{1}{4}(e^{2x/a} + 2 + e^{-2x/a}) = \left[\frac{1}{2}(e^{x/a} + e^{-x/a})\right]^2$。

$$
s = \int_0^a \frac{1}{2}(e^{x/a} + e^{-x/a}) dx = \frac{a}{2}(e^{x/a} - e^{-x/a})\Big|_0^a = \frac{a}{2}(e - e^{-1})
$$

#### 例题 3.2（进阶·参数方程）

求摆线 $x = a(t-\sin t), y = a(1-\cos t)$ 一拱（$0 \leq t \leq 2\pi$）的弧长。

**解**：

$x'(t) = a(1-\cos t)$，$y'(t) = a\sin t$。

$$
\sqrt{[x']^2 + [y']^2} = a\sqrt{(1-\cos t)^2 + \sin^2 t} = a\sqrt{1 - 2\cos t + \cos^2 t + \sin^2 t}
$$

$$
= a\sqrt{2 - 2\cos t} = a\sqrt{4\sin^2\frac{t}{2}} = 2a\left|\sin\frac{t}{2}\right|
$$

$$
s = \int_0^{2\pi} 2a\sin\frac{t}{2} dt = 4a\left[-\cos\frac{t}{2}\right]_0^{2\pi} = 4a(1-(-1)) = 8a
$$

#### 例题 3.3（进阶·极坐标弧长）

求心形线 $r = a(1 + \cos\theta)$（$a>0$）的全长。

**思路溯源**：由对称性（关于极轴对称），全长 $= 2 \times$ 上半段弧长。极坐标弧长公式：$s = \int_\alpha^\beta \sqrt{r^2 + (r')^2}\,d\theta$。

**解**：

$r = a(1+\cos\theta)$，$r' = -a\sin\theta$。

$$
\begin{aligned}
\sqrt{r^2 + (r')^2} &= a\sqrt{(1+\cos\theta)^2 + \sin^2\theta} \\
&= a\sqrt{1 + 2\cos\theta + \cos^2\theta + \sin^2\theta} \\
&= a\sqrt{2 + 2\cos\theta} = a\sqrt{4\cos^2\frac{\theta}{2}} = 2a\left|\cos\frac{\theta}{2}\right|
\end{aligned}
$$

心形线 $\theta \in [0, 2\pi]$。当 $\theta \in [0,\pi]$ 时 $\cos(\theta/2) \geq 0$，当 $\theta \in [\pi,2\pi]$ 时 $\cos(\theta/2) \leq 0$。利用对称性仅积 $[0,\pi]$ 再乘 2：

$$
s = 2 \cdot \int_0^\pi 2a\cos\frac{\theta}{2}\,d\theta = 4a\left[2\sin\frac{\theta}{2}\right]_0^\pi = 8a
$$

> 💡 极坐标弧长的关键在于化简 $\sqrt{r^2 + (r')^2}$，此处利用了倍角公式 $1+\cos\theta = 2\cos^2(\theta/2)$。

### 题型 4：旋转曲面面积

#### 例题 4.1

求 $y = \sqrt{x}$（$0 \leq x \leq 1$）绕 x 轴旋转所得旋转面的面积。

**解**：

$y' = \frac{1}{2\sqrt{x}}$。$\sqrt{1+(y')^2} = \sqrt{1+\frac{1}{4x}} = \sqrt{\frac{4x+1}{4x}} = \frac{\sqrt{4x+1}}{2\sqrt{x}}$。

$$
\begin{aligned}
S &= 2\pi\int_0^1 \sqrt{x} \cdot \frac{\sqrt{4x+1}}{2\sqrt{x}} dx
= \pi\int_0^1 \sqrt{4x+1}\,dx \\[4pt]
&= \frac{\pi}{4}\int_1^5 \sqrt{u}\,du \quad (u=4x+1) \\[4pt]
&= \frac{\pi}{4} \cdot \frac{2}{3}u^{3/2}\Big|_1^5
= \frac{\pi}{6}(5\sqrt{5} - 1)
\end{aligned}
$$

## 三、方法总结表

| 几何量 | 公式 | 关键：正确写微元 |
| :--- | :--- | :--- |
| 直角坐标面积 | $A = \int_a^b [y_{\text{上}} - y_{\text{下}}] dx$ | 确认谁在上、谁在下 |
| 极坐标面积 | $A = \frac{1}{2}\int_\alpha^\beta r^2 d\theta$ | 勿忘 $1/2$ |
| 绕 x 轴体积 | $V = \pi\int_a^b [f(x)]^2 dx$ | 垫圈：外²−内² |
| 绕 y 轴体积 | $V = 2\pi\int_a^b x f(x) dx$（柱壳） | 柱壳法无需反解！ |
| 截面法体积 | $V = \int_a^b A(x) dx$ | $A(x)$ 是截面面积函数 |
| 弧长 | $s = \int_a^b \sqrt{1+(y')^2} dx$ | 化简根号内是关键 |
| 旋转面面积 | $S = 2\pi\int_a^b y\sqrt{1+(y')^2} dx$（绕 x 轴） | 勿忘 $2\pi$ |

## 五、附录

### 附录 A：自测练习答案

**练习 1**：

$y=0$ 时 $x=1$。$A = \int_1^e \ln x\,dx = [x\ln x - x]_1^e = (e-0) - (0-1) = 1$。

**练习 2**：

双纽线 $r^2 = 2a^2 \cos 2\theta$ 要求 $\cos 2\theta \geq 0$，即 $-\frac{\pi}{4} \leq \theta \leq \frac{\pi}{4}$（第一叶）和对称的第三叶。总面积为第一象限部分的 4 倍。

$A = 4 \cdot \frac{1}{2}\int_0^{\pi/4} 2a^2 \cos 2\theta\,d\theta = 4a^2\int_0^{\pi/4} \cos 2\theta\,d\theta = 4a^2 \cdot \frac{1}{2}[\sin 2\theta]_0^{\pi/4} = 2a^2$。

**练习 3**：

柱壳法：半径 $x$，高度 $\sin x$，厚度 $dx$。

$V = 2\pi\int_0^\pi x\sin x\,dx = 2\pi\left[ -x\cos x|_0^\pi + \int_0^\pi \cos x\,dx \right] = 2\pi(\pi + 0) = 2\pi^2$

**练习 4**：

$x'(t) = -3a\cos^2 t \sin t$，$y'(t) = 3a\sin^2 t \cos t$。

$(x')^2 + (y')^2 = 9a^2\cos^4 t \sin^2 t + 9a^2\sin^4 t \cos^2 t = 9a^2\cos^2 t \sin^2 t (\cos^2 t + \sin^2 t)$

$= 9a^2\cos^2 t \sin^2 t$。

$\sqrt{(x')^2+(y')^2} = 3a|\cos t \sin t| = \frac{3a}{2}|\sin 2t|$。

星形线一拱 $t \in [0, 2\pi]$，分成 4 个象限对称。弧长 $= 4\int_0^{\pi/2} \frac{3a}{2}\sin 2t\,dt = 6a \cdot \frac{1}{2}[-\cos 2t]_0^{\pi/2} = 6a$。

**练习 5**：

$y = x^2$，$y$ 从 $0$ 到 $4$。绕 y 轴用 y 型：$x = \sqrt{y}$。

$V = \pi\int_0^4 (\sqrt{y})^2 dy = \pi\int_0^4 y\,dy = \pi\left[\frac{y^2}{2}\right]_0^4 = 8\pi$。

### 附录 B：常见曲线弧长结论

| 曲线 | 方程 | 弧长 |
| :--- | :--- | :--- |
| 摆线一拱 | $x=a(t-\sin t), y=a(1-\cos t)$，$0 \leq t \leq 2\pi$ | $8a$ |
| 星形线 | $x=a\cos^3 t, y=a\sin^3 t$ | $6a$ |
| 悬链线 | $y = a\cosh\frac{x}{a}$，$-a \leq x \leq a$ | $2a\sinh 1$ |
| 圆的周长 | $x^2+y^2=R^2$ | $2\pi R$ |
| 对数螺线 | $r = ae^{b\theta}$，$0 \leq \theta \leq 2\pi$ | $\frac{a\sqrt{1+b^2}}{b}(e^{2\pi b}-1)$ |
