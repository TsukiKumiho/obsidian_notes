# 有理函数积分 | 积分专题

> **核心公式**：有理函数 $R(x) = \frac{P(x)}{Q(x)}$ 可唯一分解为多项式 + 部分分式之和，进而用基本积分公式逐项积分。
> **核心思想**：化整为零——将复杂有理分式拆解为 $\frac{A}{x-a}$、$\frac{A}{(x-a)^k}$、$\frac{Ax+B}{x^2+px+q}$、$\frac{Ax+B}{(x^2+px+q)^k}$ 四种基本类型。
> **通法口诀**：先看分母因式分解 → 写出待定系数形式 → 通分比较系数或赋值法 → 逐项积分。

---

## 一、核心公式与推导

### 1.1 有理函数的定义

$$
R(x) = \frac{P(x)}{Q(x)} = \frac{a_m x^m + \cdots + a_1 x + a_0}{b_n x^n + \cdots + b_1 x + b_0}
$$

- 若 $m < n$：**真分式**，可直接拆分为部分分式
- 若 $m \geq n$：**假分式**，先做多项式除法 $R(x) = S(x) + \frac{R_1(x)}{Q(x)}$，其中 $S(x)$ 是多项式，$\frac{R_1(x)}{Q(x)}$ 是真分式

### 1.2 部分分式分解定理

根据实系数多项式因式分解定理，$Q(x)$ 可分解为一次因式和不可约二次因式的乘积：

$$
Q(x) = b_n \prod (x-a_i)^{m_i} \prod (x^2 + p_j x + q_j)^{n_j}
$$

其中 $x^2 + p_j x + q_j$ 的判别式 $\Delta = p_j^2 - 4q_j < 0$。

**四种基本部分分式**：

| 类型 | 分母因式 | 对应的部分分式 | 积分结果 |
| :--- | :--- | :--- | :--- |
| **I** | $x-a$（单重一次因式） | $\displaystyle\frac{A}{x-a}$ | $A\ln|x-a| + C$ |
| **II** | $(x-a)^k$（$k$ 重一次因式） | $\displaystyle\frac{A_1}{x-a} + \frac{A_2}{(x-a)^2} + \cdots + \frac{A_k}{(x-a)^k}$ | 对数 + 有理式 |
| **III** | $x^2+px+q$（单重不可约二次因式） | $\displaystyle\frac{Ax+B}{x^2+px+q}$ | 拆为 $\frac{\text{分子导数}}{\text{分母}} + \frac{\text{常数}}{\text{分母}}$ |
| **IV** | $(x^2+px+q)^k$（$k$ 重不可约二次因式） | $\displaystyle\sum_{i=1}^k \frac{A_i x + B_i}{(x^2+px+q)^i}$ | 递推降幂法 |

### 1.3 待定系数法（求 $A, B, \ldots$ 的两种策略）

| 方法 | 操作 | 适用场景 |
| :--- | :--- | :--- |
| **赋值法** | 通分后，给 $x$ 赋特定值（优先取分母的根），直接解出系数 | 分母因式简单时极快 |
| **比较系数法** | 通分后展开分子，令 $x$ 的各次幂系数相等，列方程组 | 通用，分母复杂时用 |
| **混合法** | 先用赋值法求出一部分系数，再用比较系数法求剩余的 | 实战中最常用 |

### ★ 必背专题：奥斯特洛格拉茨基方法（Ostrogradsky）

> ⚡ **重要性**：当分母含 $(x-a)^k$ 或 $(x^2+px+q)^k$ 且 $k \geq 2$ 时，传统待定系数法需要列出大量系数，计算量爆炸。奥氏方法直接提取出有理部分，**将高次分母的积分归约为低次分母**，是考研中处理此类问题的最优解。

#### 奥氏公式

对于真分式 $\frac{P(x)}{Q(x)}$，若 $Q(x)$ 含重因式，则存在多项式 $P_1(x)$、$P_2(x)$ 使得：

$$
\int \frac{P(x)}{Q(x)} dx = \frac{P_1(x)}{Q_1(x)} + \int \frac{P_2(x)}{Q_2(x)} dx
$$

其中：
- $Q_1(x)$ 是 $Q(x)$ 的所有因式各降一重（即 $Q_1 = \gcd(Q, Q')$ 的商）
- $Q_2(x) = Q(x)/Q_1(x)$，即 $Q(x)$ 中所有因式的一次幂之积（无重因式）
- $\deg P_1 < \deg Q_1$，$\deg P_2 < \deg Q_2$

#### 口诀理解

> $Q_1$ 把重数各减一，$Q_2$ 是所有因式的一次（无重复）。
> 有理部分分母是 $Q_1$，对数/反正切部分分母是 $Q_2$。

#### 即用示例 1

计算 $\displaystyle\int \frac{1}{(x+1)^2(x-2)} dx$。

**奥氏方法**：

$Q(x) = (x+1)^2(x-2)$，$Q_2(x) = (x+1)(x-2)$，$Q_1(x) = x+1$。

设：
$$
\int \frac{1}{(x+1)^2(x-2)} dx = \frac{A}{x+1} + \int \frac{Bx+C}{(x+1)(x-2)} dx
$$

（$Q_2$ 分母下还是真分式，继续拆为 $\frac{D}{x+1} + \frac{E}{x-2}$ 求和）

解得 $A = \frac{1}{3}$，最终答案：$-\frac{1}{3}\ln|x+1| + \frac{1}{3}\ln|x-2| - \frac{1}{3(x+1)} + C$

#### 即用示例 2

计算 $\displaystyle\int \frac{1}{(x^2+1)^2} dx$。

不用奥氏也行（因为这是纯二次因子），用标准递推：
$$
\int \frac{1}{(x^2+1)^2} dx = \frac{x}{2(x^2+1)} + \frac{1}{2}\arctan x + C
$$

> ⚠️ 奥氏方法的优势在分母混合了多次一次因式和多次二次因式时最明显。

## 二、题型分类与精析

---

### 题型 1：分母为不同一次因式之积

**特征**：$Q(x) = (x-a_1)(x-a_2)\cdots(x-a_k)$，所有因式各不相同。

**拆法**：
$$
\frac{P(x)}{(x-a_1)(x-a_2)\cdots(x-a_k)} = \frac{A_1}{x-a_1} + \frac{A_2}{x-a_2} + \cdots + \frac{A_k}{x-a_k}
$$

**覆核法**（快速求系数）：要求 $A_i$ 时，两边同乘 $(x-a_i)$，令 $x = a_i$，即得 $A_i = \frac{P(a_i)}{\prod_{j\neq i}(a_i-a_j)}$。

#### 例题 1.1（基础）

求 $\displaystyle\int \frac{x}{(x-1)(x-2)} dx$。

**思路溯源**：分母是两个不同一次因式——标准情形，直接套用一次因式拆分模板。

**解**：

设 $\displaystyle\frac{x}{(x-1)(x-2)} = \frac{A}{x-1} + \frac{B}{x-2}$。

赋值法：同乘分母后令 $x=1$，$1 = A(1-2) \Rightarrow A = -1$；令 $x=2$，$2 = B(2-1) \Rightarrow B = 2$。

$$
\int \left(\frac{-1}{x-1} + \frac{2}{x-2}\right) dx = -\ln|x-1| + 2\ln|x-2| + C = \ln\left|\frac{(x-2)^2}{x-1}\right| + C
$$

#### 例题 1.2（进阶·含 $x^n$ 情形）

求 $\displaystyle\int \frac{x^2+1}{x(x^2-1)} dx$。

**思路溯源**：分母看似有三个因子 $x, x-1, x+1$，属于不同一次因式。但分子次数接近分母，先检查是否为假分式——此处 $m=2, n=3$，是真分式，直接拆分。

**解**：

$$
\frac{x^2+1}{x(x-1)(x+1)} = \frac{A}{x} + \frac{B}{x-1} + \frac{C}{x+1}
$$

赋值法：$x=0 \Rightarrow 1 = A(-1)(1) \Rightarrow A=-1$；$x=1 \Rightarrow 2 = B(1)(2) \Rightarrow B=1$；$x=-1 \Rightarrow 2 = C(-1)(-2) \Rightarrow C=1$。

$$
\int \left(-\frac{1}{x} + \frac{1}{x-1} + \frac{1}{x+1}\right) dx = -\ln|x| + \ln|x-1| + \ln|x+1| + C = \ln\left|\frac{(x-1)(x+1)}{x}\right| + C
$$

### 题型 2：分母含重复一次因式

**特征**：$Q(x)$ 含 $(x-a)^k$，$k \geq 2$。

**拆法**：
$$
\frac{P(x)}{\cdots(x-a)^k\cdots} = \cdots + \frac{A_1}{x-a} + \frac{A_2}{(x-a)^2} + \cdots + \frac{A_k}{(x-a)^k} + \cdots
$$

> ⚠️ **易错**：有人只写 $\frac{A}{(x-a)^k}$ 一项，漏掉了低次项。必须从 $1$ 次幂写到 $k$ 次幂。

#### 例题 2.1（基础）

求 $\displaystyle\int \frac{1}{x(x-1)^2} dx$。

**思路溯源**：$(x-1)^2$ 是重因式，需写出 $\frac{A}{x-1} + \frac{B}{(x-1)^2}$ 两项（再加 $\frac{C}{x}$）。

**解**：

设 $\displaystyle\frac{1}{x(x-1)^2} = \frac{A}{x} + \frac{B}{x-1} + \frac{C}{(x-1)^2}$。

通分：$1 = A(x-1)^2 + Bx(x-1) + Cx$。

赋值：$x=0 \Rightarrow A=1$；$x=1 \Rightarrow C=1$。

比较 $x^2$ 系数：$0 = A + B \Rightarrow B = -1$。

$$
\int \left(\frac{1}{x} - \frac{1}{x-1} + \frac{1}{(x-1)^2}\right) dx = \ln|x| - \ln|x-1| - \frac{1}{x-1} + C
$$

#### 例题 2.2（进阶·高次重因子）

求 $\displaystyle\int \frac{x^2}{(x-1)^3} dx$。

**思路溯源**：分母是 $(x-1)^3$（单一因式的三次幂），分子 $x^2$ 次数小于 3，是真分式。此时**最快捷的方法不是待定系数，而是令 $t = x-1$ 换元**——分母只有 $(x-1)$ 的幂，换元后化为简单的 $t^{-n}$ 型积分。

**解法一（换元速算）**：

令 $t = x-1$，$x = t+1$，$dx = dt$，则：

$$
\int \frac{(t+1)^2}{t^3} dt = \int \frac{t^2+2t+1}{t^3} dt = \int \left(\frac{1}{t} + \frac{2}{t^2} + \frac{1}{t^3}\right) dt
$$

$$
= \ln|t| - \frac{2}{t} - \frac{1}{2t^2} + C = \ln|x-1| - \frac{2}{x-1} - \frac{1}{2(x-1)^2} + C
$$

**解法二（奥氏方法）**：$Q_2(x) = x-1$，$Q_1(x) = (x-1)^2$，可直接验证结果一致。

### 题型 3：分母含不可约二次因式

**特征**：$Q(x)$ 含 $x^2 + px + q$（$\Delta < 0$），单重。

**拆法**：
$$
\frac{P(x)}{\cdots(x^2+px+q)\cdots} = \cdots + \frac{Ax+B}{x^2+px+q} + \cdots
$$

**积分套路**：
1. 将分子拆为 $Ax + B = \frac{A}{2}(2x+p) + \left(B - \frac{Ap}{2}\right)$
2. 第一项：$\int \frac{2x+p}{x^2+px+q} dx = \ln(x^2+px+q)$
3. 第二项：配方后 $\int \frac{1}{(x+\frac{p}{2})^2 + a^2} dx = \frac{1}{a}\arctan\frac{x+p/2}{a}$

#### 例题 3.1（基础）

求 $\displaystyle\int \frac{1}{x^3+1} dx$。

**思路溯源**：$x^3+1 = (x+1)(x^2-x+1)$，含一个一次因式和一个不可约二次因式（$\Delta = 1-4 = -3 < 0$）。

**解**：

设 $\displaystyle\frac{1}{x^3+1} = \frac{A}{x+1} + \frac{Bx+C}{x^2-x+1}$。

赋值 $x=-1$：$1 = A(1+1+1) = 3A \Rightarrow A = \frac{1}{3}$。

比较系数：$x^2$ 系数 $0 = A + B \Rightarrow B = -\frac{1}{3}$；常数项 $1 = A + C \Rightarrow C = \frac{2}{3}$。

$$
\begin{aligned}
\int \frac{1}{x^3+1} dx &= \frac{1}{3}\int \frac{1}{x+1} dx - \frac{1}{3}\int \frac{x-2}{x^2-x+1} dx \\[4pt]
&= \frac{1}{3}\ln|x+1| - \frac{1}{6}\ln(x^2-x+1) + \frac{1}{\sqrt{3}}\arctan\frac{2x-1}{\sqrt{3}} + C
\end{aligned}
$$

#### 例题 3.2（进阶·分子次数较高）

求 $\displaystyle\int \frac{x^3}{x^2+1} dx$。

**思路溯源**：假分式（分子 3 次 > 分母 2 次），先做多项式除法。

**解**：

$$
\frac{x^3}{x^2+1} = x - \frac{x}{x^2+1}
$$

$$
\int \left(x - \frac{x}{x^2+1}\right) dx = \frac{x^2}{2} - \frac{1}{2}\ln(x^2+1) + C
$$

### 题型 4：分母含重复不可约二次因式

**特征**：$Q(x)$ 含 $(x^2+px+q)^k$，$k \geq 2$。

**拆法**：
$$
\frac{P(x)}{\cdots(x^2+px+q)^k\cdots} = \cdots + \frac{A_1x+B_1}{x^2+px+q} + \frac{A_2x+B_2}{(x^2+px+q)^2} + \cdots + \frac{A_kx+B_k}{(x^2+px+q)^k} + \cdots
$$

**积分套路**：$\int \frac{1}{(x^2+a^2)^k} dx$ 的递推公式（分部积分导出）：

$$
I_k = \frac{x}{2a^2(k-1)(x^2+a^2)^{k-1}} + \frac{2k-3}{2a^2(k-1)} I_{k-1}, \quad I_1 = \frac{1}{a}\arctan\frac{x}{a}
$$

#### 例题 4.1（综合）

求 $\displaystyle\int \frac{2x^3+3x^2+2x+1}{(x^2+1)^2} dx$。

**思路溯源**：分母 $(x^2+1)^2$ 是二重不可约二次因式——这是奥氏方法的最佳适用场景。

**解**：

设 $\displaystyle\frac{2x^3+3x^2+2x+1}{(x^2+1)^2} = \frac{Ax+B}{x^2+1} + \frac{Cx+D}{(x^2+1)^2}$。

通分比较系数，得 $A=2, B=3, C=0, D=-2$。

$$
\int \left(\frac{2x+3}{x^2+1} + \frac{-2}{(x^2+1)^2}\right) dx
$$

第一项：$\int \frac{2x}{x^2+1} dx + 3\int \frac{1}{x^2+1} dx = \ln(x^2+1) + 3\arctan x$

第二项：用 $k=2$ 递推，$\int \frac{1}{(x^2+1)^2} dx = \frac{x}{2(x^2+1)} + \frac{1}{2}\arctan x$

$$
\text{原式} = \ln(x^2+1) + 3\arctan x - 2\left[\frac{x}{2(x^2+1)} + \frac{1}{2}\arctan x\right] + C
$$

$$
= \ln(x^2+1) - \frac{x}{x^2+1} + 2\arctan x + C
$$

### 题型 5：三角函数有理式的积分（万能公式法）

**特征**：被积函数是 $\sin x$、$\cos x$ 的有理函数 $R(\sin x, \cos x)$。

**通用方法**：万能代换

$$
t = \tan\frac{x}{2}, \quad \sin x = \frac{2t}{1+t^2}, \quad \cos x = \frac{1-t^2}{1+t^2}, \quad dx = \frac{2}{1+t^2}dt
$$

> ⚠️ 万能公式能解决所有三角函数有理式积分，但计算量可能较大。实战中优先考虑以下简化策略。

**三角有理式简化策略表**：

| 条件 | 替换策略 | 原因 |
| :--- | :--- | :--- |
| $R(-\sin x, \cos x) = -R(\sin x, \cos x)$ | 令 $t = \cos x$ | $\sin x\,dx$ 可凑为 $-d(\cos x)$ |
| $R(\sin x, -\cos x) = -R(\sin x, \cos x)$ | 令 $t = \sin x$ | $\cos x\,dx$ 可凑为 $d(\sin x)$ |
| $R(-\sin x, -\cos x) = R(\sin x, \cos x)$ | 令 $t = \tan x$ | 分子分母同除 $\cos^2 x$ 化为 $t$ 的有理式 |
| 以上都不满足 | 万能代换 $t = \tan\frac{x}{2}$ | 万能通解 |

#### 例题 5.1（基础·简化策略优先）

求 $\displaystyle\int \frac{\sin x}{1+\cos^2 x} dx$。

**思路溯源**：含 $\sin x$ 奇数次幂且 $\cos$ 是偶次——满足 $R(-\sin x,\cos x) = -R$，用 $t = \cos x$。

**解**：令 $t = \cos x$，$dt = -\sin x\,dx$。

$$
\int \frac{-dt}{1+t^2} = -\arctan t + C = -\arctan(\cos x) + C
$$

#### 例题 5.2（进阶·万能公式必用）

求 $\displaystyle\int \frac{1}{2+\sin x} dx$。

**思路溯源**：分子分母无奇偶对称性可简化，直接上万能代换。

**解**：令 $t = \tan\frac{x}{2}$。

$$
\int \frac{1}{2+\frac{2t}{1+t^2}} \cdot \frac{2}{1+t^2} dt = \int \frac{2}{2(1+t^2)+2t} dt = \int \frac{1}{t^2+t+1} dt
$$

$$
= \int \frac{1}{(t+\frac{1}{2})^2 + \frac{3}{4}} dt = \frac{2}{\sqrt{3}}\arctan\frac{2t+1}{\sqrt{3}} + C
$$

代回 $t = \tan\frac{x}{2}$。

$$
= \frac{2}{\sqrt{3}}\arctan\frac{2\tan\frac{x}{2}+1}{\sqrt{3}} + C
$$

### 题型 6：特殊高次有理函数的简化技巧

#### 6.1 倒代换（$t = 1/x$）

**适用场景**：分母次数远高于分子，或 $x \to \infty$ 型。

$$
\int \frac{1}{x^n+1} dx \xrightarrow{t=1/x} -\int \frac{t^{n-2}}{1+t^n} dt
$$

#### 6.2 组合拆分（分子凑分母的导数）

**适用场景**：分子分母存在导数关系。

$$
\int \frac{f'(x)}{f(x)} dx = \ln|f(x)| + C
$$

#### 6.3 可化为有理式的无理函数

| 被积函数含 | 替换 | $dx$ |
| :--- | :--- | :--- |
| $\sqrt[n]{ax+b}$ | $t = \sqrt[n]{ax+b}$ | $dx = \frac{n}{a}t^{n-1}dt$ |
| $\sqrt[n]{\frac{ax+b}{cx+d}}$ | $t = \sqrt[n]{\frac{ax+b}{cx+d}}$ | 解出 $x$ 后求 $dx$ |
| $\sqrt{a^2-x^2}$ | $x = a\sin t$ | $dx = a\cos t\,dt$ |
| $\sqrt{a^2+x^2}$ | $x = a\tan t$ | $dx = a\sec^2 t\,dt$ |
| $\sqrt{x^2-a^2}$ | $x = a\sec t$ | $dx = a\sec t\tan t\,dt$ |

> 注：后三个三角换元将在「定积分换元法」专题中详细展开。

#### 例题 6.1（倒代换）

求 $\displaystyle\int \frac{1}{x\sqrt{x^2-1}} dx$（$x > 1$）。

**思路溯源**：根号下是 $x^2-1$，标准三角换元 $\sec t$，但也用倒代换。

**解**：令 $x = \sec t$，$dx = \sec t \tan t\,dt$。

$$
\int \frac{1}{\sec t \cdot \tan t} \cdot \sec t \tan t\,dt = \int dt = t + C = \operatorname{arcsec} x + C = \arccos\frac{1}{x} + C
$$

## 三、方法总结表

| 题型 | 识别特征 | 拆分策略 | 积分手法 | 难度 |
| :--- | :--- | :--- | :--- | :---: |
| 不同一次因式 | 分母 $\prod(x-a_i)$ | $\sum\frac{A_i}{x-a_i}$ | $\ln\vert x-a_i\vert$ | ★ |
| 重复一次因式 | 分母含 $(x-a)^k$ | $\sum_{i=1}^k\frac{A_i}{(x-a)^i}$ | 对数 + 负幂 | ★★ |
| 单重二次因式 | $x^2+px+q$，$\Delta<0$ | $\frac{Ax+B}{x^2+px+q}$ | $\ln$ + $\arctan$ | ★★ |
| 重复二次因式 | $(x^2+px+q)^k$ | $\sum\frac{A_i x+B_i}{(\cdots)^i}$ | 递推降幂 | ★★★ |
| 三角函数有理式 | $R(\sin x,\cos x)$ | 万能代换 $t=\tan\frac{x}{2}$ | 化有理函数 | ★★★ |
| 高次有理/无理 | 分母高次或含根式 | 倒代换/三角换元 | 化标准型 | ★★ |
| 假分式 | $\deg P \geq \deg Q$ | **先做多项式除法** | 多项式 + 真分式 | ★ |

\frac{x^2+2}{(x-1)^2(x+1)} = \frac{1/4}{x+1} + \frac{3/4}{x-1} + \frac{3/2}{(x-1)^2}
$$
原式 $= \frac{1}{4}\ln|x+1| + \frac{3}{4}\ln|x-1| - \frac{3}{2(x-1)} + C$

**练习 3**：
$x^3-1 = (x-1)(x^2+x+1)$，拆分后得：
$$
\frac{1}{x^3-1} = \frac{1/3}{x-1} - \frac{x+2}{3(x^2+x+1)}
$$
原式 $= \frac{1}{3}\ln|x-1| - \frac{1}{6}\ln(x^2+x+1) - \frac{1}{\sqrt{3}}\arctan\frac{2x+1}{\sqrt{3}} + C$

**练习 4**：
$$
\frac{x+1}{(x^2+4)^2} = \frac{x}{(x^2+4)^2} + \frac{1}{(x^2+4)^2}
$$
第一项 $\int \frac{x}{(x^2+4)^2}dx = -\frac{1}{2(x^2+4)}$

第二项用递推 $k=2, a=2$：
$\int \frac{1}{(x^2+4)^2}dx = \frac{x}{8(x^2+4)} + \frac{1}{16}\arctan\frac{x}{2}$

原式 $= -\frac{1}{2(x^2+4)} + \frac{x}{8(x^2+4)} + \frac{1}{16}\arctan\frac{x}{2} + C$

**练习 5**：
万能代换 $t = \tan\frac{x}{2}$，化为 $\int \frac{2}{2t+2} dt = \int \frac{1}{t+1} dt = \ln|t+1| + C = \ln|\tan\frac{x}{2}+1| + C$

### 附录 C：奥氏方法推导过程

对于真分式 $\frac{P}{Q}$，由分部积分公式可证存在 $P_1, P_2$ 使：

$$
\int \frac{P}{Q} = \frac{P_1}{Q_1} + \int \frac{P_2}{Q_2}
$$

其中 $Q_1 = \gcd(Q,Q')$，$Q_2 = Q/Q_1$，且各项次数满足 $\deg P_1 < \deg Q_1$，$\deg P_2 < \deg Q_2$。

对等式两边求导，通分比较系数即可确定 $P_1, P_2$ 的系数。该方法**避免了传统待定系数法中因重因式而导致的系数爆炸问题**。
