# 分部积分法 | 积分专题

> **核心公式**：$\displaystyle\int u\,dv = uv - \int v\,du$
> **核心思想**：将不易直接积分的乘积式 $\int u\,dv$，转化为更易处理的 $\int v\,du$。
> **$u$ 的选取口诀**：**反、对、幂、指、三**（按此优先级选 $u$，余下为 $dv$）

---

## 一、核心公式与推导

### 公式证明

由乘积求导法则 $(uv)' = u'v + uv'$，移项得 $uv' = (uv)' - u'v$。两边积分：

$$
\int uv'\,dx = uv - \int u'v\,dx
$$

令 $du = u'\,dx$，$dv = v'\,dx$，即得分部积分公式的标准形式。

### $u$ 的选取原则：反·对·幂·指·三

| 优先级 | 函数类型 | 选为 $u$ | 选为 $dv$ | 理由 |
| :---: | :--- | :---: | :---: | :--- |
| 1 | **反**三角函数（arcsin, arctan…） | ✅ | — | 求导后变为代数函数，降级 |
| 2 | **对**数函数（ln x） | ✅ | — | 求导后变为 $1/x$，降级 |
| 3 | **幂**函数（xⁿ） | — | — | 居中，由搭档决定 |
| 4 | **指**数函数（eˣ, aˣ） | — | ✅ | 积分后仍是自身，不升级 |
| 5 | **三**角函数（sin, cos） | — | ✅ | 积分后仍是三角函数，不升级 |

> 💡 当被积函数是**两种类型函数的乘积**时，按此表选 $u$（优先级高的做 $u$）。特例：$\ln x$ 和 $\arctan x$ 单独出现时，视为 $1\cdot$ 该函数，取 $u = \ln x$ 或 $u = \arctan x$，$dv = 1\cdot dx$。

### ★ 必背专题：Wallis 积分与点火公式

> ⚡ **重要性**：Wallis 积分 $\int_0^{\pi/2}\sin^n x\,dx$（及 $\int_0^{\pi/2}\cos^n x\,dx$）是考研数学一中**出镜率最高**的定积分结论之一。但凡遇到 $[0,\pi/2]$ 上 $\sin^n x$ 或 $\cos^n x$ 的定积分，直接套用点火公式秒杀，无需每次从头分部。

#### 点火公式（Wallis 公式）

$$
\boxed{\int_0^{\frac{\pi}{2}} \sin^n x\,dx = \int_0^{\frac{\pi}{2}} \cos^n x\,dx = \begin{cases}
\dfrac{(n-1)!!}{n!!} \cdot \dfrac{\pi}{2}, & n \text{ 为偶数} \\[14pt]
\dfrac{(n-1)!!}{n!!}, & n \text{ 为奇数}
\end{cases}}
$$

其中双阶乘记号：$n!! = n(n-2)(n-4)\cdots$（降到 $1$ 或 $2$ 为止）。

#### 推导（分部积分法）

**递推公式**（$n \geq 2$）：

$$
\begin{aligned}
I_n &= \int_0^{\frac{\pi}{2}} \sin^n x\,dx
= \int_0^{\frac{\pi}{2}} \sin^{n-1}x \cdot \sin x\,dx \\[4pt]
&= \bigl[-\sin^{n-1}x \cos x\bigr]_0^{\frac{\pi}{2}}
   + (n-1)\int_0^{\frac{\pi}{2}} \sin^{n-2}x \cos^2 x\,dx \\[4pt]
&= 0 + (n-1)\int_0^{\frac{\pi}{2}} \sin^{n-2}x\,(1 - \sin^2 x)\,dx \\[4pt]
&= (n-1)I_{n-2} - (n-1)I_n
\end{aligned}
$$

移项得 $n I_n = (n-1)I_{n-2}$，即

$$
\boxed{I_n = \frac{n-1}{n}\,I_{n-2}} \qquad (n \geq 2)
$$

**初始值与闭式**：

- $I_0 = \displaystyle\int_0^{\pi/2} 1\,dx = \frac{\pi}{2}$
- $I_1 = \displaystyle\int_0^{\pi/2} \sin x\,dx = 1$

反复应用递推：
- $n$ **为偶数**（$n = 2m$）：$I_{2m} = \dfrac{2m-1}{2m} \cdot \dfrac{2m-3}{2m-2} \cdots \dfrac{1}{2} \cdot I_0 = \dfrac{(2m-1)!!}{(2m)!!} \cdot \dfrac{\pi}{2}$
- $n$ **为奇数**（$n = 2m+1$）：$I_{2m+1} = \dfrac{2m}{2m+1} \cdot \dfrac{2m-2}{2m-1} \cdots \dfrac{2}{3} \cdot I_1 = \dfrac{(2m)!!}{(2m+1)!!}$

#### 为什么叫"点火公式"？

递推每步降 $2$，奇偶分开，"点燃引线"一路降到底：

```
n=6: I₆ → (5/6) → I₄ → (3/4) → I₂ → (1/2) → I₀ = π/2
n=5: I₅ → (4/5) → I₃ → (2/3) → I₁ = 1
```

**口诀**：偶停 $\pi/2$，奇停 $1$。

#### 例题演示

**例 1**：$\displaystyle\int_0^{\frac{\pi}{2}} \sin^6 x\,dx = \frac{5}{6}\cdot\frac{3}{4}\cdot\frac{1}{2}\cdot\frac{\pi}{2} = \frac{5\pi}{32}$

**例 2**：$\displaystyle\int_0^{\frac{\pi}{2}} \cos^7 x\,dx = \frac{6}{7}\cdot\frac{4}{5}\cdot\frac{2}{3}\cdot 1 = \frac{16}{35}$

**例 3**（与换元结合）：$\displaystyle\int_0^\pi \sin^5 x\,dx$。由 $\sin x$ 在 $[0,\pi]$ 上的对称性，$= 2\displaystyle\int_0^{\pi/2}\sin^5 x\,dx = 2\cdot\frac{4}{5}\cdot\frac{2}{3}\cdot 1 = \frac{16}{15}$。

> ⚠️ 注意：点火公式**仅适用于区间 $[0,\pi/2]$** 且被积函数为纯 $\sin^n x$ 或 $\cos^n x$。若区间不同，需先用对称性/周期性归化到 $[0,\pi/2]$。

### ★ 必背技巧：表格法（DI Method / 列表法）

> ⚡ **来源**：表格法是张宇、Kira 等考研名师在课程中反复推荐的**分部积分加速技巧**，在 B站/知乎拥有数百万播放量的教学视频。它本质上是对「多次分部积分」过程的**表格化速算**，避免了反复写 $uv - \int vdu$ 的繁琐。

#### 表格法的适用场景

| 场景 | 特征 | 表格法效果 |
| :--- | :--- | :--- |
| $x^n e^{ax}$ 或 $x^n \sin bx$ | 幂函数（可一直求导到 $0$）+ 指数/三角（可一直积分） | 一次表格，一步出结果 |
| $e^{ax}\sin bx$（循环型） | 指数与三角相乘，两次分部回到自身 | 表格法 + 解方程 |
| $x^n \ln x$ | 幂函数 + 对数（对数做 $u$ 放微分列） | 对数求导后降级 |

#### 表格法的操作步骤

构造两列：**微分列（D）** 放 $u$ 及其逐次导数，**积分列（I）** 放 $dv$ 及其逐次积分。然后按对角线相乘，**符号正负交替**（$+ - + - \cdots$），最后一项横向相乘再加积分号（或不加，取决于微分列是否到 $0$）。

```
 D (求导列)      I (积分列)
   u     →     dv
   u'    →     v        + u·v
   u''   →     ∫v       - u'·∫v
   u'''  →     ∫∫v      + u''·∫∫v
   ...         ...
```

#### 例题演示

**例 A**：$\displaystyle\int x^2 e^x\,dx$（幂×指，$x^2$ 求导两次到常数 $2$）

| D 列（求导） | I 列（积分） | 符号 | 对角线乘积 |
| :---: | :---: | :---: | :--- |
| $x^2$ | $e^x$ | | |
| $2x$ | $e^x$ | $+$ | $x^2 e^x$ |
| $2$ | $e^x$ | $-$ | $-2x e^x$ |
| $0$ | $e^x$ | $+$ | $2 e^x$ |

（D 列求导到 $0$ 时停止，最后一行横向乘不再积分。）

$$
\int x^2 e^x\,dx = x^2 e^x - 2x e^x + 2 e^x + C = e^x(x^2 - 2x + 2) + C
$$

> 💡 对比传统分部：此题需手动分部两次。表格法只需填表 + 对角线乘 + 归并。

**例 B**：$\displaystyle\int x^3 \sin x\,dx$（幂×三角）

| D 列 | I 列 | 符号 | 对角线乘积 |
| :---: | :---: | :---: | :--- |
| $x^3$ | $\sin x$ | | |
| $3x^2$ | $-\cos x$ | $+$ | $-x^3\cos x$ |
| $6x$ | $-\sin x$ | $-$ | $+3x^2\sin x$ |
| $6$ | $\cos x$ | $+$ | $+6x\cos x$ |
| $0$ | $\sin x$ | $-$ | $-6\sin x$ |

$$
\int x^3 \sin x\,dx = -x^3\cos x + 3x^2\sin x + 6x\cos x - 6\sin x + C
$$

**例 C**（循环型）：$\displaystyle\int e^{2x}\sin 3x\,dx$

| D 列 | I 列 | 符号 | 对角线乘积 |
| :---: | :---: | :---: | :--- |
| $\sin 3x$ | $e^{2x}$ | | |
| $3\cos 3x$ | $\frac{1}{2}e^{2x}$ | $+$ | $\frac{1}{2}e^{2x}\sin 3x$ |
| $-9\sin 3x$ | $\frac{1}{4}e^{2x}$ | $-$ | $-\frac{3}{4}e^{2x}\cos 3x$ |

（D 列求导两次回到了 $\sin 3x$ 的倍数 $(-9\sin 3x)$。此时停止扩展表格，最后一行横向乘**加积分号**，设为 $I$。）

$$
I = \frac{1}{2}e^{2x}\sin 3x - \frac{3}{4}e^{2x}\cos 3x + \iint (-9\sin 3x)\cdot\frac{1}{4}e^{2x}\,dx
$$

最后一项 $= -\dfrac{9}{4}\displaystyle\int e^{2x}\sin 3x\,dx = -\dfrac{9}{4}I$。故

$$
I = \frac{1}{2}e^{2x}\sin 3x - \frac{3}{4}e^{2x}\cos 3x - \frac{9}{4}I
$$

解方程得 $I = \dfrac{e^{2x}}{13}(2\sin 3x - 3\cos 3x) + C$。

> 💡 **循环型的表格法关键**：当 D 列出现与原函数同型的函数时停止，最后一行加积分号，设为 $I$，解方程。

#### 表格法 vs 传统分部：什么时候用？

| 情形 | 推荐方法 |
| :--- | :--- |
| $x^n$（$n \leq 3$）乘以指数/三角 | **表格法**（填表秒杀） |
| $x^n$（$n \geq 4$）乘以指数/三角 | 表格法 + 归纳（或用递推公式） |
| 含 $\ln x$、$\arctan x$ | **传统分部**（这些函数在 D 列不会求导到 $0$） |
| 循环型（$e^{ax}\sin bx$） | 表格法 + 解方程 或 传统分部 |
| 只分部一次即终结 | 传统分部即可，表格法无优势 |

#### 表格法常见错误

> ⚠️ **符号错误**：对角线乘积的符号是 **$+ - + - \cdots$**（起始为 $+$），不是每行都 $+$。
>
> ⚠️ **D/I 列放反**：求导列放 $u$（被微分的那一个），积分列放 $dv$（被积分的那一个）。放反则全部错误。
>
> ⚠️ **循环型忘记加积分号**：当 D 列出现原函数的倍数时，最后一行不是横向乘完就结束，而是要**再加 $\int$（最后行横向乘）**，再设为 $I$ 解方程。

### 题型一 [基础]：幂函数 × 指数/三角 — 直接分部

**核心特征**：被积函数为 $x^n$ 乘 $e^{ax}$（或 $\sin bx$, $\cos bx$）。**幂函数选作 $u$**，每用一次分部，幂次降 $1$。$n$ 次分部后可化为纯指数/三角积分。

#### 题 1 【基础】

$$
\int x e^x\,dx
$$

**思路溯源**：$x$（幂）与 $e^x$（指）相遇。按"反对幂指三"，幂函数做 $u$，$e^x dx$ 做 $dv$。

**解法**：

令 $u = x$，$dv = e^x\,dx$，则 $du = dx$，$v = e^x$。

$$
\int x e^x\,dx = x e^x - \int e^x\,dx = x e^x - e^x + C = e^x(x-1) + C
$$

> 💡 分部一次即终结——幂次从 $x^1$ 降为常数 $1$。

**答案**：$e^x(x-1) + C$

---

#### 题 2 【基础】

$$
\int x^2 \cos x\,dx
$$

**解法**：

令 $u = x^2$，$dv = \cos x\,dx$，则 $du = 2x\,dx$，$v = \sin x$。

$$
I = x^2 \sin x - \int 2x \sin x\,dx = x^2 \sin x - 2J
$$

对 $J = \int x \sin x\,dx$ 再分部：令 $u = x$，$dv = \sin x\,dx$，$du = dx$，$v = -\cos x$。

$$
J = -x \cos x - \int (-\cos x)\,dx = -x \cos x + \sin x + C
$$

代回：

$$
I = x^2 \sin x - 2(-x \cos x + \sin x) + C = (x^2 - 2)\sin x + 2x \cos x + C
$$

> 💡 $x^2$ 需分部两次：第一次降为 $x$，第二次降为常数。幂次 $n$ 意味着需 $n$ 次分部。

**答案**：$(x^2 - 2)\sin x + 2x \cos x + C$

---

### 题型二 [基础]：对数/反三角 — "$1 \times$ 函数" 技巧

**核心特征**：被积函数中单独出现 $\ln x$ 或 $\arctan x$ 等，没有明显的乘积结构。**补上因子 $1$ 作为 $dv$**，取该函数为 $u$。

#### 题 3 【基础】

$$
\int \ln x\,dx
$$

**解法**：

令 $u = \ln x$，$dv = 1\cdot dx$，则 $du = \dfrac{1}{x}\,dx$，$v = x$。

$$
\int \ln x\,dx = x \ln x - \int x \cdot \frac{1}{x}\,dx = x \ln x - \int 1\,dx = x \ln x - x + C
$$

**答案**：$x \ln x - x + C$

---

#### 题 4 【基础】

$$
\int \arcsin x\,dx
$$

**解法**：

令 $u = \arcsin x$，$dv = 1\cdot dx$，则 $du = \dfrac{dx}{\sqrt{1-x^2}}$，$v = x$。

$$
\int \arcsin x\,dx = x \arcsin x - \int \frac{x}{\sqrt{1-x^2}}\,dx
$$

对于剩余积分：$\int \frac{x}{\sqrt{1-x^2}}dx = -\sqrt{1-x^2} + C$（凑微分：$d(1-x^2) = -2x\,dx$）。

故

$$
\int \arcsin x\,dx = x \arcsin x + \sqrt{1-x^2} + C
$$

**答案**：$x \arcsin x + \sqrt{1-x^2} + C$

---

### 题型三 [进阶]：循环型 — 两次分部回到自身

**核心特征**：指数函数 $\times$ 三角函数（$\int e^{ax}\sin bx\,dx$ 或 $\int e^{ax}\cos bx\,dx$）。两次分部后原积分重现，联立方程即可解出。

#### 题 5 【进阶】

$$
I = \int e^x \sin x\,dx
$$

**思路溯源**：$e^x$ 无论求导还是积分都是自身，$\sin x$ 求导两次变为 $-\sin x$。两次分部后必然回到原积分，只是多了一个系数。

**解法**：

第一次分部：$u = \sin x$，$dv = e^x\,dx$，$du = \cos x\,dx$，$v = e^x$。

$$
I = e^x \sin x - \int e^x \cos x\,dx
$$

第二次分部（对 $\int e^x \cos x\,dx$）：$u = \cos x$，$dv = e^x\,dx$，$du = -\sin x\,dx$，$v = e^x$。

$$
\int e^x \cos x\,dx = e^x \cos x - \int e^x (-\sin x)\,dx = e^x \cos x + I
$$

代回：

$$
I = e^x \sin x - (e^x \cos x + I) = e^x \sin x - e^x \cos x - I
$$

移项得 $2I = e^x(\sin x - \cos x)$，故

$$
I = \frac{e^x}{2}(\sin x - \cos x) + C
$$

> 💡 **关键**：第二次分部时 $u$ 仍需选同类型的函数（两次都选三角函数），否则会还原而非产生循环。

**答案**：$\dfrac{e^x}{2}(\sin x - \cos x) + C$

---

#### 题 6 【进阶 — 含参数】

求 $\displaystyle\int e^{ax} \cos bx\,dx$（$a, b \neq 0$）。

**解法**：

令 $I = \int e^{ax}\cos bx\,dx$。

第一次分部：$u = \cos bx$，$dv = e^{ax}dx$，$du = -b\sin bx\,dx$，$v = \frac{1}{a}e^{ax}$。

$$
I = \frac{1}{a}e^{ax}\cos bx + \frac{b}{a}\int e^{ax}\sin bx\,dx
$$

第二次分部：$u = \sin bx$，$dv = e^{ax}dx$，$du = b\cos bx\,dx$，$v = \frac{1}{a}e^{ax}$。

$$
\int e^{ax}\sin bx\,dx = \frac{1}{a}e^{ax}\sin bx - \frac{b}{a}\int e^{ax}\cos bx\,dx
= \frac{1}{a}e^{ax}\sin bx - \frac{b}{a}I
$$

代回：

$$
I = \frac{1}{a}e^{ax}\cos bx + \frac{b}{a}\left(\frac{1}{a}e^{ax}\sin bx - \frac{b}{a}I\right)
$$

$$
I = \frac{e^{ax}}{a}\cos bx + \frac{b e^{ax}}{a^2}\sin bx - \frac{b^2}{a^2}I
$$

$$
\left(1 + \frac{b^2}{a^2}\right)I = \frac{e^{ax}}{a^2}\left(a\cos bx + b\sin bx\right)
$$

$$
I = \frac{e^{ax}}{a^2 + b^2}\left(a\cos bx + b\sin bx\right) + C
$$

> 💡 结果呈现优美的对称性。特例 $a=b=1$ 时 $\int e^x \cos x\,dx = \frac{e^x}{2}(\cos x + \sin x)$，与题 5 对照（互换 $\sin,\cos$ 角色）。

**答案**：$\dfrac{e^{ax}}{a^2+b^2}(a\cos bx + b\sin bx) + C$

### 题型四 [进阶]：降幂递推型

**核心特征**：被积函数含 $n$ 次幂 $x^n$ 或 $(\ln x)^n$。通过一次分部，$n$ 降为 $n-1$，得到递推公式 $I_n = f(I_{n-1})$。反复递推可求闭式。

#### 题 7 【进阶】

设 $I_n = \displaystyle\int_0^1 x^n e^x\,dx$（$n \geq 0$）。导出 $I_n$ 的递推公式，并求 $I_3$。

**解法**：

令 $u = x^n$，$dv = e^x\,dx$，则 $du = n x^{n-1}\,dx$，$v = e^x$。

$$
\begin{aligned}
I_n &= x^n e^x\Big|_0^1 - \int_0^1 n x^{n-1} e^x\,dx \\[4pt]
&= e - n I_{n-1}
\end{aligned}
$$

递推公式：$I_n = e - n I_{n-1}$（$n \geq 1$），初始值 $I_0 = \int_0^1 e^x dx = e - 1$。

逐次计算：

$$
\begin{aligned}
I_1 &= e - 1\cdot I_0 = e - (e-1) = 1 \\[4pt]
I_2 &= e - 2\cdot I_1 = e - 2 \\[4pt]
I_3 &= e - 3\cdot I_2 = e - 3(e-2) = e - 3e + 6 = 6 - 2e
\end{aligned}
$$

> 💡 定积分中的分部公式：$\int_a^b u\,dv = uv\big|_a^b - \int_a^b v\,du$。边界项 $uv\big|_a^b$ 需特别注意 $x^n e^x$ 在端点处的取值。

**答案**：$I_n = e - n I_{n-1}$，$I_3 = 6 - 2e$

---

#### 题 8 【基础 — 点火公式直用】

计算：

$$
\int_0^{\frac{\pi}{2}} \sin^8 x\,dx
$$

**解法**：

直接套用上文 ★ 点火公式（$n=8$ 为偶数）：

$$
\int_0^{\frac{\pi}{2}} \sin^8 x\,dx
= \frac{7}{8}\cdot\frac{5}{6}\cdot\frac{3}{4}\cdot\frac{1}{2}\cdot\frac{\pi}{2}
= \frac{35\pi}{256}
$$

> 💡 若不用点火公式而从 $\sin^8 x$ 降幂或用分部积分逐步递推，需要至少 4 轮操作。点火公式将复杂度从 $O(n)$ 降为 $O(1)$——这正是其"必背"价值所在。

**推导过程与完整递推**：见上文 ★ 必背专题。

**答案**：$\dfrac{35\pi}{256}$

### 题型五 [困难]：分部 + 换元的组合技

**核心特征**：单一技巧不足以解决，需要**先换元再分部**（或反过来）。常见于含复合函数（如 $e^{\sqrt{x}}$）或被积函数交叉多个技巧的情况。

#### 题 9 【困难】

$$
\int e^{\sqrt{x}}\,dx
$$

**思路溯源**：$\sqrt{x}$ 使分部无从下手。先用换元 $t = \sqrt{x}$ 消去复合结构，化为关于 $t$ 的可分部积分。

**解法**：

令 $t = \sqrt{x}$，则 $x = t^2$，$dx = 2t\,dt$。

$$
\int e^{\sqrt{x}}\,dx = \int e^t \cdot 2t\,dt = 2\int t e^t\,dt
$$

这就是题型一的标准形式（幂 × 指）。分部：$u = t$，$dv = e^t dt$，$v = e^t$。

$$
\int t e^t\,dt = t e^t - \int e^t\,dt = t e^t - e^t + C = e^t(t-1) + C
$$

乘 $2$ 并回代 $t = \sqrt{x}$：

$$
\int e^{\sqrt{x}}\,dx = 2e^{\sqrt{x}}(\sqrt{x} - 1) + C
$$

> 💡 先换元消除复合结构，再对"曝光"后的幂×指结构分部——顺序不可颠倒。

**答案**：$2e^{\sqrt{x}}(\sqrt{x} - 1) + C$

---

#### 题 10 【困难】

计算 $\displaystyle I = \int_0^1 x \arctan x\,dx$。

**解法**：

分部：$u = \arctan x$，$dv = x\,dx$，$du = \dfrac{dx}{1+x^2}$，$v = \dfrac{x^2}{2}$。

$$
\begin{aligned}
I &= \frac{x^2}{2}\arctan x\Bigg|_0^1 - \frac{1}{2}\int_0^1 \frac{x^2}{1+x^2}\,dx \\[6pt]
&= \frac{1}{2}\cdot\frac{\pi}{4} - \frac{1}{2}\int_0^1 \left(1 - \frac{1}{1+x^2}\right)dx \\[6pt]
&= \frac{\pi}{8} - \frac{1}{2}\bigl[x - \arctan x\bigr]_0^1 \\[6pt]
&= \frac{\pi}{8} - \frac{1}{2}\left(1 - \frac{\pi}{4}\right) \\[6pt]
&= \frac{\pi}{4} - \frac{1}{2}
\end{aligned}
$$

> 💡 分部后剩余的有理分式 $\frac{x^2}{1+x^2}$ 通过 **"加 1 减 1"** 技巧化为 $1 - \frac{1}{1+x^2}$，分别积分。这是 $\arctan$ 类分部积分后的常见套路。

**答案**：$\dfrac{\pi}{4} - \dfrac{1}{2}$

### 题型六 [综合]：特殊结构识别 — 导数配对

**核心特征**：被积函数形如 $e^x[f(x) + f'(x)]$，因 $\frac{d}{dx}[e^x f(x)] = e^x[f(x) + f'(x)]$，直接"看出"原函数，无需分部。这是分部积分公式的逆用。

#### 题 11 【综合】

$$
\int e^x\left(\frac{x-1}{x^2}\right) dx
$$

**思路溯源**：$\frac{x-1}{x^2} = \frac{1}{x} - \frac{1}{x^2}$。注意到 $\frac{d}{dx}\left(\frac{1}{x}\right) = -\frac{1}{x^2}$。令 $f(x) = \frac{1}{x}$，则 $f(x) + f'(x) = \frac{1}{x} - \frac{1}{x^2}$。

**解法**：

观察 $\dfrac{x-1}{x^2} = \dfrac{1}{x} - \dfrac{1}{x^2}$，而 $\dfrac{d}{dx}\!\left(\dfrac{1}{x}\right) = -\dfrac{1}{x^2}$，即 $-\dfrac{1}{x^2} = \left(\dfrac{1}{x}\right)'$。

故被积函数为 $e^x\!\left[\frac{1}{x} + \left(\frac{1}{x}\right)'\right] = \frac{d}{dx}\!\left[e^x \cdot \frac{1}{x}\right]$。因此

$$
\int e^x\left(\frac{x-1}{x^2}\right) dx = \frac{e^x}{x} + C
$$

**验证**：$\frac{d}{dx}\!\left(\frac{e^x}{x}\right) = \frac{x e^x - e^x}{x^2} = e^x\frac{x-1}{x^2}$。✓

> 💡 不必分部！只需识别 $f(x) + f'(x)$ 的配对结构。这是分部积分公式从右往左读的形式：$\int (uv' + u'v) = uv$。

**答案**：$\dfrac{e^x}{x} + C$

---

#### 题 12 【综合】

求 $\displaystyle\int e^x \left(\frac{1+\sin x}{1+\cos x}\right) dx$。

**解法**：

先化简三角函数：$\dfrac{1+\sin x}{1+\cos x} = \dfrac{(1+\sin x)(1-\cos x)}{1-\cos^2 x} = \dfrac{1-\cos x + \sin x - \sin x\cos x}{\sin^2 x}$。

这条路太复杂。换思路：$\dfrac{1+\sin x}{1+\cos x} = \dfrac{1+2\sin\frac{x}{2}\cos\frac{x}{2}}{2\cos^2\frac{x}{2}} = \dfrac{1}{2}\sec^2\frac{x}{2} + \tan\frac{x}{2}$。

注到 $\frac{d}{dx}(\tan\frac{x}{2}) = \frac{1}{2}\sec^2\frac{x}{2}$。故 $\frac{1+\sin x}{1+\cos x} = \tan\frac{x}{2} + (\tan\frac{x}{2})'$。

由导数配对公式 $\int e^x[f(x)+f'(x)]dx = e^x f(x) + C$，取 $f(x) = \tan\frac{x}{2}$：

$$
\int e^x\left(\frac{1+\sin x}{1+\cos x}\right) dx = e^x \tan\frac{x}{2} + C
$$

> 💡 此题体现了从复杂表达式中"提取" $f+f'$ 结构的洞察力。先用半角公式化简，对照导数配对模式。

**答案**：$e^x\tan\dfrac{x}{2} + C$

## 五、附录

### 自测练习答案

**练习 1**：令 $u = \ln x$，$dv = x\,dx$，$v = \frac{x^2}{2}$。

$$
\int x\ln x\,dx = \frac{x^2}{2}\ln x - \int \frac{x^2}{2}\cdot\frac{1}{x}\,dx
= \frac{x^2}{2}\ln x - \frac{x^2}{4} + C
$$

---

**练习 2**：令 $I = \int e^{2x}\sin 3x\,dx$。两次分部（$u$ 选 $\sin 3x$，再 $u$ 选 $\cos 3x$）：

第一次：$u = \sin 3x$，$dv = e^{2x}dx$，$v = \frac{1}{2}e^{2x}$。

$I = \frac{1}{2}e^{2x}\sin 3x - \frac{3}{2}\int e^{2x}\cos 3x\,dx$

第二次：对 $\int e^{2x}\cos 3x\,dx$，$u = \cos 3x$，$dv = e^{2x}dx$。

$\int e^{2x}\cos 3x\,dx = \frac{1}{2}e^{2x}\cos 3x + \frac{3}{2}I$

代回：

$I = \frac{1}{2}e^{2x}\sin 3x - \frac{3}{2}\left(\frac{1}{2}e^{2x}\cos 3x + \frac{3}{2}I\right)$

$I = \frac{1}{2}e^{2x}\sin 3x - \frac{3}{4}e^{2x}\cos 3x - \frac{9}{4}I$

$\frac{13}{4}I = \frac{e^{2x}}{4}(2\sin 3x - 3\cos 3x)$

$I = \dfrac{e^{2x}}{13}(2\sin 3x - 3\cos 3x) + C$

---

**练习 3**：$u = (\ln x)^n$，$dv = dx$，$v = x$。

$$
I_n = x(\ln x)^n - \int x \cdot n(\ln x)^{n-1}\cdot\frac{1}{x}\,dx
= x(\ln x)^n - n I_{n-1}
$$

递推公式：$I_n = x(\ln x)^n - n I_{n-1}$，$I_0 = x + C$（或对不定积分引入常数）。

---

**练习 4**：$u = x$，$dv = \cos x\,dx$，$v = \sin x$。

$$
\begin{aligned}
\int_0^{\frac{\pi}{2}} x\cos x\,dx
&= x\sin x\Big|_0^{\frac{\pi}{2}} - \int_0^{\frac{\pi}{2}} \sin x\,dx \\[4pt]
&= \frac{\pi}{2}\cdot 1 - \bigl[-\cos x\bigr]_0^{\frac{\pi}{2}} \\[4pt]
&= \frac{\pi}{2} - (0 - (-1)) = \frac{\pi}{2} - 1
\end{aligned}
$$

---

**练习 5**：注意 $\frac{1}{x} + \ln x = \ln x + (\ln x)'$。由 $e^x[f(x)+f'(x)]$ 配对：

$$
\int e^x\left(\frac{1}{x} + \ln x\right) dx = e^x \ln x + C
$$
