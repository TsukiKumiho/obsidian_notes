# 不定积分 | 全题型系统整理

> 目标：从基本公式到综合技巧，覆盖考研数学一不定积分的全部常见题型。每道例题均含详细解析，适合基础薄弱者逐步建立"积分直觉"。

---

## 一、核心公式与推导

### 1.1 不定积分定义

$F'(x) = f(x)$ 则称 $F(x)$ 为 $f(x)$ 的一个原函数。全体原函数称为不定积分：

$$
\int f(x)\,dx = F(x) + C
$$

### 1.2 基本积分公式（必须倒背如流）

| 序号 | 被积函数 | 原函数 | 记忆提示 |
| :---: | :--- | :--- | :--- |
| 1 | $\int k\,dx$ | $kx + C$ | 常数积分乘 $x$ |
| 2 | $\int x^\mu dx$ ($\mu \neq -1$) | $\dfrac{x^{\mu+1}}{\mu+1} + C$ | 指数 +1 作分母 |
| 3 | $\int \dfrac{1}{x}dx$ | $\ln\|x\| + C$ | **绝对值勿忘** |
| 4 | $\int e^x dx$ | $e^x + C$ | $e^x$ 不变 |
| 5 | $\int a^x dx$ | $\dfrac{a^x}{\ln a} + C$ | 多除一个 $\ln a$ |
| 6 | $\int \sin x\,dx$ | $-\cos x + C$ | 正弦积出**负**余弦 |
| 7 | $\int \cos x\,dx$ | $\sin x + C$ | 余弦积出正弦 |
| 8 | $\int \tan x\,dx$ | $-\ln\|\cos x\| + C$ | $\tan = \sin/\cos$，凑微分 |
| 9 | $\int \cot x\,dx$ | $\ln\|\sin x\| + C$ | $\cot = \cos/\sin$，凑微分 |
| 10 | $\int \sec x\,dx$ | $\ln\|\sec x + \tan x\| + C$ | **必背**，推导见下文 |
| 11 | $\int \csc x\,dx$ | $\ln\|\csc x - \cot x\| + C$ | 对称公式 |
| 12 | $\int \sec^2 x\,dx$ | $\tan x + C$ | $(\tan x)' = \sec^2 x$ |
| 13 | $\int \csc^2 x\,dx$ | $-\cot x + C$ | $(\cot x)' = -\csc^2 x$ |
| 14 | $\int \sec x\tan x\,dx$ | $\sec x + C$ | $(\sec x)' = \sec x\tan x$ |
| 15 | $\int \csc x\cot x\,dx$ | $-\csc x + C$ | $(\csc x)' = -\csc x\cot x$ |
| 16 | $\int \dfrac{1}{1+x^2}dx$ | $\arctan x + C$ | 最重要反三角积分 |
| 17 | $\int \dfrac{1}{\sqrt{1-x^2}}dx$ | $\arcsin x + C$ | 根号下 $1-x^2$ |
| 18 | $\int \dfrac{1}{\sqrt{x^2 \pm a^2}}dx$ | $\ln\|x + \sqrt{x^2 \pm a^2}\| + C$ | 反双曲型 |
| 19 | $\int \dfrac{1}{x^2 - a^2}dx$ | $\dfrac{1}{2a}\ln\left\|\dfrac{x-a}{x+a}\right\| + C$ | 裂项法 |

> **公式 10 的推导**：$\displaystyle \int \sec x\,dx = \int \frac{\sec x(\sec x + \tan x)}{\sec x + \tan x}dx = \int \frac{d(\sec x + \tan x)}{\sec x + \tan x} = \ln\|\sec x + \tan x\| + C$

### 1.3 三大积分法的基本框架

| 方法 | 核心公式/操作 | 口诀 |
| :--- | :--- | :--- |
| **第一类换元（凑微分）** | $\int f[\varphi(x)]\varphi'(x)dx = \int f(u)du$ | 导数塞回去 |
| **第二类换元（变量代换）** | $x = \psi(t)$，$dx = \psi'(t)dt$ | 换元必**回代** |
| **分部积分** | $\int u\,dv = uv - \int v\,du$ | 反对幂指三 |

## 二、题型分类与精析

> 每个题型按**基础 → 进阶 → 综合**递进排列。基础薄弱的读者请从头逐题练习。

---

### 题型 2.1：直接积分法（基本公式直接套用 / 简单代数变形）

**核心思路**：将被积函数通过代数变形（展开、拆分、三角恒等式）化为基本公式表中形式的组合，然后逐项积分。

#### 例题 2.1.1【基础】多项式展开

$$
\int (x^2+1)(x-3)\,dx
$$

**解法**：展开后再逐项积分。

$$
(x^2+1)(x-3) = x^3 - 3x^2 + x - 3
$$

$$
\int (x^3 - 3x^2 + x - 3)dx = \frac{x^4}{4} - x^3 + \frac{x^2}{2} - 3x + C
$$

**答案**：$\displaystyle \frac{x^4}{4} - x^3 + \frac{x^2}{2} - 3x + C$

---

#### 例题 2.1.2【基础】三角恒等式化简

$$
\int \frac{\cos 2x}{\cos x - \sin x}dx
$$

**解法**：$\cos 2x = \cos^2 x - \sin^2 x = (\cos x - \sin x)(\cos x + \sin x)$。

$$
\int \frac{(\cos x - \sin x)(\cos x + \sin x)}{\cos x - \sin x}dx = \int (\cos x + \sin x)dx = \sin x - \cos x + C
$$

**答案**：$\sin x - \cos x + C$

---

#### 例题 2.1.3【基础】$\dfrac{1}{\text{二次式}}$ 配方

$$
\int \frac{dx}{x^2 + 4x + 13}
$$

**解法**：配成平方和形式，用 $\arctan$ 公式。

$$
x^2 + 4x + 13 = (x+2)^2 + 9 = (x+2)^2 + 3^2
$$

$$
\int \frac{dx}{(x+2)^2 + 3^2} = \frac{1}{3}\arctan\!\left(\frac{x+2}{3}\right) + C
$$

**答案**：$\displaystyle \frac{1}{3}\arctan\!\left(\frac{x+2}{3}\right) + C$

---

#### 例题 2.1.4【基础】$\dfrac{1}{\sqrt{\text{二次式}}}$ 配方

$$
\int \frac{dx}{\sqrt{8 + 2x - x^2}}
$$

**解法**：配方 → $\arcsin$ 型。

$$
8 + 2x - x^2 = 9 - (x-1)^2
$$

$$
\int \frac{dx}{\sqrt{9 - (x-1)^2}} = \arcsin\!\left(\frac{x-1}{3}\right) + C
$$

**答案**：$\displaystyle \arcsin\!\left(\frac{x-1}{3}\right) + C$

---

### 题型 2.2：第一类换元法（凑微分法）

**核心思路**：识别被积函数中是否存在 $\varphi'(x)$ 与 $f[\varphi(x)]$ 的乘积结构。

**凑微分速查表**（必背）：

| 导数形式 | 微分形式 | 常见应用 |
| :--- | :--- | :--- |
| $(x^n)' = nx^{n-1}$ | $x^{n-1}dx = \frac{1}{n}d(x^n)$ | 幂函数凑微分 |
| $(\sin x)' = \cos x$ | $\cos x\,dx = d(\sin x)$ | 含 $\cos x$ 的奇次幂 |
| $(\cos x)' = -\sin x$ | $\sin x\,dx = -d(\cos x)$ | 含 $\sin x$ 的奇次幂 |
| $(\ln x)' = \frac{1}{x}$ | $\frac{1}{x}dx = d(\ln x)$ | 分母含 $x$ |
| $(e^x)' = e^x$ | $e^x dx = d(e^x)$ | 分子含 $e^x$ |
| $(\arctan x)' = \frac{1}{1+x^2}$ | $\frac{dx}{1+x^2} = d(\arctan x)$ | 分母 $1+x^2$ |
| $(\arcsin x)' = \frac{1}{\sqrt{1-x^2}}$ | $\frac{dx}{\sqrt{1-x^2}} = d(\arcsin x)$ | 根号下 $1-x^2$ |
| $(\tan x)' = \sec^2 x$ | $\sec^2 x\,dx = d(\tan x)$ | 含 $\sec^2 x$ |

#### 例题 2.2.1【基础】幂函数的凑微分

$$
\int x\sqrt{1+x^2}\,dx
$$

**思路溯源**：观察到 $x\,dx$ 与 $(1+x^2)' = 2x$ 差一个常数因子。令 $u = 1+x^2$，则 $du = 2x\,dx$。

**解法**：

$$
\int x\sqrt{1+x^2}\,dx = \frac{1}{2}\int \sqrt{1+x^2}\,d(1+x^2) = \frac{1}{2} \cdot \frac{2}{3}(1+x^2)^{3/2} + C
$$

**答案**：$\displaystyle \frac{1}{3}(1+x^2)^{3/2} + C$

---

#### 例题 2.2.2【基础】$\frac{1}{x}$ 型凑微分

$$
\int \frac{\ln x}{x}\,dx
$$

**解法**：$\frac{1}{x}dx = d(\ln x)$。

$$
\int \frac{\ln x}{x}\,dx = \int \ln x\,d(\ln x) = \frac{(\ln x)^2}{2} + C
$$

**答案**：$\displaystyle \frac{(\ln x)^2}{2} + C$

---

#### 例题 2.2.3【基础】指数型凑微分

$$
\int \frac{e^x}{1+e^x}\,dx
$$

**解法**：$e^x dx = d(1+e^x)$。

$$
\int \frac{e^x}{1+e^x}\,dx = \int \frac{d(1+e^x)}{1+e^x} = \ln(1+e^x) + C
$$

**答案**：$\ln(1+e^x) + C$

---

#### 例题 2.2.4【基础】三角函数的凑微分

$$
\int \sin^3 x \cos x\,dx
$$

**解法**：$\cos x\,dx = d(\sin x)$。

$$
\int \sin^3 x \cos x\,dx = \int \sin^3 x\,d(\sin x) = \frac{\sin^4 x}{4} + C
$$

**答案**：$\displaystyle \frac{\sin^4 x}{4} + C$

---

#### 例题 2.2.5【进阶】复杂凑微分（分子分母配合）

$$
\int \frac{dx}{x(1+\ln x)}
$$

**解法**：$\frac{1}{x}dx = d(\ln x)$，令 $u = \ln x$。

$$
\int \frac{dx}{x(1+\ln x)} = \int \frac{d(\ln x)}{1+\ln x} = \ln|1+\ln x| + C
$$

**答案**：$\ln|1+\ln x| + C$

---

#### 例题 2.2.6【进阶】$\arctan$ 型凑微分

$$
\int \frac{x}{1+x^4}\,dx
$$

**解法**：$x\,dx = \frac{1}{2}d(x^2)$，分母 $1+(x^2)^2$。

$$
\int \frac{x}{1+x^4}\,dx = \frac{1}{2}\int \frac{d(x^2)}{1+(x^2)^2} = \frac{1}{2}\arctan(x^2) + C
$$

**答案**：$\displaystyle \frac{1}{2}\arctan(x^2) + C$

---

#### 例题 2.2.7【进阶】$\arcsin$ 型凑微分

$$
\int \frac{x}{\sqrt{1-x^4}}\,dx
$$

**解法**：$x\,dx = \frac{1}{2}d(x^2)$，分母 $\sqrt{1-(x^2)^2}$。

$$
\int \frac{x}{\sqrt{1-x^4}}\,dx = \frac{1}{2}\int \frac{d(x^2)}{\sqrt{1-(x^2)^2}} = \frac{1}{2}\arcsin(x^2) + C
$$

**答案**：$\displaystyle \frac{1}{2}\arcsin(x^2) + C$

---

#### 例题 2.2.8【综合】先拆后凑

$$
\int \frac{x+1}{x^2+1}\,dx
$$

**解法**：拆为两项，分别处理。

$$
\int \frac{x+1}{x^2+1}\,dx = \int \frac{x}{x^2+1}\,dx + \int \frac{1}{x^2+1}\,dx
$$

第一项：$\frac{x}{x^2+1}dx = \frac{1}{2}\cdot\frac{d(x^2+1)}{x^2+1} \to \frac{1}{2}\ln(x^2+1)$

第二项：直接 $\arctan x$

$$
= \frac{1}{2}\ln(x^2+1) + \arctan x + C
$$

**答案**：$\displaystyle \frac{1}{2}\ln(x^2+1) + \arctan x + C$

---

### 题型 2.3：第二类换元法（变量代换）

**核心思路**：直接凑微分行不通时，主动引入新变量 $t$ 替换 $x$。**换元必回代，不定积分不换限**。

#### 2.3.1 三角代换

| 被积函数含 | 代换 | $dx$ 变换 | 回代依据 |
| :--- | :--- | :--- | :--- |
| $\sqrt{a^2 - x^2}$ | $x = a\sin t$ | $dx = a\cos t\,dt$ | $\cos t = \frac{\sqrt{a^2-x^2}}{a}$ |
| $\sqrt{a^2 + x^2}$ | $x = a\tan t$ | $dx = a\sec^2 t\,dt$ | $\sec t = \frac{\sqrt{a^2+x^2}}{a}$ |
| $\sqrt{x^2 - a^2}$ | $x = a\sec t$ | $dx = a\sec t\tan t\,dt$ | $\tan t = \frac{\sqrt{x^2-a^2}}{a}$ |

#### 例题 2.3.1【基础】$\sqrt{a^2-x^2}$ 型

$$
\int \sqrt{4 - x^2}\,dx
$$

**解法**：令 $x = 2\sin t$（$t \in [-\frac{\pi}{2}, \frac{\pi}{2}]$），$dx = 2\cos t\,dt$。

$$
\begin{aligned}
\int \sqrt{4-x^2}\,dx &= \int \sqrt{4-4\sin^2 t} \cdot 2\cos t\,dt
= \int 2|\cos t| \cdot 2\cos t\,dt \\
&= 4\int \cos^2 t\,dt
= 4\int \frac{1+\cos 2t}{2}\,dt
= 2t + \sin 2t + C \\
&= 2t + 2\sin t\cos t + C
\end{aligned}
$$

回代：$\sin t = \frac{x}{2}$，$t = \arcsin\frac{x}{2}$，$\cos t = \frac{\sqrt{4-x^2}}{2}$。

$$
= 2\arcsin\frac{x}{2} + 2 \cdot \frac{x}{2} \cdot \frac{\sqrt{4-x^2}}{2} + C
= 2\arcsin\frac{x}{2} + \frac{x\sqrt{4-x^2}}{2} + C
$$

**答案**：$\displaystyle 2\arcsin\frac{x}{2} + \frac{x\sqrt{4-x^2}}{2} + C$

---

#### 例题 2.3.2【基础】$\sqrt{a^2+x^2}$ 型

$$
\int \frac{dx}{\sqrt{1+x^2}}
$$

**解法**：令 $x = \tan t$（$t \in (-\frac{\pi}{2}, \frac{\pi}{2})$），$dx = \sec^2 t\,dt$。

$$
\int \frac{dx}{\sqrt{1+x^2}} = \int \frac{\sec^2 t}{\sec t}\,dt = \int \sec t\,dt = \ln|\sec t + \tan t| + C
$$

回代：$\tan t = x$，$\sec t = \sqrt{1+x^2}$。

$$
= \ln|x + \sqrt{1+x^2}| + C
$$

**答案**：$\ln|x + \sqrt{1+x^2}| + C$

---

#### 例题 2.3.3【进阶】$\sqrt{x^2-a^2}$ 型

$$
\int \frac{dx}{x^2\sqrt{x^2-1}}
$$

**解法**：令 $x = \sec t$（$t \in (0, \frac{\pi}{2})$），$dx = \sec t\tan t\,dt$。

$$
\begin{aligned}
\int \frac{dx}{x^2\sqrt{x^2-1}}
&= \int \frac{\sec t\tan t}{\sec^2 t \cdot \tan t}\,dt
= \int \cos t\,dt = \sin t + C
\end{aligned}
$$

回代：$\sec t = x$，$\sin t = \frac{\sqrt{x^2-1}}{x}$。

**答案**：$\displaystyle \frac{\sqrt{x^2-1}}{x} + C$

---

#### 2.3.2 根式代换（整体代换）

**适用场景**：被积函数含 $\sqrt[n]{ax+b}$ 或 $\sqrt[n]{\frac{ax+b}{cx+d}}$ 时，将整个根式设为 $t$。

#### 例题 2.3.4【基础】一次根式代换

$$
\int \frac{dx}{1 + \sqrt{x}}
$$

**解法**：令 $t = \sqrt{x}$，$x = t^2$，$dx = 2t\,dt$。

$$
\begin{aligned}
\int \frac{dx}{1+\sqrt{x}}
&= \int \frac{2t}{1+t}\,dt
= 2\int \left(1 - \frac{1}{1+t}\right)dt \\
&= 2(t - \ln|1+t|) + C
= 2\sqrt{x} - 2\ln(1+\sqrt{x}) + C
\end{aligned}
$$

**答案**：$2\sqrt{x} - 2\ln(1+\sqrt{x}) + C$

---

#### 例题 2.3.5【进阶】二次根式代换

$$
\int \frac{dx}{\sqrt{x} + \sqrt[3]{x}}
$$

**解法**：令 $t = \sqrt[6]{x}$（取 $\sqrt{x}$ 和 $\sqrt[3]{x}$ 的最小公倍指数 6），$x = t^6$，$dx = 6t^5 dt$。

$$
\begin{aligned}
\int \frac{dx}{\sqrt{x} + \sqrt[3]{x}}
&= \int \frac{6t^5}{t^3 + t^2}\,dt
= 6\int \frac{t^3}{t+1}\,dt
= 6\int \left(t^2 - t + 1 - \frac{1}{t+1}\right)dt \\[4pt]
&= 6\left(\frac{t^3}{3} - \frac{t^2}{2} + t - \ln|t+1|\right) + C
\end{aligned}
$$

回代 $t = \sqrt[6]{x}$。

**答案**：$\displaystyle 2\sqrt{x} - 3\sqrt[3]{x} + 6\sqrt[6]{x} - 6\ln(\sqrt[6]{x} + 1) + C$

---

#### 2.3.3 倒代换 $t = \frac{1}{x}$

**适用场景**：分母次数远高于分子，或 $x \to \infty$ 时需处理含 $\frac{1}{x}$ 的被积函数。

#### 例题 2.3.6【进阶】倒代换

$$
\int \frac{dx}{x\sqrt{x^2-1}}\quad (x>1)
$$

**解法**：令 $t = \frac{1}{x}$，$x = \frac{1}{t}$，$dx = -\frac{1}{t^2}dt$。

$$
\begin{aligned}
\int \frac{dx}{x\sqrt{x^2-1}}
&= \int \frac{-1/t^2}{\frac{1}{t}\sqrt{\frac{1}{t^2}-1}}\,dt
= -\int \frac{dt}{\sqrt{1-t^2}} \\
&= -\arcsin t + C
= -\arcsin\frac{1}{x} + C
\end{aligned}
$$

**另解（直接凑微分）**：$\displaystyle \int \frac{dx}{x\sqrt{x^2-1}} = \int \frac{dx}{x^2\sqrt{1-\frac{1}{x^2}}} = -\int \frac{d(\frac{1}{x})}{\sqrt{1-(\frac{1}{x})^2}} = -\arcsin\frac{1}{x} + C$，与倒代换殊途同归。

**答案**：$\displaystyle -\arcsin\frac{1}{x} + C$（或 $\operatorname{arcsec} x + C$）

### 题型 2.4：分部积分法

**核心公式**：$\displaystyle \int u\,dv = uv - \int v\,du$

**选 $u$ 的优先级口诀**：**反**三角函数 > **对**数函数 > **幂**函数 > **指**数函数 > **三**角函数（"**反对幂指三**"）

> **口诀含义**：优先级越高的函数越应该选作 $u$（求导后变简单）；优先级越低的越应该放入 $dv$（积分后不太复杂）。
>
> 📖 **完整题型分类与大量例题（含 $\int x^n e^{ax}$、$\int x^n \sin bx$、$\int x^n \ln x$、$\int \arcsin x$、$\int \arctan x$、Wallis 点火公式、分部积分还原法等）** → 参见 [[分部积分]]

### ★ 必背专题：分部积分的表格法（DI Method）

分部积分是使用频率最高的积分方法之一，但当被积函数形如 $\int x^n e^{ax}dx$、$\int x^n \sin bx\,dx$ 等需要**连续多次分部**时，逐次写 $u$、$dv$ 非常繁琐。表格法提供了一种机械化计算方式。

**表格结构**：

| 列 | 内容 | 操作 |
| :--- | :--- | :--- |
| **第 1 列（D 列）** | $u$（逐次求导） | $u$ → $u'$ → $u''$ → … → 0 |
| **第 2 列（I 列）** | $v$（逐次积分） | $v$ → $\int v$ → $\iint v$ → … |

**计算规则**：D 列第 $k$ 行 × I 列第 $k+1$ 行，符号交替 $(+,-,+,-,\ldots)$，全部相加。

> **适用条件**：$u$ 必须是**多项式**（求若干次导后归零）或**求导后回归自身**的函数（如 $e^{ax}$、$\sin bx$、$\cos bx$）。

---

#### 表格法示例 1【多项式 × 指数】

$$
\int x^3 e^{2x}\,dx
$$

不用表格法需 3 次分部，极其繁琐。建表：

| 符号 | D 列（$u = x^3$ 求导） | I 列（$dv = e^{2x}dx$ 积分） |
| :---: | :--- | :--- |
| | $x^3$ | $e^{2x}$ |
| $+$ | $3x^2$ | $\frac{1}{2}e^{2x}$ |
| $-$ | $6x$ | $\frac{1}{4}e^{2x}$ |
| $+$ | $6$ | $\frac{1}{8}e^{2x}$ |
| $-$ | $0$ | $\frac{1}{16}e^{2x}$ |

符号列从第 2 行开始取 $+,-,+,-$。结果：

$$
\begin{aligned}
\int x^3 e^{2x}\,dx
&= x^3 \cdot \frac{1}{2}e^{2x} \;{\color{red}-}\; 3x^2 \cdot \frac{1}{4}e^{2x} \;{\color{red}+}\; 6x \cdot \frac{1}{8}e^{2x} \;{\color{red}-}\; 6 \cdot \frac{1}{16}e^{2x} + C \\[4pt]
&= \frac{e^{2x}}{2}\!\left(x^3 - \frac{3}{2}x^2 + \frac{3}{2}x - \frac{3}{4}\right) + C
\end{aligned}
$$

> $\boxed{\dfrac{e^{2x}}{2}\!\left(x^3 - \dfrac{3}{2}x^2 + \dfrac{3}{2}x - \dfrac{3}{4}\right) + C}$

---

#### 表格法示例 2【多项式 × 三角】

$$
\int x^2 \cos 3x\,dx
$$

| 符号 | D 列（$u = x^2$） | I 列（$dv = \cos 3x\,dx$） |
| :---: | :--- | :--- |
| | $x^2$ | $\cos 3x$ |
| $+$ | $2x$ | $\frac{1}{3}\sin 3x$ |
| $-$ | $2$ | $-\frac{1}{9}\cos 3x$ |
| $+$ | $0$ | $-\frac{1}{27}\sin 3x$ |

结果：

$$
\begin{aligned}
\int x^2 \cos 3x\,dx
&= x^2 \cdot \frac{\sin 3x}{3} - 2x \cdot \!\left(-\frac{\cos 3x}{9}\right) + 2 \cdot \!\left(-\frac{\sin 3x}{27}\right) + C \\[4pt]
&= \frac{x^2}{3}\sin 3x + \frac{2x}{9}\cos 3x - \frac{2}{27}\sin 3x + C
\end{aligned}
$$

> $\boxed{\dfrac{x^2}{3}\sin 3x + \dfrac{2x}{9}\cos 3x - \dfrac{2}{27}\sin 3x + C}$

> **表格法的精髓**：把多次分部积分的"套娃"过程压成一张表，适合 $\int$多项式$\times$指数/三角 型。但若 $u$ 求导不归零（如 $\ln x$）则无法使用，此时回退到标准分部积分。

---

### 题型 2.5：有理函数积分（部分分式法）

**核心流程**：假分式 → 多项式除法化为真分式 → 分母因式分解 → 设部分分式 → 待定系数求解 → 逐项积分

#### 部分分式速查

| 分母因子 | 部分分式形式 | 积分结果 |
| :--- | :--- | :--- |
| $(x-a)$ | $\dfrac{A}{x-a}$ | $A\ln\|x-a\|$ |
| $(x-a)^m$ | $\dfrac{A_1}{x-a} + \cdots + \dfrac{A_m}{(x-a)^m}$ | 对数 + 有理式 |
| $(x^2+px+q)$（不可约） | $\dfrac{Ax+B}{x^2+px+q}$ | 拆项 → 对数 + $\arctan$ |
| $(x^2+px+q)^m$ | 逐次升幂 | 递推降幂 |

> 📖 **完整例题与详细解法（含重因式、不可约二次因式的待定系数通法）** → 参见 [[有理函数积分]]

### 题型 2.6：三角函数有理式积分

**核心策略速查**：

| 被积函数特征 | 首选方法 | 关键操作 |
| :--- | :--- | :--- |
| $\sin x$ 或 $\cos x$ 的**奇次幂** | 凑微分 | 拆一个因式 → $d(\sin x)$ 或 $d(\cos x)$ |
| $\sin x$ 和 $\cos x$ 的**偶次幂** | 降幂公式 | $\sin^2 x = \frac{1-\cos 2x}{2}$，$\cos^2 x = \frac{1+\cos 2x}{2}$ |
| $\sin mx\cos nx$ 型 | 积化和差 | 化为线性组合 |
| 前几种都不行 | **万能公式** $t = \tan\frac{x}{2}$ | $\sin x = \frac{2t}{1+t^2},\; \cos x = \frac{1-t^2}{1+t^2}$ |

> 📖 **完整例题与详细解法（含 Wallis 点火公式、递推降幂、三角定积分对称性等）** → 参见 [[三角函数积分]]

### 题型 2.7：简单无理函数积分

#### 例题 2.7.1【进阶】$\sqrt{\dfrac{a-x}{a+x}}$ 型

$$
\int \sqrt{\frac{1-x}{1+x}}\,dx
$$

**解法**：分子分母同乘 $\sqrt{1-x}$。

$$
\sqrt{\frac{1-x}{1+x}} = \frac{\sqrt{1-x}}{\sqrt{1+x}} = \frac{\sqrt{1-x^2}}{1+x}
$$

令 $x = \sin t$（$t \in [-\frac{\pi}{2}, \frac{\pi}{2}]$），$dx = \cos t\,dt$。

$$
\begin{aligned}
\int \sqrt{\frac{1-x}{1+x}}\,dx
&= \int \frac{\cos t}{1+\sin t}\cdot \cos t\,dt
= \int \frac{\cos^2 t}{1+\sin t}\,dt
= \int \frac{1-\sin^2 t}{1+\sin t}\,dt \\
&= \int (1-\sin t)dt = t + \cos t + C
\end{aligned}
$$

回代：$t = \arcsin x$，$\cos t = \sqrt{1-x^2}$。

**答案**：$\arcsin x + \sqrt{1-x^2} + C$

---

#### 例题 2.7.2【综合】$\sqrt{x^2 \pm a^2}$ 型（配方后三角代换）

$$
\int \frac{dx}{\sqrt{x^2+2x+5}}
$$

**解法**：先配方。

$$
x^2+2x+5 = (x+1)^2 + 4
$$

$$
\int \frac{dx}{\sqrt{(x+1)^2+4}} = \ln\left|x+1 + \sqrt{x^2+2x+5}\right| + C
$$

**答案**：$\ln\left|x+1 + \sqrt{x^2+2x+5}\right| + C$

#### ★ Euler 代换法（$\sqrt{ax^2+bx+c}$ 型的通用武器）

三角代换在高次项或混合项时不够直接。**Euler 代换**是一套代数化方法，将 $\int R(x,\sqrt{ax^2+bx+c})\,dx$ 系统化为有理函数积分。

**三种 Euler 代换**：

| 条件 | 代换 | 变形 |
| :--- | :--- | :--- |
| $a > 0$ | $\sqrt{ax^2+bx+c} = t - \sqrt{a}\,x$ | 两边平方消去 $ax^2$，解出 $x = \dfrac{t^2-c}{b+2\sqrt{a}\,t}$ |
| $c > 0$ | $\sqrt{ax^2+bx+c} = xt - \sqrt{c}$ | 两边平方消去 $c$，解出 $x = \dfrac{2\sqrt{c}\,t-b}{a-t^2}$ |
| $ax^2+bx+c$ 有实根 | $\sqrt{a(x-\alpha)(x-\beta)} = t(x-\alpha)$ | 消去一个因式 |

> **实用经验**：考研范围内，90% 的 $\sqrt{ax^2+bx+c}$ 型不定积分可用**先配方 + 三角代换**解决（如 2.7.2）。但当配方后三角代换仍繁琐时（如含 $\sqrt{x^2+x+1}$ 在分母且分子含 $x$），Euler 代换提供代数出路。

**Euler 代换示例**：

$$
\int \frac{dx}{x + \sqrt{x^2+x+1}}
$$

分母含 $\sqrt{x^2+x+1}$，$a=1>0$，用第一种 Euler 代换：$\sqrt{x^2+x+1} = t - x$。

两边平方：
$$
x^2+x+1 = t^2 - 2tx + x^2 \;\Longrightarrow\; x + 2tx = t^2 - 1 \;\Longrightarrow\; x = \frac{t^2-1}{1+2t}
$$

$$
dx = \frac{2t(1+2t) - 2(t^2-1)}{(1+2t)^2}\,dt = \frac{2t+2}{(1+2t)^2}\,dt = \frac{2(t+1)}{(1+2t)^2}\,dt
$$

分母 $x + \sqrt{x^2+x+1} = x + (t - x) = t$。代入：

$$
\int \frac{1}{t} \cdot \frac{2(t+1)}{(1+2t)^2}\,dt
= 2\int \frac{t+1}{t(1+2t)^2}\,dt
$$

化为有理函数，用部分分式法即可完成（步骤略）。

> **结论**：Euler 代换将无理积分彻底化为有理积分，计算量虽大但路径明确。考研中优先配方+三角代换，Euler 作为备用。

## 三、方法总结表

| 识别信号 | 首选方法 | 操作步骤 |
| :--- | :--- | :--- |
| 基本公式可直接套用 | **直接积分** | 代数变形 → 拆项 → 逐项积分 |
| 被积函数含 $\varphi'(x) \cdot f[\varphi(x)]$ 结构 | **第一类换元（凑微分）** | 识别导数关系 → 将导数部分写成 $d\varphi(x)$ → 换元 $\int f(u)du$ |
| 含 $\sqrt{a^2-x^2}$ | **三角代换** $x = a\sin t$ | 换元 → 化简 → 积分 → **回代**（画直角三角形） |
| 含 $\sqrt{a^2+x^2}$ | **三角代换** $x = a\tan t$ | 同上 |
| 含 $\sqrt{x^2-a^2}$ | **三角代换** $x = a\sec t$ | 同上 |
| 含 $\sqrt{ax^2+bx+c}$（$a \neq 0$） | **先配方 + 三角代换**；不行则 **Euler 代换** | 配方化为 $\sqrt{A^2 \pm u^2}$ 型 → 三角代换；或 Euler: $\sqrt{ax^2+bx+c}=t\pm\sqrt{a}x$ |
| 含 $\sqrt[n]{ax+b}$ | **根式代换** $t = \sqrt[n]{ax+b}$ | 整式化 → 积分 → 回代 |
| 含 $\sqrt[n]{\cdot}$ 和 $\sqrt[m]{\cdot}$ 共存 | **取最小公倍指数** $t = \sqrt[\text{lcm}]{\cdot}$ | 化为有理函数积分 |
| 分母次数 ≫ 分子次数 | **倒代换** $t = 1/x$ | 化繁为简 |
| 两类不同函数相乘（$\int x^n e^x, \int x^n \sin x, \int x^n \ln x$） | **分部积分** → [[分部积分]] | 口诀选 $u$：反>对>幂>指>三 |
| 多项式($n\!\geq\!2$) × 指数/三角 需多次分部 | **表格法（DI Method）** | 建表(D列求导,I列积分) → 交错正负号 → 对应行列相乘求和 |
| $\int e^{ax}\sin bx$ 或 $\int e^{ax}\cos bx$ | **分部积分还原法** → [[分部积分]] | 两次分部 → 移项解方程 |
| $\int \ln x\,dx$ 或 $\int \arctan x\,dx$ 等单函数 | **分部积分**（选 $dv = dx$）→ [[分部积分]] | $u =$ 函数本身 |
| $\dfrac{P(x)}{Q(x)}$ 有理函数 | **部分分式法** → [[有理函数积分]] | 假分式→多项式除法→分母因式分解→设分式→待定系数→逐项积分 |
| $\sin,\cos$ 的偶次幂 | **降幂公式** → [[三角函数积分]] | $\sin^2 x = \frac{1-\cos 2x}{2}$ |
| $\sin,\cos$ 的奇次幂 | **凑微分** → [[三角函数积分]] | 拆一个去凑 $d(\sin x)$ 或 $d(\cos x)$ |
| $\sin mx\cos nx$ 型 | **积化和差** → [[三角函数积分]] | 化为 $\sin/\cos$ 的线性组合 |
| 万能备用（前几种都行不通时） | **万能公式** $t = \tan\frac{x}{2}$ → [[三角函数积分]] | $\sin x = \frac{2t}{1+t^2},\; \cos x = \frac{1-t^2}{1+t^2}$ |

## 五、自测练习答案

### 题 1 答案

$$
x^2 - 4x + 8 = (x-2)^2 + 4
$$

$$
\int \frac{dx}{(x-2)^2 + 4} = \frac{1}{2}\arctan\!\left(\frac{x-2}{2}\right) + C
$$

> $\boxed{\dfrac{1}{2}\arctan\!\left(\dfrac{x-2}{2}\right) + C}$

---

### 题 2 答案

分子恰好是分母的导数：$(e^x+e^{-x})' = e^x - e^{-x}$。

$$
\int \frac{e^x - e^{-x}}{e^x + e^{-x}}\,dx = \ln(e^x + e^{-x}) + C
$$

> $\boxed{\ln(e^x + e^{-x}) + C}$

---

### 题 3 答案

令 $x = \tan t$，$dx = \sec^2 t\,dt$，$1+x^2 = \sec^2 t$。

$$
\int \frac{dx}{(1+x^2)^{3/2}}
= \int \frac{\sec^2 t}{\sec^3 t}\,dt
= \int \cos t\,dt
= \sin t + C
$$

回代：$\sin t = \dfrac{x}{\sqrt{1+x^2}}$（画直角三角形：对边 $x$，邻边 $1$，斜边 $\sqrt{1+x^2}$）。

> $\boxed{\dfrac{x}{\sqrt{1+x^2}} + C}$

---

### 题 4 答案

分部积分（$u = x^2$，$dv = e^{-x}dx$）：

$$
\begin{aligned}
\int x^2 e^{-x}dx
&= -x^2 e^{-x} - \int (-2x e^{-x})dx
= -x^2 e^{-x} + 2\int x e^{-x}dx
\end{aligned}
$$

对 $\int x e^{-x}dx$ 再分部（$u = x$，$dv = e^{-x}dx$）：

$$
\int x e^{-x}dx = -x e^{-x} - \int (-e^{-x})dx = -x e^{-x} + \int e^{-x}dx = -x e^{-x} - e^{-x}
$$

代回：

$$
\begin{aligned}
\int x^2 e^{-x}dx
&= -x^2 e^{-x} + 2(-x e^{-x} - e^{-x}) + C \\
&= -e^{-x}(x^2 + 2x + 2) + C
\end{aligned}
$$

> $\boxed{-e^{-x}(x^2 + 2x + 2) + C}$

---

### 题 5 答案

设 $\displaystyle \frac{2x+3}{(x-1)(x^2+4)} = \frac{A}{x-1} + \frac{Bx+C}{x^2+4}$。

通分：$2x+3 = A(x^2+4) + (Bx+C)(x-1) = (A+B)x^2 + (-B+C)x + (4A-C)$。

$$
\begin{cases} A+B = 0 \\ -B+C = 2 \\ 4A-C = 3 \end{cases}
$$

$B = -A$。由 (2)：$A + C = 2$。由 (3)：$4A - C = 3$。相加：$5A = 5 \Rightarrow A = 1$。故 $B = -1$，$C = 1$。

$$
\begin{aligned}
\int \frac{2x+3}{(x-1)(x^2+4)}dx
&= \int \frac{dx}{x-1} + \int \frac{-x+1}{x^2+4}dx \\[4pt]
&= \ln|x-1| - \int \frac{x}{x^2+4}dx + \int \frac{dx}{x^2+4} \\[4pt]
&= \ln|x-1| - \frac{1}{2}\ln(x^2+4) + \frac{1}{2}\arctan\frac{x}{2} + C
\end{aligned}
$$

> $\boxed{\ln|x-1| - \dfrac{1}{2}\ln(x^2+4) + \dfrac{1}{2}\arctan\dfrac{x}{2} + C}$

---

### 题 6 答案

两次降幂：

$$
\begin{aligned}
\sin^4 x &= (\sin^2 x)^2 = \left(\frac{1-\cos 2x}{2}\right)^2
= \frac{1 - 2\cos 2x + \cos^2 2x}{4} \\[4pt]
&= \frac{1 - 2\cos 2x + \frac{1+\cos 4x}{2}}{4}
= \frac{2 - 4\cos 2x + 1 + \cos 4x}{8} \\[4pt]
&= \frac{3 - 4\cos 2x + \cos 4x}{8}
\end{aligned}
$$

逐项积分：

$$
\int \sin^4 x\,dx
= \frac{3}{8}x - \frac{4}{8} \cdot \frac{\sin 2x}{2} + \frac{1}{8} \cdot \frac{\sin 4x}{4} + C
= \frac{3x}{8} - \frac{\sin 2x}{4} + \frac{\sin 4x}{32} + C
$$

> $\boxed{\dfrac{3x}{8} - \dfrac{\sin 2x}{4} + \dfrac{\sin 4x}{32} + C}$

---

### 题 7 答案

令 $t = \sqrt{x}$，$x = t^2$，$dx = 2t\,dt$。

$$
\begin{aligned}
\int \frac{\sqrt{x}}{1+x}\,dx
&= \int \frac{t}{1+t^2} \cdot 2t\,dt
= 2\int \frac{t^2}{1+t^2}\,dt \\
&= 2\int \!\left(1 - \frac{1}{1+t^2}\right)dt
= 2t - 2\arctan t + C \\
&= 2\sqrt{x} - 2\arctan\sqrt{x} + C
\end{aligned}
$$

> $\boxed{2\sqrt{x} - 2\arctan\sqrt{x} + C}$

---

### 题 8 答案

令 $t = \sqrt{x}$，$x = t^2$，$dx = 2t\,dt$。

$$
\int e^{\sqrt{x}}\,dx = \int e^t \cdot 2t\,dt = 2\int t e^t\,dt
$$

分部积分（$u = t$，$dv = e^t dt$）：

$$
\int t e^t\,dt = t e^t - \int e^t\,dt = t e^t - e^t + C
$$

$$
\int e^{\sqrt{x}}\,dx = 2(t e^t - e^t) + C = 2e^{\sqrt{x}}(\sqrt{x} - 1) + C
$$

> $\boxed{2e^{\sqrt{x}}(\sqrt{x} - 1) + C}$
