# 定积分的对称性与奇偶性 | 积分专题

> **核心公式**：
> - 奇函数在对称区间上积分为零：若 $f(-x) = -f(x)$，则 $\displaystyle\int_{-a}^a f(x)dx = 0$
> - 偶函数在对称区间上积分翻倍：若 $f(-x) = f(x)$，则 $\displaystyle\int_{-a}^a f(x)dx = 2\int_0^a f(x)dx$
> - 一般拆解公式：$\displaystyle\int_{-a}^a f(x)dx = \int_0^a [f(x)+f(-x)]dx$
> **核心思想**：先看区间是否对称，再看被积函数奇偶性。宁可多花 5 秒判断，节省 5 分钟计算。

---

## 一、核心公式与推导

### 1.1 奇偶性基本定理

**定理**：设 $f(x)$ 在 $[-a,a]$ 上连续。

| 条件 | 结论 | 几何意义 |
| :--- | :--- | :--- |
| $f(-x) = -f(x)$（奇函数） | $\displaystyle\int_{-a}^a f(x)dx = 0$ | 正负半轴对称抵消 |
| $f(-x) = f(x)$（偶函数） | $\displaystyle\int_{-a}^a f(x)dx = 2\int_0^a f(x)dx$ | 两半全等，翻倍 |

**证明**（奇函数情形）：

$$
\int_{-a}^a f(x)dx = \int_{-a}^0 f(x)dx + \int_0^a f(x)dx
$$

对第一项令 $x = -t$，$dx = -dt$，$x: -a\to 0 \Rightarrow t: a\to 0$：

$$
\int_{-a}^0 f(x)dx = \int_a^0 f(-t)(-dt) = -\int_0^a f(-t)dt = -\int_0^a -f(t)dt = \int_0^a f(t)dt
$$

代入拆分式：$\int_{-a}^a f(x)dx = \int_0^a f(t)dt + \int_0^a f(x)dx = 0$（注意 $f(-t) = -f(t)$ 的代入使两项相消）。

### 1.2 一般拆解公式（不要求严格奇偶）

对于任意 $f(x)$ 在 $[-a,a]$ 上连续：

$$
\boxed{\int_{-a}^a f(x)dx = \int_0^a [f(x) + f(-x)] dx}
$$

**推导**：对 $\int_{-a}^0 f(x)dx$ 作 $x = -t$：

$$
\int_{-a}^a f(x)dx = \int_{-a}^0 f(x)dx + \int_0^a f(x)dx = \int_0^a f(-t)dt + \int_0^a f(x)dx = \int_0^a [f(x)+f(-x)]dx
$$

> 💡 这个推广极其实用：即使 $f(x)$ 本身不奇不偶，拆成 $f(x)+f(-x)$ 后往往能大幅简化。

### ★ 必背专题：奇偶性判别速判法

| 函数的奇偶组合 | 结果 | 示例 |
| :--- | :---: | :--- |
| 奇 × 奇 | **偶** | $x \cdot \sin x$ → 偶 |
| 偶 × 偶 | **偶** | $x^2 \cdot \cos x$ → 偶 |
| 奇 × 偶 | **奇** | $x \cdot \cos x$ → 奇 |
| 奇 + 奇 | **奇** | $x + \sin x$ → 奇 |
| 偶 + 偶 | **偶** | $x^2 + \cos x$ → 偶 |
| 奇 + 偶 | 无奇偶性 | $x + x^2$ → 非奇非偶 |
| 奇函数的复合（偶函数作为内层） | 不一定 | $f(g(x))$ 需具体分析 |
| 导函数 | $f$ 偶 ⇒ $f'$ 奇；$f$ 奇 ⇒ $f'$ 偶 | — |

> 📌 **高频结论**：$x^{2k+1}$ 是奇函数，$x^{2k}$ 是偶函数；$\sin x$ 是奇函数，$\cos x$ 是偶函数；$\tan x$ 是奇函数。

### 题型 1：直接利用奇偶性简化

**识别特征**：积分区间 $[-a, a]$，被积函数有明显的奇偶结构。

#### 例题 1.1（基础·纯奇函数）

计算 $\displaystyle\int_{-1}^1 (x^3 + x^5 + \sin x) dx$。

**思路溯源**：$x^3$、$x^5$、$\sin x$ 都是奇函数——奇函数在对称区间上积分为零。

**解**：

$$
\int_{-1}^1 x^3 dx + \int_{-1}^1 x^5 dx + \int_{-1}^1 \sin x dx = 0 + 0 + 0 = 0
$$

> 💡 有学生展开一个个算原函数再代入——**完全浪费时间**。对称区间先看奇偶。

#### 例题 1.2（进阶·奇偶混合）

计算 $\displaystyle\int_{-2}^2 (x^2 + x\sin x + \cos x) dx$。

**思路溯源**：$x^2$ → 偶，$x\sin x$ → 奇×奇=偶，$\cos x$ → 偶。三项全为偶函数！

**解**：

$$
\int_{-2}^2 (x^2 + x\sin x + \cos x) dx = 2\int_0^2 (x^2 + x\sin x + \cos x) dx
$$

分别计算：
$$
2\left[\frac{x^3}{3}\right]_0^2 + 2\int_0^2 x\sin x\,dx + 2[\sin x]_0^2
$$

其中 $\int_0^2 x\sin x\,dx$ 用分部积分：
$= [-x\cos x]_0^2 + \int_0^2 \cos x\,dx = -2\cos 2 + [\sin x]_0^2 = -2\cos 2 + \sin 2$

$$
= 2\cdot\frac{8}{3} + 2(-2\cos 2 + \sin 2) + 2\sin 2 = \frac{16}{3} - 4\cos 2 + 4\sin 2
$$

#### 例题 1.3（综合·需要先观察再判断）

计算 $\displaystyle\int_{-\frac{\pi}{4}}^{\frac{\pi}{4}} \frac{\sin^5 x}{1+x^2} dx$。

**思路溯源**：分子 $\sin^5 x$ 是奇函数（$\sin$ 是奇的，奇数次幂仍是奇），分母 $1+x^2$ 是偶函数。奇/偶 = 奇。对称区间上奇函数积分为零。

**解**：

直接写答案：

$$
\int_{-\frac{\pi}{4}}^{\frac{\pi}{4}} \frac{\sin^5 x}{1+x^2} dx = 0
$$

> ⚠️ 不要被复杂的分式吓到。先看区间是否对称，再看被积函数奇偶。

### 题型 2：一般拆解公式的应用

**识别特征**：区间对称，但 $f(x)$ 不是严格的奇函数或偶函数。用 $f(x)+f(-x)$ 简化。

#### 例题 2.1（基础）

计算 $\displaystyle\int_{-1}^1 \frac{dx}{1+e^x}$。

**思路溯源**：分母 $1+e^x$ 不是奇函数也不是偶函数，但用拆解公式后 $\frac{1}{1+e^x} + \frac{1}{1+e^{-x}} = 1$。

**解**：

$$
\begin{aligned}
\int_{-1}^1 \frac{dx}{1+e^x}
&= \int_0^1 \left(\frac{1}{1+e^x} + \frac{1}{1+e^{-x}}\right) dx \\[4pt]
&= \int_0^1 \frac{(1+e^{-x}) + (1+e^x)}{(1+e^x)(1+e^{-x})} dx
= \int_0^1 \frac{2 + e^x + e^{-x}}{2 + e^x + e^{-x}} dx \\[4pt]
&= \int_0^1 1\,dx = 1
\end{aligned}
$$

**简化**：其实 $\frac{1}{1+e^x} + \frac{1}{1+e^{-x}} = \frac{1+e^{-x}+1+e^x}{(1+e^x)(1+e^{-x})} = \frac{2+e^x+e^{-x}}{2+e^x+e^{-x}} = 1$，所以原式 $= \int_0^1 1\,dx = 1$。

#### 例题 2.2（进阶·通分简化型）

计算 $\displaystyle\int_{-1}^1 \frac{dx}{2^x+1}$。

**思路溯源**：用拆解公式 $f(x)+f(-x) = \frac{1}{2^x+1} + \frac{1}{2^{-x}+1} = \frac{1}{2^x+1} + \frac{2^x}{1+2^x} = 1$。

**解**：

$$
\int_{-1}^1 \frac{dx}{2^x+1} = \int_0^1 \left(\frac{1}{2^x+1} + \frac{1}{2^{-x}+1}\right) dx = \int_0^1 1\,dx = 1
$$

#### 例题 2.3（综合·含参数）

计算 $\displaystyle\int_{-a}^a \frac{\arctan e^x}{1+x^2} dx$（$a>0$）。

**思路溯源**：$\arctan e^x$ 不奇不偶，用拆解公式。关键观察：$\arctan e^x + \arctan e^{-x} = \frac{\pi}{2}$。

**解**：

由 $\arctan u + \arctan\frac{1}{u} = \frac{\pi}{2}$（$u>0$），令 $u = e^x$：

$$
\arctan e^x + \arctan e^{-x} = \frac{\pi}{2}
$$

故 $f(x) + f(-x) = \frac{\arctan e^x + \arctan e^{-x}}{1+x^2} = \frac{\pi/2}{1+x^2}$。

$$
\int_{-a}^a \frac{\arctan e^x}{1+x^2} dx = \int_0^a \frac{\pi/2}{1+x^2} dx = \frac{\pi}{2}[\arctan x]_0^a = \frac{\pi}{2}\arctan a
$$

### 题型 3：三角函数的对称性质

**识别特征**：积分区间 $[0, \pi]$、$[0, 2\pi]$，或含 $\sin^n x$、$\cos^n x$。

| 区间 | 性质 | 公式 |
| :--- | :--- | :--- |
| $[0, \pi]$ | $\sin x$ 对称 | $\int_0^\pi f(\sin x)dx = 2\int_0^{\frac{\pi}{2}} f(\sin x)dx$ |
| $[0, \frac{\pi}{2}]$ | $\sin$ 和 $\cos$ 对偶 | $\int_0^{\frac{\pi}{2}} f(\sin x)dx = \int_0^{\frac{\pi}{2}} f(\cos x)dx$ |
| $[0, \pi]$ | $\cos x$ 对称 | $\int_0^\pi f(|\cos x|)dx = 2\int_0^{\frac{\pi}{2}} f(\cos x)dx$ |
| $[-\pi, \pi]$ | 奇偶性 | $\int_{-\pi}^\pi \sin^{2k+1}x\,dx = 0$ |

#### 例题 3.1（基础）

计算 $\displaystyle\int_0^\pi \sin^3 x\,dx$。

**思路溯源**：$[0,\pi]$ 上的 $\sin^3 x$——利用 $\int_0^\pi f(\sin x)dx = 2\int_0^{\pi/2} f(\sin x)dx$。

**解**：

$$
\int_0^\pi \sin^3 x\,dx = 2\int_0^{\frac{\pi}{2}} \sin^3 x\,dx = 2 \cdot \frac{2}{3} = \frac{4}{3}
$$

（由 Wallis 点火公式：$n=3$ 为奇数，$\int_0^{\pi/2} \sin^3 x\,dx = \frac{2!!}{3!!} = \frac{2}{3}$）

#### 例题 3.2（进阶·$\sin/\cos$ 对偶）

计算 $\displaystyle\int_0^{\frac{\pi}{2}} \frac{\sin^n x}{\sin^n x + \cos^n x} dx$。

**思路溯源**：利用 $\sin/\cos$ 对偶性：设 $I = \int_0^{\pi/2} \frac{\sin^n x}{\sin^n x + \cos^n x} dx$，令 $x = \frac{\pi}{2} - t$，则 $I$ 变为 $\int_0^{\pi/2} \frac{\cos^n t}{\cos^n t + \sin^n t} dt$。

两者相加：$2I = \int_0^{\pi/2} 1\,dx = \frac{\pi}{2}$，故 $I = \frac{\pi}{4}$。

> 💡 **这个结论与 $n$ 无关**——无论 $\sin^n$ 还是 $\sin^{100}$，积分值恒为 $\pi/4$。

### 题型 4：周期性函数的定积分

**识别特征**：被积函数是周期函数，积分区间跨多个周期。

**定理**：若 $f(x)$ 以 $T$ 为周期，则：

$$
\boxed{\int_a^{a+T} f(x)dx = \int_0^T f(x)dx}
$$

即一个周期上的积分与起点无关。

**推论**：$\displaystyle\int_a^{a+nT} f(x)dx = n\int_0^T f(x)dx$

#### 例题 4.1

计算 $\displaystyle\int_0^{100\pi} |\sin x|\,dx$。

**思路溯源**：$|\sin x|$ 的周期是 $\pi$。$100\pi$ 是 100 个周期。

**解**：

$$
\int_0^{100\pi} |\sin x|\,dx = 100\int_0^\pi \sin x\,dx = 100 \cdot [-\cos x]_0^\pi = 100 \cdot 2 = 200
$$

---

### 题型 5：对称性 + 换元的组合应用

**识别特征**：区间对称，但需先经换元才能暴露对称性。

#### 例题 5.1（基础）

计算 $\displaystyle\int_{-2}^2 \frac{x^3 \cos \frac{x}{2}}{\sqrt{4-x^2}} dx$。

**思路溯源**：分母 $\sqrt{4-x^2}$ 是偶函数，$\cos(x/2)$ 是偶函数，$x^3$ 是奇函数。整体 = 奇×偶×偶 = 奇。对称区间上奇函数积分为零。

**解**：直接得到 $0$。

#### 例题 5.2（进阶·需拆项）

计算 $\displaystyle\int_{-1}^1 \frac{x^2 + x}{1+\sqrt{1-x^2}} dx$。

**思路溯源**：拆分为两个积分：$\int_{-1}^1 \frac{x^2}{1+\sqrt{1-x^2}} dx + \int_{-1}^1 \frac{x}{1+\sqrt{1-x^2}} dx$。

第一项被积函数是偶函数（$x^2$偶，分母偶 → 偶）；第二项被积函数是奇函数（$x$奇，分母偶 → 奇）。

则第二项 = 0，第一项 = $2\int_0^1 \frac{x^2}{1+\sqrt{1-x^2}} dx$（需进一步用三角换元计算）。

## 三、方法总结表

| 技巧 | 适用条件 | 操作 | 关键点 |
| :--- | :--- | :--- | :--- |
| 奇偶直接判断 | $[-a,a]$ + 被积函数奇偶明显 | 奇=0，偶=2倍 | **先看区间再看函数** |
| 一般拆解公式 | $[-a,a]$ + 函数无奇偶性 | $f(x)+f(-x)$ 简化 | 常得到 $\frac{\text{常数}}{分母}$ |
| $\sin/\cos$ 对偶 | $[0,\frac{\pi}{2}]$ + $f(\sin x), f(\cos x)$ | $\int_0^{\pi/2} f(\sin) = \int_0^{\pi/2} f(\cos)$ | 两者相加常得常数 |
| 周期性简化 | 周期函数 + 跨多周期 | $\int_a^{a+nT} = n\int_0^T$ | 与起点无关 |
| $\sin^n x$ 在 $[0,\pi]$ | 对称区间 | $\int_0^\pi \sin^n x = 2\int_0^{\pi/2} \sin^n x$ | 直接套 Wallis |
| 奇偶函数乘除 | 判断复杂函数的奇偶性 | 奇×奇=偶，奇×偶=奇，偶×偶=偶 | **先拆因式再判断** |

> - 一般拆解公式：$\displaystyle\int_{-a}^a f(x)dx = \int_0^a [f(x)+f(-x)]dx$
> **核心思想**：先看区间是否对称，再看被积函数奇偶性。宁可多花5秒判断，节省5分钟计算。

## 一、核心公式与推导

### 1.1 奇偶性基本定理

**定理**：设 $f(x)$ 在 $[-a,a]$ 上连续。

| 条件 | 结论 | 几何意义 |
| :--- | :--- | :--- |
| $f(-x) = -f(x)$（奇函数） | $\displaystyle\int_{-a}^a f(x)dx = 0$ | 正负半轴对称抵消 |
| $f(-x) = f(x)$（偶函数） | $\displaystyle\int_{-a}^a f(x)dx = 2\int_0^a f(x)dx$ | 两半全等，翻倍 |

**证明**（以奇函数为例）：

将积分拆分为 $\int_{-a}^0 + \int_0^a$。对前一项作换元 $x = -t$：

$$
\int_{-a}^0 f(x)dx \xrightarrow{x=-t} \int_a^0 f(-t)(-dt) = \int_0^a f(-t)dt = -\int_0^a f(t)dt
$$

因此 $\int_{-a}^a f(x)dx = -\int_0^a f(x)dx + \int_0^a f(x)dx = 0$。

### 1.2 一般拆解公式（推广形式）

对于 $[-a,a]$ 上的任意连续函数 $f(x)$：

$$
\boxed{\int_{-a}^a f(x)dx = \int_0^a [f(x) + f(-x)] dx}
$$

**推导**：对 $\int_{-a}^0 f(x)dx$ 作 $x = -t$ 换元，立即得到。

> 💡 即使 $f(x)$ 本身不奇不偶，$f(x)+f(-x)$ 往往是更简单的表达式。这是**转化而非直接抵消**的思路。

### ★ 必背专题：奇偶性判别速判表

| 函数组合 | 结果 | 示例 |
| :--- | :---: | :--- |
| 奇 × 奇 | **偶** | $x \cdot \sin x$ → 偶 |
| 偶 × 偶 | **偶** | $x^2 \cdot \cos x$ → 偶 |
| 奇 × 偶 | **奇** | $x \cdot \cos x$ → 奇 |
| 奇 + 奇 | **奇** | $x^3 + \sin x$ → 奇 |
| 偶 + 偶 | **偶** | $x^2 + \cos x$ → 偶 |
| 奇 + 偶 | 非奇非偶 | $x + x^2$ |
| 奇 / 偶 | **奇** | $\frac{\sin x}{1+x^2}$ → 奇 |
| 偶 / 奇 | **偶**（在定义域内） | $\frac{\cos x}{\sin x} = \cot x$ → 奇（注意：$\cot$ 是奇函数！） |
| $f$ 偶 ⇒ $f'$ | **奇** | $f(x)=x^2 \Rightarrow f'(x)=2x$ |
| $f$ 奇 ⇒ $f'$ | **偶** | $f(x)=\sin x \Rightarrow f'(x)=\cos x$ |

> ⚠️ **导函数奇偶性反转**是高频考点：偶函数的导数是奇函数，奇函数的导数是偶函数。

### 经典恒等式（用于拆解公式）

| 恒等式 | 推导 |
| :--- | :--- |
| $\displaystyle\frac{1}{1+a^x} + \frac{1}{1+a^{-x}} = 1$ | 通分，利用 $a^x \cdot a^{-x} = 1$ |
| $\arctan e^x + \arctan e^{-x} = \frac{\pi}{2}$ | $\arctan u + \arctan\frac{1}{u} = \frac{\pi}{2}$（$u>0$） |
| $\displaystyle\frac{1}{1+e^x} - \frac{1}{2} = -\frac{e^x-1}{2(e^x+1)}$ | $\frac{1}{1+e^x} - \frac{1}{2} = \frac{1-e^x}{2(1+e^x)}$（奇函数！） |

> 📌 上面第三条说明 $\frac{1}{1+e^x}$ 可以写为 **偶函数 $1/2$ + 奇函数** 的和，这使得它在对称区间上的积分 = 区间长度的一半。

## 二、题型分类与精析

---

### 题型 1：直接利用奇偶性速算

**识别特征**：积分区间 $[-a, a]$，被积函数有明显的奇偶分解。

#### 例题 1.1（基础·纯奇函数）

计算 $\displaystyle\int_{-1}^1 (x^3 + x^5 + \sin x) dx$。

**思路溯源**：$x^3, x^5, \sin x$ 均为奇函数 → 对称区间上积分全为零。

**解**：直接写 $0$。

#### 例题 1.2（进阶·奇偶混合）

计算 $\displaystyle\int_{-2}^2 (x^2\cos x + x\sin x^2) dx$。

**思路溯源**：分两项判断。
- $x^2\cos x$：$x^2$ 偶 × $\cos x$ 偶 = 偶 → 翻倍计算
- $x\sin(x^2)$：$x$ 奇，$\sin(x^2)$ 偶（$\sin$ 奇复合偶 = 奇？不对，$\sin(x^2)$ 中内层偶外层奇 → 奇？需验证）

验证：令 $g(x) = \sin(x^2)$，$g(-x) = \sin((-x)^2) = \sin(x^2) = g(x)$，$\sin(x^2)$ 是**偶函数**。
$x \cdot \sin(x^2)$ = 奇 × 偶 = **奇函数** → 积分为零。

**解**：

$$
\begin{aligned}
\int_{-2}^2 x^2\cos x\,dx &= 2\int_0^2 x^2\cos x\,dx \\[4pt]
&= 2\left[ x^2\sin x \big|_0^2 - \int_0^2 2x\sin x\,dx \right] \quad \text{(分部：} u=x^2, dv=\cos x\,dx\text{)} \\[4pt]
&= 2\left[ 4\sin 2 - \left( -2x\cos x\big|_0^2 + \int_0^2 2\cos x\,dx \right) \right] \\[4pt]
&= 2\left[ 4\sin 2 + 4\cos 2 - 2\sin 2 \right] = 4\sin 2 + 8\cos 2
\end{aligned}
$$

第二项积分为 0。故答案为 $4\sin 2 + 8\cos 2$。

#### 例题 1.3（综合·需要先观察再判断）

计算 $\displaystyle\int_{-\frac{\pi}{4}}^{\frac{\pi}{4}} \frac{\sin^5 x}{1+x^2} dx$。

**思路溯源**：分子 $\sin^5 x$ 是奇函数（$\sin$ 奇，奇数次幂仍奇），分母 $1+x^2$ 偶。奇/偶 = 奇函数。对称区间 → 0。

**解**：答案为 $0$。

> ⚠️ 不要被复杂分式吓到。三步判断：区间对称？→ 拆因式 → 判奇偶。

---

### 题型 2：一般拆解公式——转化思路

**识别特征**：区间对称，但 $f(x)$ 不奇不偶。用 $f(x)+f(-x)$ 求和后往往能大幅简化。

#### 例题 2.1（基础·指数分式型）

计算 $\displaystyle\int_{-1}^1 \frac{dx}{1+e^x}$。

**思路溯源**：$\frac{1}{1+e^x}$ 不奇不偶。计算其与 $\frac{1}{1+e^{-x}}$ 之和：

$$
\frac{1}{1+e^x} + \frac{1}{1+e^{-x}} = \frac{1}{1+e^x} + \frac{e^x}{e^x+1} = \frac{1+e^x}{1+e^x} = 1
$$

**解**：

$$
\int_{-1}^1 \frac{dx}{1+e^x} = \int_0^1 \left(\frac{1}{1+e^x} + \frac{1}{1+e^{-x}}\right) dx = \int_0^1 1\,dx = 1
$$

> 🎯 **通用结论**：$\displaystyle\int_{-a}^a \frac{dx}{1+a^x} = a$，对任意 $a>0, a\neq 1$ 成立。

#### 例题 2.2（进阶·反三角恒等式型）

计算 $\displaystyle\int_{-a}^a \frac{\arctan e^x}{1+x^2} dx$。

**思路溯源**：$\arctan e^x + \arctan e^{-x} = \frac{\pi}{2}$（由 $\arctan u + \arctan\frac{1}{u} = \frac{\pi}{2}$）。

**解**：

令 $f(x) = \frac{\arctan e^x}{1+x^2}$，则

$$
f(x) + f(-x) = \frac{\arctan e^x + \arctan e^{-x}}{1+x^2} = \frac{\pi/2}{1+x^2}
$$

$$
\text{原式} = \int_0^a \frac{\pi/2}{1+x^2} dx = \frac{\pi}{2}[\arctan x]_0^a = \frac{\pi}{2}\arctan a
$$

---

### 题型 3：三角函数的对称性质

| 区间 | 性质 | 公式 |
| :--- | :--- | :--- |
| $[0, \pi]$ | $\sin x$ 关于 $x=\frac{\pi}{2}$ 对称 | $\int_0^\pi f(\sin x)dx = 2\int_0^{\frac{\pi}{2}} f(\sin x)dx$ |
| $[0, \frac{\pi}{2}]$ | $\sin$ 和 $\cos$ 对偶 | $\int_0^{\frac{\pi}{2}} f(\sin x)dx = \int_0^{\frac{\pi}{2}} f(\cos x)dx$ |
| $[0, \pi]$ | $|\cos x|$ 对称 | $\int_0^\pi f(|\cos x|)dx = 2\int_0^{\frac{\pi}{2}} f(\cos x)dx$ |
| $[-\pi, \pi]$ | 奇偶性 | $\int_{-\pi}^\pi \sin^{2k+1}x\,dx = 0$ |

#### 例题 3.1（基础）

计算 $\displaystyle\int_0^\pi \sin^3 x\,dx$。

**思路溯源**：$[0,\pi]$ 上的 $\sin^3 x$ → $\int_0^\pi f(\sin x)dx = 2\int_0^{\pi/2} f(\sin x)dx$ → 套 Wallis 点火公式。

**解**：

$$
\int_0^\pi \sin^3 x\,dx = 2\int_0^{\frac{\pi}{2}} \sin^3 x\,dx = 2 \cdot \frac{2}{3} = \frac{4}{3}
$$

#### 例题 3.2（进阶·对偶+方程法）

计算 $\displaystyle\int_0^{\frac{\pi}{2}} \frac{\sin^n x}{\sin^n x + \cos^n x} dx$。

**思路溯源**：设 $I = \int_0^{\frac{\pi}{2}} \frac{\sin^n x}{\sin^n x + \cos^n x} dx$。利用 $\sin/\cos$ 对偶性：令 $x = \frac{\pi}{2} - t$，则 $I = \int_0^{\frac{\pi}{2}} \frac{\cos^n t}{\cos^n t + \sin^n t} dt$。二式相加：

$2I = \int_0^{\frac{\pi}{2}} 1\,dx = \frac{\pi}{2}$，故 $I = \frac{\pi}{4}$。

> 💡 **结论与 $n$ 无关**——$\int_0^{\frac{\pi}{2}} \frac{\sin^n x}{\sin^n x + \cos^n x} dx = \frac{\pi}{4}$ 对任意 $n$ 成立。

---

### 题型 4：周期函数的定积分简化

**识别特征**：被积函数是周期函数，积分区间跨多个周期。

**定理**：若 $f(x)$ 以 $T$ 为周期，则：

$$
\boxed{\int_a^{a+T} f(x)dx = \int_0^T f(x)dx} \qquad\text{（一个周期上的积分与起点无关）}
$$

**推论**：$\displaystyle\int_a^{a+nT} f(x)dx = n\int_0^T f(x)dx$

#### 例题 4.1

计算 $\displaystyle\int_0^{100\pi} |\sin x|\,dx$。

**思路溯源**：$|\sin x|$ 的周期是 $\pi$。$100\pi = 100 \times \pi$ → 100 个完整周期。

**解**：

$$
\int_0^{100\pi} |\sin x|\,dx = 100\int_0^\pi \sin x\,dx = 100 \cdot [-\cos x]_0^\pi = 200
$$

---

### 题型 5：对称区间 + 拆项 + 换元的组合技

**识别特征**：区间对称，函数可拆为奇偶部分，利用对称性消去奇部，对偶部用换元。

#### 例题 5.1（基础）

计算 $\displaystyle\int_{-1}^1 \frac{x^2 + x}{1+x^2} dx$。

**思路溯源**：拆项 → $\frac{x^2}{1+x^2}$ 偶 + $\frac{x}{1+x^2}$ 奇。奇部积分为 0。

**解**：

偶部：$2\int_0^1 \frac{x^2}{1+x^2} dx = 2\int_0^1 \left(1 - \frac{1}{1+x^2}\right) dx = 2\left[ x - \arctan x \right]_0^1 = 2 - \frac{\pi}{2}$

奇部：0。答案为 $2 - \frac{\pi}{2}$。

#### 例题 5.2（综合·需多步判断）

计算 $\displaystyle\int_{-1}^1 \frac{x^4 \sin x + x^3}{1+x^2} dx$。

**思路溯源**：分两项：
- $\frac{x^4 \sin x}{1+x^2}$：$x^4$ 偶，$\sin x$ 奇，分母偶 → 奇×偶/偶 = 奇 → 积分为 0
- $\frac{x^3}{1+x^2}$：分子奇 / 分母偶 = 奇 → 积分为 0

**解**：两项均为奇函数 → 答案 $0$。

## 三、方法总结表

| 技巧 | 适用条件 | 操作 | 易错点 |
| :--- | :--- | :--- | :--- |
| **奇偶直接判断** | $[-a,a]$ + 函数奇偶明显 | 奇=0，偶=$2\int_0^a$ | $\sin(x^2)$ 是偶函数！ |
| **一般拆解公式** | $[-a,a]$ + 函数无奇偶性 | $f(x)+f(-x)$ 通分简化 | 常用恒等式要记牢 |

| **拆项消奇** | 对称区间混合函数 | 拆分奇偶，奇部归零 | 分项后每项单独判 |

## 五、附录

### 附录 A：自测练习答案

**练习 1**：$x^2$ 偶，$\sin x$ 奇，乘积为奇函数。$\int_{-\pi}^\pi = 0$。

**练习 2**：分子全为奇函数，分母 $\sqrt{4-x^2}$ 为偶函数。奇/偶 = 奇。答案为 $0$。

**练习 3**：利用 $\frac{1}{1+3^x} + \frac{1}{1+3^{-x}} = 1$。

$\int_{-1}^1 = \int_0^1 1\,dx = 1$。

**练习 4**：令 $f(x) = x\ln(1+e^x)$，则

$f(-x) = -x\ln(1+e^{-x}) = -x\ln\frac{e^x+1}{e^x} = -x[\ln(1+e^x) - x] = -x\ln(1+e^x) + x^2$

$f(x) + f(-x) = x\ln(1+e^x) - x\ln(1+e^x) + x^2 = x^2$

原式 $= \int_0^a x^2 dx = \frac{a^3}{3}$。

**练习 5**：$\sin^4\frac{x}{2}$ 的周期为 $2\pi$（注意$\sin^2$ 周期是 $\pi$，但这里 $\sin^4(x/2)$ 需要验证）。

实际上用降幂公式：$\sin^2\frac{x}{2} = \frac{1-\cos x}{2}$。

$\sin^4\frac{x}{2} = \left(\frac{1-\cos x}{2}\right)^2 = \frac{1-2\cos x+\cos^2 x}{4} = \frac{1}{4} - \frac{\cos x}{2} + \frac{1+\cos 2x}{8}$

$= \frac{3}{8} - \frac{\cos x}{2} + \frac{\cos 2x}{8}$

积分：$\int_0^{2\pi} \left(\frac{3}{8} - \frac{\cos x}{2} + \frac{\cos 2x}{8}\right) dx = \frac{3}{8}\cdot 2\pi - 0 + 0 = \frac{3\pi}{4}$

（$\cos x$ 和 $\cos 2x$ 在 $[0,2\pi]$ 上积分为 0，因为它们是周期函数跨完整周期且均值为 0。）
