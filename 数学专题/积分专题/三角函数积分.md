# 三角函数的积分 | 积分专题

> **核心问题**：三角函数的不定积分、定积分、反常积分的系统解法。
> **核心思想**：
> - **不定积分**：降幂、凑微分、万能代换、分部积分的递推
> - **定积分**：对称性（区间再现、$\sin$/$\cos$ 对偶）+ Wallis 点火公式
> - **反常积分**：p-积分比较 + Dirichlet 判别 + $\Gamma$ 函数

---

## 一、核心公式与推导

### 1.1 基本三角函数积分公式

### 1.1.1 基本三角函数的积分

| 被积函数 | 原函数 | 推导/记忆法 |
| :--- | :--- | :--- |
| $\displaystyle\int \sin x\,dx$ | $-\cos x + C$ | 基本公式 |
| $\displaystyle\int \cos x\,dx$ | $\sin x + C$ | 基本公式 |
| $\displaystyle\int \tan x\,dx$ | $-\ln\vert\cos x\vert + C$ | $\tan x = \frac{\sin x}{\cos x}$，凑 $d(\cos x)$ |
| $\displaystyle\int \cot x\,dx$ | $\ln\vert\sin x\vert + C$ | $\cot x = \frac{\cos x}{\sin x}$，凑 $d(\sin x)$ |
| $\displaystyle\int \sec x\,dx$ | $\ln\vert\sec x + \tan x\vert + C$ | 乘 $\frac{\sec x+\tan x}{\sec x+\tan x}$ |
| $\displaystyle\int \csc x\,dx$ | $\ln\vert\csc x - \cot x\vert + C$ | 乘 $\frac{\csc x-\cot x}{\csc x-\cot x}$ |
| $\displaystyle\int \sec^2 x\,dx$ | $\tan x + C$ | $(\tan x)' = \sec^2 x$ |
| $\displaystyle\int \csc^2 x\,dx$ | $-\cot x + C$ | $(\cot x)' = -\csc^2 x$ |
| $\displaystyle\int \sec x\tan x\,dx$ | $\sec x + C$ | $(\sec x)' = \sec x\tan x$ |
| $\displaystyle\int \csc x\cot x\,dx$ | $-\csc x + C$ | $(\csc x)' = -\csc x\cot x$ |
| $\displaystyle\int \sin^2 x\,dx$ | $\frac{x}{2} - \frac{\sin 2x}{4} + C$ | 降幂 $\sin^2 x = \frac{1-\cos 2x}{2}$ |
| $\displaystyle\int \cos^2 x\,dx$ | $\frac{x}{2} + \frac{\sin 2x}{4} + C$ | 降幂 $\cos^2 x = \frac{1+\cos 2x}{2}$ |

### 1.1.2 反三角函数的积分

| 被积函数 | 原函数 | 推导 |
| :--- | :--- | :--- |
| $\displaystyle\int \arcsin x\,dx$ | $x\arcsin x + \sqrt{1-x^2} + C$ | 分部积分：$u=\arcsin x, dv=dx$ |
| $\displaystyle\int \arccos x\,dx$ | $x\arccos x - \sqrt{1-x^2} + C$ | 分部积分：$u=\arccos x, dv=dx$ |
| $\displaystyle\int \arctan x\,dx$ | $x\arctan x - \frac{1}{2}\ln(1+x^2) + C$ | 分部积分：$u=\arctan x, dv=dx$ |
| $\displaystyle\int \operatorname{arccot} x\,dx$ | $x\operatorname{arccot} x + \frac{1}{2}\ln(1+x^2) + C$ | 分部积分：$u=\operatorname{arccot} x, dv=dx$ |

> ⚠️ **反三角函数积分口诀**：「反三角，分部上；$u$ 取反三角，$dv$ 取 $dx$；求导变代数，积分变多项式再乘 $x$。」

### 1.2 三角恒等式（积分必备）

| 类别 | 公式 |
| :--- | :--- |
| **降幂公式** | $\sin^2 x = \frac{1-\cos 2x}{2}$，$\cos^2 x = \frac{1+\cos 2x}{2}$ |
| **积化和差** | $\sin ax\cos bx = \frac{1}{2}[\sin(a+b)x + \sin(a-b)x]$ |
| | $\cos ax\cos bx = \frac{1}{2}[\cos(a+b)x + \cos(a-b)x]$ |
| | $\sin ax\sin bx = \frac{1}{2}[\cos(a-b)x - \cos(a+b)x]$ |
| **倍角公式** | $\sin 2x = 2\sin x\cos x$，$\cos 2x = \cos^2 x - \sin^2 x = 1-2\sin^2 x = 2\cos^2 x - 1$ |
| **万能代换** | $t = \tan\frac{x}{2}$，$\sin x = \frac{2t}{1+t^2}$，$\cos x = \frac{1-t^2}{1+t^2}$，$dx = \frac{2}{1+t^2}dt$ |

### 1.3 $\sin^n x$/$\cos^n x$ 的递推公式

设 $I_n = \int \sin^n x\,dx$（$n \geq 2$）：

$$
\boxed{I_n = -\frac{1}{n}\sin^{n-1}x\cos x + \frac{n-1}{n}I_{n-2}}
$$

**推导**（分部积分）：

$$
\begin{aligned}
I_n &= \int \sin^{n-1}x \cdot \sin x\,dx \\
&= -\sin^{n-1}x\cos x + (n-1)\int \sin^{n-2}x\cos^2 x\,dx \\
&= -\sin^{n-1}x\cos x + (n-1)\int \sin^{n-2}x\,(1-\sin^2 x)dx \\
&= -\sin^{n-1}x\cos x + (n-1)I_{n-2} - (n-1)I_n
\end{aligned}
$$

移项得 $n I_n = -\sin^{n-1}x\cos x + (n-1)I_{n-2}$。

### ★ 必背专题：三角函数积分策略决策树

> ⚡ 遇到三角积分，按此顺序决策——优先级从高到低，**能凑微分就不用万能代换**。

```
∫ R(sin x, cos x) dx
    │
    ├─ sin x 奇次幂（或 cos x 奇次幂）
    │   → 拆出一个 sin x 凑 d(cos x)（或 cos x 凑 d(sin x)）
    │   例：∫ sin³x cos²x dx → 拆 sin x, 令 u=cos x
    │
    ├─ sin x, cos x 均为偶次幂
    │   → 降幂公式重复降次
    │   例：∫ sin²x cos²x dx → 降幂四次
    │
    ├─ 仅含 tan x / cot x
    │   → 令 t = tan x，dt = sec²x dx
    │   例：∫ tan⁵x dx → 拆 tan²x = sec²x - 1
    │
    ├─ 仅含 sec x / csc x 的偶次幂
    │   → 用 sec²x = 1 + tan²x 转化
    │
    ├─ 分子分母关于 sin/cos 有特殊对称性
    │   → 先检查 R(-sin x, cos x) = -R, R(sin x, -cos x) = -R 等
    │       优先用 t = cos x, t = sin x, t = tan x
    │
    └─ 以上均不适用 → 万能代换 t = tan(x/2)
        （万能代换是兜底方案，计算量大，尽量不用）
```

### 题型 1：$\sin^m x \cos^n x$ 型不定积分

**核心策略**：看 $m$ 和 $n$ 的奇偶性。

| 情形 | 策略 | 替换 |
| :--- | :--- | :--- |
| $m$ **奇**（$n$ 任意） | 拆 $\sin x$，凑 $d(\cos x)$ | $u = \cos x$ |
| $n$ **奇**（$m$ 任意） | 拆 $\cos x$，凑 $d(\sin x)$ | $u = \sin x$ |
| $m, n$ **均为偶** | 用降幂公式 $\sin^2 x = \frac{1-\cos 2x}{2}$ 等 | 反复降次 |
| $m, n$ **均为奇** | 两种策略均可，选次数较低的拆 | — |

#### 例题 1.1（基础·$\sin$ 奇次）

求 $\displaystyle\int \sin^3 x\,dx$。

**思路溯源**：$m=3$ 为奇 → 拆出一个 $\sin x$ 凑 $d(\cos x)$。

**解**：

$$
\begin{aligned}
\int \sin^3 x\,dx &= \int \sin^2 x \cdot \sin x\,dx
= \int (1-\cos^2 x)\sin x\,dx \\[4pt]
&\xrightarrow{u=\cos x} -\int (1-u^2)du
= -u + \frac{u^3}{3} + C \\[4pt]
&= -\cos x + \frac{\cos^3 x}{3} + C
\end{aligned}
$$

#### 例题 1.2（基础·$\cos$ 奇次）

求 $\displaystyle\int \sin^2 x \cos^3 x\,dx$。

**思路溯源**：$\cos$ 是奇次（$n=3$），拆 $\cos x$ 凑 $d(\sin x)$。

**解**：

$$
\begin{aligned}
\int \sin^2 x \cos^3 x\,dx &= \int \sin^2 x \cos^2 x \cdot \cos x\,dx \\
&= \int \sin^2 x\,(1-\sin^2 x)\,d(\sin x) \\
&\xrightarrow{u=\sin x} \int u^2(1-u^2)du
= \frac{u^3}{3} - \frac{u^5}{5} + C \\[4pt]
&= \frac{\sin^3 x}{3} - \frac{\sin^5 x}{5} + C
\end{aligned}
$$

#### 例题 1.3（进阶·均为偶次）

求 $\displaystyle\int \sin^2 x \cos^2 x\,dx$。

**思路溯源**：$m=2, n=2$ 均为偶 → 降幂公式反复降次。

**解**：

$$
\begin{aligned}
\sin^2 x \cos^2 x &= \frac{1}{4}\sin^2 2x
= \frac{1}{4}\cdot\frac{1-\cos 4x}{2}
= \frac{1}{8}(1-\cos 4x) \\[4pt]
\int \sin^2 x \cos^2 x\,dx &= \frac{1}{8}\int (1-\cos 4x)dx
= \frac{x}{8} - \frac{\sin 4x}{32} + C
\end{aligned}
$$

#### 例题 1.4（综合·高次幂）

求 $\displaystyle\int \sin^5 x \cos^2 x\,dx$。

**思路溯源**：$\sin$ 奇次（$m=5$），拆 $\sin x$ 凑 $d(\cos x)$。

**解**：

令 $u = \cos x$，$du = -\sin x\,dx$。

$$
\begin{aligned}
\int \sin^5 x \cos^2 x\,dx &= \int \sin^4 x \cos^2 x \cdot \sin x\,dx \\
&= \int (1-\cos^2 x)^2 \cos^2 x \cdot \sin x\,dx \\
&= -\int (1-u^2)^2 u^2 du \\
&= -\int (u^2 - 2u^4 + u^6)du \\
&= -\frac{u^3}{3} + \frac{2u^5}{5} - \frac{u^7}{7} + C \\
&= -\frac{\cos^3 x}{3} + \frac{2\cos^5 x}{5} - \frac{\cos^7 x}{7} + C
\end{aligned}
$$

### 题型 2：$\tan^n x$、$\cot^n x$、$\sec^n x$、$\csc^n x$ 型

#### 2.1 $\tan^n x$ 与 $\cot^n x$

**核心策略**：利用 $\tan^2 x = \sec^2 x - 1$（或 $\cot^2 x = \csc^2 x - 1$）降幂，配合 $\int \tan x\,dx = -\ln|\cos x| + C$。

**递推公式**（$n \geq 2$）：

$$
\int \tan^n x\,dx = \frac{\tan^{n-1}x}{n-1} - \int \tan^{n-2}x\,dx
$$

**推导**：$\int \tan^n x\,dx = \int \tan^{n-2}x\,(\sec^2 x - 1)dx = \int \tan^{n-2}x\,d(\tan x) - \int \tan^{n-2}x\,dx = \frac{\tan^{n-1}x}{n-1} - \int \tan^{n-2}x\,dx$。

#### 例题 2.1（基础）

求 $\displaystyle\int \tan^3 x\,dx$。

**解**：

$$
\begin{aligned}
\int \tan^3 x\,dx &= \int \tan x\,(\sec^2 x - 1)dx \\
&= \int \tan x\,d(\tan x) - \int \tan x\,dx \\
&= \frac{\tan^2 x}{2} + \ln|\cos x| + C
\end{aligned}
$$

#### 2.2 $\sec^n x$ 与 $\csc^n x$

**核心策略**：按 $n$ 的奇偶分流。

| $n$ | 策略 |
| :---: | :--- |
| **偶** | 拆 $\sec^2 x$，用 $\sec^2 x = 1+\tan^2 x$ 化归 $\tan x$ |
| **奇** | 用分部积分建立递推（或特殊处理低次） |

**递推公式**（$n \geq 2$）：

$$
\int \sec^n x\,dx = \frac{\sec^{n-2}x\tan x}{n-1} + \frac{n-2}{n-1}\int \sec^{n-2}x\,dx
$$

#### 例题 2.2（基础）

求 $\displaystyle\int \sec^4 x\,dx$。

**解**：

$$
\begin{aligned}
\int \sec^4 x\,dx &= \int \sec^2 x \cdot \sec^2 x\,dx
= \int (1+\tan^2 x)\,d(\tan x) \\
&= \tan x + \frac{\tan^3 x}{3} + C
\end{aligned}
$$

#### 例题 2.3（进阶·$\sec$ 奇次）

求 $\displaystyle\int \sec^3 x\,dx$。

**思路溯源**：这是 $\sec$ 奇次幂中最经典的一个（高频考题）。用分部积分法。

**解**：

$$
\begin{aligned}
\int \sec^3 x\,dx &= \int \sec x \cdot \sec^2 x\,dx \\
&= \sec x \tan x - \int \tan x \cdot \sec x \tan x\,dx \quad (\text{分部：} u=\sec x, dv=\sec^2 x dx) \\
&= \sec x \tan x - \int \sec x \tan^2 x\,dx \\
&= \sec x \tan x - \int \sec x\,(\sec^2 x - 1)dx \\
&= \sec x \tan x - \int \sec^3 x\,dx + \int \sec x\,dx
\end{aligned}
$$

移项：
$$
2\int \sec^3 x\,dx = \sec x \tan x + \ln|\sec x + \tan x| + C
$$

$$
\boxed{\int \sec^3 x\,dx = \frac{1}{2}\sec x \tan x + \frac{1}{2}\ln|\sec x + \tan x| + C}
$$

### 题型 3：三角函数有理式（$R(\sin x, \cos x)$）的积分

**策略优先级**（按简化程度排序）：

| 优先级 | 条件 | 替换 | 原因 |
| :---: | :--- | :--- | :--- |
| 1 | $R(-\sin x, \cos x) = -R$ | $t = \cos x$ | 分子可提取 $\sin x$ 凑 $d(\cos x)$ |
| 2 | $R(\sin x, -\cos x) = -R$ | $t = \sin x$ | 分子可提取 $\cos x$ 凑 $d(\sin x)$ |
| 3 | $R(-\sin x, -\cos x) = R$ | $t = \tan x$ | 分子分母同除 $\cos^2 x$，化为 $t$ 的有理式 |
| 4 | 以上均不满足 | $t = \tan\frac{x}{2}$（万能） | 兜底方案，计算量大 |

#### 例题 3.1（基础·策略 3）

求 $\displaystyle\int \frac{dx}{\sin^2 x + 2\cos^2 x}$。

**思路溯源**：$R(-\sin x, -\cos x) = \frac{1}{\sin^2 x + 2\cos^2 x} = R(\sin x, \cos x)$ ✓ → 策略 3，令 $t = \tan x$。

**解**：

分子分母同除 $\cos^2 x$：$\frac{1}{\sin^2 x + 2\cos^2 x} = \frac{\sec^2 x}{\tan^2 x + 2}$。

令 $t = \tan x$，$dt = \sec^2 x\,dx$。

$$
\int \frac{dt}{t^2+2} = \frac{1}{\sqrt{2}}\arctan\frac{t}{\sqrt{2}} + C
= \frac{1}{\sqrt{2}}\arctan\frac{\tan x}{\sqrt{2}} + C
$$

#### 例题 3.2（进阶·万能代换）

求 $\displaystyle\int \frac{dx}{2+\sin x}$。

**思路溯源**：$R(-\sin x, \cos x) \neq \pm R$，$R(\sin x, -\cos x) \neq \pm R$ → 直接万能代换。

**解**：

令 $t = \tan\frac{x}{2}$，$\sin x = \frac{2t}{1+t^2}$，$dx = \frac{2}{1+t^2}dt$。

$$
\begin{aligned}
\int \frac{1}{2+\frac{2t}{1+t^2}} \cdot \frac{2}{1+t^2} dt
&= \int \frac{2}{2(1+t^2)+2t} dt
= \int \frac{1}{t^2+t+1} dt \\[4pt]
&= \int \frac{1}{(t+\frac{1}{2})^2 + \frac{3}{4}} dt
= \frac{2}{\sqrt{3}}\arctan\frac{2t+1}{\sqrt{3}} + C \\[4pt]
&= \frac{2}{\sqrt{3}}\arctan\frac{2\tan\frac{x}{2}+1}{\sqrt{3}} + C
\end{aligned}
$$

### 题型 4：三角函数的定积分（对称性 + Wallis）

#### 4.1 $\sin/\cos$ 在特殊区间上的对称性

| 区间 | 对称性质 | 公式 |
| :--- | :--- | :--- |
| $[0, \pi]$ | $\sin x$ 关于 $x=\frac{\pi}{2}$ 对称 | $\int_0^\pi f(\sin x)dx = 2\int_0^{\frac{\pi}{2}} f(\sin x)dx$ |
| $[0, \frac{\pi}{2}]$ | $\sin$ 和 $\cos$ 对偶 | $\int_0^{\frac{\pi}{2}} f(\sin x)dx = \int_0^{\frac{\pi}{2}} f(\cos x)dx$ |
| $[-\pi, \pi]$ | 奇偶性 | $\int_{-\pi}^\pi \sin^{2k+1}x\,dx = 0$ |
| $[0, 2\pi]$ | 周期性 | $\int_0^{2\pi} f(\sin x, \cos x)dx$ 可用周期简化 |

#### ★ 必背：Wallis 点火公式

$$
\boxed{\int_0^{\frac{\pi}{2}} \sin^n x\,dx = \int_0^{\frac{\pi}{2}} \cos^n x\,dx = \begin{cases}
\dfrac{(n-1)!!}{n!!} \cdot \dfrac{\pi}{2}, & n \text{ 为偶数} \\[14pt]
\dfrac{(n-1)!!}{n!!}, & n \text{ 为奇数}
\end{cases}}
$$

其中 $n!! = n(n-2)(n-4)\cdots$（降到 $1$ 或 $2$）。

**速算口诀**：
- 偶数（如 $n=6$）：$\frac{5}{6} \cdot \frac{3}{4} \cdot \frac{1}{2} \cdot \frac{\pi}{2}$
- 奇数（如 $n=5$）：$\frac{4}{5} \cdot \frac{2}{3} \cdot 1$

#### 例题 4.1（基础·Wallis 直接套）

计算 $\displaystyle\int_0^{\frac{\pi}{2}} \sin^7 x\,dx$。

**解**：$n=7$ 为奇数。

$$
\int_0^{\frac{\pi}{2}} \sin^7 x\,dx = \frac{6!!}{7!!} = \frac{6\cdot4\cdot2}{7\cdot5\cdot3\cdot1} = \frac{48}{105} = \frac{16}{35}
$$

#### 例题 4.2（进阶·对称性 + Wallis）

计算 $\displaystyle\int_0^\pi \sin^4 \frac{x}{2}\,dx$。

**思路溯源**：先用 $\int_0^\pi f(\sin\frac{x}{2})dx = 2\int_0^{\frac{\pi}{2}} f(\sin t)dt$（令 $t = x/2$），再套 Wallis。

**解**：

令 $t = x/2$，$dx = 2dt$，$x: 0\to\pi \Rightarrow t: 0\to\frac{\pi}{2}$。

$$
\int_0^\pi \sin^4\frac{x}{2}\,dx = 2\int_0^{\frac{\pi}{2}} \sin^4 t\,dt
= 2 \cdot \frac{3!!}{4!!} \cdot \frac{\pi}{2}
= 2 \cdot \frac{3\cdot1}{4\cdot2} \cdot \frac{\pi}{2}
= \frac{3\pi}{8}
$$

#### 例题 4.3（综合·$\sin$/$\cos$ 对偶联立方程）

计算 $\displaystyle\int_0^{\frac{\pi}{2}} \frac{\sin^n x}{\sin^n x + \cos^n x} dx$。

**思路溯源**：设 $I = \int_0^{\frac{\pi}{2}} \frac{\sin^n x}{\sin^n x + \cos^n x} dx$。令 $x = \frac{\pi}{2} - t$，利用对偶性：

$I = \int_0^{\frac{\pi}{2}} \frac{\cos^n t}{\cos^n t + \sin^n t} dt$。

两式相加：$2I = \int_0^{\frac{\pi}{2}} 1\,dx = \frac{\pi}{2}$。故 $I = \frac{\pi}{4}$。

> 💡 结论与 $n$ 无关——无论 $\sin$ 的多少次幂，积分值恒为 $\frac{\pi}{4}$。

#### 例题 4.4（综合·区间再现消去 $x$）

计算 $\displaystyle\int_0^\pi \frac{x\sin x}{1+\cos^2 x} dx$。

**思路溯源**：被积函数含 $x f(\sin x)$ 型 → 区间再现公式 (D1)。

**解**：

由区间再现：$\int_0^\pi x f(\sin x)dx = \frac{\pi}{2}\int_0^\pi f(\sin x)dx$。

$$
\begin{aligned}
I &= \frac{\pi}{2}\int_0^\pi \frac{\sin x}{1+\cos^2 x} dx
= \frac{\pi}{2}\int_0^\pi \frac{-d(\cos x)}{1+\cos^2 x} \\[4pt]
&= \frac{\pi}{2}\Big[-\arctan(\cos x)\Big]_0^\pi
= \frac{\pi}{2}\big[-\arctan(-1) + \arctan(1)\big] \\[4pt]
&= \frac{\pi}{2}\cdot\frac{\pi}{2} = \frac{\pi^2}{4}
\end{aligned}
$$

### 题型 5：含三角函数的反常积分

**核心方法**：等价无穷小/无穷大分析 → p-积分比较。

#### 5.1 Dirichlet 积分

$$
\boxed{\int_0^{+\infty} \frac{\sin x}{x} dx = \frac{\pi}{2}}
$$

这是考研数一中需要掌握的条件收敛反常积分。证明超出大纲，但结论必须记忆。

#### 5.2 概率积分与 $\Gamma$ 函数结合

$$
\boxed{\int_0^{+\infty} e^{-x^2} dx = \frac{\sqrt{\pi}}{2}}
$$

#### 例题 5.1（基础·p-积分比较）

判断 $\displaystyle\int_0^{\frac{\pi}{2}} \frac{\sin x}{x^p} dx$ 的敛散性（讨论 $p$）。

**思路溯源**：$x\to 0^+$ 处的瑕积分。$\frac{\sin x}{x^p} \sim \frac{x}{x^p} = \frac{1}{x^{p-1}}$。

**解**：瑕积分 $\int_0^{\pi/2} \frac{1}{x^{p-1}}dx$ 收敛 $\iff$ $p-1 < 1 \iff p < 2$。

#### 例题 5.2（进阶·多坏点）

判断 $\displaystyle\int_0^{+\infty} \frac{\sin x}{x^p} dx$（$p>0$）的敛散性。

**思路溯源**：
- $x\to 0^+$：$\sin x \sim x$，$\sim \frac{1}{x^{p-1}}$。收敛 $\iff p < 2$。
- $x\to +\infty$：$|\frac{\sin x}{x^p}| \leq \frac{1}{x^p}$。收敛若 $p > 1$（绝对收敛）。实际上 $p>0$ 时条件收敛（Dirichlet 判别）。

**结论**：$0 < p < 2$ 时收敛（$p\leq 0$ 时 $\infty$ 处发散，$p \geq 2$ 时 $0$ 处发散）。

#### 例题 5.3（综合·三角+对数）

计算 $\displaystyle\int_0^{\frac{\pi}{2}} \ln\sin x\,dx$。

**思路溯源**：利用对称性 $I = \int_0^{\pi/2} \ln\sin x\,dx = \int_0^{\pi/2} \ln\cos x\,dx$。

**解**：

设 $I = \int_0^{\frac{\pi}{2}} \ln\sin x\,dx$。由 $\sin/\cos$ 对偶性 $I = \int_0^{\frac{\pi}{2}} \ln\cos x\,dx$。

$$
\begin{aligned}
2I &= \int_0^{\frac{\pi}{2}} (\ln\sin x + \ln\cos x)dx
= \int_0^{\frac{\pi}{2}} \ln(\sin x\cos x)dx \\[4pt]
&= \int_0^{\frac{\pi}{2}} \ln\frac{\sin 2x}{2} dx
= \int_0^{\frac{\pi}{2}} \ln\sin 2x\,dx - \frac{\pi}{2}\ln 2
\end{aligned}
$$

令 $t = 2x$，$\int_0^{\pi/2} \ln\sin 2x\,dx = \frac{1}{2}\int_0^\pi \ln\sin t\,dt = \frac{1}{2}\cdot 2\int_0^{\pi/2} \ln\sin t\,dt = I$。

故 $2I = I - \frac{\pi}{2}\ln 2$，$I = -\frac{\pi}{2}\ln 2$。

$$
\boxed{\int_0^{\frac{\pi}{2}} \ln\sin x\,dx = -\frac{\pi}{2}\ln 2}
$$

## 五、附录

### 附录 A：自测练习答案

**练习 1**：

$n=5$ 奇 → 拆 $\cos x$ 凑 $d(\sin x)$。令 $u = \sin x$。

$$
\int \sin^2 x \cos^5 x\,dx = \int \sin^2 x \cos^4 x \cdot \cos x\,dx
= \int u^2(1-u^2)^2 du
$$

$$
= \int (u^2 - 2u^4 + u^6)du
= \frac{u^3}{3} - \frac{2u^5}{5} + \frac{u^7}{7} + C
= \frac{\sin^3 x}{3} - \frac{2\sin^5 x}{5} + \frac{\sin^7 x}{7} + C
$$

**练习 2**：

用递推两次：

$$
\int \tan^5 x\,dx = \frac{\tan^4 x}{4} - \int \tan^3 x\,dx
$$

$$
\int \tan^3 x\,dx = \frac{\tan^2 x}{2} - \int \tan x\,dx = \frac{\tan^2 x}{2} + \ln|\cos x| + C
$$

$$
\int \tan^5 x\,dx = \frac{\tan^4 x}{4} - \frac{\tan^2 x}{2} - \ln|\cos x| + C
$$

**练习 3**：

万能代换：$t = \tan\frac{x}{2}$。

$$
\begin{aligned}
\int \frac{1}{1+\frac{2t}{1+t^2}+\frac{1-t^2}{1+t^2}} \cdot \frac{2}{1+t^2} dt
&= \int \frac{2}{1+t^2+2t+1-t^2} dt \\
&= \int \frac{2}{2+2t} dt = \int \frac{1}{1+t} dt \\
&= \ln|1+t| + C = \ln\left|1+\tan\frac{x}{2}\right| + C
\end{aligned}
$$

**练习 4**：

$n=6$ 为偶数：

$$
\int_0^{\frac{\pi}{2}} \sin^6 x\,dx = \frac{5!!}{6!!} \cdot \frac{\pi}{2}
= \frac{5\cdot3\cdot1}{6\cdot4\cdot2} \cdot \frac{\pi}{2}
= \frac{15}{48} \cdot \frac{\pi}{2}
= \frac{5\pi}{32}
$$

**练习 5**：

被积函数含 $x f(\sin x)$ 型（注意 $\sin^3 x = \sin x \cdot \sin^2 x = \sin x(1-\cos^2 x)$，确实只含 $\sin x$ 和 $\cos x$），用区间再现 (D1)：

$$
I = \frac{\pi}{2}\int_0^\pi \frac{\sin^3 x}{1+\cos^2 x} dx
$$

由 $\int_0^\pi f(\sin x)g(\cos^2 x)dx = 2\int_0^{\pi/2} \cdots$（被积函数中 $\cos^2 x$ 关于 $\pi/2$ 对称）：

$$
I = \pi\int_0^{\frac{\pi}{2}} \frac{\sin^3 x}{1+\cos^2 x} dx
$$

令 $u = \cos x$，$du = -\sin x\,dx$。$\sin^3 x\,dx = \sin^2 x \cdot \sin x\,dx = (1-u^2)(-du)$。

$x: 0\to\frac{\pi}{2} \Rightarrow u: 1\to 0$。

$$
\begin{aligned}
I &= \pi\int_1^0 \frac{1-u^2}{1+u^2}(-du)
= \pi\int_0^1 \frac{1-u^2}{1+u^2} du \\[4pt]
&= \pi\int_0^1 \left(\frac{2}{1+u^2} - 1\right) du
= \pi\Big[2\arctan u - u\Big]_0^1 \\[4pt]
&= \pi\left(2\cdot\frac{\pi}{4} - 1\right)
= \frac{\pi^2}{2} - \pi
\end{aligned}
$$
