# 傅里叶级数 | 级数专题

> **核心公式**：$\displaystyle f(x) \sim \frac{a_0}{2} + \sum_{n=1}^{\infty} \left(a_n \cos nx + b_n \sin nx\right)$
> **核心思想**：将周期函数展开为**三角函数系**的无穷级数，利用三角函数系的正交性确定各频率分量的系数。本质上是把信号从"时间域"分解到"频率域"。
> **适用场景**：周期函数展开、和式求值（Basel 问题 $\sum 1/n^2$）、偏微分方程边值问题。
> 📖 *数一专属考点，考研每年必有 1 道填空题或解答题。*

---

## 〇、前置知识：三角函数系的正交性

这是傅里叶级数**最底层、最核心**的原理。理解了正交性，系数公式就无需死记硬背。

### 三角函数系

在区间 $[-\pi, \pi]$ 上，以下函数族构成一个**正交函数系**：

$$1,\ \cos x,\ \sin x,\ \cos 2x,\ \sin 2x,\ \dots,\ \cos nx,\ \sin nx,\ \dots$$

### 正交性（5 条关键积分）

| 编号 | 积分 | 结果 | 含义 |
| :---: | :--- | :---: | :--- |
| (1) | $\displaystyle\int_{-\pi}^{\pi} \cos nx\,dx$ | $0$（$n \ge 1$） | $\cos nx$ 与 $1$ 正交 |
| (2) | $\displaystyle\int_{-\pi}^{\pi} \sin nx\,dx$ | $0$（$n \ge 1$） | $\sin nx$ 与 $1$ 正交 |
| (3) | $\displaystyle\int_{-\pi}^{\pi} \cos mx \cos nx\,dx$ | $\begin{cases} 0, & m \neq n \\ \pi, & m = n \ge 1 \end{cases}$ | 不同频率的余弦正交 |
| (4) | $\displaystyle\int_{-\pi}^{\pi} \sin mx \sin nx\,dx$ | $\begin{cases} 0, & m \neq n \\ \pi, & m = n \ge 1 \end{cases}$ | 不同频率的正弦正交 |
| (5) | $\displaystyle\int_{-\pi}^{\pi} \cos mx \sin nx\,dx$ | $0$（对所有 $m,n$） | 余弦与正弦永远正交 |

> **补充**：$\displaystyle\int_{-\pi}^{\pi} 1 \cdot 1\,dx = 2\pi$。这就是 $a_0$ 公式中分母为 $\pi$ 而 $a_n, b_n$ 分母为 $\pi$ 的原因——$1$ 的"平方积分"是 $2\pi$，其他函数的"平方积分"是 $\pi$。

### 证明示范（以 (3) 为例）

利用积化和差 $\cos A\cos B = \frac{1}{2}[\cos(A+B) + \cos(A-B)]$：

$$\int_{-\pi}^{\pi} \cos mx \cos nx\,dx = \frac{1}{2}\int_{-\pi}^{\pi} \left[\cos(m+n)x + \cos(m-n)x\right]dx$$

- 若 $m \neq n$：两项均为余弦在整周期上的积分 → $0$
- 若 $m = n$：$\cos(m-n)x = \cos 0 = 1$，$\int 1 dx = 2\pi$，配合 $\frac{1}{2}$ 得 $\pi$

## 一、傅里叶级数的定义与系数公式

### 1.1 定义（周期 $2\pi$）

设 $f(x)$ 以 $2\pi$ 为周期（或定义在 $[-\pi, \pi]$ 上），其**傅里叶级数**为：

$$\boxed{f(x) \sim \frac{a_0}{2} + \sum_{n=1}^{\infty} \left(a_n \cos nx + b_n \sin nx\right)}$$

> ⚠️ 符号 $\sim$ 而非 $=$：傅里叶级数不一定处处收敛于 $f(x)$。何时能写 $=$ 由 **Dirichlet 收敛定理**决定。

### 1.2 傅里叶系数公式（欧拉公式）

由正交性，分别用 $1$、$\cos nx$、$\sin nx$ 乘以展开式两端并积分，可得系数：

$$\boxed{a_0 = \frac{1}{\pi}\int_{-\pi}^{\pi} f(x)\,dx}$$

$$\boxed{a_n = \frac{1}{\pi}\int_{-\pi}^{\pi} f(x)\cos nx\,dx \quad (n = 1,2,3,\dots)}$$

$$\boxed{b_n = \frac{1}{\pi}\int_{-\pi}^{\pi} f(x)\sin nx\,dx \quad (n = 1,2,3,\dots)}$$

### 1.3 推导过程（必懂！）

假设等号成立 $f(x) = \frac{a_0}{2} + \sum_{k=1}^{\infty} (a_k \cos kx + b_k \sin kx)$。

**求 $a_0$**：两端在 $[-\pi, \pi]$ 上积分。所有 $\cos kx$ 和 $\sin kx$ 积分均为 $0$：

$$\int_{-\pi}^{\pi} f(x)dx = \int_{-\pi}^{\pi} \frac{a_0}{2}dx = \frac{a_0}{2} \cdot 2\pi = a_0 \pi \quad\Rightarrow\quad a_0 = \frac{1}{\pi}\int_{-\pi}^{\pi} f(x)dx$$

**求 $a_n$**：两端乘以 $\cos nx$ 再积分。由正交性，$\int \cos nx \cdot \cos kx = 0$（$k \neq n$），$\int \cos nx \cdot \sin kx = 0$（始终）：

$$\int_{-\pi}^{\pi} f(x)\cos nx\,dx = a_n \int_{-\pi}^{\pi} \cos^2 nx\,dx = a_n \cdot \pi \quad\Rightarrow\quad a_n = \frac{1}{\pi}\int_{-\pi}^{\pi} f(x)\cos nx\,dx$$

**求 $b_n$**：同理，乘以 $\sin nx$ 再积分即可。

> 💡 **这就是正交性的威力**：每个系数可以**独立**求出，不被其他频率干扰。就像从混合信号中"调谐"出单一频率。

## 二、Dirichlet 收敛定理（狄利克雷定理）

这是考研数学一的**核心定理**，决定傅里叶级数在每一点是否收敛、收敛到什么值。

### 2.1 定理表述

设 $f(x)$ 以 $2\pi$ 为周期，在 $[-\pi, \pi]$ 上满足：

1. **分段连续**（至多有有限个第一类间断点）
2. **分段单调**（至多有有限个极值点，即不作无限次振荡）

则 $f(x)$ 的傅里叶级数**处处收敛**，且和函数 $S(x)$ 满足：

$$\boxed{S(x) = \begin{cases}
f(x), & x \text{ 为 } f \text{ 的连续点} \\[8pt]
\dfrac{f(x^-) + f(x^+)}{2}, & x \text{ 为 } f \text{ 的间断点}
\end{cases}}$$

其中 $f(x^-) = \lim_{t \to x^-} f(t)$，$f(x^+) = \lim_{t \to x^+} f(t)$。

### 2.2 通俗理解

- 连续点：傅里叶级数值 = 原函数值
- 间断点：傅里叶级数值 = 左右极限的**算术平均**
- 区间端点 $x = \pm\pi$：由于周期延拓，端点处和 = $\dfrac{f(\pi^-) + f(-\pi^+)}{2}$

### 2.3 在端点处的特殊处理

设 $f(x)$ 定义在 $[-\pi, \pi]$ 上。若 $f(-\pi) \neq f(\pi)$，将 $f$ 周期延拓时，端点 $x = \pm\pi$ 处左右极限分别为：

$$f(\pi^+) = f(-\pi^+),\quad f(\pi^-) = f(\pi)$$

因此傅里叶级数在 $x = \pm\pi$ 处的和为：

$$S(\pm\pi) = \frac{f(\pi) + f(-\pi)}{2}$$

> ⚠️ 这是高频易错点！周期延拓后的端点值未必等于原端点值。

## 三、正弦级数与余弦级数（奇偶延拓）

这是考研**最高频的考点**。给定 $[0, \pi]$ 上的函数，通过延拓展开为正弦级数或余弦级数。

### 3.1 核心概念

| 级数类型 | 延拓方式 | 系数特征 | 展开范围 |
| :--- | :--- | :--- | :--- |
| **傅里叶级数**（一般） | 周期延拓（$2\pi$ 周期） | $a_0, a_n, b_n$ 均有 | $[-\pi, \pi]$ |
| **正弦级数** | **奇延拓** + 周期延拓 | $a_0 = 0$，$a_n = 0$，仅 $b_n \neq 0$ | $[0, \pi]$ |
| **余弦级数** | **偶延拓** + 周期延拓 | $b_n = 0$，仅 $a_0, a_n \neq 0$ | $[0, \pi]$ |

### 3.2 正弦级数（奇延拓）

将 $f(x)$（定义在 $[0, \pi]$）**奇延拓**到 $[-\pi, \pi]$：

$$F(x) = \begin{cases} f(x), & 0 \le x \le \pi \\ -f(-x), & -\pi \le x < 0 \end{cases}$$

$F(x)$ 为奇函数 → $a_0 = 0$，$a_n = 0$（余弦项全部消亡），仅剩正弦项：

$$\boxed{f(x) \sim \sum_{n=1}^{\infty} b_n \sin nx}$$

其中系数公式简化为：

$$\boxed{b_n = \frac{2}{\pi}\int_{0}^{\pi} f(x)\sin nx\,dx}$$

> 💡 为什么是 $\frac{2}{\pi}$ 而非 $\frac{1}{\pi}$？因为奇延拓后 $f(x)\sin nx$ 是偶函数（奇×奇=偶），$[-\pi,\pi]$ 上的积分 = $2 \times [0,\pi]$ 上的积分。$\frac{1}{\pi} \times 2\int_0^\pi = \frac{2}{\pi}\int_0^\pi$。

**收敛情况**：
- 在 $(0, \pi)$ 内的连续点 → $S(x) = f(x)$
- 在 $x = 0$ 处 → $S(0) = 0$（奇函数在原点必为零）
- 在 $x = \pi$ 处 → $S(\pi) = 0$（奇延拓后 $\pi$ 处左右极限均值为 $0$）

### 3.3 余弦级数（偶延拓）

将 $f(x)$（定义在 $[0, \pi]$）**偶延拓**到 $[-\pi, \pi]$：

$$F(x) = \begin{cases} f(x), & 0 \le x \le \pi \\ f(-x), & -\pi \le x < 0 \end{cases}$$

$F(x)$ 为偶函数 → $b_n = 0$（正弦项全部消亡），仅剩余弦项：

$$\boxed{f(x) \sim \frac{a_0}{2} + \sum_{n=1}^{\infty} a_n \cos nx}$$

其中系数公式简化为：

$$\boxed{a_0 = \frac{2}{\pi}\int_{0}^{\pi} f(x)\,dx,\qquad a_n = \frac{2}{\pi}\int_{0}^{\pi} f(x)\cos nx\,dx}$$

> 💡 同理，偶延拓后 $f(x)\cos nx$ 是偶函数（偶×偶=偶），$[-\pi,\pi]$ 上的积分 = $2 \times [0,\pi]$ 的积分。

**收敛情况**：
- 在 $(0, \pi)$ 内的连续点 → $S(x) = f(x)$
- 在 $x = 0$ 处 → $S(0) = f(0^+)$（偶延拓后连续，通常等于原函数）
- 在 $x = \pi$ 处 → $S(\pi) = f(\pi^-)$（同上）

### 3.4 何时用正弦级数，何时用余弦级数？

| 题目暗示 | 选择 |
| :--- | :--- |
| "展开为**正弦级数**" | 奇延拓 |
| "展开为**余弦级数**" | 偶延拓 |
| "将 $[0, \pi]$ 上的 $f(x)$ 展开为傅里叶级数" | **两者都行**，题会指定或设问某一类 |
| $f(x)$ 在 $[0, \pi]$ 上有定义，问"其正弦级数在 $x=0$ 处的和" | 奇延拓 + 收敛定理 |

## 四、周期不为 $2\pi$ — 一般周期函数的傅里叶级数

### 4.1 周期 $2l$

设 $f(x)$ 以 $2l$ 为周期（或定义在 $[-l, l]$ 上）。只需将"标准频率" $nx$ 缩放为 $\frac{n\pi x}{l}$。

**系数公式**：

$$\boxed{a_0 = \frac{1}{l}\int_{-l}^{l} f(x)\,dx}$$

$$\boxed{a_n = \frac{1}{l}\int_{-l}^{l} f(x)\cos\frac{n\pi x}{l}\,dx}$$

$$\boxed{b_n = \frac{1}{l}\int_{-l}^{l} f(x)\sin\frac{n\pi x}{l}\,dx}$$

**傅里叶级数**：

$$\boxed{f(x) \sim \frac{a_0}{2} + \sum_{n=1}^{\infty} \left(a_n \cos\frac{n\pi x}{l} + b_n \sin\frac{n\pi x}{l}\right)}$$

### 4.2 对应奇偶延拓

**正弦级数**（奇延拓到 $[-l, l]$）：

$$b_n = \frac{2}{l}\int_{0}^{l} f(x)\sin\frac{n\pi x}{l}\,dx,\quad f(x) \sim \sum_{n=1}^{\infty} b_n \sin\frac{n\pi x}{l}$$

**余弦级数**（偶延拓到 $[-l, l]$）：

$$a_0 = \frac{2}{l}\int_{0}^{l} f(x)\,dx,\quad a_n = \frac{2}{l}\int_{0}^{l} f(x)\cos\frac{n\pi x}{l}\,dx$$

$$f(x) \sim \frac{a_0}{2} + \sum_{n=1}^{\infty} a_n \cos\frac{n\pi x}{l}$$

### 4.3 两种常见非标准周期

| 定义区间 | 周期 | $l$ 取值 | 频率基 |
| :--- | :--- | :---: | :--- |
| $[-\pi, \pi]$ | $2\pi$ | $l = \pi$ | $\cos nx$ |
| $[-l, l]$ | $2l$ | $l$ | $\cos\frac{n\pi x}{l}$ |
| $[0, 2\pi]$ | $2\pi$ | $l = \pi$ | $\cos nx$（积分限 $[0,2\pi]$） |
| $[0, l]$ | $2l$（延拓后） | $l$ | $\cos\frac{n\pi x}{l}$（先延拓） |

## 五、Parseval 等式（帕塞瓦尔恒等式）

### 5.1 公式

$$\boxed{\frac{1}{\pi}\int_{-\pi}^{\pi} [f(x)]^2\,dx = \frac{a_0^2}{2} + \sum_{n=1}^{\infty} (a_n^2 + b_n^2)}$$

或等价形式（更常用于求和）：

$$\boxed{\int_{-\pi}^{\pi} [f(x)]^2\,dx = \pi\left[\frac{a_0^2}{2} + \sum_{n=1}^{\infty} (a_n^2 + b_n^2)\right]}$$

### 5.2 考研最大用途：求数项级数和

这是解决 **$\sum 1/n^2$（Basel 问题）** 和 **$\sum 1/n^4$** 的标准方法。

**经典流程**：

1. 将 $f(x) = x$（或 $x^2$）展开为傅里叶级数 → 得到 $a_n, b_n$
2. 代入 Parseval 等式 → 左边可算出定积分，右边是 $\sum$ 形式的系数平方和
3. 整理即得 $\sum 1/n^2$ 或 $\sum 1/n^4$

## 六、题型全解

---

### 题型 A：求傅里叶级数展开（周期 $2\pi$）

#### ★ 例题 A1 | 基本型

将 $f(x) = x$（$-\pi < x < \pi$）展开为傅里叶级数，并利用展开式求 $\displaystyle\sum_{n=1}^{\infty} \frac{(-1)^{n-1}}{n}$。

---

#### 思路溯源

$f(x) = x$ 是**奇函数** → 预判 $a_0 = 0$，$a_n = 0$，仅需算 $b_n$。这大幅节省计算量。

#### 解

$f(x) = x$ 为奇函数，$a_0 = 0$，$a_n = 0$（$n \ge 1$）。

$$b_n = \frac{1}{\pi}\int_{-\pi}^{\pi} x\sin nx\,dx$$

被积函数 $x\sin nx$ 为偶函数（奇×奇=偶）：

$$b_n = \frac{2}{\pi}\int_{0}^{\pi} x\sin nx\,dx$$

分部积分：$\int x\sin nx\,dx = -\frac{x\cos nx}{n} + \frac{\sin nx}{n^2}$

$$b_n = \frac{2}{\pi}\left[-\frac{x\cos nx}{n} + \frac{\sin nx}{n^2}\right]_{0}^{\pi} = \frac{2}{\pi}\left(-\frac{\pi\cos n\pi}{n} + 0\right) = -\frac{2\cos n\pi}{n}$$

$\cos n\pi = (-1)^n$，故：

$$b_n = -\frac{2(-1)^n}{n} = (-1)^{n-1}\frac{2}{n}$$

傅里叶级数：

$$f(x) \sim 2\sum_{n=1}^{\infty} \frac{(-1)^{n-1}}{n}\sin nx$$

由 Dirichlet 定理，在 $(-\pi, \pi)$ 内 $f(x)$ 连续，$S(x) = x$。代入 $x = \pi/2$：

$$\frac{\pi}{2} = 2\sum_{n=1}^{\infty} \frac{(-1)^{n-1}}{n}\sin\frac{n\pi}{2}$$

当 $n$ 为偶数时 $\sin(n\pi/2) = 0$；$n$ 为奇数 $n=2k-1$ 时 $\sin((2k-1)\pi/2) = (-1)^{k-1}$：

$$\frac{\pi}{2} = 2\sum_{k=1}^{\infty} \frac{(-1)^{k-1}}{2k-1} \cdot (-1)^{k-1} = 2\sum_{k=1}^{\infty} \frac{1}{2k-1}$$

得 $\sum_{k=1}^{\infty} \frac{1}{2k-1} = \frac{\pi}{4}$（附带结论）。

对原问，代 $x = \pi$（间断点）。$S(\pi) = \frac{f(\pi^-) + f(-\pi^+)}{2} = \frac{\pi + (-\pi)}{2} = 0$。展开式在 $x=\pi$ 处：$\sin n\pi = 0$ 对所有 $n$，和为 $0 = S(\pi)$，验证一致。

代 $x = \pi/2$ 已得 $\sum_{k=1}^\infty \frac{1}{2k-1} = \frac{\pi}{4}$。对 $\sum (-1)^{n-1}/n$（Leibniz 级数），此和可另由 $\ln 2$ 的展开得到，但此处可通过 Parseval 或其他方式。

### 题型 B：正弦/余弦级数展开（延拓型）

#### ★ 例题 B1 | 余弦级数

将 $f(x) = x$（$0 \le x \le \pi$）展开为**余弦级数**。

---

#### 思路溯源

余弦级数 → 偶延拓 → $b_n = 0$。$f(x) = x$ 在 $[0,\pi]$ 上不是偶函数，但经过偶延拓后变为 $F(x) = |x|$（在 $[-\pi,\pi]$ 上），$|x|$ 是偶函数。

#### 解

余弦级数，仅算 $a_0, a_n$：

$$a_0 = \frac{2}{\pi}\int_{0}^{\pi} x\,dx = \frac{2}{\pi} \cdot \frac{\pi^2}{2} = \pi$$

$$a_n = \frac{2}{\pi}\int_{0}^{\pi} x\cos nx\,dx$$

分部积分：

$$\int x\cos nx\,dx = \frac{x\sin nx}{n} + \frac{\cos nx}{n^2}$$

$$a_n = \frac{2}{\pi}\left[\frac{x\sin nx}{n} + \frac{\cos nx}{n^2}\right]_{0}^{\pi} = \frac{2}{\pi}\left(0 + \frac{\cos n\pi}{n^2} - 0 - \frac{1}{n^2}\right)$$

$$= \frac{2}{\pi n^2}\left((-1)^n - 1\right)$$

- $n$ 为偶数：$(-1)^n - 1 = 0$ → $a_n = 0$
- $n$ 为奇数：$n = 2k-1$，$(-1)^{2k-1} - 1 = -2$ → $a_{2k-1} = -\frac{4}{\pi(2k-1)^2}$

余弦级数：

$$\boxed{x \sim \frac{\pi}{2} - \frac{4}{\pi}\sum_{k=1}^{\infty} \frac{\cos(2k-1)x}{(2k-1)^2},\quad 0 \le x \le \pi}$$

---

#### ★ 例题 B2 | 正弦级数

将 $f(x) = x$（$0 \le x \le \pi$）展开为**正弦级数**。

---

#### 思路溯源

正弦级数 → 奇延拓 → $a_n = 0$。奇延拓后 $F(x) = x$ 在 $[-\pi,\pi]$ 上本身就是奇函数（恰好延拓回例题 A1）。

#### 解

$$b_n = \frac{2}{\pi}\int_{0}^{\pi} x\sin nx\,dx$$

（与例题 A1 中 $b_n$ 计算相同，仅积分限不同 — 但被积函数为偶函数，结果一致。）

$$b_n = \frac{2}{\pi}\left[-\frac{x\cos nx}{n} + \frac{\sin nx}{n^2}\right]_{0}^{\pi} = -\frac{2\cos n\pi}{n} = (-1)^{n-1}\frac{2}{n}$$

正弦级数：

$$\boxed{x \sim 2\sum_{n=1}^{\infty} \frac{(-1)^{n-1}}{n}\sin nx,\quad 0 \le x < \pi}$$

在 $x = \pi$ 处，正弦级数的和 $S(\pi) = 0$（奇延拓端点均值），而 $f(\pi) = \pi$，两者不等——这是延拓导致的不连续。

### 题型 C：利用傅里叶级数求数项级数和

#### ★ 例题 C1 | Basel 问题 ($\sum 1/n^2$)

利用 $f(x) = x^2$（$-\pi \le x \le \pi$）的傅里叶级数展开，求 $\displaystyle\sum_{n=1}^{\infty} \frac{1}{n^2}$。

---

#### 解

$f(x) = x^2$ 为偶函数 → $b_n = 0$。

$$a_0 = \frac{1}{\pi}\int_{-\pi}^{\pi} x^2\,dx = \frac{2}{\pi}\int_{0}^{\pi} x^2\,dx = \frac{2}{\pi} \cdot \frac{\pi^3}{3} = \frac{2\pi^2}{3}$$

$$a_n = \frac{1}{\pi}\int_{-\pi}^{\pi} x^2\cos nx\,dx = \frac{2}{\pi}\int_{0}^{\pi} x^2\cos nx\,dx$$

分部积分两次：

$$\int x^2\cos nx\,dx = \frac{x^2\sin nx}{n} - \frac{2}{n}\int x\sin nx\,dx$$

$$= \frac{x^2\sin nx}{n} + \frac{2x\cos nx}{n^2} - \frac{2\sin nx}{n^3}$$

$$a_n = \frac{2}{\pi}\left[\frac{x^2\sin nx}{n} + \frac{2x\cos nx}{n^2} - \frac{2\sin nx}{n^3}\right]_{0}^{\pi}$$

$$= \frac{2}{\pi}\left(0 + \frac{2\pi\cos n\pi}{n^2} - 0\right) = \frac{4(-1)^n}{n^2}$$

$x^2$ 在 $[-\pi,\pi]$ 上连续，两端相等，Dirichlet 定理保证处处 $S(x) = x^2$：

$$x^2 = \frac{a_0}{2} + \sum_{n=1}^{\infty} a_n \cos nx = \frac{\pi^2}{3} + 4\sum_{n=1}^{\infty} \frac{(-1)^n}{n^2}\cos nx$$

代入 $x = \pi$：

$$\pi^2 = \frac{\pi^2}{3} + 4\sum_{n=1}^{\infty} \frac{(-1)^n}{n^2}\cos n\pi$$

$\cos n\pi = (-1)^n$，$(-1)^n \cdot (-1)^n = 1$：

$$\frac{2\pi^2}{3} = 4\sum_{n=1}^{\infty} \frac{1}{n^2} \quad\Rightarrow\quad \boxed{\sum_{n=1}^{\infty} \frac{1}{n^2} = \frac{\pi^2}{6}}$$

> 💡 这就是著名的 **Basel 问题**的解。欧拉 1734 年首次给出此结果。考研中此展开式反复使用。

代入 $x = 0$：

$$0 = \frac{\pi^2}{3} + 4\sum_{n=1}^{\infty} \frac{(-1)^n}{n^2} \quad\Rightarrow\quad \sum_{n=1}^{\infty} \frac{(-1)^{n+1}}{n^2} = \frac{\pi^2}{12}$$

---

### 题型 D：周期不为 $2\pi$ 的展开

#### ★ 例题 D1

将 $f(x) = x$（$0 < x < 2$）展开为周期 $4$ 的**正弦级数**。

---

#### 解

周期 $4$ → $l = 2$。正弦级数 → 奇延拓。

$$b_n = \frac{2}{l}\int_{0}^{l} f(x)\sin\frac{n\pi x}{l}\,dx = \frac{2}{2}\int_{0}^{2} x\sin\frac{n\pi x}{2}\,dx = \int_{0}^{2} x\sin\frac{n\pi x}{2}\,dx$$

分部积分：令 $u = x$，$dv = \sin\frac{n\pi x}{2}dx$，$du = dx$，$v = -\frac{2}{n\pi}\cos\frac{n\pi x}{2}$

$$b_n = \left[-x\cdot\frac{2}{n\pi}\cos\frac{n\pi x}{2}\right]_{0}^{2} + \frac{2}{n\pi}\int_{0}^{2} \cos\frac{n\pi x}{2}\,dx$$

$$= -\frac{4}{n\pi}\cos n\pi + 0 = -\frac{4}{n\pi}(-1)^n = (-1)^{n-1}\frac{4}{n\pi}$$

$$\boxed{x \sim \frac{4}{\pi}\sum_{n=1}^{\infty} \frac{(-1)^{n-1}}{n}\sin\frac{n\pi x}{2},\quad 0 < x < 2}$$

### 题型 E：Parseval 等式求 $\sum 1/n^4$

#### ★ 例题 E1

利用 $f(x) = x^2$ 的傅里叶系数和 Parseval 等式，求 $\displaystyle\sum_{n=1}^{\infty} \frac{1}{n^4}$。

---

#### 解

由例题 C1：$a_0 = \frac{2\pi^2}{3}$，$a_n = \frac{4(-1)^n}{n^2}$，$b_n = 0$。

Parseval 等式：

$$\frac{1}{\pi}\int_{-\pi}^{\pi} (x^2)^2\,dx = \frac{a_0^2}{2} + \sum_{n=1}^{\infty} a_n^2$$

$$\frac{1}{\pi}\int_{-\pi}^{\pi} x^4\,dx = \frac{1}{\pi} \cdot \frac{2\pi^5}{5} = \frac{2\pi^4}{5}$$

$$\frac{a_0^2}{2} = \frac{1}{2}\left(\frac{2\pi^2}{3}\right)^2 = \frac{2\pi^4}{9}$$

$$\sum_{n=1}^{\infty} a_n^2 = \sum_{n=1}^{\infty} \frac{16}{n^4} = 16\sum_{n=1}^{\infty} \frac{1}{n^4}$$

代入：

$$\frac{2\pi^4}{5} = \frac{2\pi^4}{9} + 16\sum_{n=1}^{\infty} \frac{1}{n^4}$$

$$16\sum_{n=1}^{\infty} \frac{1}{n^4} = 2\pi^4\left(\frac{1}{5} - \frac{1}{9}\right) = 2\pi^4 \cdot \frac{4}{45} = \frac{8\pi^4}{45}$$

$$\boxed{\sum_{n=1}^{\infty} \frac{1}{n^4} = \frac{\pi^4}{90}}$$

## 七、考场速判与技巧

### 7.1 奇偶性预判（计算前必看！）

| 函数特性 | $a_0$ | $a_n$ | $b_n$ | 级数形式 |
| :--- | :---: | :---: | :---: | :--- |
| $f(x)$ 为**奇函数** | $0$ | $0$ | 看实算 | 纯正弦 |
| $f(x)$ 为**偶函数** | 看实算 | 看实算 | $0$ | 纯余弦 |
| 一般函数 | 看实算 | 看实算 | 看实算 | 混合 |

> ⚠️ 奇偶性判断的区间是 $[-\pi, \pi]$（或 $[-l, l]$），不是 $[0, \pi]$。若只在 $[0, \pi]$ 上定义，取决于延拓方式。

### 7.2 积分计算的加速技巧

| 情况 | 简化操作 |
| :--- | :--- |
| 被积函数为偶函数 | $\int_{-a}^{a} = 2\int_{0}^{a}$ |
| 被积函数为奇函数 | $\int_{-a}^{a} = 0$ |
| 被积函数含 $\sin nx \cos nx$ | 积化和差 |
| $\int x\sin nx$ 或 $\int x\cos nx$ | 分部积分（表格法更快） |
| $\int \sin^2 nx$ 或 $\int \cos^2 nx$ | 用半角公式化为 $\frac{1}{2}(1 \pm \cos 2nx)$ |

### 7.3 处理间断点的步骤

1. 先写出展开式 $\sim$ 形式
2. 对连续点 $x_0$，确定 $S(x_0) = f(x_0)$，必要时代入求级数和
3. 对间断点 $x_0$，$S(x_0) = \frac{f(x_0^-) + f(x_0^+)}{2}$
4. 对端点 $x = \pm l$，由周期延拓的左右极限确定和值

### 7.4 求数项级数和的标准流程

1. 选择一个适当的 $f(x)$，展开为傅里叶级数
2. 令 $x$ 等于某个特定值（使 $\sin$ 或 $\cos$ 项简化，使 $f(x)$ 为已知值）
3. 从展开式解出所求 $\sum$

| 欲求级数 | 常用函数 | 代入点 | 为什么选它 |
| :--- | :--- | :---: | :--- |
| $\sum 1/n^2$ | $f(x) = x^2$ | $x = \pi$ | $\cos n\pi = (-1)^n$，$f(\pi) = \pi^2$ 已知 |
| $\sum (-1)^{n+1}/n^2$ | $f(x) = x^2$ | $x = 0$ | $\cos 0 = 1$，$f(0) = 0$ 已知 |
| $\sum 1/n^4$ | $f(x) = x^2$ | Parseval | $a_n \propto 1/n^2$ → $a_n^2 \propto 1/n^4$ |
| $\sum (-1)^{n-1}/n$ | $f(x) = x$ | $x = \pi/2$ | $\sin(n\pi/2)$ 交错取 $0, 1, 0, -1, \dots$ |
| $\sum 1/(2n-1)^2$ | $f(x) = x$ 余弦展开 | $x = 0$ | $\cos 0 = 1$，奇数项留下 |

## 八、避坑警示

> ⚠️ **坑 1：忘了 $\frac{a_0}{2}$ 而不是 $a_0$**
> 傅里叶级数第一项是 $\frac{a_0}{2}$，不是 $a_0$。系数公式中 $a_0$ 本身已被放大为平均值的 $2$ 倍。

> ⚠️ **坑 2：奇偶延拓后端点可能不连续**
> 正弦级数在 $x = 0, \pi$ 处和为 $0$；若原函数 $f(0) \neq 0$ 或 $f(\pi) \neq 0$，展开式在此处不等于原函数值。

> ⚠️ **坑 3：周期延拓后的端点值**
> $x = \pm\pi$（或 $x = \pm l$）处的和可能不等于 $f(\pm\pi)$，需用 Dirichlet 定理单独判断。

> ⚠️ **坑 4：积分时忘了 $(-1)^n$ 的符号**
> $\cos n\pi = (-1)^n$，$\sin n\pi = 0$。$\cos\frac{n\pi}{2}$ 按 $n \bmod 4$ 循环取值 $1, 0, -1, 0$。

> ⚠️ **坑 5：周期 $2l$ 时套错了公式**
> 标准公式属于 $2\pi$ 周期。若周期为 $2l$，$\cos nx \to \cos\frac{n\pi x}{l}$，分母 $\frac{1}{\pi} \to \frac{1}{l}$。

> ⚠️ **坑 6：$a_0$ 在 Parseval 等式中的项**
> Parseval 等式中常数为 $\frac{a_0^2}{2}$，不是 $a_0^2$。

## 九、核心公式闪卡

| 项目 | 公式 |
| :--- | :--- |
| 傅里叶系数（$2\pi$ 周期） | $a_n = \frac{1}{\pi}\int_{-\pi}^{\pi} f(x)\cos nx\,dx$，$b_n = \frac{1}{\pi}\int_{-\pi}^{\pi} f(x)\sin nx\,dx$ |
| 正弦系数（奇延拓） | $b_n = \frac{2}{\pi}\int_{0}^{\pi} f(x)\sin nx\,dx$ |
| 余弦系数（偶延拓） | $a_n = \frac{2}{\pi}\int_{0}^{\pi} f(x)\cos nx\,dx$ |
| 周期 $2l$ 系数 | $a_n = \frac{1}{l}\int_{-l}^{l} f(x)\cos\frac{n\pi x}{l}\,dx$ |
| 收敛定理（连续点） | $S(x) = f(x)$ |
| 收敛定理（间断点） | $S(x) = \frac{f(x^-) + f(x^+)}{2}$ |
| Parseval 等式 | $\frac{1}{\pi}\int_{-\pi}^{\pi} f^2 dx = \frac{a_0^2}{2} + \sum(a_n^2+b_n^2)$ |

## 十、推荐练习顺序（初学者）

1. **奇偶性识别** → 练 $f(x) = x$（奇）、$f(x) = x^2$（偶）、$f(x) = |x|$（偶）
2. **基本展开** → $x$、$x^2$、$e^x$ 的 $[-\pi,\pi]$ 傅里叶级数
3. **延拓展开** → $x$、$x^2$ 在 $[0,\pi]$ 上的正弦/余弦级数
4. **求级数和** → Basel $\sum 1/n^2$、$\sum 1/n^4$、$\sum (-1)^{n-1}/n$
5. **非标准周期** → 周期为 $2$、$4$、$2l$ 的展开
6. **Parseval** → 验证系数平方和与积分的关系
