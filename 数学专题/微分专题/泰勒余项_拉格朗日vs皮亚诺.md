# 泰勒展开的拉格朗日余项与皮亚诺余项

> "做题用 Peano，证明用 Lagrange"——一个管极限，一个管不等式。

---

## 一、两种余项的定义

设 $f$ 在 $x_0$ 处 $n$ 阶可导（Peano）或 $n+1$ 阶可导（Lagrange）：

$$
f(x) = \underbrace{\sum_{k=0}^n \frac{f^{(k)}(x_0)}{k!}(x-x_0)^k}_{\text{泰勒多项式 }P_n(x)} + R_n(x)
$$

| | 皮亚诺余项 (Peano) | 拉格朗日余项 (Lagrange) |
|:---|:---|:---|
| 表达式 | $R_n(x)=o((x-x_0)^n)$ | $R_n(x)=\frac{f^{(n+1)}(\xi)}{(n+1)!}(x-x_0)^{n+1}$ |
| 含义 | 定性：余项比 $(x-x_0)^n$ 更高阶 | 定量：给出余项的精确表达式 |
| $\xi$ | 无 | $\xi$ 在 $x_0$ 与 $x$ 之间 |
| 存在条件 | $f^{(n)}(x_0)$ 存在（**只需一点**） | $f^{(n+1)}$ 在区间上存在（**需要整段**） |
| 适用范围 | 局部（$x$ 靠近 $x_0$） | 可全局（$x$ 在区间内任意点） |

---

## 二、使用场景对照表

| 题型 | 用哪种余项 | 原因 |
|:---|:---:|:---|
| 求极限 $\lim_{x\to0}\frac{\sin x-x}{x^3}$ | **Peano** | 只需 $x\to0$ 时的渐近阶，不关心具体误差大小 |
| 证 $e^x\ge 1+x+\frac{x^2}{2}$（$x\ge0$） | **Lagrange** | 需给出一段区间上的**定量**不等式 |
| 证 $\sin x$ 的 Maclaurin 级数收敛于 $\sin x$ | **Lagrange** | 需估计 $R_n(x)\to0$ 的速度 |
| 求 $f(0.1)$ 的近似值并估计误差 | **Lagrange** | 需知道近似值的误差上限 |
| 求 $f(x)$ 在 $x_0$ 附近的渐近展开 | **Peano** | 只关心局部阶，不关心具体误差 |
| 证中值定理类不等式 | **Lagrange** | 通过选取合适的 $\xi$ 得到不等式方向 |

## 三、典型例题

### ★ 题型一：极限计算 → Peano

**例 1**：求 $\displaystyle\lim_{x\to0}\frac{\tan x-x}{x^3}$。

展开 $\tan x = x + \frac13 x^3 + o(x^3)$，代入：

$$
\frac{(x+\frac13x^3+o(x^3))-x}{x^3}
= \frac13 + o(1) \to \frac13
$$

Peano 的 $o(x^3)$ 自动吞掉所有高于三阶的项，极限直接出。

---

### ★ 题型二：区间不等式 → Lagrange

**例 2**：证 $e^x \ge 1+x$ 对一切 $x\in\mathbb{R}$ 成立。

在 $0$ 处展开到一阶，带 Lagrange 余项：

$$
e^x = 1 + x + \frac{e^\xi}{2}x^2, \quad \xi \text{ 在 } 0 \text{ 与 } x \text{ 之间}
$$

$\frac{e^\xi}{2}x^2 \ge 0$，故 $e^x \ge 1+x$。$\square$

这里**不能**用 Peano——$o(x)$ 只在 $x\to0$ 时趋于 0，无法对任意 $x$ 给出不等式方向。

---

### ★ 题型三：同一个题，两种余项的不同用途

**例 3**：设 $f''(x)>0$，证 $f(x)\ge f(x_0)+f'(x_0)(x-x_0)$。

展开到一阶，带 Lagrange 余项（$\xi$ 在 $x_0$ 与 $x$ 之间）：

$$
f(x) = f(x_0) + f'(x_0)(x-x_0) + \frac{f''(\xi)}{2}(x-x_0)^2
$$

由 $f''(\xi)>0$ 得余项 $\ge0$，不等式成立。$\square$

Peano 在此完全失效——$o(x-x_0)$ 无法确定符号。

---

### ★ 题型四：泰勒级数收敛性 → Lagrange

**例 4**：证 $\sin x = \displaystyle\sum_{n=0}^\infty \frac{(-1)^n x^{2n+1}}{(2n+1)!}$ 对一切 $x$ 成立。

$\sin x$ 的 $n$ 阶 Maclaurin 展开的 Lagrange 余项：

$$
|R_n(x)| = \left|\frac{\sin^{(n+1)}(\xi)}{(n+1)!}x^{n+1}\right| \le \frac{|x|^{n+1}}{(n+1)!} \to 0 \quad (n\to\infty)
$$

因为正弦的任意阶导数绝对值 $\le1$。余项趋于 0 → 级数收敛于原函数。

Peano 对此无能为力——$o(x^n)$ 只在固定 $x$ 取极限时有意义，无法讨论 $n\to\infty$ 的一致收敛性。

---

### ★ 题型五：极值的第三充分条件 → 必须用 Peano

**问题**：$f'(x_0)=\cdots=f^{(n-1)}(x_0)=0$，$f^{(n)}(x_0)\neq0$，判断 $x_0$ 是否为极值点。

**定理**：$n$ 为偶数时 $f^{(n)}(x_0)>0$ 为极小、$<0$ 为极大；$n$ 为奇数时非极值（拐点）。

**证明**（用 Peano）：

$$
f(x)-f(x_0)=\frac{f^{(n)}(x_0)}{n!}(x-x_0)^n+o((x-x_0)^n)
$$

当 $x$ 足够靠近 $x_0$ 时，$o((x-x_0)^n)$ 与主项相比可忽略，差值的符号由 $\frac{f^{(n)}(x_0)}{n!}(x-x_0)^n$ 主导：
- $n$ 为偶：$(x-x_0)^n\ge0$，符号恒与 $f^{(n)}(x_0)$ 同号 → 极值
- $n$ 为奇：$(x-x_0)^n$ 在 $x_0$ 两侧变号 → 非极值

> **补充说明**：当 $n$ 为奇数时，设 $f^{(n)}(x_0)>0$。$x>x_0$ 时 $(x-x_0)^n>0$，$f(x)-f(x_0)>0$；$x<x_0$ 时 $(x-x_0)^n<0$，$f(x)-f(x_0)<0$。这意味着**在 $x_0$ 的任意邻域内，函数值既大于 $f(x_0)$ 又小于 $f(x_0)$**——这就是"非极值"的定义本身：极小值要求附近所有点都 $\ge$ 它，极大值要求附近所有点都 $\le$ 它，两者均不满足。不是"不知道有没有极值"，而是"确定没有极值"。

**为什么不能用 Lagrange**：Lagrange 余项是 $\frac{f^{(n+1)}(\xi)}{(n+1)!}(x-x_0)^{n+1}$，阶为 $n+1$，虽然形式上比 $o((x-x_0)^n)$ 更精确，但它无法帮助判断主项 $(x-x_0)^n$ 的符号——因为 Lagrange 余项的阶和主项不同，不能直接相加比较。Peano 的 $o(\cdot)$ 恰好表达"比主项更高阶，可忽略"这一核心逻辑。

## 四、选择决策树

```
题目要求什么？
    │
    ├─ 求 x→x₀ 的极限
    │       → Peano（展到足够高阶，o() 吞掉余项）
    │
    ├─ 证 x 在某区间上的不等式
    │       → Lagrange（ξ 给出余项的符号/范围）
    │
    ├─ 估计近似值的误差
    │       → Lagrange（f^(n+1) 的最大值决定误差上限）
    │
    ├─ 证泰勒级数收敛于原函数
    │       → Lagrange（证 R_n(x)→0）
    │
    └─ 求函数在局部的渐近阶
            → Peano（简洁，o() 即阶）
```

## 五、常见误区

| 误区 | 正确认知 |
|:---|:---|
| "Peano 不精确，Lagrange 更严格" | 各有适用场景。极限题用 Peano 比 Lagrange 快 10 倍 |
| "Lagrange 需要 $f^{(n+1)}$ 在**闭区间**上连续" | 只需 $f^{(n+1)}$ 在**开区间**内存在，$f^{(n)}$ 在闭区间上连续 |
| "展开到同一阶，两种余项的系数相同" | 公式不同。Peano 无系数，Lagrange 有 $\frac{f^{(n+1)}(\xi)}{(n+1)!}$ |
| "有 Peano 就够了" | 不等式和误差估计必须用 Lagrange |

> **一句话**：求极限→Peano，证不等式→Lagrange。前者的 $o(x^n)$ 是"定性高阶"，后者的 $\frac{f^{(n+1)}(\xi)}{(n+1)!}x^{n+1}$ 是"定量表达式"。


> **记忆法则**：局部问题用 Peano，全局问题用 Lagrange。极值是局部性质 → Peano。不等式是整个区间上的全局比较 → Lagrange。级数收敛是 $n\to\infty$ 的一致行为 → Lagrange。求 $f(x)$ 在 $x_0$ 附近的近似值并估计误差 → Lagrange（需要定量误差上界）。求 $x\to x_0$ 时的极限 → Peano（只需渐近阶）。
