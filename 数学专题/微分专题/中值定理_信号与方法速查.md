# 中值定理：信号 → 方法速查

> 不要背构造公式，要背"看到什么条件想到什么方法"。

---

## 一、Rolle 定理 — 什么时候用

### 信号

结论要求证**存在 $\xi$ 使某表达式 $=0$**，且能找到两点函数值相等。

### 决策链

```
结论含 f'(ξ) = 0 / F'(ξ) = 0
    → 找两个点 a,b 使 f(a)=f(b)（或 F(a)=F(b)）
    → 对 f（或 F）在 [a,b] 上 Rolle
```

### 典例

证存在 $\xi$ 使 $f'(\xi)=0$ → 找 $f(a)=f(b)$ → Rolle。

---

## 二、Lagrange 中值定理 — 什么时候用

### 信号

结论含**一个中值 $\xi$**，且 $\xi$ 出现在 $f'(\xi)$ 与区间端点值的组合中，但**没有明显的原函数形式**。

### 决策链

```
结论含 f'(ξ) 和 f(a),f(b)
    → 直接对 f 在 [a,b] 上 Lagrange：f'(ξ) = [f(b)-f(a)]/(b-a)
    → 代入结论化简
```

### 典例

证 $\exists\xi\in(0,1)$ 使 $f'(\xi)=2\xi[f(1)-f(0)]$ → Lagrange 得 $f'(\xi)=f(1)-f(0)$，需额外处理 $\xi$ 和 $2\xi$ 的关系 → 可能需要构造函数再用。

---

## 三、Cauchy 中值定理 — 什么时候用

### 信号

结论含**两个函数在同一中值点的导数之比**：$\frac{f'(\xi)}{g'(\xi)}$。

### 决策链

```
结论含 f'(ξ)/g'(ξ)
    → 对 f 和 g 在同一区间上 Cauchy
    → [f(b)-f(a)]/[g(b)-g(a)] = f'(ξ)/g'(ξ)
```

### 典例

证 $\frac{f'(\xi)}{g'(\xi)}=\frac{f(b)-f(a)}{g(b)-g(a)}$ → 直接 Cauchy。

---

## 四、构造辅助函数 — 通用方法

### 4.1 结论形如 $f'(\xi) + p(\xi)f(\xi) = q(\xi)$

这是**一阶线性微分方程** $y'+p(x)y=q(x)$。

构造函数：$F(x)=e^{\int p(x)dx}f(x) - \int e^{\int p(x)dx}q(x)dx$

令 $G(x)=e^{\int p(x)dx}$，则 $(Gf)' = G(f'+pf)$。

**典例**：

| 结论 | $p(x)$ | $G(x)$ | $F(x)$ |
|:---|:---|:---|:---|
| $f'(\xi)+g'(\xi)f(\xi)=0$ | $g'(x)$ | $e^{g(x)}$ | $F=e^{g}f$ |
| $f'(\xi)-f(\xi)=0$ | $-1$ | $e^{-x}$ | $F=e^{-x}f$ |
| $f'(\xi)+f(\xi)=g(x)$ | $1$ | $e^x$ | $F=e^x f-\int e^x g$ |

### 4.2 结论移项后形如 $f'(\xi) + g(\xi) = 0$

移项 → $[f(x)+\int g(x)dx]'$ 在 $\xi$ 处为零。

**构造**：$F(x)=f(x)+\int g(x)dx$

**典例**：

- $f'(\xi)+\xi^2=0$ → $F(x)=f(x)+\frac13 x^3$
- $f'(\xi)-\sin\xi=0$ → $F(x)=f(x)+\cos x$

### 4.3 结论含 $f''+f$（二阶微分方程型）

**信号**：$f''+f=0$ 是 $y''+y=0$。

注意到 $(f'^2+f^2)'=2f'(f''+f)$。

**构造**：$F(x)=[f'(x)]^2+[f(x)]^2$

**典例**：证存在 $\xi$ 使 $f''(\xi)+f(\xi)=0$ → 构造 $F=f'^2+f^2$，用已知条件证 $F$ 在某两点值相等 → $F'$ 有零点。

## 五、泰勒展开 — 什么时候用

### 信号

结论含**二阶或更高阶导数**（$f'',f'''$ 等），且给了函数值/导数值在某已知点的信息。

### 决策链

```
要估计 f'(x) 的界，已知 |f| 和 |f''| 的界
    → 以 x 为基点，向已知点展开（不要反了！）
    → 泰勒展开：f(已知点) = f(x) + f'(x)(已知点-x) + f''(ξ)/2·(已知点-x)²
    → 两个已知点相减消去 f(x)，解出 f'(x) 的表达式
    → 代入 |f|≤M, |f''|≤M 得 |f'(x)| 的界
```

### 典例

已知 $|f|\le1,|f''|\le1$，证 $|f'|\le2$：

以 $x$ 为基点（不是以 0 和 2 为基点！）：

$$
\begin{aligned}
f(0) &= f(x) + f'(x)(-x) + \frac{f''(\xi_1)}{2}x^2 \\
f(2) &= f(x) + f'(x)(2-x) + \frac{f''(\xi_2)}{2}(2-x)^2
\end{aligned}
$$

相减 → $f'(x)=\frac{f(2)-f(0)}{2} +$ 含 $f''$ 的项 → 取绝对值放缩 → $|f'(x)|\le2$。

> **核心规则**：泰勒展开永远是**从你想要求的东西出发，走到你知道的东西**。你要 $f'(x)$，就以 $x$ 为基点；你要 $f'(0)$，就以 $0$ 为基点。

---

## 六、积分中值定理 — 当条件里有 $\int$

### 信号

条件中出现了定积分 $\int_a^b f(x)dx$。

### 决策链

```
条件含 ∫_a^b f(x)dx
    → 积分中值定理：∃η∈(a,b) 使 ∫_a^b f = f(η)(b-a)
    → 消掉积分号，得到一个函数值 f(η)
    → 后续把 f(η) 当作已知常数使用
```

### 典例

已知 $\int_0^1 f = \frac32\int_{1/2}^1 f$ → 积分中值得 $\exists\eta$ 使 $f(\eta)$ 等于某值 → 构造函数时把 $f(\eta)$ 当常数处理。

---

## 七、综合决策流程

```
看结论：
    ├─ 含 f''(ξ) + f(ξ) = 0 ──→ 能量函数 F = f'² + f²
    ├─ 含 f'(ξ)/g'(ξ) ────→ Cauchy
    ├─ 含 f'(ξ) + p(ξ)f(ξ) ──→ 构造 e^{∫p} f
    ├─ 可移项为 f'(ξ) + g(ξ) = 0 → F = f + ∫g
    ├─ 只有一个 f'(ξ) 和端点 ──→ Lagrange
    │
    └─ 含高阶导 + 已知点信息 ──→ Taylor（往已知点展）
    
看条件：
    ├─ 含 ∫ ──→ 积分中值定理介入
    ├─ 有两端点值相等 ──→ Rolle
    ├─ 有 |f| 和 |f''| 的界 ──→ Taylor 放缩
    └─ 有最大值 M ──→ 导数零点 f'(c)=0 + Lagrange 分段
```
