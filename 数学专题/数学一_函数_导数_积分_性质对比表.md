# 数学一 | $f(x)$ vs $f'(x)$ vs $\int f(x)$ — 性质对比速查

> 核心问题：已知 $f(x)$ 有性质 P，问 $f'(x)$ 或 $\int f(x)$ 是否也有性质 P？（以及反过来）

---

## 一、介值性（Intermediate Value Property）

| 情形 | 结论 | 反例 / 依据 |
| :--- | :---: | :--- |
| $f(x)$ 连续 | $\Rightarrow$ $f(x)$ 有介值性 | 闭区间连续函数介值定理 |
| $f(x)$ **仅存在**（未必连续） | $\not\Rightarrow$ $f(x)$ 有介值性 | $f(x)=\begin{cases}1,&x\geq0\\ 0,&x<0\end{cases}$ 无介值性 |
| $f'(x)$ **存在** | $\Rightarrow$ $f'(x)$ 有介值性 | **达布定理**：导数即使不连续也必有介值性 |
| $\int f(x)$（原函数） | $\Rightarrow$ 连续，故有介值性 | 可积函数的变上限积分必连续 |

> ⚠️ **经典坑**：$f'(x)$ 可以不连续，但不能没有介值性——这是导数区别于一般函数的核心特征。

---

## 二、连续性

| 情形 | 结论 | 反例 / 依据 |
| :--- | :---: | :--- |
| $f(x)$ 存在 | $\not\Rightarrow$ $f(x)$ 连续 | $f(x)=[x]$ 取整函数 |
| $f(x)$ **可导** | $\Rightarrow$ $f(x)$ 连续 | 可导必连续（基本定理） |
| $f(x)$ 连续 | $\not\Rightarrow$ $f(x)$ 可导 | $f(x)=\vert x\vert$ 在 $x=0$ |
| $f'(x)$ 存在 | $\not\Rightarrow$ $f'(x)$ 连续 | $f(x)=x^2\sin\frac{1}{x}\;(x\neq0),f(0)=0$，其导数在 $0$ 处不连续 |
| $f(x)$ 连续 | $\Rightarrow$ $\int_a^x f(t)dt$ 可导（且导数 $=f(x)$） | 原函数存在定理 |
| $f(x)$ 可积 | $\Rightarrow$ $\int_a^x f(t)dt$ 连续 | 变上限积分必连续 |
| $f(x)$ 可积 | $\not\Rightarrow$ $\int_a^x f(t)dt$ 可导 | $f$ 有间断点时，原函数在间断点处有**角点** |

---

## 三、可积性（Riemann）

| 情形 | 结论 | 反例 / 依据 |
| :--- | :---: | :--- |
| $f(x)$ 连续 | $\Rightarrow$ $f(x)$ 可积 | 连续函数在闭区间必黎曼可积 |
| $f(x)$ 有界 + 有限个间断点 | $\Rightarrow$ $f(x)$ 可积 | 黎曼可积的充分条件 |
| $f(x)$ 无界 | $\not\Rightarrow$ $f(x)$ 可积 | 黎曼可积的必要条件是有界 |
| $f'(x)$ 存在 | $\not\Rightarrow$ $f'(x)$ 可积 | 存在处处可导但导数黎曼不可积的函数（Volterra 函数） |
| $f(x)$ 可积 | $\Rightarrow$ 原函数 $F(x)=\int_a^x f$ 存在且连续 | — |

---

## 四、有界性

| 情形 | 结论 | 反例 / 依据 |
| :--- | :---: | :--- |
| $f(x)$ 在 $[a,b]$ 连续 | $\Rightarrow$ $f(x)$ 有界 | 闭区间连续函数必有界（最值定理） |
| $f(x)$ 在 $(a,b)$ 连续 | $\not\Rightarrow$ $f(x)$ 有界 | $f(x)=\frac{1}{x}$ 在 $(0,1)$ |
| $f'(x)$ 存在 | $\not\Rightarrow$ $f'(x)$ 有界 | $f(x)=\sqrt{x}$ 在 $(0,1]$，$f'(x)=\frac{1}{2\sqrt{x}}$ 无界 |
| $f(x)$ 黎曼可积 | $\Rightarrow$ $f(x)$ 有界 | **必要条件**：无界必不可积 |

---

## 五、奇偶性传递

| 前提 | $\to f'(x)$ | $\to \int_0^x f(t)dt$ |
| :--- | :---: | :---: |
| $f(x)$ 是**奇函数** | 偶函数 | 偶函数 |
| $f(x)$ 是**偶函数** | 奇函数 | 奇函数 |

> 口诀：**导一次，奇偶互换；积一次，奇偶互换**（从 $0$ 积起）
>
> ⚠️ 对不定积分 $\int f(x)dx$：若 $f$ 为奇，则原函数**全体**为偶（$+C$ 中只有 $C=0$ 那个是奇函数）。

---

## 六、周期性传递

| 前提 | $\to f'(x)$ | $\to \int_0^x f(t)dt$ |
| :--- | :---: | :--- |
| $f(x)$ 周期为 $T$ | 周期仍为 $T$（保周期） | 周期为 $T$ $\iff$ $\int_0^T f(t)dt=0$ |

> ⚠️ **积分的周期性不一定保持**：$f(x)=\sin x$ 周期 $2\pi$，$\int_0^x \sin t\,dt=1-\cos x$ 仍是周期函数（因为 $\int_0^{2\pi}\sin x=0$）。
> 反例：$f(x)=1+\sin x$ 周期 $2\pi$，但 $\int_0^x(1+\sin t)dt=x-\cos x+1$，不是周期函数。

---

## 七、极限相关

| 情形 | 结论 | 说明 |
| :--- | :---: | :--- |
| $\lim_{x\to\infty}f'(x)$ 存在且有限 | $\Rightarrow$ $\lim_{x\to\infty}\frac{f(x)}{x}=$ 该极限 | L'Hospital 推论 |
| $\lim_{x\to\infty}f(x)=A$（有限） | $\not\Rightarrow$ $\lim_{x\to\infty}f'(x)=0$ | 即使 $f$ 趋向常数，导数也未必趋于 $0$ |
| $\lim_{x\to\infty}f(x)=A$ **且** $f'(x)$ 一致连续 | $\Rightarrow$ $\lim_{x\to\infty}f'(x)=0$ | 需附加条件 |
| $\lim_{x\to x_0}f'(x)=A$ **且** $f$ 在 $x_0$ 连续 | $\Rightarrow$ $f'(x_0)=A$ | 导数极限定理（导数的极限 = 极限的导数，需附加条件） |

---

## 八、单调性

| 情形 | 结论 |
| :--- | :---: |
| $f'(x)>0$ 在区间 $I$ | $\Rightarrow$ $f(x)$ 严格单调递增 |
| $f'(x)\geq 0$ 在区间 $I$ | $\Rightarrow$ $f(x)$ 单调不减 |
| $f(x)$ 单调递增 | $\not\Rightarrow$ $f'(x)\geq 0$（$f$ 可能不可导） |
| $f(x)$ 单调递增 **且可导** | $\Rightarrow$ $f'(x)\geq 0$ |

---

## 九、核心反例速记

| 反例 | 说明的现象 |
| :--- | :--- |
| $f(x)=x^2\sin\frac{1}{x}\;(x\neq0), f(0)=0$ | **处处可导，但导数在 $0$ 处不连续** |
| $f(x)=\begin{cases}1,&x\geq0\\ 0,&x<0\end{cases}$ | 函数存在但不连续，**无介值性** |
| $f(x)=\sqrt{x}$ 在 $(0,1]$ | **导数无界** |
| $f(x)=1+\sin x$ 积分 | **周期函数的原函数不一定周期** |
| Dirichlet 函数 | 处处不连续，不可积 |

## 十、不定积分 vs 定积分 vs 变限积分 — 性质对比

> 三个概念极易混淆，核心区分点：**不定积分是个函数族，定积分是个数，变限积分是个函数**。

| 维度 | 不定积分 $\int f(x)dx$ | 定积分 $\int_a^b f(x)dx$ | 变限积分 $\int_a^x f(t)dt$ |
| :--- | :--- | :--- | :--- |
| **本质** | 原函数族 $F(x)+C$ | 一个**数值** | 一个**函数** $\Phi(x)$ |
| **定义** | 求导的逆运算 | Riemann 和的极限 | 上限为变量的定积分 |
| **存在条件** | $f$ 有原函数（不要求连续） | $f$ 在 $[a,b]$ 有界且几乎处处连续 | $f$ 在 $[a,b]$ 可积即可 |
| **与 $f$ 的关系** | 求导还原：$F'(x)=f(x)$ | N-L：$=F(b)-F(a)$ | 求导还原：$\Phi'(x)=f(x)$（$f$ 连续点） |

### 10.1 连续性与可导性

| 性质 | 不定积分 $F(x)+C$ | 变限积分 $\Phi(x)=\int_a^x f$ | 说明 |
| :--- | :---: | :---: | :--- |
| $F$ / $\Phi$ 是否连续？ | ✅ 可导必连续 | ✅ **$f$ 可积即连续**（不要求 $f$ 连续） | 变限积分连续性条件更弱 |
| $F$ / $\Phi$ 是否可导？ | ✅ 定义即要求可导 | ⚠️ **$f$ 连续处可导**；$f$ 间断处可能不可导 | $f$ 有跳跃间断点时 $\Phi$ 有角点 |
| 导数等于 $f$ 吗？ | ✅ $F'(x)=f(x)$ 处处成立 | ⚠️ $f$ 连续点处 $\Phi'=f$；间断点处不一定 | — |

> ⚠️ **经典结论**：$f(x)$ 可积 ⇒ $\Phi(x)$ **连续**；$f(x)$ 连续 ⇒ $\Phi(x)$ **可导**。这两个箭头方向不能反。

### 10.2 奇偶性对比

| $f(x)$ 性质 | 不定积分（全体原函数） | 变限积分 $\int_0^x f$ | 定积分 $\int_{-a}^a f$ |
| :--- | :--- | :--- | :--- |
| $f$ 为**奇函数** | 全体为偶函数 | 偶函数 | $=0$（对称区间） |
| $f$ 为**偶函数** | 仅 $F(0)=0$ 那个是奇函数 | 奇函数 | $=2\int_0^a f$ |

### 10.3 周期性对比

| 情形 | 结论 |
| :--- | :--- |
| $f$ 周期 $T$ ⇒ 不定积分（原函数）周期？ | ❌ 不一定。$\int f = F(x) + \underbrace{C}_{\text{常数}}$，$F$ 未必是周期的 |
| $f$ 周期 $T$ ⇒ 变限积分 $\Phi(x)=\int_0^x f$ 周期？ | $\iff$ $\int_0^T f(t)dt = 0$ |
| $f$ 周期 $T$ ⇒ 定积分 $\int_a^{a+T} f$？ | $=\int_0^T f$（**与起点 $a$ 无关**） |

### 10.4 其他性质有无对比

| 性质 | 不定积分 | 定积分 | 变限积分 |
| :--- | :---: | :---: | :---: |
| **线性性** | ✅ $\int(\alpha f+\beta g)=\alpha\int f+\beta\int g$ | ✅ 同左 | ✅ 同左 |
| **区间可加性** | — 无此概念 | ✅ $\int_a^b=\int_a^c+\int_c^b$ | — 隐含在上下限中 |
| **保号性** | — 无（$+C$ 可上下平移） | ✅ $f\geq0\Rightarrow\int\geq0$ | ✅ 继承 $f$ 的符号 |
| **估值定理** | — 无 | ✅ $m(b-a)\leq\int\leq M(b-a)$ | — 可用 N-L 定值 |
| **积分中值定理** | — 无 | ✅ $\int_a^b f=f(\xi)(b-a)$ | — 用 N-L 替代 |
| **换元必换限** | ❌ 换元后必须**回代** | ✅ 换元同时换限 | ✅ 同定积分 |

### 10.5 核心易错点

| # | 易错 | 正解 |
| :---: | :--- | :--- |
| 1 | "$f$ 可积 ⇒ 变限积分可导" | ❌ 可积仅保证**连续**；$f$ **连续**才保证可导 |
| 2 | "$f$ 连续 ⇒ 原函数存在" | ✅ 连续必有原函数（变限积分就是其中一个） |
| 3 | "$f$ 有原函数 ⇒ $f$ 可积" | ❌ 反例：$f(x)=\frac{d}{dx}(x^2\sin\frac{1}{x^2})$ 有原函数但无界，不可积 |
| 4 | "$f$ 可积 ⇒ $f$ 有原函数" | ❌ 反例：$f$ 有第一类间断点时可积但无原函数 |
| 5 | "不定积分换元后不用回代" | ❌ 定积分换元换限可不回代；**不定积分必须回代** |
| 6 | "$f$ 为奇函数 ⇒ 全体原函数为偶"中的"全体" | ✅ 因为 $F(x)+C$ 中 $F$ 为偶，加常数 $C$ 仍是偶函数 |
