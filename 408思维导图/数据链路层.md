# 数据链路层 — 按功能重组的思维导图

```
                         ┌── 怎么知道从哪到哪？
                         │   物理地址(MAC)·交换机自学习(MAC↔端口)
                         │   802.3用2个地址·802.11用4个地址
                         │
                         ├── 怎么知道一帧的开始和结束？
                         │   四种组帧方法：字符计数(×)|字节填充|零比特填充★|违规编码
                         │   零比特：连续5个1插0 / 收到连续5个1去0
                         │
                         ├── 传错了怎么办？
                         │   ├─ 只检不纠：奇偶·CRC
                         │   └─ 又检又纠：海明码(d=检二纠一)
                         │
         数 据 链 路 层 ─┼── 发太快了收不下怎么办？
         干 了 什 么      │   滑动窗口 ──┬ 停等: 发1收1, 确认后再发
                         │              ├ GBN: 发多收1, 累积确认, 错一个往后全重发
                         │              └ SR:  发多收多, 逐个确认, 只重传出错帧
                         │
                         ├── 多个站同时想发怎么办？（共享信道）
                         │   ├─ 有线以太网 ── CSMA/CD ★
                         │   │   等没人说话→开始说→边说自己边听→撞了停，随机等再试
                         │   │   最小帧长=2τ×速率 (保证能在撞之前发完最短帧)
                         │   │
                         │   └─ 无线802.11 ── CSMA/CA ★
                         │       不能边发边听(无线做不到)→改成"预约+确认"
                         │       RTS预约→CTS确认→DATA→ACK
                         │       NAV(别人要发多久)·SIFS<DIFS(ACK优先)
                         │
                         ├── 连成网络后怎么管？
                         │   ├─ 以太网：全双工时代已不用CSMA/CD
                         │   ├─ VLAN：一个物理交换机切成多个虚拟网络(802.1Q标签4字节)
                         │   └─ 生成树：防环路(选根桥→选根端口→选指定端口, 阻塞其余)
                         │
                         └── 用什么设备？
                             ├─ 集线器(物理层)·不隔冲突·不隔广播
                             ├─ 交换机(链路层)·隔冲突✅·隔广播❌ ★
                             └─ 路由器(网络层)·隔冲突✅·隔广播✅
```

## 抄写方法

这张图不是让你一次抄完的。画法：

1. 中心写"数据链路层"，画 6 条分支对应上面 6 个问题（不是 8 个章节）
2. 每学完一个子节，在对应分支上补一两笔——不追求一次画全
3. 做题碰到哪个概念混淆了，回来在这张图上圈出来——这才是这张图的价值
4. 考前这张 A4 应该是密密麻麻但你自己完全看得懂的

和课本目录的区别：目录告诉你"3.4 讲了滑动窗口"，这张图告诉你"滑动窗口是解决'发太快'的，三个协议的区别是窗口大小和确认方式"。前者是存储，后者是理解。
