# 网络层 — 按功能重组的思维导图

> 核心问题：**数据包怎么跨越多个网络，从源送到目的？**

---

```
                         ┌── 怎么选路？（路由协议）
                         │   【RIP】距离向量·BF算法·UDP520·15跳·坏消息慢
                         │   【OSPF】链路状态·Dijkstra·IP协议号89·分区·收敛快
                         │   【BGP】路径向量·AS间·TCP179·策略优先(AS_PATH防环)
                         │
                         ├── 往哪发？（路由表→转发）
                         │   【路由表】目的网络·掩码·下一跳·出接口
                         │   【最长前缀匹配】命中多项→选前缀最长(最具体)的
                         │   【默认路由】0.0.0.0/0 兜底
                         │   ★ 转发时IP不变，MAC每跳重写（NAT除外）
                         │
                         ├── 地址怎么编？
                         │   A(/8)·B(/16)·C(/24)·D(多播) → CIDR：IP/前缀长度
        网 络 层           │   【子网划分】借主机位 → 二叉树，兄弟才能聚合
       "包怎么跨网到"       │   【私网】10/8·172.16/12·192.168/16 → 公网无路由
                         │
                         ├── IPv4配套协议（四个助手）         ← 细节见 [IPv4.md](IPv4.md)
                         │   【ARP】IP→MAC，广播请求+单播应答，同一链路段有效
                         │   【DHCP】自动配IP，UDP67/68，DORA全广播
                         │   【ICMP】差错报告，协议号1，PING用类型8/0
                         │   【NAT】私网↔公网，NAPT用端口区分多主机
                         │
                         ├── IPv4包格式（分片三兄弟）
                         │   标识(同包同值)·标志(MF=1还有/DF=1禁分)·片偏移(8B单位)
                         │   TTL逐跳-1·协议号(TCP=6/UDP=17)·首部检验和(只检首部)
                         │
                         ├── IPv6 — 128位，简化首部40B，无分片无检验和
                         │   过渡：双栈·隧道·NAT64
                         │
                         ├── 网络层两种服务
                         │   虚电路(面向连接·ATM/X.25) vs 数据报(无连接·IP)
                         │   今天互联网 = 数据报的天下（健壮 > 有序）
                         │
                         ├── SDN：控制面与数据面分离，集中控制器(OpenFlow)
                         │
                         └── 路由器：用IP选路+用MAC转发，隔离冲突域也隔离广播域
```

---

```
                         ┌── RIP vs OSPF vs BGP（必考对比）
                         │   |        |  RIP    |  OSPF     | BGP     |
                         │   | 算法    | DV+BF   | SPF(Dij)  | 路径向量 |
                         │   | 范围    | IGP域内 | IGP域内   | EGP域间 |
     最 易 混 的           │   | 封装    | UDP 520 | IP 89     | TCP 179 |
     三 组 对 比           │   | 度量    | 跳数     | 带宽+代价 | 多属性   |
                         │   | 特点    | 坏消息慢 | 收敛快     | 策略优先 |
                         │
                         ├── 路由 vs 转发
                         │   路由 = 建表(控制面·路由协议) | 转发 = 查表(数据面·逐包)
                         │
                         └── 虚电路 vs 数据报
                            虚电路：先建路·同路有序·断则重来
                            数据报：独立选路·可乱序·健壮（IP的选择）
```

---

```
                         ┌── 源IP和目的IP：始终不变（除非NAT）
     一 个 包 跨 网        ─┤
     的 "变 与 不 变"       ├── 源MAC和目的MAC：每经过一个路由器变一次
                         │
                         └── TTL：每跳-1，减到0丢弃(收ICMP时间超过)
```

## 抄写方法

1. 中心写"网络层"，按上面 9 条分支画一轮廓
2. 先画 IPv4 格式 + 路由表结构（砖块），IPv4 细节去看 [IPv4.md](IPv4.md)
3. 再画四个助手（ARP/DHCP/ICMP/NAT）——它们是砖块间的胶水
4. 最后画三个路由协议——区分 IGP/EGP、DV/LS、UDP/IP/TCP 封装
5. 做题碰到分不清 RIP/OSPF/BGP 时，回来在对比表上圈

和课本目录的区别：目录是平铺的 7 个小节，这张图是按"一条包交付流水线"组织的——路由协议建表 → IP 包头承载地址 → ARP 翻译 MAC → 路由器执行转发。
