# 物理层 — 按功能重组的思维导图

> 核心问题：**比特怎么变成信号、信号能跑多快、用什么介质跑、用什么设备接力？**

---

```
                         ┌── 通信的基础：单工/半双工/全双工
                         │   单工：单向（广播）
                         │   半双工：双向但不同时（对讲机·CSMA/CD是半双工逻辑）
                         │   全双工：同时双向（电话·交换式以太网全双工不用CSMA/CD）
                         │
                         ├── 信号怎么表示比特？
                         │   【基带传输】直接传数字信号，以太网用曼彻斯特编码
                         │   【频带传输】数字→模拟→传输→模拟→数字，需要调制解调
                         │   【编码（数字→数字）】
                         │     不归零编码(NRZ)：1高0低，无同步 → 不用
                         │     归零编码(RZ)：每位中间归零 → 占两倍带宽
                         │     曼彻斯特编码：每位中间跳变，位中是上跳=0/下跳=1
                         │       → 自带时钟同步，带宽翻倍，以太网用
                         │     差分曼彻斯特：位初有跳变=0/无跳变=1 → 抗干扰更强
                         │   【调制（数字→模拟）】
                         │     调幅(ASK)·调频(FSK)·调相(PSK)·正交调幅(QAM)
                         │     QAM = ASK + PSK 结合 → 一个码元多比特
        物 理 层           │
       "比特怎么传"        ├── 能传多快？两个极限公式（必考计算）
                         │   【码元/波特率】$B = \frac{1}{T}$（码元宽度T的倒数），单位 Baud
                         │   【比特率】$R = B \cdot \log_2 V$（V=码元离散电平数）
                         │   【奈奎斯特(Nyquist)】理想低通信道无噪声
                         │     → 最大波特率 $= 2W$，最大比特率 $= 2W \log_2 V$
                         │   【香农(Shannon)】有噪声信道
                         │     → 最大比特率 $= W \log_2(1 + S/N)$
                         │     ★ S/N 常给 dB：$S/N(dB) = 10\lg(S/N)$ → 先换回比值再带入
                         │     ★ 实际速率 ≤ min(Nyquist上限, Shannon上限)
                         │
                         ├── 用什么介质？传输介质和物理层接口特性
                         │   【双绞线】8芯·RJ45·STP(屏蔽)比UTP(非屏蔽)抗干扰强·成本低
                         │     以太网用，模拟信号/数字信号都能跑
                         │   【同轴电缆】比双绞线抗干扰强但笨重，电视/早期以太网
                         │   【光纤】多模(便宜·短距·LED)·单模(贵·长距·激光二极管)
                         │     频带宽·抗电磁干扰·体积小·但不方便接分支
                         │   【无线】无线电/微波/红外/激光 → 不用铺线但干扰多
                         │   【物理层接口特性】机械·电气·功能·规程（四特性）
                         │
                         ├── 数据怎么算？计算必考三件套
                         │   【传播时延】$\frac{链路长度}{电磁波传播速率}$
                         │   【发送时延】$\frac{数据量}{发送速率}$（=传输时延）
                         │   【处理时延+排队时延】在节点内部，通常题目给定
                         │   ★ 总时延 = 发送 + 传播 + 处理 + 排队
                         │   【时延带宽积】= 传播时延 × 带宽 → 管道中最多容纳的比特数
                         │   【往返时延 RTT】= 来回传播时延 + 中间节点处理时间
                         │
                         └── 物理层设备：延长信号用的
                             【中继器(Repeater)】信号整形放大 → 延长传输距离
                               连接的是同一个网络（同一冲突域·同一广播域）
                               不能互连不同速率的网段
                               ★ "5-4-3 规则"：5个网段·4个中继器·最多3个共享段
                             【集线器(Hub)】多端口中继器，星形拓扑，共享带宽
                               所有端口在同一冲突域 → 半双工时用CSMA/CD
                               工作在物理层，不认识帧结构和MAC地址
```

```
                         ┌── 奈奎斯特 vs 香农（什么时候用哪个？）
                         │   |          | 理想无噪声    | 有噪声              |
                         │   | 公式      | 2W·log₂V     | W·log₂(1+S/N)       |
                         │   | 限制因素  | 带宽+码元数    | 带宽+信噪比          |
                         │   | 提分方法  | 增加电平数V   | 提高信噪比或带宽     |
                         │   | 给"无噪声" | √ 只用奈奎斯特 | ×                   |
         最 易 混 的       │   | 给"有噪声" | ×             | √ 只用香农          |
         三 组 对 比     ─┼── 中继器 vs 集线器（物理层兄弟）
                         │   【中继器】：两个端口·信号再生·一个冲突域
                         │   【集线器】：多个端口·信号再生+广播到所有端口·一个冲突域
                         │   【共同点】：都在物理层，只动信号不动数据，
                         │   不隔离冲突域也不隔离广播域
                         │
                         └── 编码对比（谁自带时钟？）
                            【NRZ】无时钟 → 不用
                            【曼彻斯特】每位中间跳变→自带时钟·带宽翻倍 → 以太网
                            【差分曼彻斯特】跳在开头→自带时钟·抗干扰 → 令牌环
                             曼彻斯特和差分曼彻斯特都会让波特率 = 2×比特率
```

```
                         ┌── 传播时延 vs 发送时延（最基础也最容易混）
                         │   传播时延 = 距离 ÷ 速度 → 取决于介质长度
       考 前 速 记         │   发送时延 = 数据量 ÷ 带宽 → 取决于数据大小
                         │   ★ 一个比特的传播时延 = 所有人同时出发，最后一个人到达的时间
                         │
                         ├── 基带 vs 频带
                         │   基带：直接传数字信号 → 以太网
                         │   频带：数字→载波调制→传输→解调→数字 → WiFi/手机
                         │
                         └── 物理层没有"帧"、"分组"、"报文段"
                            物理层的单位是"比特(bit)" —— 只关心0和1怎么变信号
                            帧是链路层的、分组是网络层的、报文段是传输层的
```

## 抄写方法

1. 中心写"物理层"，画 5 条分支：通信方式、编码调制、速率极限、传输介质、设备
2. 两个公式（奈奎斯特+香农）要写大，旁边标注："Nyquist=无噪声、Shannon=有噪声、dB要换算"
3. 四种编码（NRZ/RZ/曼彻斯特/差分曼彻斯特）画成一行，每个下面写波形特征
4. 中继器和集线器画在一起，标注同一个点：**"都在物理层、都不隔冲突域、都不隔广播域"**
5. 时延四个公式单独画一块：发送时延(数据/速率) + 传播时延(距离/速度) = 总时延

做题心得：物理层选择题基本在考两个方向——（1）Nyquist和Shannon的计算题（至少一道，给dB要先换算）、（2）编码波形的识别（给图让你判断是哪种编码）。计算题套路固定，不要丢分；编码题就是上面四种中选，曼彻斯特考最多。
